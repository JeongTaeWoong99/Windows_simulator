# ui-check 규칙

> 최종 업데이트: 2026-11-15 (자동 축소 글자 허용치 3px · 원칙은 UI 규칙 §3으로) · 2026-11-15 (`TextOverflowChecker` 추가 — T-201) · 대상: `Assets/Scripts_Client/Editor/ui-check/`

UI를 **눈 대신 숫자로** 점검하는 에디터 도구를 둔다.

| 파일 | 메뉴 | 무엇을 |
|------|------|--------|
| `TextOverflowChecker.cs` | `Window/DesktopWindowControl/UI/잘린 글자 검사` | 켜진 TMP 글자 중 **잘림**('…'·Truncate)·**넘침**(칸 밖으로 그려짐)을 화면(열·오버레이 캔버스)별로 콘솔에 뽑는다 |

## 쓰는 법

- **플레이 중에 돌린다.** 이름·숫자가 실제 값으로 채워져야 길이가 맞다. 편집 모드는 견본 글자를 잰다.
- **켜진 것만 본다.** 꺼진 창·투명한 창(CanvasGroup alpha 0)은 건너뛴다 — 창을 열고 다시 돌린다.
- 자동화에서는 `TextOverflowChecker.Run()`이 같은 보고서를 문자열로 돌려준다.
- 넘침 허용치는 1.5px, **자동 축소 글자는 3px**이다 — TMP는 글자 진행 폭으로 맞추고 끝 글자 획이 1~2px 삐져나온다(금화 152.6 > 151). 눈에 안 보인다.

## 고칠 때의 원칙 (2026-11-15 사용자) — 전문은 [`UI 규칙.md`](<../../UI/UI 규칙.md>) §3 "글자가 칸보다 길 때"

- **한 줄 + 자동 축소(Auto Size 최대→최소)가 기본**이다. 줄바꿈하면 글자가 틀을 뚫고 나간다.
- 세로가 넉넉해 여러 줄이 들어가는 칸만 줄바꿈을 허용하고, 그때도 최대→최소 축소를 함께 건다.
