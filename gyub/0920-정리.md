### 개선
- [UI] 창 배율(FitTaskbar 등) 및 글자 크기 가독성 개선
    - 작업표시줄 맞춤(FitTaskbar, 약 x0.92) 및 1.5x 배율에서 글자가 지나치게 작아져 메뉴 텍스트 가독성이 떨어짐.
    - 폰트 최소 크기 상향 및 조작 레이어(3열 창) 가독성 확보 방안 검토 필요.
- [창고] 정렬 기준 다각화 (T-058 연계)
    - 기존 등급/산업 순 외에 '이름순', '보유 수량순' 정렬 기준 추가 (서버 정렬 패킷 스펙 반영 필요).

### 추가
- [창고] 아이템 필터 기능 (산업별 / 희귀도별)
    - 150종 이상의 자원을 빠르게 찾을 수 있도록 산업별(농사·낚시·채광·벌목·사냥) 및 희귀도별 필터링 기능 추가.
- [창고] 창고 내 탭별 이름 검색 기능 (Search Bar)
    - 자원, 캐릭터, 장비 등 탭별로 원하는 대상을 빠르게 찾을 수 있도록 도구 줄에 통합 텍스트 검색창 추가.
    - 서버 통신 없이 현재 활성화된 탭의 공급자(StorageSlotSource)에서 클라이언트 뷰 필터링으로 처리.
- [UI] 창 최소화 및 백그라운드 중요 알림 기능 (트레이 상주)
    - 투명 창을 작업표시줄/트레이로 최소화할 수 있는 기능 추가 (백그라운드 수확 유지).
    - 최소화 상태에서 중요한 알림(창고 가득 참 등) 발생 시 토스트 팝업 알림 (설정에서 On/Off).
- [UX] 시스템 가이드 및 도움말(?) 기능
    - 각 메뉴의 수치(산업 점수, 작업 속도 등)와 조작법을 확인할 수 있는 도움말 UI 추가.
    - 아이템/캐릭터 상세 정보는 T-050(칸 정보 호버)으로 연계 진행.
- [채취/창고] 특정 희귀도 이하 자원 수확 시 자동 판매 기능
    - 사용자가 지정한 희귀도(예: 일반 이하) 자원은 수확과 동시에 골드로 즉시 환산되는 서버 설정 기능.

### 기타 (기획 검토)
- 캐릭터 스탯/확률 기반 보상 가치 증대 방안
    <br>(참고: 아이템 상태 등급(상/중/하)은 스택 인벤토리 원칙 및 기획코어의 '개체 변량 금지' 규칙과 충돌함)
    - 대안: 캐릭터 적성이나 수치에 따라 상위 희귀도 아이템 드롭 확률 증가 또는 수확 수량 보너스(+N) 지급 형태로 검토.
