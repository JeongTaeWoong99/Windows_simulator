# 03. 특성 (Trait)

> 상위 문서: [`게임기획코어.md`](../게임기획코어.md)
> 최종 업데이트: 2026-07-26 · 상태: **골격 확정 · 수치 미정**

방치형에서 플레이어가 체감하는 **유일한 "내가 강해졌다"** 축이다.
채취량이 아니라 **채취 효율 배수**를 다루므로, 여기서의 성장이 곧 루프 가속이다.

---

## 1. 확정 사항

- 특성은 **패시브**와 **액티브** 두 종류다.
- **패시브** — 각 자원 채취 시 **상시 적용**되는 효과.
- **액티브** — 각 자원 채취 시 발동하는 **부스트**.
- 산업별 채취 효율을 강화한다.
- 획득한 자원(아이템)으로 해금·성장시킨다.

---

## 2. 구조 설계 (제안)

> ⚠️ 전부 제안이다.

### 2.1 패시브

| 항목 | 내용 |
| --- | --- |
| 적용 | 조건 없이 상시 |
| 대상 | 특정 산업 1개 또는 전 산업 |
| 효과축 | 산출량 배수 / 채취주기 단축 / 희귀도 확률 가산 |
| 성장 | 레벨업 방식 (재료 소모 → 수치 상승) |
| 상한 | 레벨 상한 필요 — 없으면 무한 스케일링으로 경제 붕괴 |

### 2.2 액티브

| 항목 | 내용 |
| --- | --- |
| 적용 | 플레이어가 발동 → 지속시간 동안 |
| 문제 | **P1과 정면 충돌** — 발동을 위해 게임을 지켜봐야 함 |
| 완화안 A | 지속시간을 길게(수 시간), 쿨타임도 길게 → 하루 1~2회 발동 |
| 완화안 B | 자동 발동 옵션 제공 (쿨 돌면 자동) |
| 완화안 C | 오프라인 중에도 발동 예약 가능 |

> 액티브는 이 게임에서 **가장 위험한 설계 요소**다. 상세는 [`기획평가.md`](../기획평가.md) 참조.
> 권장: 완화안 A + B 병행. "발동 안 하면 손해"를 만들지 않는다.

### 2.3 효과 축 정리

특성이 건드릴 수 있는 값은 [자원채취](../자원채취/README.md) 공식의 항들이다.

| 효과 | 대상 항 | 스케일링 위험 |
| --- | --- | --- |
| 산출량 증가 | `회당산출` | 곱연산 중첩 시 폭주 |
| 주기 단축 | `채취주기` | 하한 필요 (0 수렴 방지) |
| 희귀도 상승 | 드랍 롤 | 경제 영향 가장 큼 |
| 오프라인 상한 연장 | 오프라인 규칙 | 접속 빈도에 직접 영향 |

> 곱연산(×1.2 × ×1.2 …)은 후반에 반드시 폭주한다. 합연산(+20% +20%) 기반을 권장한다.

## 3. 획득 · 성장 경로 (제안)

```
채취 → 재료 아이템 → 특성 해금 → 특성 레벨업 → 채취 효율 ↑ → (루프)
```

| 논점 | 선택지 | 권장 |
| --- | --- | --- |
| 해금 방식 | 재료 소모 / 퀘스트 / 레벨 | **재료 소모** — 채취와 직결 |
| 재료 종류 | 해당 산업 재료 / 공용 재료 | **해당 산업** — 산업별 진행 독립 |
| 리셋(초기화) | 가능 / 불가 | 가능하되 비용 부과 |
| 특성 슬롯 제한 | 있음 / 없음 | **있음** — 선택의 의미 발생 |

슬롯 제한이 없으면 "전부 찍기"가 유일한 최적해가 되어 빌드 선택이 사라진다.

## 4. 데이터 설계 (제안)

| 신규 테이블(제안) | 용도 | 주요 컬럼 |
| --- | --- | --- |
| `TraitTable` | 특성 정의 | `TraitTID`, `Name`, `TraitKind`(Passive/Active), `IndustryType`, `EffectType`, `MaxLevel` |
| `TraitLevelTable` | 레벨별 수치·비용 | `TraitTID`, `Level`, `EffectValue`, `CostItemTID`, `CostCount` |

신규 enum(`TraitKind`, `EffectType`)은 `GameDesign/Excel/Enum.xlsx`에 추가한다.
보유·레벨은 유저 DB에 저장한다.
