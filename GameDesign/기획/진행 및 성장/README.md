# 06. 진행 및 성장

> 상위 문서: [`게임기획코어.md`](../게임기획코어.md)
> 최종 업데이트: 2026-07-26 · 상태: **전부 미정**

기획에서 통째로 비어 있는 영역이다. 개별 시스템은 형태가 잡혔지만
**"플레이어가 1일차·1주차·1개월차에 무엇을 하고 있는가"** 가 정의되지 않았다.

---

## 1. 왜 이게 먼저인가

각 시스템의 수치는 곡선이 정해져야 결정할 수 있다. 순서가 반대면 전부 다시 계산해야 한다.

```
성장 곡선 확정
   ├→ 채취 산출량 (자원채취)
   ├→ 특성 레벨 비용 (특성)
   ├→ 퀘스트 보상량 (퀘스트)
   └→ 거래소 시세 기준가 (거래)
```

그래서 이 문서의 우선순위가 가장 높다.

---

## 2. 정의해야 할 3구간

> ⚠️ 아래는 구조 제안이며, 내용은 비어 있다.

### 2.1 온보딩 (0 ~ 1일차)

| 질문 | 답 |
| --- | --- |
| 첫 실행 후 몇 분 만에 첫 보상을 받는가? | ? |
| 처음부터 모든 산업이 열려 있는가? | ? |
| 첫 특성 해금까지 얼마나 걸리는가? | ? |
| 거래소는 언제 열리는가? | ? |
| 튜토리얼을 두는가, 가이드 퀘스트로 대체하는가? | ? → [퀘스트](../퀘스트/README.md) |

> 방치형의 온보딩은 "첫 세션에 성장이 눈에 보이는가"가 전부다.
> 첫날 체감 성장이 없으면 다음 날 실행되지 않는다.

### 2.2 성장 페이스 (1일 ~ 수 주)

| 질문 | 답 |
| --- | --- |
| 하루 접속 1회 기준, 세션당 할 일은 몇 분치인가? | ? |
| 주 단위로 유의미한 성장이 체감되는가? | ? |
| 요일 로테이션 한 바퀴(1주)가 성장 단위인가? | ? |
| 성장 속도의 병목은 시간인가, 재료인가, 화폐인가? | ? |

> P1(주의를 뺏지 않는다)을 지키려면 **세션당 3~5분**이 상한이다.
> 이보다 길어지면 방치형이 아니라 관리형 게임이 된다.

### 2.3 후반 목표 (수 주 ~)

| 질문 | 답 |
| --- | --- |
| 특성을 다 찍은 뒤 무엇을 하는가? | ? |
| 거래소 자산 경쟁 외의 목표가 있는가? | ? |
| 랭킹·시즌 같은 리셋 장치가 있는가? | ? |
| 콘텐츠 소진 후 이탈을 무엇으로 막는가? | ? |

> **가장 취약한 지점이다.** 승패 조건이 없고 후반 목표가 "자원 축적"뿐이면,
> 특성 만렙 이후 플레이 이유가 사라진다. 랭킹·시즌·수집 도감 중
> 최소 하나는 필요하다.

#### 🆕 보스 — 후반 목표의 첫 후보 (2026-07-27)

[사냥](../자원채취/사냥/README.md)의 특별보상에서 **보스 티켓**이 나오고,
모아서 플레이어가 도전하는 콘텐츠가 추가됐다.

| 왜 후반 목표가 될 수 있나 | 내용 |
| --- | --- |
| **채취 루프 바깥** | 5개 산업이 전부 "모으기"인데, 보스는 **쓰는** 콘텐츠다 |
| 특성 이후의 목표 | 특성을 다 찍은 뒤에도 도전할 대상이 남는다 |
| 난이도 단계 | 보스를 여러 단계로 두면 장기 목표선이 생긴다 |
| 사냥 정체성과 결합 | "축적 후 도전"이라는 사냥의 심리 정의와 일치 |

**다만 이것만으로 2.3이 채워지지는 않는다.**

- 보스는 **콘텐츠 소진형**이다. 다 잡으면 다시 비어버린다.
- 반복 가능한 축(랭킹·시즌)이나 무한 축(도감 수집률)이 여전히 필요하다.
- 보스 상세가 미정이므로 지금은 **후보**로만 기록한다. → [사냥](../자원채취/사냥/README.md) 4장

## 3. 곡선 설계 시 고정 제약

| 제약 | 근거 |
| --- | --- |
| 하루 1회 접속으로 손해가 없어야 함 | P1 · P2 |
| 세션 길이 3~5분 | P1 |
| 요일 1주기 = 성장 리듬의 기본 단위 | P3 |
| 성장 곡선은 곱연산 폭주를 피할 것 | [특성](../특성/README.md) 2.3 |
| 재화 총량 증가율은 거래소 인플레와 직결 | [거래](../거래/README.md) 3.1 |

## 5. 결정 필요 (Open Questions)

1. **핵심 재미가 무엇인가?** (게임기획코어 5장에서도 미작성 — 이게 없으면 곡선을 정할 기준이 없다)

   → **보스**가 첫 후보로 생겼다(2.3). 다만 소진형이라 반복 축이 별도로 필요하다
4. 시즌/리셋 개념이 있는가?
5. 최초 목표 플레이 기간은? (2주? 3개월?)
