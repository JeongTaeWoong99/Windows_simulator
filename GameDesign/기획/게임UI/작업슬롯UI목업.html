모드내용
① 설정 패널 게임을 띄워 둔 상태에서 여는 큰 창. 8슬롯 중 1개만 해금, 나머지는 자물쇠. 슬롯을 누르면 배치할 캐릭터 목록이 뜨고, 캐릭터를 누르면 즉시 배치된다.
② 상시 스트립 작업표시줄로 내려가거나 계속 플로팅할 때 보이는 좁은 바. 슬롯 1·2·3에 간략한 애니메이션(캐릭터 이동 · 진행바 · +1 수확 팝)

적성 0 = 매우 느림 (2026-07-30 변경)

이전적성 0 → 배치 거절
현재적성 0 → 배치 허용, 대신 매우 느리다. 배치 목록에 전부 나오고 예상 주기를 함께 보여 준다
수치 미정 목업은 BaseWorkSpeedPermille = 250(0.25배). 임의값이다. 0으로 두면 안 된다 — 0으로 나누게 되고, "정지"는 배치를 비우는 것으로 표현한다
⚠️ 코드·엑셀 아직 "배치 불가"다. Character.CanWork · User.CanAssignCharacter · WorkSpeedTable TID 0이 기획과 어긋나 있다
