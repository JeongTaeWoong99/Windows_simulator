# 1차 산업 — 채굴 (Mining)

> 상위: [`자원채취`](../README.md) · [`게임기획코어.md`](../../게임기획코어.md)
> 최종 업데이트: 2026-07-27 · 상태: **정체성 제안 · 수치 미정**
> enum: `ItemType.Mining = 3` ✅ 존재 (주석은 "채광")

---

## 1. 산업 정체성 (제안)

> ⚠️ 제안이다.

| 항목 | 값 |
| --- | --- |
| 한 줄 | **깊이 갈수록 좋아진다** |
| 리듬 | 중주기 · 누적 성장형 |
| 변동성 | 중간 |
| 역할 | **장기 투자** 축 — 유일하게 진행도가 누적된다 |
| 플레이어 개입 | 하강 ↔ 채굴 중 배분 |

채굴은 5개 산업 중 **유일하게 "어제의 진행이 오늘에 남는"** 구조다.
다른 산업이 매일 리셋되는 반복이라면, 채굴은 계속 깊어진다.

---

## 2. 채취 특성 (제안)

```
깊이 0 ─하강→ 깊이 N ─채굴→ 광석 (깊을수록 등급↑)
```

| 파라미터 | 상대값 | 비고 |
| --- | --- | --- |
| 채취주기 | 중간 | |
| 회당 산출 | 중간 | 깊이에 비례 |
| 희귀도 편차 | 중간 | **깊이가 희귀도 하한을 올린다** |
| 특이 규칙 | 깊이 누적 | 리셋되지 않음 |

### 깊이 (제안)

- 깊이는 **유저별로 누적**되며 리셋되지 않는다.
- 깊이 구간마다 산출 광석과 희귀도 분포가 달라진다.
- 더 깊이 가려면 시간(또는 재료)이 든다.

| 논점 | 권장 |
| --- | --- |
| 하강과 채굴을 동시에? | **택1** — 선택이 생긴다 (지금 캘까, 더 갈까) |
| 깊이 상한 | 있음 — 없으면 무한 스케일링 |
| 오프라인 중 진행 | 자동 채굴 (현재 깊이에서) |

> 이 "지금 캘까 / 더 내려갈까"가 채굴의 유일한 의사결정이다.
> 요일 로테이션(P3)으로 채굴이 주 1회만 열리면 깊이 진행이 매우 느려지므로,
> [자원채취](../README.md)의 요일 배정과 함께 속도를 잡아야 한다.

## 3. 산출물

| 구분 | 내용 |
| --- | --- |
| 기본 자원 | 광석 (깊이별 등급) |
| 희귀 산출 | 보석류 |
| 용도 | 특성 재료 (고레벨 재료의 주 출처) |

> 광석을 **고레벨 특성 재료**로 묶으면, 깊이 진행 = 성장 진행이 되어
> [특성](../../특성/README.md)와 자연스럽게 연결된다.

## 5. 결정 필요

1. 깊이 개념을 넣는가? (넣지 않으면 농사·벌목과 차별점이 약하다)
2. 깊이 상한은?
3. 하강에 재료(곡괭이·연료)가 소모되는가?
4. 깊이가 리셋되는 상황이 있는가? (붕괴 이벤트 등 — P1 관점에서 비권장)
5. `ItemType.Mining` 주석이 "채광"인데 기획 용어는 "채굴"이다. 용어를 통일할 것
