아티팩트 도감 장착 — 제안 목업

감정으로 나온 아티팩트는 인벤토리 장비 탭의 칸이 된다. 조작은 장비와 같고 좌클릭만 다르다 — 장비는 아래 칸에 큐브 창이 뜨고, 아티팩트는 같은 자리에 설명 + [도감에 장착]이 뜬다. 장착하면 경매장 넓이의 도감이 펼쳐진다. 이미 장착한 번호의 중복은 장비처럼 우클릭(즉시 판매) · Ctrl+우클릭(경매 등록)으로 판다.

기존 기획: GameDesign/design/gathering/excavation/유물감정.md 3장 · 기존 목업: 유물감정목업.html (T-150 · T-151 · T-152). 이름 · 효과는 3.4 목록(일반 · 고급 22종) · 가격은 가제다. 조작 키는 지금 인게임 기준이다 — T-173(우클릭 메뉴화)이 오면 함께 바뀐다.

    ③ 칸 상태 — 지금 기획 vs 제안

    어디지금 기획제안
    감정 결과가 가는 곳보관함 번호 칸 (인벤토리 칸을 먹지 않는다)인벤토리 장비 탭 (칸을 먹는다)
    도감이 있는 곳보관함 = 도감 한 화면경매장 넓이의 오버레이 — 장착하면 열린다
    도감 칸3가지 — 보유 · 0개(흐리게 · 효과 꺼짐) · 미획득2가지 — 장착됨(효과 켜짐) · 미획득(점선)
    도감 칸의 수량n개 (중복 = 재고)없음 — 번호마다 1개
    인벤토리 칸 표시—NEW 도감에 없는 번호만. 중복은 표시 없음 — 보통 장비 칸처럼 보인다
    중복 출구거래소만즉시 판매(우클릭) · 경매(Ctrl+우클릭)

    ④ 정할 것

    1. 도감에 장착한 것을 다시 뺄 수 있는가추천: 못 뺀다 — 실수로 효과를 끌 일이 없고, 도감 칸 상태가 둘로 준다
    2. 장착하지 않고 도감을 여는 길목업은 아티팩트 창의 [도감 보기]만 그렸다 — 하단 메뉴 [인벤토리 · 거점 · 경매장] 옆에 [도감]을 둘지
    3. 인벤토리에서 같은 번호가 스택되는가 · 개체마다 1칸인가목업은 번호별 스택 — 아티팩트에는 강화 · 인챈트가 없어 개체를 나눌 이유가 없다
    4. 즉시 판매가목업 가제: 감정 비용의 절반(일반 100 · 고급 300) — 경매 단가 하한(BasePrice 400 · 1,200)보다 낮아야 "높은 건 경매"가 선다
    5. NEW(도감에 없는 번호)를 판매 목록에 담을 때목업은 담되 경고한다 — 판매 목록 [High Rarity Warning] 자리 · T-170과 같은 자리
    6. 인벤토리가 가득 찼을 때 감정 결과상자 보상처럼 우편 넘침으로 보낼지
