T-114 레이드 목업 — 메인 UI → 보스 선택 → 프리셋 편성 → 전투 화면

메인 화면 아래 메뉴의 [레이드](옛 [길드] 자리)를 누르면 보스 선택 화면이 열린다. 보스를 누르면 상세 정보가 뜨고, 프리셋을 골라 도전하면 창이 통째로 전투 화면으로 바뀐다. 프리셋은 따로 뜨는 편성 창에서 고친다. 전투는 앞뒤 깊이가 있는 2.5D 무대에서 서버가 보낸 로그를 재생한다 — 아군은 왼쪽, 보스는 오른쪽.

목업 조작:
← 아래 메뉴의 [길드] 자리가 [레이드]가 됐다.
눌러서 레이드 화면을 연다.

(검은 곳은 투명 — 바탕화면이 비친다)

창 넷

  • ① 메인 UI — 아래 메뉴 줄의 [길드] 버튼이 [레이드]로 바뀐다. 누르면 경매장·거점처럼 화면을 덮는 레이드 화면이 열린다. (목업의 메인 화면은 2026-11-20 플레이 화면 캡처다)
  • ② 보스 선택 — 왼쪽에 보스 목록. 보스를 눌러야 오른쪽에 상세 정보(스탯·보상)와 프리셋 고르기 · [도전]이 뜬다. 프리셋 카드에는 누가 들었는지와 합계만 보인다.
  • ③ 프리셋 편성 창 — 프리셋 카드의 [편성]을 누르면 뜬다. 프리셋 3개를 탭으로 오가며 1~3명을 넣고 뺀다(1번이 맨 앞). 작업슬롯에 있는 캐릭터는 목록에 남기되 잠근다.
  • ④ 전투 화면 — [도전]을 누르면 창이 통째로 무대가 된다(목록·제목 줄 없음). 끝나면 결과 창 → [확인]으로 보스 선택에 돌아온다.
  • 2.5D 무대 — 좌우에 더해 앞뒤(화면 위 = 뒤, 아래 = 앞)가 있다. 뒤에 설수록 작게, 앞에 설수록 크게 그리고 앞사람이 뒷사람을 가린다. 아군은 왼쪽에 삼각 대형(1번이 앞 가운데 · 2번 뒤쪽 위 · 3번 뒤쪽 아래), 보스는 오른쪽.
  • 공격은 걸어가서 친다 — 근접은 보스 앞으로 뛰어가 치고 돌아온다. 보스는 맞을 캐릭터가 선 자리(앞뒤 포함)로 와서 친다. 마법사는 제자리에서 쏜다. 광역기는 바닥에 눕힌 고리가 퍼진다.
  • 배속은 ×1·×2·×3뿐 — 건너뛰기와 전투 기록은 없다. 전투 중 나가기도 없다(길어야 60초 · ×3이면 20초).
  • 재생만 한다 — 맞는 시각·피해·남은 체력은 전부 로그 값이다. 화면은 맞는 시각보다 조금 일찍 움직이기 시작해 그 시각에 타격을 맞춘다.
  • 도전권 숫자는 재생이 끝난 뒤에 바뀐다 — 결과를 미리 알려 주지 않으려고.

가정한 것 · 정해야 하는 것

  • [길드]가 [레이드]가 되면 길드 열(상점·뽑기·창고)로 가는 버튼이 없어진다. 어디로 옮길지는 이 목업이 정하지 않았다.
  • 프리셋 여러 개는 지금 서버에 없다. 서버는 편성 하나(PartyCharacterIds)만 저장한다. 프리셋 번호를 저장·도전 패킷에 넣거나, 프리셋은 클라가 갖고 도전 직전에 저장을 보내야 한다.
  • 스킬은 지금 서버에 없다. 로그는 평타(RaidHitInfo)뿐이다. 사건에 SkillId(0 = 평타)가 붙는다고 가정했다 — 광역기는 같은 ElapsedMs·SkillId의 줄 여러 개. 위 체크를 끄면 지금 서버 그대로다. 스킬 규칙(몇 번째마다·배율·광역)은 전부 가짜다.
  • 서 있는 자리(앞뒤)는 연출일 뿐이다. 서버 전투에는 위치가 없다 — 편성 순서로 자리를 정했다. 위치가 규칙이 되려면(범위·전열/후열) 전투 기획(T-197)이 먼저다.
  • 보스 2·3번(이끼 거인 · 용암 문지기)은 패배·시간 초과를 보려고 넣은 가짜다. 실제 데이터는 돌문 수호자 하나다.
  • 캐릭터 스탯은 RaidStatTable의 Lv1 기본값 · 주기는 CharacterTable.AttackIntervalMs. 편성 창에 보일 캐릭터별 전투 스탯과 보상 내용은 지금 패킷에 없다.
  • 캐릭터·보스·무대 그림은 자리만 잡은 임시 그림이다. 글꼴은 게임과 같은 Galmuri11.
