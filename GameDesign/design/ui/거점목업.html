거점 — 건물을 키워 특성을 찍는다

[거점]을 누르면 메인 3열을 덮는 거점 화면이 열린다. 건물 다섯 채가 2D로 놓여 있고, 건물을 누르면 [업그레이드] · [특성]이 뜬다. 업그레이드는 자원 + 골드로 레벨을 올리고, 레벨이 오르면 그 건물의 특성 포인트가 생겨 트리 노드를 찍는다. 이름 · 분류 · 수치는 모두 가칭과 테스트값이다.

① 무엇이 바뀌나

지금 서버(T-166)는 산업마다 건물 하나, 비용은 자원만, 특성은 계정 레벨 포인트로 따로 찍는다. 목업은 이 셋을 바꾼다.

기록

    ③ 건물 5개 (가칭)

    사용자가 정한 셋(편의 · 산업 · 거래)에 인력 · 수집 두 분류를 제안으로 더했다. 노드는 지금 게임에 있는 시스템에서 골랐고, 수치는 정하지 않았다.

    건물분류무엇이 좋아지나노드 (테스트)

    ④ 정할 것

    1. 분류 4·5번 — 인력 · 수집이 맞는지사용자는 "편의 / 산업 / 거래 …"까지만 정했다. 다른 분류(예: 의뢰 · 탐험)를 원하면 바꾼다. 건물 이름도 전부 가칭이다
    2. ✅ 포인트 — 건물 Lv1당 그 건물 포인트 1점 (사용자 결정)건물마다 따로 쌓인다. 작업장 포인트는 작업장 트리에만 쓴다
    3. ✅ 계정 레벨 — 특성 포인트(AccountLevelTable.TraitPoint)는 없애고, 건물 레벨의 상한으로 쓴다 (사용자 결정)계정 최대 레벨은 100 → 150. 건물은 계정 레벨까지만 올릴 수 있다. 목업은 계정 Lv8에서 시작한다
    4. ✅ 비용에 골드를 넣는다 — 골드의 출구 (사용자 결정 · 건물 README 확정 #8 "자원만"을 바꾼다)남은 것은 비중 — 레벨이 오를수록 자원과 골드 중 무엇이 더 커지는지
    5. 작업장 포인트 총량옛 특성은 전부 찍는 데 130점, 계정 Lv100까지 99점이라 "전부는 못 찍는다"가 선택을 만들었다. 계정 최대 Lv150을 따라 작업장도 Lv150 = 150점이면 130점을 전부 찍을 수 있다 — 선택의 긴장을 남기려면 작업장 상한을 130 아래로 두거나 노드를 더 늘린다. 나머지 건물은 노드 레벨 합보다 많게 둬서 전부 찍을 수 있다 — 이것도 막을지 정한다
    6. 최대 레벨 · 다른 건물 선행목업은 계정 Lv150 · 작업장 Lv150 · 관리소 · 상회 Lv20 · 숙소 · 감정소 Lv25 · 작업장 Lv4부터 관리소 레벨(다음 레벨 − 1)이 선행이다. 건물 레벨은 포인트만 주고 노드를 잠그지 않는다 — 깊은 노드는 앞 노드를 다 찍어야 열린다(예: 농사 개척 4/4 → 농사 속도)
    7. ✅ 서버 T-166의 건물 5개(BuildingTID = IndustryType)는 갈아엎는다 (사용자 결정)해금 행(UnlockTable 4xxx)을 그대로 쓸 수 있지만 노드에 레벨이 생기면 해금 행 하나로는 모자란다 — 특성의 t_user_trait 방식에 가깝다
    8. 화면 이름 — [거점]T-182에서 열 · 지도 화면 이름이 아직 미정이다
