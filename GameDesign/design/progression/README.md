# 06. 진행 및 성장

> 상위 문서: [`게임기획코어.md`](../게임기획코어.md)
> 상태: **도달 목표 타임라인 확정(2026-10-02) · 후반 목표 확정 · 수치 역산 미착수**
> **바뀌면 갱신:** [`게임기획코어`](../게임기획코어.md) · [`기획평가`](../기획평가.md) · [`캐릭터`](../character/README.md)

**"플레이어가 첫 세션·1일차·1주차·10주차에 무엇을 하고 있는가"** 를 정하는 문서다.
모든 수치가 여기서 역산되므로 우선순위가 가장 높다.

> ⚠️ **2026-08-01 갱신.** 비어 있던 **후반 목표(R3 🔴)** 가 채워졌다 → 2.8.

## 1. 왜 이게 먼저인가

각 시스템의 수치는 곡선이 정해져야 결정할 수 있다. 순서가 반대면 전부 다시 계산해야 한다.

```
성장 곡선 확정
   ├→ 채취 산출량 (자원채취)
   ├→ 계정 레벨 · 슬롯 해금 곡선 (거래 3.3 · 캐릭터 3.2)
   ├→ 퀘스트 보상량 (퀘스트)
   └→ 거래소 시세 기준가 · BasePrice (거래 · 아이템)
```

---

## 2. 도달 목표 — 언제 무엇을 하는가 (2026-10-02)

**모든 수치는 이 표에서 역산한다.** 경험치 곡선·해금 골드·`BasePrice`·가챠 비용·확률은
"이 시점에 여기 도달한다"를 맞추도록 정한다. 지금 수치는 이 표에 아직 맞춰지지 않았다.

### 2.0 기준 가정

| 항목 | 값 |
| --- | --- |
| 평균 유저 | **매일 켜 둔다 — 24시간 상시 접속.** 경제 총량은 이 기준으로 계산한다 |
| 첫 세션 | 첫날 **약 1시간은 화면을 보며** 플레이한다. 그 뒤로는 켜 둔다 |
| 곡선 모양 | **앞이 짧고 뒤가 길다** — 첫 세션에 보상을 몰고, 뒤로 갈수록 간격을 넓힌다 |
| 최종 도달 | **약 10주(2.5개월).** 그 뒤는 업데이트로 최신 콘텐츠를 더한다 |
| 계산 기준 | Lv1 · 적성 1 · 판정 30초. 시점은 평균값이다 |
| 산업 개방 | **5개 산업 Lv1은 처음부터 열려 있다.** Lv2~5는 개척 특성을 올려 연다 → [특성](../trait/README.md) 2.2 |
| 특성 포인트 | 계정 레벨마다 1점(Lv100까지 99점) · 특성 전부는 130점이라 **다 찍지 못한다** |

> **상자는 첫 세션 안에 나무·은을 본다** — 판정당 2% · 0.3% · 0.03% → [아이템](../item/README.md) 4.1.
> 상자 상한이 50개라 **약 5시간이면 나무 상자가 찬다.** 하루 두세 번 열지 않으면 일부가 버려진다 —
> 상자를 자주 까는 것을 재미로 보고 받아들인 손해다(2026-10-01).

### 2.1 구간 0 — 첫 세션 (0~60분 · 계속 본다)

시작은 **슬롯 2칸 · 캐릭터 1명(램볼)** 이라 한 칸이 비어 있다. 이 빈칸이 첫 가챠의 동기다.

| 시점 | 하는 일 | 얻는 맛 |
| --- | --- | --- |
| 0분 | 램볼을 슬롯 1에 배치 · 첫 판정 연출 | 섬에서 뭔가 나온다 |
| 2분 | 램볼 Lv2 | 숫자가 오른다 |
| 5분 | 판매 → 첫 캐릭터 가챠 → 빈 슬롯 2를 채운다 | 새 캐릭터 · 동시 가동 |
| 15분 | 슬롯 3칸째 · **첫 나무 상자** | 섬이 커진다 · 상자 |
| 20분 | 첫 장비 뽑기 → 착용 | 빨라진다 |
| 30분 | 계정 Lv5 → 개척 특성으로 **산업 Lv2를 어디에 쓸지** 고른다 | 첫 선택 고민 |
| 40분 | 액티브 부스트 첫 사용 | 확 빨라진다 |
| 1시간 | 램볼 Lv10(속도 +9%) · Rare 캐릭터 · **첫 은 상자** | 육성 시작 |

> ⚠️ **업데이트로 최신을 맞추는 구조라 "신규 유저가 몇 주 만에 최신에 닿는가"도 정해야 한다** — 지금은 10주.

### 2.7 온보딩 — 개방 시점 · 가이드 퀘스트 (⚠️ 초안 · 2026-10-10 · T-019)

> **초안이다.** 확정은 261024 회차에서 한다. 수치(계정 레벨)는 테스트값이고 2.1~2.3 타임라인에서 역산해 다시 맞춘다.

**원칙 — 잠금은 최소로 둔다.** 기능은 **쓸 재료가 생기는 순간 저절로 열린다**(큐브가 생겨야 인챈트를 한다).
레벨로 막는 것은 **거래소 하나**뿐이다 — 부계정 골드 몰아주기를 막는 목적이 따로 있다(T-012).

#### 개방 시점 (제안)

| 기능 | 열리는 때 | 근거 |
| --- | --- | --- |
| 즉시 판매(상점) · 캐릭터 가챠 | **0분** | 5분 "판매 → 가챠 → 빈 슬롯 채우기"가 첫 세션 루프의 축이다. 막으면 첫 성장이 멈춘다 |
| 장비 뽑기 · 장착 | 0분 (골드가 모이는 약 20분) | 잠금 없음 — 비용이 시점을 정한다 |
| 상자 · 인챈트 | 0분 (상자 15분 · 큐브 약 2시간) | 잠금 없음 — 드롭이 시점을 정한다 |
| 특성 | 계정 Lv5 (약 30분) | 포인트가 생기는 때가 곧 개방이다 |
| **거래소(경매장)** | **계정 Lv10** (목표: 2일차) | T-012 "거래 최소 계정 레벨" 제안값과 같은 값을 쓴다 — 두 목적(부계정 차단 · 2일차 첫 등록)을 한 줄로 |
| 섬 가치 랭킹 | 랭킹 기획이 선 뒤 | 기획 없음 — 타임라인에 아직 못 넣는다 |

#### 튜토리얼 대신 가이드 퀘스트

**강제 튜토리얼은 두지 않는다.** 바탕화면에 상주하는 창이 화면을 덮고 클릭을 강요하면 P1(주의를 뺏지 않는다)을 첫 1분에 어긴다.
대신 **가이드 퀘스트**([퀘스트](../quest/README.md) 3장)가 다음 할 일을 한 줄로 보여 준다. 화면 강조는 **첫 배치(G1) 한 번만** 한다.

| # | 시점 | 조건 | 보상 (제안) | 무엇을 가르치나 |
| --- | --- | --- | --- | --- |
| G1 | 0분 | 램볼을 슬롯 1에 배치 | 자원 소량 | 배치 = 일이 시작된다 |
| G2 | 2분 | 캐릭터 레벨 2 달성 | 자원 소량 | 일하면 자란다 |
| G3 | 5분 | 자원을 판매 | — (판매 대금이 보상) | 자원 → 골드 |
| G4 | 5분 | 캐릭터 가챠 1회 | 자원 소량 | 골드 → 일꾼 |
| G5 | 5분 | 슬롯 2에 배치 | 나무 상자 1 | 동시 가동 |
| G6 | 15분 | 슬롯 3칸째 해금 | 나무 상자 1 | 섬이 커진다(땅 개간) |
| G7 | 15분 | 상자 열기 | 인챈트 큐브 1 | 상자 = 보너스 |
| G8 | 20분 | 장비 뽑기 → 착용 | 자원 소량 | 장비 = 속도 |
| G9 | 30분 | 특성 1회 찍기 (산업 개척 권장) | 자원 소량 | 섬주인의 선택 |
| G10 | 40분 | 액티브 부스트 1회 사용 | 자원 소량 | ⚠️ 액티브 미착수 — 서기 전엔 뺀다 |
| G11 | 약 2시간 | 인챈트 큐브 사용 | 은 상자 1 | 장비를 키운다 |
| G12 | 2일차 | 거래소에 1회 등록 (Lv10) | 자원 소량 | 섬 밖의 시장 |

- **골드는 보상에 넣지 않는다** — 채취가 유일한 faucet이다([퀘스트](../quest/README.md) 4장). 그래서 G3은 보상이 없다
- 보상은 **다음 단계를 당겨 주는 것**만 준다(G6 상자 → G7 상자 열기 · G7 큐브 → G11 인챈트)
- 순차 진행 · 1회성. 건너뛴 단계(이미 한 행동)는 **열리는 즉시 완료**로 처리한다 — 먼저 해 본 유저를 되돌리지 않는다

#### 섬 컨셉을 보여 주는 법

- **첫 실행 한 줄**: "싼값에 산 섬. 와 보니 아무것도 없다. 이제 개발한다." — 컷신·스토리는 두지 않는다([게임기획코어](../게임기획코어.md) — 컨셉 한 줄 이상은 두지 않기로 했다)
- **화면 문구로 번역한다**: 슬롯 해금 = "땅 개간" · 캐릭터 = "일꾼" · 계정 = "섬주인" · 거래소 = "섬 밖의 시장"

#### 이 초안이 남긴 것

| 질문 | 상태 |
| --- | --- |
| 계정 Lv10이 정말 2일차에 오는가? | ❌ 계정 경험치 곡선 역산이 필요하다 |
| 퀘스트 시스템 자체 (`QuestTable` · `t_user_quest` · 진행 판정) | ❌ 미구현 — 구현 일감이 따로 필요하다 |
| 가이드 보상 수량 ("자원 소량") | ❌ 수치 미정 |
| 일일 퀘스트·섬 가치 랭킹을 타임라인 어디에 두는가? | ? — 두 기획이 서야 넣는다 |

> P1(주의를 뺏지 않는다)을 지키려면 **세션당 3~5분**이 상한이다.
> 이보다 길어지면 방치형이 아니라 관리형 게임이 된다.

### 2.8 후반 목표 — **섬 가치 랭킹** (2026-08-01 확정)

승패 조건이 없는 게임에서 **장기 목표를 대신하는 장치**다.
유저들끼리 **섬의 가치를 합산해 순위를 공개**한다.

| 항목 | 확정 내용 |
| --- | --- |
| **장치** | **섬 가치 랭킹** — 개발한 섬끼리의 경쟁 |
| **점수 기준** | **종합 개발도** (계정 레벨 + 슬롯 수 + 캐릭터 + 특성 + 자산의 가중합) |
| **보완** | **구간 리그** — 비슷한 규모끼리 묶어 경쟁시킨다 |
| **시즌 리셋** | ❌ **두지 않는다** |
| 가중치 설계 | ❌ 미정 |

#### 왜 종합 개발도인가

| 후보 | 기각 사유 |
| --- | --- |
| 총자산 평가액 | 시세가 흔들리면 순위도 흔들리고, **자전거래로 조작된다** |
| 누적 산출량 | 사실상 "접속 시간 × 슬롯 수" 랭킹 — **신규 유저가 영구히 못 따라잡는다** |
| **종합 개발도** ✅ | 섬 개발 컨셉과 가장 맞고 **시세 변동·조작에 둔감하다.** 대가는 가중치 설계 비용 |

#### 왜 시즌 리셋을 두지 않는가

리셋은 **"오래 굴린 캐릭터에 애착이 생긴다"** 는 성장 설계와 정면 충돌한다.
방치형에서 쌓아 온 것을 소각하는 것은 리텐션 장치가 아니라 **이탈 사유**다.
"1000위 밖에는 동기가 없다"는 문제는 **구간 리그**가 대신 푼다 —
같은 규모끼리 묶으면 순위표 어디에 있든 경쟁 상대가 있다.

#### 보스 — 병립하는 두 번째 축

[사냥](../gathering/hunting/README.md)에서 티켓을 모아 도전하는 콘텐츠다.
채취 루프 **바깥**의 유일한 통로이며, 랭킹과 성격이 다르다.

| | 랭킹 | 보스 |
| --- | --- | --- |
| 성격 | **무한** (남과의 상대 위치) | **소진형** (다 잡으면 비어버린다) |
| 역할 | 장기 목표선 | 층을 하나 더한다 |

> ⚠️ **보스 티켓 획득 경로가 아직 미정이다.** 경로가 없는 동안 이 축은 닫혀 있다
> → [자원채취](../gathering/README.md) 2.4.

## 3. 곡선 설계 시 고정 제약

| 제약 | 근거 |
| --- | --- |
| **하루 1회 접속으로 손해가 없어야 함** — 예외: 상자 상한 50(2.0) | P1 · P2 |
| 세션 길이 3~5분 | P1 |
| **하루 리듬 = 액티브 부스트 2회 · 일일 퀘스트.** 놓쳐도 손해가 없어야 한다 | P3 (재정의) |
