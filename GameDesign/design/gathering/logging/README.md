## 1. 산업 정체성 (제안)

> ⚠️ 제안이다.

| 항목 | 값 |
| --- | --- |
| **심리 정의** | **절제하면 지속되는 수익** |
| 투자 비유 | 배당주 — 원금을 건드리지 않아야 계속 나온다 |
| 한 줄 | ~~**베면 줄고, 시간이 지나면 돌아온다**~~ (고갈 폐지 · 재검토) |
| 회당 산출 | 중간 — ~~숲 자원량에 비례해 변동~~ (고갈 폐지) |
| 실패율 | 없음 |
| ~~특별보상(10%)~~ | ❌ **층 폐지 (2026-07-30).** 고급 원목의 경로 미정 |
| 역할 | ~~경제의 **속도 조절** — 무한 채취 방지~~ (고갈 폐지 · 재검토) |
| 플레이어 개입 | ~~벌목 강도 조절 (보존 ↔ 남벌)~~ → **수종(레벨) 선택** |

> 벌목의 차별점은 **회당 산출이 자원량에 따라 움직인다**는 것 —
> 5종 중 유일하게 산출이 변동하는 산업이다.
> 희귀도 분포도 벌목만 다르게 둘 수 있지만(2026-07-31), **고유 메커니즘이 이미 강해서
> 굳이 기울일 필요가 없다.** 기준값으로 두는 편이 낫다.

> 주기 통일(30초)의 영향이 **가장 적은 산업**이다.
> 벌목의 고유 축은 주기가 아니라 **자원량 상태**이므로 그대로 유지된다.
> 다만 30초마다 자원이 줄어들므로 **고갈 속도와 재생률을 그 빈도에 맞춰** 잡아야 한다.

벌목은 5개 산업 중 **유일하게 자원 총량에 상한이 있는** 구조다.
"많이 캘수록 다음에 덜 나온다"는 감가 메커니즘을 담당한다.

## 2. 채취 특성 (제안)

```
숲 자원량 ─벌목→ 감소 ─시간→ 재생 ─→ 회복
```

| 파라미터 | 값 | 비고 |
| --- | --- | --- |
| 채취주기 | **30초** ✅ | 전 산업 공통 → [자원채취](../README.md) 2.1 |
| 회당 산출 | 중간 ⚠️ | 수치 미정 (자원량 비례는 폐지) |
| 실패율 | 없음 ✅ | |
| 희귀도 분포 | **벌목 고유** ✅ | 2026-07-31. `LoggingBasicTable.Weight`가 벌목의 분포다 |
| ~~특별보상(10%)~~ | ❌ 폐지 | 2026-07-30. 고급 원목은 희귀도 롤 편입 검토 |
| ~~특이 규칙~~ | ~~자원 고갈~~ | ❌ 폐지 (2026-09-27) |

> ~~⚠️ **고갈 속도는 30초 주기 기준으로 계산한다.**~~ (고갈 폐지) 하루 2,880회 벌목이 일어나므로,
> 판정당 감소량을 크게 잡으면 숲이 몇 시간 만에 바닥난다.
> 재생률도 같은 시간축에서 잡아야 "자고 일어나면 회복"이 성립한다.

### ~~자원 고갈·재생 (제안)~~ — 폐지 (2026-09-27)

- 숲마다 `자원량(0~100%)`이 있고, 벌목하면 감소한다.
- 시간이 지나면 자연 회복한다.
- 자원량이 낮으면 회당 산출이 줄어든다.

| 논점 | 권장 |
| --- | --- |
| 완전 고갈 가능? | **불가** — 하한(예: 20%)을 두어 채취가 멈추지 않게 |
| 재생 속도 | 하루 방치로 완전 회복되는 수준 |
| ~~오프라인 중 재생~~ | ⚠️ **질문이 바뀌었다 (2026-07-29).** 오프라인 진행이 폐지돼 "오프라인 중"이라는 구간 자체가 없다 |

> ⚠️ **비접속 중 자원이 재생되는가는 다시 정해야 한다.**
> 채취는 접속 중에만 돌지만, **재생까지 멈추면** 오래 안 들어온 유저의 숲이
> 고갈된 채로 굳는다(접속하자마자 산출이 바닥). 반대로 **재생만 오프라인에 두면**
> "안 들어오는 것이 이득"이 되어 P2와 부딪힌다.
> 재생을 **접속 시각 기준으로 소급 계산**하는 방식이 현재로선 가장 무난하다 — 미결.

> **주의:** 고갈이 "접속해서 관리해야 함"으로 이어지면 P1을 위반한다.
> 고갈은 **총량 상한**을 위한 장치이지, 플레이어에게 노동을 시키기 위한 장치가 아니다.
> 하한을 두고, 방치 시 자동으로 지속 가능한 속도에 수렴하게 만드는 편이 안전하다.

### 수종 = 벌목 레벨 (2026-08-01)

`TreeTable`이 하려던 "수종별로 산출물이 갈린다"는 [산업 레벨](../산업레벨.md)이 담당한다.
~~**자원 고갈·재생은 레벨과 직교한다**~~ — 고갈 폐지로 수종(레벨)만 남는다.

| 축 | 어디에 |
| --- | --- |
| 수종(무엇이 나오는가) | **슬롯의 `IndustryLevel`** |
| ~~자원량(얼마나 나오는가)~~ | ❌ 폐지 (2026-09-27) |

> ~~⚠️ **자원량을 레벨별로 따로 둘지 정해야 한다.**~~ (고갈 폐지로 소멸) 하나로 두면 레벨을 바꿔도
> 고갈이 이어지고, 레벨별로 두면 **고갈될 때마다 레벨을 갈아타는 회피**가 가능해진다.
> 벌목의 "절제하면 지속된다"는 정체성이 여기 걸려 있다.
