## 1. 산업 정체성 (제안)

> ⚠️ 제안이다. 5개 산업이 서로 다른 리듬을 갖게 하기 위한 차별화 축.

| 항목 | 값 |
| --- | --- |
| **심리 정의** | **안정적인 수익** |
| 투자 비유 | 적금 — 오늘도 어제만큼 들어온다 |
| 한 줄 | **가장 많이, 가장 확실하게 나온다** |
| 회당 산출 | **가장 많음** (5종 중 1위) |
| 실패율 | **없음** — 판정마다 반드시 나온다 |
| ~~특별보상(10%)~~ | ❌ **층 폐지 (2026-07-30).** 변종 작물의 경로 미정 |
| 역할 | 경제의 **기반 물량** 공급 |
| 플레이어 개입 | **산업 레벨 선택** (텃밭 · 밭 · 농장 · 대농장 · 신성한 대지) — 다른 4종과 같다 |

> **희귀도 분포를 농사만 좁게 둘 수 있다** (2026-07-31 — 분포 통일 폐지).
> 농사의 차별점은 **회당 산출 1위 + 실패 없음**이고, 여기에
> **분포를 하위 등급에 몰아** "많이 나오지만 흔한 것 위주"라는 적금 감각을 수치로 만들 수 있다.
> 낚시(상위 편중·소량)와 정확히 반대편에 선다.

농사는 **양으로 승부하는 산업**이다. 실패가 없고 분포가 좁아 산출이 예측 가능하다.
"오늘 얼마나 벌었나"가 아니라 "꾸준히 쌓인다"가 농사의 감각이다.

> 주기 통일(30초)로 **"장주기 대량 산출"에서 장주기가 빠지고 대량만 남았다.**
> 농사의 정체성은 개입 방식이 아니라 **회당 산출 · 실패율 · 희귀도 분포** 세 수치가 맡는다.

## 2. 채취 특성

| 파라미터 | 값 | 비고 |
| --- | --- | --- |
| 채취주기 | **30초** ✅ | 전 산업 공통 → [자원채취](../README.md) 2.1 |
| 회당 산출 | **가장 많음** ⚠️ | 5종 중 1위. 수치 미정 |
| 실패율 | **없음** ✅ | 판정마다 반드시 나온다 |
| 희귀도 분포 | **농사 고유** ✅ | 2026-07-31. `FarmingBasicTable.Weight`가 농사의 분포다 |
| ~~특별보상(10%)~~ | ❌ 폐지 | 2026-07-30. 변종 작물은 희귀도 롤 편입 검토 |

### 파종을 두지 않는다 — 작물 세트는 산업 레벨이 정한다 (2026-10-09 · T-014)

**농사도 다른 4종과 똑같이 `(산업, 레벨, 캐릭터)`를 배치하면 도는 공통 슬롯 진행이다.**
작물을 골라 심는 단계·성장 대기·작물 선택 칸이 없다. 어떤 작물이 나오는지는
**산업 레벨**(텃밭 · 밭 · 농장 · 대농장 · 신성한 대지)이 정한다 → [산업 레벨](../산업레벨.md) 5.2

| 이유 | 내용 |
| --- | --- |
| 슬롯 연출 | 전 산업 공통 방치형 루프(대상 등장 → 공격 → 처치 → 아이템, **처치 1회 = 판정 1회**)에 "심고 → 기다렸다 → 수확"이 들어갈 자리가 없다 |
| 주기 통일 | 채취주기 30초 통일로 작물별 성장시간이 갈 곳이 없다. 작물 선택은 산업 레벨 선택과 **같은 일**이라 두 층으로 두면 농사만 배치 칸이 하나 더 생긴다 |
| 재미 | 30초마다 수확되는 구조에서 작물 선택은 "최적 작물 고르기" 한 번으로 끝난다 |
