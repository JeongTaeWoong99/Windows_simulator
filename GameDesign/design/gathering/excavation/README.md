## 2. 발굴 루프

### 2.1 판정 루프 — 실패 없음

```
판정 ── 반드시 보상
  │
  ├─ ① 채취 보상 (분기 없음)
  │        └─ 가중치 롤 한 번 ← ExcavationBasicTable (그 레벨의 유물 6종)
  │             예) 깨진 토기 조각 6590 / 녹슨 동전 2000 / 흙 묻은 구슬 1000 …
  │
  └─ ② 상자 롤 (①과 별개, 매 판정) ← CommonRewardTable (레벨)
          └─ 그 레벨 상자 3종
```

채취 속도는 `적성 × (1 + Σ가산) × Π승산`으로 정해진다
(→ [작업슬롯](../../workslot/README.md) 3.4). 서버가 굴리는 롤은 **판정당 2회**(채취 → 공통보상).

### 2.2 체감 루프

슬롯 연출은 전 산업 공통 방치형 루프다 — 캐릭터가 달려가 대상(흙더미·항아리·석상 등)을 공격하고,
**처치 1회 = 판정 1회**로 유물이 나온다 → [게임UI](../../ui/README.md) 2.5

접속 중에만 진행한다. 접속하면 진행도 0에서 시작하고,
접속이 끊기면 완성된 판정만 지급하고 진행 조각은 버린다 → [자원채취](../README.md) 2.2

> 실패가 없다는 것이 **"확실한 도파민"의 근거**다 — 위젯을 볼 때마다 뭔가 파여 있다.

### 2.3 하루 기준 (24시간 연속 접속 · Lv1 · 기준 속도 1.0배 · 슬롯 1개)

| 구분 | 값 |
| --- | --- |
| 총 판정 | 2,880 |
| 채취 보상 | **2,880** (전량) |

## 3. 산업 정체성

| 항목 | 값 |
| --- | --- |
| **심리 정의** | **확실한 도파민** |
| 투자 비유 | 소액 잦은 당첨 |
| 한 줄 | **파면 반드시, 자주 나온다** |
| 실패율 | **없음** |
| 역할 | 접속 동기 — "오늘 뭐 나왔나 볼까" |
| 플레이어 개입 | **배치할 때 발굴지(레벨) 선택** — 다른 4종과 같다 |
| 자원 출구 | **즉시 판매 · 거래소 · 캐릭터 먹이기** — 발굴만의 고유 출구는 아직 없다 |

**발굴은 다른 4산업과 수치·구조가 같다.** 주기·희귀도 가중치·상자 확률이 5산업 공통값이고(#42),
차이는 **자원(유물)과 발굴지 이름**뿐이다. 산업 개성은 숨은 확률이 아니라 자원의 쓰임새로 낸다 → [T-125](../../../../tasks/T-125-산업특성화.md)

> 낚시를 대체한 이유: 캐릭터 모션이 대기·공격·달리기 셋뿐이라 낚시(던지기·기다리기·당기기)를 그릴 수 없다.
> 발굴은 "대상에게 달려가 공격한다"로 자연스럽다 → [T-142](../../../../tasks/archive/T-142-낚시제거대체산업.md)

## 5. 데이터 설계

> `ExcavationBasicTable`은 **`GameDesign/Excel/DropExcavation.xlsx`의 레벨별 시트**(`ExcavationBasicTable.Lv1`~`.Lv5`)로
> 존재하고, 제너레이터가 한 테이블로 병합한다.

| 테이블 | 컬럼 | 키 | 범위 |
| --- | --- | --- | --- |
| `ExcavationBasicTable` | `DropTID`, **`IndustryLevel`**, `ItemTID`, `Weight`, `Description` | `DropTID` | **유물 + 가중치.** ✅ **30행** (레벨마다 6행) |

**Lv1 값** (가중치는 5산업 공통값):

| `DropTID` | `ItemTID` | 유물 | `Weight` |
| --- | --- | --- | --- |
| 200101 | 10001 | 깨진 토기 조각 | 6590 |
| 200102 | 10002 | 녹슨 동전 | 2000 |
| 200103 | 10003 | 흙 묻은 구슬 | 1000 |
| 200104 | 10004 | 청동 거울 | 300 |
| 200105 | 10005 | 옛 장인의 도장 | 100 |
| 200106 | 10006 | 개척자의 일지 | 10 |

- **`DropTID`는 6자리**: `산업 × 100000 + 레벨 × 100 + 순번`. 산업 자리는 `IndustryType` 값이라 **발굴은 2** — `200101~200506`이다.
- 레벨 이름(옛 집터 · 무너진 성벽 · 고대 신전 · 지하 묘실 · 잊힌 왕도)은 `IndustryLevelTable.Name`에 있다.
  판정 점수·경험치는 다른 산업과 같다 → [산업 레벨](../산업레벨.md) 4.3
- 첫 컬럼 `ID` 타입 `DropTID` · `ItemTID`의 `Ref` 검사는 다른 드롭 시트와 같다
  → [`excel-table-creator`](../../../../.claude/skills/common/excel-table-creator/SKILL.md)

**발굴 테이블에 두지 않는 것:**

| 항목 | 어디에 있나 |
| --- | --- |
| `CycleSec` (30초) | 전역 상수 |
| `Rarity` 중복 컬럼 | `ItemTable.GlobalRarity`가 원본 |

> 밸런스 수치는 `GameDesign/Excel/*.xlsx`가 원본. 수정 후 `GameDesign/generate-tables.ps1` 실행.
