## 0. 한 줄

**발굴은 상자 대신 "미감정 유물"을 캔다. 골드를 내고 감정하면 상자처럼 보상이 나오고, 낮은 확률로 아티팩트가 나온다.**
아티팩트는 **갖고 있기만 하면 계정에 영구 효과**를 주는 수집 아이템이고, 거래할 수 있다.

```
발굴 판정 ─┬─ 채취 보상 (그 레벨 유물 자원 6종 — 다른 산업과 같다)
           └─ 유물 롤 (상자 롤 자리) ──→ 미감정 유물 (일반·고급·희귀 × Lv1~5 · Special)
                                              │  감정 (골드)
                                              ▼
                                  상자와 비슷한 보상 ┬ 골드 · 자원 · 장비 · 큐브 · 소모품
                                                     └ 낮은 확률 → 아티팩트 (유물과 같은 등급)
                                                                       │ 보유 = 계정 영구 효과
                                                                       └ 거래소 · 즉시 판매
```

이게 발굴의 **고유 출구**가 된다 — 다른 4산업(도시락 · 설비 개량 · 토벌령)처럼 쓰임새로 개성을 낸다(T-125).
"확실한 도파민"(심리 정의)은 **감정하는 순간**이 담당한다.

## 1. 미감정 유물

| 항목 | 구상 |
| --- | --- |
| 얻는 곳 | **발굴 판정의 상자 롤 자리.** `CommonRewardOverrideTable`에 (발굴, Lv) 행을 넣어 공통 상자 3줄을 **통째로** 유물로 바꾼다 — 서버 로직은 그대로다 |
| 등급 | 레벨마다 **일반 · 고급 · 희귀** 3종(상자의 나무·은·황금 자리) + **Special 1종(레벨 무관)** = 16종 |
| 확률 | 일반·고급·희귀는 상자와 같은 값(2% · 0.3% · 0.03%) · **Special은 모든 레벨에서 뜬다** (1.3) |
| 생김새 | 아이콘 가운데 **`?`** — 흙 묻은 보따리·봉인된 조각 느낌. 등급은 테두리 색으로 |
| 아이템 | `ItemTable` 행 · 스택 · 상자처럼 `OpenGachaId`로 감정 풀을 가리킨다 |
| 거래 | **된다**(P4) — 감정 전 유물을 사고판다 = "도박 매물" |

### 1.1 Special 유물

- **레벨과 무관하게 같은 TID 하나.** Lv1에서 캐도, Lv5에서 캐도 같은 Special 유물이다.
- 감정 비용이 **가장 비싸고**, Special 아티팩트는 **여기서만** 나온다.

### 1.2 등급 = 아티팩트 등급

**유물의 등급이 그 유물에서 나올 수 있는 아티팩트의 등급이다.** 일반 유물 → 일반 아티팩트만, Special 유물 → Special 아티팩트만.
그래서 아티팩트 등급은 **일반 · 고급 · 희귀 · Special 넷**이 된다.

### 1.3 ⚠️ Special 확률을 판정마다 같게 두면 Lv1이 가장 좋은 사냥터가 된다

판정 1회가 Lv1 30초 · Lv5 40분 30초다(81배). Special 확률을 **판정당** 같은 값으로 두면 **시간당** Lv1이 81배 많이 캔다.
"레벨에 관계없이 뜬다"를 **시간당 같은 기회**로 읽는 쪽을 추천한다:

| 방식 | 판정당 확률 | 시간당 기대 | 결과 |
| --- | --- | --- | --- |
| A. 판정당 고정 | 전 레벨 p | Lv1이 Lv5의 81배 | Special을 노리면 Lv1에 몰린다 |
| **B. 판정 비용에 비례 (추천)** | Lv1 p · Lv2 3p · … · Lv5 81p | **전 레벨 같다** | 어느 레벨을 돌려도 Special 기회는 같다 |

일반·고급·희귀 유물은 상자처럼 판정당 고정이다 — 상위 레벨 유물이 더 비싸서 벌충된다(상자와 같은 구조).

## 2. 감정

| 항목 | 구상 |
| --- | --- |
| 행동 | 인벤토리에서 유물을 골라 **감정** — 상자 열기와 같은 흐름(한 번에 1~50개) · 대기 시간 없음 |
| 비용 | **골드.** 유물마다 고정값 · 등급이 높을수록, 레벨이 높을수록 비싸다 · **Special이 가장 비싸다** |
| 실패 | **없다** — 감정하면 반드시 무언가 나온다(전 산업 공통 원칙) |
| 결과 | 그 유물의 감정 풀을 돈다 — 상자와 같은 모양(`GachaRewardInfo`)이라 개봉 연출을 그대로 쓴다 |
| 경제 | 감정 비용은 **sink**다 — 거래의 sink 3종(수수료 · 슬롯 확장 · 가챠)에 하나가 더 붙는다 |

### 2.1 감정 풀 — 상자 + 아티팩트 한 줄

**같은 자리 상자의 풀을 베이스로 하고 아티팩트 줄을 얹는다.** (일반 유물 Lv3 ≈ 나무 상자 Lv3 + 일반 아티팩트)

| 내용물 | 구상 |
| --- | --- |
| 골드 · 자원 · 장비 · 큐브 · 소모품 | 상자 4.1과 같은 구성·가치 기준(V) |
| **아티팩트** | **일정 확률**(테스트값 — 예: 일반·고급·희귀 2~5% · Special 유물은 더 높게). 그 등급 아티팩트 중 하나를 균등으로 |
| 상자 · 유물 | **나오지 않는다** — 무한 개봉 방지(상자와 같은 규칙) |

> 감정 비용만큼 보상 기대값이 상자보다 높아야 손해가 아니다. 숫자는 상자 V와 함께 맞춘다(테스트값부터).

## 3. 아티팩트

| 항목 | 구상 |
| --- | --- |
| 정체 | **수집 아이템.** 장착·사용하지 않는다 — **보유만으로** 계정에 효과 |
| 효과 | **계정 영구 가산** — 특성과 같은 효과 종류를 쓴다: 작업속도 가산(전체·산업별) · 산출량 가산(전체·산업별). 작은 값(‰) |
| 등급 | 일반 · 고급 · 희귀 · Special — 등급이 높을수록 효과가 크다 |
| **중복** | **종류마다 1개만 센다** — 같은 아티팩트를 10개 들고 있어도 효과는 1개분. 남는 것은 팔거나 거래한다 |
| 보유의 범위 | **인벤토리 + 창고.** 경매에 걸면(에스크로) 그동안 효과가 꺼진다 · 팔면 즉시 꺼진다 |
| 거래 | **된다** — 거래소(자원처럼 스택 매물) · 즉시 판매(`BasePrice`) |
| 도감 | 아티팩트 전 종류를 보여 주고, 가진 것만 밝힌다 · 합계 효과를 한 줄로 |

### 3.1 설계 원칙과 맞추기

| 원칙 | 아티팩트 |
| --- | --- |
| P1 주의를 뺏지 않는다 | 감정은 플레이어가 원할 때만 · 알림 없음 |
| P3 놓쳐도 손해 없다 | 기간·일일 제한 없음 · 유물은 쌓아 두면 된다 |
| P4 모든 재화는 흐른다 | 유물·아티팩트 모두 거래 가능 · 중복은 시장으로 나간다 |
| 캐릭터는 판정의 양·질에 관여하지 않는다 | 아티팩트는 **계정** 효과다 — 특성처럼 속도·산출량에 붙는다 |

## 4. 데이터 · 구현 스케치 (확정 뒤)

| 대상 | 구상 |
| --- | --- |
| `ItemTable` | 미감정 유물 16행 · 아티팩트 N행. 유물은 `OpenGachaId` → 감정 풀 |
| 감정 비용 | `ItemTable`에 **`OpenCostGold`** 컬럼 하나 — 0이면 상자(무료), 0보다 크면 감정. 상자 열기 경로를 그대로 쓰고 골드만 먼저 뺀다 |
| `ArtifactTable` (새 시트) | `ItemTID` · `EffectType`(`eUserTraitEffect` 재사용) · `Industry` · `EffectValue` |
| `Gacha.xlsx` | 감정 풀 16개 (상자 풀 복사 + 아티팩트 줄) |
| `CommonRewardOverrideTable` | (발굴, Lv1~5) 행 — 유물 4종씩 (Special 확률은 1.3 B안이면 레벨마다 다르다) |
| enum | `GlobalRarity`에 **`Special` 뒤에 추가** · `ItemType`에 유물·아티팩트 분류를 둘지 (5장) |
| 서버 | 감정 = 골드 차감 + 상자 열기 · 보유 아티팩트 집합 → 속도·산출량 합산(특성과 같은 자리) · 보유가 바뀌면 슬롯 속도 재계산 |
| 클라 | 유물 `?` 아이콘 · 감정 버튼(비용 표시) · 아티팩트 도감 · 속도 내역에 "아티팩트" 줄([T-055](../../../../tasks/archive/T-055-속도보정내역전달.md) 내역) |

## 5. 결정할 것

- [ ] **유물이 상자를 대신하나, 상자에 더해지나** — 추천: **대신한다**(발굴의 상자 자리 = 유물). 더하면 발굴만 보상 총량이 커져 #42 공통값과 어긋난다
- [ ] **Special 확률 방식** — 추천: **B안 판정 비용에 비례**(1.3)
- [ ] **Special의 이름** — `GlobalRarity.Special`은 이미 있는 `ItemType.Special`(상자·소모품 분류)과 이름이 겹친다. 다른 이름(예: `Ancient` 고대)을 쓸지
- [ ] **Special을 `GlobalRarity`에 넣나** — 넣으면 장비·캐릭터·가챠 등급 축에도 7번째 등급이 생긴다(색상·정렬·필터가 따라온다). 유물·아티팩트만 쓰는 별도 표시로 둘지
- [ ] **아티팩트 효과 종류** — 특성과 같은 속도·산출량만인가, 다른 것(캐릭터 경험치 · 감정 비용 할인 · 상자 확률)도 넣나
- [ ] **아티팩트 종 수** — 등급마다 몇 종 (예: 일반 10 · 고급 8 · 희귀 6 · Special 3)
- [ ] **세트 효과** — 같은 시대·장소 아티팩트를 모으면 추가 효과를 줄지 (지금은 없음)
- [ ] **미감정 유물 거래** — 허용(추천, P4) · 막을지
- [ ] **아티팩트 효과 상한** — 다 모은 계정의 속도·산출량 합계를 얼마로 묶을지(판정 최소 주기 2.1초가 속도 상한은 이미 자른다)
