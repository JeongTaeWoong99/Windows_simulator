## 0. 한 줄

**발굴은 상자 대신 "미감정 유물"을 캔다. 골드를 내고 감정하면 상자처럼 보상이 나오고, 낮은 확률로 아티팩트가 나온다.**
아티팩트는 **갖고 있기만 하면 계정에 영구 효과**를 주는 수집 아이템이고, 거래할 수 있다.

```
발굴 판정 ─┬─ 채취 보상 (그 레벨 유물 자원 6종 — 다른 산업과 같다)
           └─ 유물 롤 (상자 롤 자리) ──→ 미감정 유물 (희귀도마다 1종 · 일반 ~ 신화 + Special)
                                              │  감정 (골드)
                                              ▼
                                  상자와 비슷한 보상 ┬ 골드 · 자원 · 장비 · 큐브 · 소모품
                                                     └ 낮은 확률 → 아티팩트 (유물과 같은 등급)
                                                                       │ 보유 = 계정 영구 효과
                                                                       └ 거래소 · 즉시 판매
```

이게 발굴의 **고유 출구**가 된다 — 다른 4산업(도시락 · 설비 개량 · 토벌령)처럼 쓰임새로 개성을 낸다(T-125).
"확실한 도파민"(심리 정의)은 **감정하는 순간**이 담당한다.

목업: [`유물감정목업.html`](../../ui/유물감정목업.html) — 유물 아이콘 7종 · Special 무지개 효과 · 감정 연출(깨짐 → 번쩍 → 등장).

## 1. 미감정 유물 — 희귀도마다 1종 (1:1)

**유물은 레벨을 갖지 않는다.** 희귀도 하나에 유물 하나 — **7종**이다. 산업 레벨은 **어느 유물이 나올지의 확률**로만 갈린다.

| 유물 | 등급 | 생김새 (목업) |
| --- | --- | --- |
| 흙 묻은 유물 | 일반 | 모래·흙에 덮인 토기 덩이 · 가운데 `?` |
| 조개 박힌 유물 | 고급 | 〃 + 녹색 광택 |
| 산호 엉긴 유물 | 희귀 | 〃 + 청색 광택 |
| 봉인된 유물 | 영웅 | 〃 + 보라 문양 |
| 황금 띠 유물 | 전설 | 〃 + 주황 테 |
| 왕의 유물 | 신화 | 〃 + 금빛 테 |
| **무지개 유물** | **Special** | 무지개 테두리 · 계속 도는 빛 · 반짝임 — **아이템 칸에서도 애니메이션이 돈다** |

> 이름은 목업용 가제다. 아이콘은 **섬에서 캔 것** — 모래 · 흙 · 조개 · 산호가 엉긴 덩어리에 `?`가 새겨진 모양.

| 항목 | 구상 |
| --- | --- |
| 얻는 곳 | **발굴 판정의 상자 롤 자리.** `CommonRewardOverrideTable`에 (발굴, Lv) 행을 넣어 공통 상자 3줄을 **통째로** 유물 줄로 바꾼다 — 서버 로직은 그대로다 |
| 레벨의 역할 | **확률만 다르다** — 레벨이 오를수록 높은 등급 유물이 잘 나온다 (1.1) |
| 아이템 | `ItemTable` 7행 · 스택 · 상자처럼 `OpenGachaId`로 감정 풀을 가리킨다 |
| 거래 | **된다**(P4) — 감정 전 유물을 사고판다 = "도박 매물". 레벨이 없으니 시장에서 같은 등급끼리 섞인다 |

### 1.1 레벨별 확률 (모양 예시 — 값은 테스트값으로 정한다)

판정당 확률(%). 낮은 레벨은 아래 등급 위주, 높은 레벨은 위 등급이 열린다. **Special은 모든 레벨에서 뜬다.**

| 레벨 | 일반 | 고급 | 희귀 | 영웅 | 전설 | 신화 | Special |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Lv1 | 2 | 0.3 | 0.03 | — | — | — | p |
| Lv2 | 2 | 0.6 | 0.1 | 0.01 | — | — | 3p |
| Lv3 | 1.5 | 1 | 0.3 | 0.03 | 0.003 | — | 9p |
| Lv4 | 1 | 1.5 | 0.6 | 0.1 | 0.01 | 0.001 | 27p |
| Lv5 | 0.5 | 1.5 | 1 | 0.3 | 0.03 | 0.003 | 81p |

### 1.2 Special 유물

- **어느 레벨에서든 뜬다.** 감정 비용이 **가장 비싸고**, Special 아티팩트는 **여기서만** 나온다.
- ⚠️ **판정당 같은 확률이면 Lv1이 가장 좋은 사냥터가 된다** — 판정 1회가 Lv1 30초 · Lv5 40분 30초(81배)라 시간당 Lv1이 81배 많이 캔다.
  위 표처럼 **판정 비용에 비례**(p · 3p · 9p · 27p · 81p)로 두면 **시간당 기회가 전 레벨 같다**(추천).

### 1.3 등급 = 아티팩트 등급

**유물의 등급이 그 유물에서 나올 수 있는 아티팩트의 등급이다.** 일반 유물 → 일반 아티팩트만, Special 유물 → Special 아티팩트만.
그래서 아티팩트 등급도 **일반 ~ 신화 + Special 일곱**이다.

## 2. 감정

| 항목 | 구상 |
| --- | --- |
| 행동 | 인벤토리에서 유물을 골라 **감정** — 상자 열기와 같은 흐름(한 번에 1~50개) · 대기 시간 없음 |
| 비용 | **골드.** 유물마다 고정값 · 등급이 높을수록 비싸다 · **Special이 가장 비싸다** |
| 실패 | **없다** — 감정하면 반드시 무언가 나온다(전 산업 공통 원칙) |
| 결과 | 그 유물의 감정 풀을 돈다 — 결과 모양은 상자와 같다(`GachaRewardInfo`) |
| 경제 | 감정 비용은 **sink**다 — 거래의 sink 3종(수수료 · 슬롯 확장 · 가챠)에 하나가 더 붙는다 |

### 2.1 감정 풀 — 상자와 비슷한 보상 + 아티팩트 한 줄

| 내용물 | 구상 |
| --- | --- |
| 골드 · 자원 · 장비 · 큐브 · 소모품 | 상자 4.1과 같은 구성. **유물에 레벨이 없으니 가치는 등급으로만 정한다** — 자원은 등급에 맞는 레벨의 것 |
| **아티팩트** | **일정 확률**(테스트값). 그 등급 아티팩트 중 하나를 균등으로 |
| 상자 · 유물 | **나오지 않는다** — 무한 개봉 방지(상자와 같은 규칙) |

> 감정 비용만큼 보상 기대값이 상자보다 높아야 손해가 아니다. 숫자는 상자 V와 함께 맞춘다(테스트값부터).

### 2.2 감정 연출 (목업)

```
① 흔들림 0.6초 → ② 금이 간다 0.8초(세 번에 나눠 퍼진다) → ③ 번쩍 0.25초(등급 색 · Special은 무지개)
→ ④ 조각이 흩어지고 아이템이 튀어나온다 0.5초 → ⑤ 아티팩트면 띠와 함께 한 번 더 빛난다
```

- 여러 개를 한 번에 감정하면 **가장 높은 결과 하나만** 이 연출을 쓰고 나머지는 목록으로 — P1(주의를 뺏지 않는다)
- 연출 중 클릭하면 건너뛴다

## 3. 아티팩트

| 항목 | 구상 |
| --- | --- |
| 정체 | **수집 아이템.** 장착·사용하지 않는다 — **보유만으로** 계정에 효과 |
| **고유번호** | **No.001 ~ No.699** — 아티팩트 종류마다 하나. 화면에는 세 자리(`No.007`)로 보인다. **앞 번호일수록 희귀하다** — 등급마다 대역이 있고 Special이 맨 앞, 일반이 맨 뒤 (3.2) |
| 효과 | **계정 영구 가산** — 특성과 같은 효과 종류를 쓴다: 작업속도 가산(전체·산업별) · 산출량 가산(전체·산업별). 작은 값(‰) |
| 등급 | 일반 ~ 신화 + Special — 등급이 높을수록 효과가 크다 |
| **중복** | **가질 수 있다 · 효과는 겹치지 않는다** — 같은 번호를 10개 가져도 효과는 1개분. 남는 것은 팔거나 거래한다 |
| **보관 — 전용 칸** | **인벤토리에 들어가지 않는다.** 아티팩트 전용 보관함(3.1)에 번호별 고정 칸으로 들어간다 — 인벤토리 칸 수(200)를 먹지 않는다 |
| 효과가 켜지는 조건 | 그 번호 칸의 수량이 **1 이상**. 경매에 걸면(에스크로) 그 수량만큼 빠지고, 0이 되면 효과가 꺼진다 |
| 거래 | **된다** — 전용 보관함에서 바로 거래소 매물(스택) · 즉시 판매(`BasePrice`) |

### 3.1 아티팩트 보관함 = 도감

**전용 칸은 데이터에 있는 번호마다 하나, 번호 순서로 고정된다.** 보관함이 곧 도감이다 — 등급 대역별로 묶어 보여 준다(Special 줄 · 신화 줄 …).

| 칸 상태 | 보이는 것 |
| --- | --- |
| 아직 얻은 적 없음 | 번호와 실루엣만 (`No.342 ???`) |
| 가지고 있음 (1개 이상) | 아이콘 · 이름 · 효과 · 수량 — **효과 켜짐** 표시 |
| 얻었다가 다 팔았음 (0개) | 아이콘 · 이름은 남기고 흐리게 — 효과 꺼짐 |

- **보관함과 도감은 한 화면이다** — 장착 없이 보유만으로 켜지니 두 화면이 같은 데이터를 보여 주게 된다. 관리는 **`보유 중` 필터**(가진 칸만)로 한다. 목업: `design/ui/유물감정목업.html`
- 보관함 위에 **합계 효과 한 줄**(예: 전 산업 작업속도 +4.5% · 발굴 산출량 +3%)과 **수집 수**(`37 / 120` — 분모는 지금 있는 종 수)를 둔다.
- 감정으로 얻은 아티팩트는 인벤토리를 거치지 않고 **바로 그 번호 칸에** 들어간다 — 인벤토리가 가득 차도 막히지 않는다(우편 넘침 처리가 필요 없다).
- "얻은 적 있음"은 수량과 따로 기록한다 — 다 팔아도 도감에서 지워지지 않게.

### 3.2 번호 매기기 — 앞 번호 = 희귀

**번호는 세 자리이고, 맨 앞 자리가 등급이다(100번대 = 한 등급). 희귀한 등급이 앞 자리를 갖는다.** 번호 첫 글자만 봐도 귀함이 읽힌다(`No.003`은 자랑거리).
등급마다 100칸(Special은 99칸) — 짧은 번호라 칸 아래에 붙여도 읽힌다.

| 맨 앞 자리 | 등급 | 번호 대역 |
| --- | --- | --- |
| `0` | Special | No.001 ~ 099 |
| `1` | 신화 | No.100 ~ 199 |
| `2` | 전설 | No.200 ~ 299 |
| `3` | 영웅 | No.300 ~ 399 |
| `4` | 희귀 | No.400 ~ 499 |
| `5` | 고급 | No.500 ~ 599 |
| `6` | 일반 | No.600 ~ 699 |
| `7`~`9` | (예비) | 등급이 늘 때 쓴다 |

- **`00000`은 쓰지 않는다** — 코드·DB에서 0은 "없음"으로 읽힌다(`CharacterTID 1` 결번과 같은 이유).
- 데이터 검사: 아티팩트의 등급과 번호 대역이 맞지 않으면 파이프라인·서버 테스트가 막는다.

- 대역 안에서는 **뒤로 비워 두고** 앞에서부터 채운다 — 나중에 같은 등급을 추가해도 번호가 등급 순서를 지킨다.
- 한 번 매긴 번호는 바꾸지 않는다(DB에 저장되는 식별자 — 게임기획코어 4장 규칙).

### 3.3 설계 원칙과 맞추기

| 원칙 | 아티팩트 |
| --- | --- |
| P1 주의를 뺏지 않는다 | 감정은 플레이어가 원할 때만 · 알림 없음 · 연출은 건너뛸 수 있다 |
| P3 놓쳐도 손해 없다 | 기간·일일 제한 없음 · 유물은 쌓아 두면 된다 |
| P4 모든 재화는 흐른다 | 유물·아티팩트 모두 거래 가능 · 중복은 시장으로 나간다 |
| 캐릭터는 판정의 양·질에 관여하지 않는다 | 아티팩트는 **계정** 효과다 — 특성처럼 속도·산출량에 붙는다 |

## 4. 데이터 · 구현 스케치 (확정 뒤)

| `CommonRewardOverrideTable` | (발굴, Lv1~5) 행 — 레벨마다 유물 7종의 확률(1.1) |
| enum | `GlobalRarity.Special = 7` ✅ · `ItemType.Box = 8` · `Consumable = 9` ✅ (상자·소모품 재분류) · 유물은 `ItemType.Relic`을 뒤에 더한다 · 아티팩트는 아이템이 아니라 분류가 필요 없다 |
| 서버 | 감정 = 골드 차감 + 상자 열기 · 아티팩트는 전용 보관함에 넣는다 · **수량 1 이상인 번호 집합** → 속도·산출량 합산(특성과 같은 자리 · 중복은 한 번) · 0↔1 경계를 넘을 때만 슬롯 속도 재계산 · 경매는 새 매물 종류(아티팩트) |
| 클라 | 유물 `?` 아이콘 · **Special 칸 애니메이션** · 감정 버튼(비용 표시) · 감정 연출 · **아티팩트 보관함(999칸 도감)** · 속도 내역에 "아티팩트" 줄 |
| 아트 | 유물 아이콘 7장(Special은 무지개 테 + 반짝임 레이어) · 깨짐 조각 · 아티팩트 아이콘 |
