# 문서 사이트 (Astro)

> 최종 업데이트: 2026-09-28 (일감 보드 — 왼쪽 탭 · 회차 · 상태 5단계 · 담당은 사람 · 진우는 서버·기획)

`tasks/`와 `GameDesign/design/`의 마크다운을 **그대로 읽어** 정적 사이트로 만든다.
문서를 여기로 복사하거나 옮기지 않는다 — 편집 위치가 곧 단일 진실이다.

```powershell
cd GameDesign/web
npm install      # 최초 1회
npm run dev      # http://localhost:4321
npm run build    # dist/ 생성
```

---

## 어떻게 읽는가

`src/lib/content-loader.ts`가 `node:fs`로 원본을 직접 읽고 markdown-it으로 렌더한다.
Astro의 glob loader 대신 **커스텀 loader**를 쓰는 이유는 링크 리라이트 때문이다.

| 파일 | 하는 일 |
|------|---------|
| `src/lib/paths.ts` | `REPO_ROOT` 기준 경로. **`web/`이 `GameDesign/` 아래라 `../`가 4개다** |
| `src/lib/slugs.ts` | 한글 파일명 → URL 슬러그 (`게임기획코어.md` → `core`) |
| `src/lib/content-loader.ts` | 읽기 · 프론트매터 파싱 · **링크 리라이트** · 렌더 |
| `src/lib/labels.ts` | 영문 폴더 → 한글 라벨, 상태·담당 배지 스타일 |
| `src/lib/status.ts` | **게임기획코어 5장 확정/미확정 표**를 읽어 확정·검토중·미정으로 가른다 |
| `scripts/sync-assets.mjs` | 목업(`.html`)·이미지를 `public/assets`로 복사 + 대응표 생성 |

### 링크 리라이트가 핵심이다

원본 문서는 서로를 `.md` 상대경로로 가리킨다. 그대로 두면 웹에서 전부 404다.
`routeFor()`가 절대경로 하나를 라우트로 옮긴다:

| 대상 | 결과 |
|------|------|
| `GameDesign/design/**/*.md` | `/design/<슬러그>` |
| `tasks/**/*.md` | `/tasks/t-0NN` (`archive/`·`art/`·`later/`도 같은 자리) |
| `design` 옆의 `.html`·이미지 | `/assets/<복사본>` |
| 그 밖의 저장소 파일 (`CLAUDE.md`·스킬·코드) | **GitHub blob 링크** — 죽은 링크로 두지 않는다 |

### 페이지 넷

| 라우트 | 무엇 |
|--------|------|
| `/` | 홈 — 열린 GitHub 이슈 · 담당 복수 필터 일감 목록 · 보류 목록 |
| `/status` | **현황 — 된 것과 안 된 것.** 아래 참조 |
| `/tasks` | **일감 보드 — 담당이 곧 열이다.** 아래 참조 |
| `/design/<슬러그>` | 기획 문서 |

#### `/` — 이슈는 방문할 때 불러온다

GitHub 이슈는 **빌드 때가 아니라 브라우저에서** `api.github.com`으로 읽는다.
사이트는 문서가 바뀔 때만 다시 빌드되므로, 빌드 때 박으면 이슈가 늦게 반영된다.
공개 저장소라 토큰이 없다 — 비인증 한도(IP당 시간당 60회)를 넘으면 오류 문구가 뜬다.
열린 이슈만, PR은 뺀다. 저장소 이름은 `paths.ts`의 `GITHUB_REPO` 하나에서 온다.
이슈마다 **할당자**(아바타 + 로그인)를 붙인다. 비었으면 `미할당` 칩이 뜬다 — 할당이 없으면 알림이 안 간다.

홈의 **남은 일감** 목록은 담당 버튼(태웅 · 규빈 · 진우)을 **여러 개 켤 수 있다**(`/tasks`의 필터는 하나만).
옆의 검색창은 **ID·제목**을 찾는다. 띄어 쓴 낱말이 모두 들어 있어야 걸리고, 담당 필터와 AND다.
**고른 담당 조합은 `localStorage`(`home-owner-filter-v2`)에 남아 다음 방문에도 유지된다** — 저장소를 못 쓰는 브라우저면 전부 켠 채로 시작한다.
"지금 진행중" 섹션은 없앴다(2026-09-19) — 필터 목록과 겹쳤다. 진행중 건수는 위 카드에 남는다.

#### `/tasks` — 왼쪽 탭 + 표 (2026-09-28)

2주 회차로 굴러가면서 **"이번 회차에 무엇이 들어가나"** 가 첫 질문이 됐다. 보드를 탭 구조로 바꿨다.

| 탭 | 담는 것 |
|---|---|
| `YYMMDD 목표 일감` | `목표`가 그 회차인 일감 — **닫힌 것(`archive/`)도 담아 아래에 깐다**(상태 필터 Closed로 그 회차에 끝낸 일을 본다). 탭 옆 숫자는 남은 것만 센다. **다가오는 두 회차는 비어도 띄운다**(빌드 시점 기준 — `labels.ts` `upcomingCycles`) |
| 서버·기획 일감 · 클라 구현 일감 | 담당 `진우`(서버·기획) · `태웅`(클라)의 남은 전부 (회차 무관) |
| 회차 밖 | `목표: 미정` — `art/`·`later/` |
| 남은 일감 전부 · Closed | — |

- 탭은 주소의 `#`로 남는다(`/tasks#server`) — 링크를 건네면 같은 탭이 열린다.
- 위의 **담당**(태웅·규빈·진우)·**상태**(New · In Progress · Resolve · Feedback · Closed) 필터는 하나씩 고르고 탭과 AND다. 같은 버튼을 다시 누르면 전체.
- 행을 탭마다 복제하지 않는다 — 행 하나에 `data-tabs`로 속한 탭을 전부 적고 `hidden`만 토글한다.
- 기본 정렬: 상태(In Progress → Feedback → New → Resolve → Closed) → 우선순위 → ID.
- **표 머리(ID · 제목 · 담당 · 상태 · 우선순위 · 목표)를 누르면 그 열로 정렬한다** — 누를 때마다 오름차순 ▲ → 내림차순 ▼ → 기본 순서. 상태·우선순위는 글자가 아니라 위 순서로 잰다. 탭·필터를 바꿔도 정렬은 유지된다.
- 담당·상태 값은 일감 프론트매터 그대로다. 표에 없는 값이면 배지 색이 빠진다(오타를 눈으로 잡는다).

#### `/status` — 두 축을 나란히 두되 섞지 않는다

| 축 | 출처 | 묻는 것 |
|----|------|---------|
| **구현 현황** | `tasks/` (보관 = 됨 / 남은 것 = 안 됨) | **코드가 들어갔는가** |
| **기획 확정 현황** | `게임기획코어.md` 5장 표 | **정해졌는가** |

> ⚠️ **둘은 다른 것이다.** 정해졌는데 구현이 없는 것도, 그 반대도 있다. 한 숫자로 합치지 않는다.

**기획 쪽 분류는 문서가 쓰는 마커(✅ · ⚠️ · ❌)를 그대로 따른다.** 사이트가 다시 판단하지 않는다 —
판단을 여기 넣으면 문서와 사이트가 서로 다른 말을 하게 된다.

> ⚠️ **파서는 5장 표 하나만 읽는다.** 바로 뒤에 다른 표를 가진 `###` 소절이 이어지므로
> **다음 헤딩에서 끊는다**(`status.ts`). 5장 제목을 바꾸면 표가 통째로 비니 함께 고친다.

### 한글 파일명은 슬러그 표로 옮긴다

폴더는 영문이라 그대로 쓰지만 파일명은 한글이다. `slugs.ts`의 `FILE_SLUGS`에
없는 한글 파일이 새로 생기면 URL이 percent-encoding으로 깨진다 — **문서를 추가하면 표에 한 줄 넣는다.**

## 배포

main에 push되면 [`docs-deploy.yml`](../../.github/workflows/docs-deploy.yml)이 빌드해 **Cloudflare Pages `wsdocs`** 에 올린다.
루트 경로에 올라가므로 `astro.config.mjs`의 `base`는 비워 둔다.
**하위 경로(`github.io/Windows_simulator/` 등)로 옮기면 `base`를 반드시 넣는다** — 빼면 CSS·링크가 전부 깨진다.

| 버전 | 달라진 것 |
|------|-----------|

## 생성물

`public/assets/`와 `src/generated/assets.json`은 `sync-assets.mjs`가 만든다.
`npm run dev`·`build`·`check` 앞에 자동으로 붙어 있어 따로 돌릴 일은 없다. **직접 수정하지 않는다.**
