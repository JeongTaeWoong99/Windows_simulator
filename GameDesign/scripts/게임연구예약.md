# 게임별 재미 연구 예약

매일 **한국시간 06:00·12:00·18:00**, 한 번에 게임 하나를 조사해 wsdocs의 **기획 (AI)**에 게시한다.

## 실행 조건

- 이 PC가 켜져 있고 등록한 Windows 사용자가 로그인되어 있어야 한다. 잠금 화면은 괜찮지만 전원 종료·로그아웃 중에는 조사하지 않는다.
- Node·Git·`codex` CLI와 웹/원격 Git 연결이 필요하다. 등록한 사용자의 Codex 로그인·사용 한도를 이용한다.
- Windows 시간대는 Korea Standard Time이다. 놓친 실행은 작업 스케줄러의 StartWhenAvailable 정책을 따른다. 정확한 정각 완료를 보장하지 않으며 조사는 실행 이후 시간이 걸린다.
- 같은 작업이 돌고 있으면 중복 회차를 실행하지 않는다. CLI는 읽기 전용 sandbox·웹 검색으로 조사하고, 검증기가 게시한다. 승인 우회·전체 파일 접근 모드는 쓰지 않는다.

## 등록과 확인

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File GameDesign/scripts/register-game-research.ps1
Get-ScheduledTask -TaskName WindowsSimulator-GameResearch
Get-ScheduledTaskInfo -TaskName WindowsSimulator-GameResearch
```

작업 이름은 `WindowsSimulator-GameResearch`다. 세 개의 Daily 트리거가 한 작업에 붙고 창은 숨겨서 실행한다. 다른 PC로 저장소를 옮기거나 경로를 바꾸면 그 PC에서 다시 등록한다. 등록기는 Windows 스케줄러를 바꾸므로 저장소 pull만으로 등록되지는 않는다.

## 어떤 글을 쓰나

방치형·Desktop Companion을 해 보지 않은 독자를 위한 게임별 연구다. 누가 어떤 상황에서 즐기는지, 플레이 장면과 감정, 재미를 만드는 시스템, 불편·이탈 이유, 직접 관찰할 과제, 우리 게임에 던지는 질문과 출처를 쓴다.

공식 기능·개별 후기·작성자 해석을 구분한다. 나이·성별·직업·이용자 비중이나 집중력 향상을 근거 없이 만들지 않는다. 최소 3개 출처·2개 도메인을 인용하며 제목·필수 절·본문 길이·게임 중복·원시 HTML을 검증한다. 이 검사는 사실 정확성을 자동으로 보증하지 않으므로 중요한 판단은 출처를 다시 읽는다.

## 게시와 사용자 작업 보존

결과는 `GameDesign/design/research/game-studies/YYYY-MM-DD-HH-study-<game-id>.md`에 쌓는다. 시각은 실제 조사 시작의 KST이고 일정과 달리 지연될 수 있다. 기존 시스템 레퍼런스는 `research/references/`에 그대로 있다.

게시기는 최신 origin/main에서 **별도 detached worktree**를 만들고 새 연구 문서 한 편만 커밋·푸시한다. 원래 작업 트리의 브랜치·HEAD·staged 파일·DB는 바꾸지 않는다. main push가 기존 문서 배포를 실행한다. 원격 main이 먼저 움직였으면 게시 worktree에서만 한 번 재시도한다. 게시가 성공한 뒤에도 Cloudflare 배포 성공 여부는 GitHub Actions에서 별도로 확인한다.

이 때문에 PC의 main은 자동 연구가 게시된 만큼 원격보다 뒤에 있을 수 있다. 평소처럼 pull하면 된다. 실패를 숨기려고 사용자 작업을 stash/reset하거나 잠금 파일을 지우지 않는다.

## 실패 확인과 복구

- `.utmp/game-research/latest.json`: 마지막 성공/실패·게임·커밋·실행 폴더
- `.utmp/game-research/scheduler.log`: 스케줄러 시작/실패
- 각 실행 폴더의 `codex.log`·`article.json`: 조사 실행 로그와 결과. git에 올리지 않는다.
- 실패는 작업 종료 코드 1로 남고 검증 전 문서는 게시하지 않는다. 로그인·네트워크·사용 한도를 복구한 뒤 수동 실행하거나 다음 회차를 기다린다.
- 죽은 프로세스의 연구 잠금은 다음 실행에서 정리한다. 살아 있는 작업의 잠금이나 Git index.lock을 지우지 않는다.

```powershell
# 실제 조사·게시 1회
powershell -NoProfile -ExecutionPolicy Bypass -File GameDesign/scripts/run-game-research.ps1
# 잠시 멈추기 / 다시 켜기
Disable-ScheduledTask -TaskName WindowsSimulator-GameResearch
Enable-ScheduledTask -TaskName WindowsSimulator-GameResearch
```
