# 스팀 로그인 시험

> 최종 업데이트: 2026-11-24 (처음 작성 — 우리 AppID가 나오기 전, Valve 시험 앱 480으로 각자 PC에서 시험하는 법 · T-211 · #144)

우리 AppID가 나오기 전(T-210)에는 Valve 시험 앱 **480(Spacewar)** 으로 스팀 로그인을 시험한다.
클라는 스팀에서 받은 티켓을 서버로 보내고, 서버가 스팀 Web API로 확인한 뒤 `steam:<SteamID>` 계정으로 들인다.
처음 들어오면 계정이 생기고, 다음부터는 같은 계정을 이어 쓴다.

## 한 번만 하는 설정

1. **스팀 계정의 Web API 키를 받는다** — <https://steamcommunity.com/dev/apikey>. 도메인 칸은 아무 값이나 넣어도 된다(`localhost`).
   ⚠️ 키는 **저장소·채팅에 올리지 않는다.** 사람마다 자기 키를 쓴다.
2. **사용자 환경 변수로 넣는다** (PowerShell):

   ```powershell
   [Environment]::SetEnvironmentVariable('Game__Steam__WebApiKey', '<받은 키>', 'User')
   ```

   - 에디터 서버 콘솔은 이 변수를 직접 읽어 서버에 넘긴다 — 에디터를 다시 켤 필요 없다.
   - Rider·터미널에서 서버를 띄우면 **그 프로그램을 다시 켜야** 변수를 받는다.
   - 키가 없으면 [접속하기]가 "스팀 확인 서버에 연결하지 못했습니다"로 끝나고, 서버 로그에 `WebApiKey 미설정`이 찍힌다.

## 시험할 때마다

1. **스팀 클라이언트를 켜고 로그인해 둔다.** 꺼져 있으면 "스팀을 켜고 다시 시도해 주세요".
2. 로컬 서버를 켠다(치트 창 [서버 콘솔]).
3. 치트 창 도구 줄 **`[○] 스팀 화면`** 을 눌러 `[●]`로 켠다 — 다음 플레이부터 로그인 화면이 빌드처럼 [접속하기]·[종료]로 뜬다. 끄면 Id 로그인으로 돌아온다(각자 PC 설정 · 씬에 안 남는다).
4. 플레이 → [접속하기]. 화면 위 이름이 스팀 닉네임이면 성공이다.

## 알아둘 것

- 에디터는 프로젝트 루트 `steam_appid.txt`(480)를, 빌드는 exe 옆에 복사된 같은 파일을 읽는다. 스팀은 그동안 "Spacewar 플레이 중"으로 보인다.
- 로컬 DB에 `steam:<SteamID>` 계정이 생긴다. Id 로그인 계정과는 별개다.
- 빌드(exe)는 원격 서버에 붙는다 — 원격 서버에 키가 들어가야 스팀으로 접속된다(#152 · `Server/docs/도커.md`).
- 우리 AppID가 나오면 `steam_appid.txt`와 서버 `Game:Steam:AppId`만 바꾼다(T-210). Web API 키는 그때 퍼블리셔 키로 바꾼다.
- 코드 쪽 설명은 [`Steam 규칙.md`](../Assets/Scripts_Client/Steam/Steam%20규칙.md) · 서버 검증은 T-207.
