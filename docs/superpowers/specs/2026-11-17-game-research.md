# 게임별 재미 연구와 정기 게시

사용자는 방치형·Desktop Companion을 해 본 적이 없어 게임별로 누가 왜 즐기는지 공부하려 한다. wsdocs의 기존 `기획 제안 (AI)`를 `기획 (AI)`로 바꾸고, 매일 한국시간 06·12·18시에 게임 하나의 연구를 추가한다.

- 기존 Astro·Cloudflare 배포와 `/proposals` URL을 유지한다. 새 연구는 별도 `research/game-studies/`에서 읽으며 기존 제안과 구분한다.
- 연구는 인구통계 추정 대신 근거가 있는 이용 동기·상황을 설명한다. 공식 기능, 플레이어 관찰, 작성자 해석을 구분하고 출처·불만·직접 관찰 과제를 담는다. 게임 규칙을 확정하는 문서가 아니다.
- Windows 작업 스케줄러가 로그인된 Codex CLI의 읽기 전용 웹 조사를 실행한다. PC가 켜져 있고 사용자가 로그인되어 있어야 한다. 실패는 기록하고 미검증 결과를 게시하지 않는다.
- 게시기는 별도 Git worktree에서 새 연구 문서 하나만 커밋·푸시한다. 사용자의 현재 브랜치·staged 변경·개발 DB를 건드리지 않는다. 중복 게임·동시 실행을 막는다.
- 최초 게임별 연구 3편을 제공한다. 제목 변경·호환 목록·문서 빌드·게시 경로·예약 등록을 검증한다.
