# 게임 기획 참조 (게임 작업 전 필독)

> 게임 시스템·콘텐츠를 만지기 전에 **[`GameDesign/기획/게임기획코어.md`](../../../../GameDesign/기획/게임기획코어.md)** 를
> 먼저 읽고, 그 다음 해당 영역의 **상세 기획안**을 읽는다.
> 게임기획코어는 "무엇을 왜 만드는가", 상세 기획안은 "어떻게 만드는가"를 담는다.

---

## 트리거 — 언제 읽는가

**게임의 규칙·수치·콘텐츠에 닿는 모든 작업.** 예:

- 채취/퀘스트/특성/아이템/거래/성장 관련 로직 구현·수정
- `GameDesign/Excel/*.xlsx` 데이터 추가·변경
- 게임 데이터 테이블(`GameData`) 스키마 변경
- 게임 관련 패킷·DB 테이블 설계
- 바탕화면 위젯·팝업 UI 등 게임 표현 작업
- 기획 문서 자체의 수정·추가

## 읽지 않아도 되는 경우

- 게임 규칙과 무관한 순수 인프라 작업 (빌드 스크립트, 로깅, 네트워크 계층 자체 등)
- 파일을 바꾸지 않는 단순 질의응답

---

## 절차

1. **[`GameDesign/기획/게임기획코어.md`](../../../../GameDesign/기획/게임기획코어.md) 를 읽는다.** (항상, 예외 없이)
   - 특히 **5장 "확정 / 미확정 현황"** 을 확인한다.
   - **6장 "개발 시 지켜야 할 접점"** 의 고정 규칙을 지킨다.
2. 게임기획코어의 **3장 시스템 지도**에서 이번 작업에 해당하는 시스템을 찾아,
   그 **상세 기획안**(`GameDesign/기획/<시스템>/README.md`)을 읽는다.
   - 여러 시스템에 걸치면 관련된 것을 전부 읽는다.
   - 각 문서 말미의 **"결정 필요 (Open Questions)"** 를 반드시 확인한다.
3. 설계 판단이 갈리면 게임기획코어 1장의 **설계 원칙(P1~P4)** 을 기준으로 결정한다.
4. 리스크가 걸리는 작업이면 [`GameDesign/기획/기획평가.md`](../../../../GameDesign/기획/기획평가.md)
   의 리스크 등급표를 함께 본다.

## 지켜야 할 것

### 미확정 항목을 임의로 정하지 않는다

게임기획코어 5장과 각 상세 기획안의 "결정 필요"에 있는 항목은 **아직 기획이 없는 것**이다.
구현에 그 값이 필요하면 **사용자에게 먼저 확인한다.** 임의로 정해서 구현하지 않는다.

부득이하게 진행해야 하면, 가정을 명시하고 임시값임을 코드/문서에 남긴다.

### 기획과 다른 구현을 발견하면 알린다

코드가 기획 문서와 다르면 조용히 한쪽에 맞추지 말고, **차이를 사용자에게 보고**한다.
문서가 낡은 것인지 구현이 틀린 것인지는 사용자가 판단한다.

### 밸런스 수치는 코드에 넣지 않는다

수치·테이블은 `GameDesign/Excel/*.xlsx`가 원본이다.
엑셀 수정 후 `Server/generate-tables.ps1`을 돌려 생성물까지 같은 커밋에 담는다.
생성물(`Server/GameData`, `Server/Shared/Data`, `GameDesign/DataLog`, Unity 미러)은 직접 수정하지 않는다.

### 기획을 바꿨으면 문서도 바꾼다

구현 과정에서 기획이 확정·변경되면:

1. 해당 **상세 기획안**을 갱신하고 `⚠️`(제안) 표기를 제거한다.
2. `게임기획코어.md` **5장 확정/미확정 현황**의 상태를 갱신한다.
3. 문서 상단의 `최종 업데이트` 날짜를 그날 날짜로 바꾼다.

## 새 시스템·산업을 추가할 때

1. `GameDesign/기획/<시스템>/README.md` 를 만든다.
   **폴더명·문서명은 반드시 한글로 짓는다.** (`Gathering` ❌ / `자원채취` ⭕)
   1차 산업이면 `GameDesign/기획/자원채취/<산업>/README.md`.
2. 기존 문서와 같은 구성을 따른다:
   `확정 사항` → `설계(제안)` → `데이터 설계` → `서버/클라 책임` → `결정 필요`
3. `게임기획코어.md` **3장 시스템 지도**(산업이면 **4장 콘텐츠 지도**)에 행을 추가한다.
4. 이 스킬의 **문서 지도** 표에도 행을 추가한다.

> 이름 규칙의 전체 내용(예외 목록 포함)은 [`CLAUDE.md`](../../../../CLAUDE.md)의 **"이름 규칙 (문서·폴더)"** 참조.
> `GameDesign/Excel`·`GameDesign/DataLog`는 코드가 경로를 직접 참조하므로 **영문을 유지한다.**
