# 경매 더미 매물 치트 (T-168)

## 목적 / 배경
- #71의 "검색 결과 1,000건 이상"을 화면에서 보려면 판매 중 매물이 1,000개 넘게 있어야 하는데 만들 길이 없었다(이슈 #77). 부하 테스트에도 쓴다.

## 결정
- `ECheatCommand.SeedAuctionListings = 16` — `Arg1` 개수(1~5,000, 0이면 삭제) · `Arg2` ItemTID(0이면 `ItemTable.All`을 돌아가며)
- **원장에 바로 쓰고, 경매장에는 릴레이가 보낸다.** 경매장에 직접 넣으면 메인에 거래 행이 없어 구매가 정산에서 실패한다 — 원장 + outbox로 두면 구매·만료가 실제와 같다
- 더미 판매자 `AuctionDummy.SellerId = 9×10¹⁸`(경매장은 0 이하 거부 · 실제 계정과 안 겹침), 닉네임 `더미상점`. 대금 우편은 더미 앞으로 쌓이고 삭제 때 지운다
- 자원 매물만 — 장비·캐릭터는 개체 행이 있어야 해서 뺐다
- 삭제 순서: **원장 먼저 지우고 → 경매장에 판매자 기준으로 물어 취소.** 경매장 목록이 기준이라 다시 실행하면 남은 것만 지운다. 거래가 없으니 뒤늦은 취소·만료 이벤트는 반환 없이 지나간다
- 삭제해도 구매 확정 outbox(kind 2)는 남긴다 — 안 가면 구매자의 예약이 타임아웃까지 매물을 붙든다
- 응답은 두 번(접수 + 끝) — `SendCheatDone`
- 치트.md 4장 "치트가 DB에 직접 쓰지 않는다"에 이 명령을 예외로 적었다
