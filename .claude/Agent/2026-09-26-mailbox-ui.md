# 클라 우편함 화면 (T-083 · 이슈 #32)

## 목적 / 배경
- 서버 우편(T-081·T-082) 패킷 39~44를 클라에서 받아 그리기. 요구 목록은 이슈 #32, 기획은 `GameDesign/design/mail/README.md` → `tasks/T-083`.
- 버튼 위치는 사용자가 정했다: **상태바 맨 왼쪽**. 누르면 설정처럼 `#Main Canvas` 가운데가 바뀐다. 모양은 사용자가 준 참고 이미지(어두운 갈색 틀 · 주황 버튼 · 아래쪽 안내문 · [모두 받기])를 따랐다.

## 주요 결정 / 근거
- **우편 캐시는 `PlayerDataModel`에 뒀다** — 별도 Model을 만들지 않음. "내 계정 상태는 여기 하나만 구독한다"는 기존 축을 지켰다.
- **수령 응답은 실패여도 목록을 반영한다** — 모두 받기가 `StorageFull`로 멈춰도 그 전까지 받은 id가 `ClaimedMailIds`에 온다. 받은 시각은 패킷에 없어 클라 현재 시각으로 채운다(표시용).
- **`StorageFull` 문구를 우편 화면이 따로 쓴다** — 공용 `ResultMessages`는 "창고 가득(뽑기·상자)"이라, "아무것도 지급 안 됐고 우편은 남아 있다"가 안 전해진다.
- **줄 버튼은 하나(받기|삭제)** — 안 받은 우편은 지울 수 없어 둘이 동시에 뜨지 않는다. 삭제는 확인 창 없이(받은 우편만 지워지고 7일 뒤 어차피 사라짐).
- **참고 이미지의 탭(일반/보상)·새로고침 타이머는 넣지 않았다** — 기획에 우편 분류가 없고, 새 우편은 서버가 밀어 준다(`S_MailArrivedResponse`).
- **`ItemUseCompleted`에 `storedInMail` bool을 붙였다** — 상자 넘침 안내는 `StorageGridPresenter`가 `RaiseNotice`로 띄운다(알림이 `!System` 마지막 형제라 결과창 위).

## 함정
- ⚠️ **`※`는 neodgm_pro Static 아틀라스에 없다** → □로 나온다. 안내문은 `·`로 썼다. 새 기호를 쓰면 글리프부터 확인.
- ⚠️ **`unity cmd eval`로 씬을 저장하면 레이아웃이 계산하는 RectTransform 값(앵커·위치·크기)과 TMP 자동 크기가 0/다른 값으로 저장돼** diff가 수천 줄이 된다(기능 영향은 없음 — 실행 시 재계산). 이번엔 HEAD와 문서 단위로 비교해 "레이아웃 값만 바뀐 문서"를 HEAD로 되돌려 의도한 변경만 남겼다. 다음에도 eval로 씬을 저장했으면 커밋 전에 `git diff --stat`으로 크기를 본다.
- `unity cmd eval_file`은 `using` 지시문을 무시한다 — 타입 이름을 전부 정규화해야 컴파일된다.
- 씬 뷰 캡처는 Overlay UI를 안 그린다. 이 씬의 Root Canvas는 이미 ScreenSpaceCamera라 `capture_game_view`(카메라)로 에디트 모드에서도 UI가 찍힌다.

## 후속 작업 / 주의사항
- **실서버 왕복 확인 전이다** — 치트창 [우편 발송] → 점 → 받기·모두 받기·삭제 · 상자 넘침 알림. 확인되면 T-083 완료·보관, 이슈 #32 처리 코멘트, 기획 우편 README 상태 줄의 "클라 화면 미착수" 갱신.
- 색은 참고 이미지 톤의 임시값(`#3B2A20` 등). 스프라이트는 기존 `Background`·`UISprite`를 틴트했다.

## 업데이트 (2026-09-26) — 받은 첨부를 결과 팝업으로

- 사용자 확인: 점검 보상 받기 동작. 요청: 받으면 뽑기처럼 결과 팝업을 띄우고 확인 후 닫기.
- `PlayerDataModel.MailRewardsClaimed(List<MailInfo>)` 신설 — 수령 응답에는 받은 것 목록이 없어 **우편 캐시의 첨부**를 넘긴다. 모두 받기가 `StorageFull`로 멈춰도 그 전까지 받은 것은 뜬다.
- `GachaResultPresenter`가 구독해 첨부를 종류별로 합쳐 칸으로 그린다. `GachaRewardInfo`로 바꾸지 않은 이유: 우편엔 다이아가 있는데 `EGachaRewardType`에 다이아가 없다. 등급은 테이블에서 읽는다(첨부에 등급이 없다).
- **팝업 칸 수량 표시가 가챠 때문에 늘 꺼져 있었다** — 상자 개봉 결과도 수량이 안 보이던 상태였다. `Show(..., showCount)`로 가챠만 끄고 상자·우편은 켠다.
- **팝업 제목이 '가챠 결과'로 고정**이었다 — `titleText` 필드를 추가해 `'<출처> 결과'`로 바꾼다(씬 배선함).
- 모두 받기 성공 알림("n통을 받았습니다")은 뺐다 — 결과 팝업 위에 창이 하나 더 겹친다. 실패(인벤토리 부족) 알림은 그대로.
- 씬 저장 후 레이아웃 값 잡음은 이번에도 HEAD 대비 문서 단위로 되돌렸다(위 "함정" 참고).
- 상태바에서 우편 버튼이 Dia 패널 뒤·세팅 앞으로 옮겨져 있었다(사용자 편집으로 보임) — 그대로 두고 문서를 맞췄다.
