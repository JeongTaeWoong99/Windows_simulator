# 캐릭터 종족 표시 · 전 캐릭터 지급 치트 버튼

## 목적 / 배경
- T-054 — 기획·데이터의 `Race`는 있는데 클라가 읽지 않았고, 작업슬롯 줄에 "종족 추가 예정"이 남아 있었다.
- 사용자 요청: 툴팁·슬롯 등 캐릭터가 보이는 곳에 빠짐없이 넣는다.
- T-190 · 이슈 #102 — 서버 `GiveAllCharacters`(PR #106)에 맞춘 치트 창 버튼.
- 이슈 #84 — 계승 25% 문구 확인(코드 변경 없음).

## 변경 내용
- `UI/Shared/RaceLabel.cs` 신설 · `GameDataLoader.GetCharacterRace` 추가
- `Loc_UI.xlsx` — `UI.Character.Race*` 9줄 추가, `UI.WorkStation.RaceTbd` 삭제 → 파이프라인
- 칸: `SlotView` 종족 배지(`Race Badge` — 크기 배지 위) · 적성 칸 산업 그림(`aptitudeIconImages`) · 인벤토리·뽑기 결과가 배지를 넘긴다
- 툴팁: 인벤토리 캐릭터 칸 · 경매 매물 · 경매 등록 후보 · 판매 카트
- 줄 문구: 작업슬롯 선택 줄·카드(`raceText`) · 작업슬롯 칸 · 응축 창 · 경매 요약·시세·추천 · 우편 첨부
- `CharacterStateRowView.prefab` · 씬 — `LocalizedText`(RaceTbd)와 임시 문구 제거
- `CharacterCheatSection` — [전 종류 1장씩] 버튼

## 주요 결정 / 근거
- 응축 문구 `UI.Condense.ConfirmCondensed` · `HelpLost` — "25%만 넘어갑니다"가 나머지가 사라지는지 분명하지 않다는 사용자 지적으로 "25%(올림)만 대상에 더해지고 나머지는 사라집니다"로 고쳤다. 규칙은 그대로다.
- 칸 배지는 한 글자(인·마·언·골) — 100px 칸에 크기·레벨 배지와 같은 형식으로 쌓는다.
- 적성 칸 그림은 숫자 뒤 알파 0.35 — 숫자가 먼저 읽혀야 한다.
- 위젯 미니 칸과 장비 툴팁(`BuildWornTooltip`)에는 넣지 않았다 — 미니 칸은 이름 자리가 없고, 장비 툴팁은 장비 전용이다.
- 이름 검색은 종족을 찾지 않는다 — 표시 요청 범위 밖이다.

## 확인
- 실서버·플레이: 지급 응답 `창고 31 · 인벤토리 0 · 우편 0` · 테이블 31종과 일치. 테스트 계정으로 돌리고 개발 DB를 작업 전 사본으로 되돌렸다.
- 화면 캡처: 인벤토리 칸 · 작업슬롯 줄·카드·칸 · 응축 창 · 적성 그림.
- 값 확인: 칸 툴팁 · 경매 등록 툴팁 · 경매 요약 · 시세 문구 · 응축 문구 25%.
- 사용자 확인: 인벤토리 칸 · 응축 창 · 응축 확인 팝업.

## 후속 작업 / 주의사항
- 내가 화면으로 못 본 것: 치트 창 버튼 그림(같은 명령을 직접 보내 확인) · 뽑기 결과 칸 · 경매 매물 툴팁 · 판매 카트 툴팁 · 우편 첨부.
- 뽑기 결과 칸은 크기·레벨 배지가 없어 종족 배지만 왼쪽 중간에 뜬다 — 실플레이에서 어색하면 위치를 조정한다.
- 이슈 #84 · #102는 사용자 확인 뒤 코멘트하고 닫았다. T-054 · T-190 보관.
