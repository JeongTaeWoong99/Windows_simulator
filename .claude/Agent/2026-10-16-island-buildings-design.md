# 섬 산업 건물 기획 초안 (T-105)

## 목적 / 배경
- 자원 출구가 판매(골드)뿐이었다. 진우가 섬 컨셉에 맞춰 "1차 산업 건물을 짓고 레벨·특성을 올리는" 방향을 정했다.
- 참고 모델: Escape from Duckov 은신처(재료로 짓는 건물 · 선행 건물 · 아이템+재화로 여는 트리).

## 사용자가 정한 것 (2026-10-16)
- 건물마다 레벨별 기술 트리 · 선행 노드를 열어야 다음 노드
- 계정 특성 · 슬롯 시설 개량(T-125) 둘 다 유지
- 노드가 **수치도 연다**(처음 제안은 기능만이었는데 수치 허용으로 바뀜)
