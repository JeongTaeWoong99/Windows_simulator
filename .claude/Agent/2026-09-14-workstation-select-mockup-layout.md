# 작업슬롯 선택 화면을 목업 구조로

## 목적 / 배경
- 선택 화면이 텍스트 두 줄과 해제 버튼뿐이라 휑했다. HTML 목업 `drawDetail`의 **구조만** 가져왔다 → `tasks/archive/T-053`
- 결정 표(색·스크롤·적성 표기·임시 자리)는 일감 파일에 있다

## 변경 내용
- 코드·프리팹·씬 → 커밋 `f945bb7`
- 배치 트리 → `Assets/Scripts_Client/UI/UI 배치 현황.md`
- 신규 일감: T-054(종족·초상화·아이콘, 공용) · T-055(속도 보정 내역 전달, 서버)

## 주요 결정 / 근거
- **세팅 카드는 목록 줄 프리팹(`CharacterStateRowView`)을 재사용한다.** 버튼 라벨만 코드가 "배치"/"해제"로 넣는다 — 줄과 카드의 모양이 어긋나지 않는다
- **전역 배수는 서버가 보내지 않아 `CurrentWorkSpeed ÷ WorkSpeedTable[적성]`으로 역산한다.** 가산(장비·특성)이 아직 0이라 지금은 정확하다. 가산이 붙으면 틀리므로 T-055에 명시 필드 요청을 남겼다
- 적성 표기(`0`→`X`, 색)는 창고 칸과 캐릭터 줄이 함께 써서 `UI/Shared/AptitudeLabel.cs`로 뺐다
- 선택 화면의 두 스크롤(캐릭터 목록·효율)은 판매 목록처럼 스크롤바 `Permanent`. 기존 `AutoHideAndExpandViewport`는 줄이 적으면 스크롤바가 사라져 사용자가 "없어졌다"고 봤다

## 후속 작업 / 주의사항
- ⚠️ **ctrl on · expand off VLG의 자식은 `flexibleWidth 1`이 필요하다.** 스크롤 뷰는 선호 폭이 0이라 폭 0으로 접힌다. 카드·장비 칸은 내부 HLG의 선호 폭 덕에 멀쩡해 보여 놓치기 쉽다
- ⚠️ 꺼진 Presenter를 켜서 캡처할 때는 저장하지 말고 `EditorSceneManager.OpenScene`으로 되돌린다(T-035 때 파생 크기가 저장됐다)
- MCP `result.Log`는 `{0:0.0}` 서식을 못 쓴다 — 문자열로 미리 포맷한다
- 적성 0의 `X`는 어두운 칸 위에서 대비가 낮다(창고 스트립과 같은 색). 플레이 확인에서는 문제 삼지 않았다
