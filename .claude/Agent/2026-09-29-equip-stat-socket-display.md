# 장비 칸 능력치 칸 표시 (새 능력치 기획 선행)

## 목적 / 배경
- T-095(인챈트 UI)를 보다가 태웅이 기획을 바꾸기로 했다 — 인챈트가 장비 등급과 따로 돌아 "좋은 장비에 큐브를 돌린다"는 동기가 없다.
- 새 기획: 장비 등급 = 능력치 칸 수(일반 1 ~ 신화 6) · 큐브 1종으로 칸 하나씩 등급·능력치·수치 랜덤 · 덮어쓰기. 전체 규칙은 서버 요청 이슈에 있다 → `tasks/T-095`의 이슈 링크.
- 서버가 바뀌기 전에 클라가 할 수 있는 **표시**부터 세웠다(플레이 확인 완료).

## 변경 내용
- `SlotView` — 하단 밴드에 `Stat Socket Strip`(네모 6개). `SetStatSockets(grades)` · 밴드 주인 판정을 `RefreshSubText` 하나로 모았다(문구·적성·능력치 셋이 같은 자리).
- `StorageSlotSource.GetStatSockets` 가상 → `EquipSlotSource`만 값을 준다. 장비 칸의 보조 문구(기본 능력치)는 비우고 툴팁으로 옮겼다.
- `EquipLabel` — 칸 수 규칙 `GetStatSlotCount` · 옵션 문구 `GetOptionText`.

## 주요 결정 / 근거
- **칸 내용을 옛 인챈트 필드(`EquipInfo.EnchantOptions`)에서 읽는다(임시).** 옵션 TID의 행이 이미 등급을 들고 있어, 새 기획의 "칸마다 등급"을 그대로 그릴 수 있었다. 새 패킷이 오면 `EquipSlotSource.ReadStatOptions`만 갈아 끼운다.
- **옛 데이터가 칸 수를 넘으면 칸을 늘려 보인다**(상한 6). 일반 장비에 인챈트 2~3줄이 붙은 계정이 있다 — 자르면 실제 옵션이 화면에서 사라진다.
- 네모는 **오른쪽 끝부터** 앉는다(배열 앞쪽을 끈다). 레이아웃 그룹 없이 고정 좌표 — 칸 수에 따라 켜고 끄기만 한다.
- 빈 칸 색 `#2A2A2A` + 검은 Outline — 일반 등급 회색(#9D9D9D) · 일반 장비의 회색 바탕 위에서 구분되게.
- 네모에는 `UIThemeColor`를 붙이지 않았다 — 색을 코드가 칠하므로 테마가 덮으면 안 된다.

## 후속 작업 / 주의사항
- ⏸ 칸 수 규칙은 서버가 주인이다 — 서버 값이 오면 `EquipLabel.GetStatSlotCount`를 그쪽에 맞추거나 지운다.
- 큐브 사용 화면 · 효율 계산(`GetEquipSpeedAdd`)은 새 패킷 대기 → `tasks/T-095`.
- 가챠 결과 등 같은 프리팹을 쓰는 곳은 `SetStatSockets`를 부르지 않아 줄이 꺼진 채다.
