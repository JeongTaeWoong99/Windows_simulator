# 문서 사이트 회차 탭에 닫힌 일감도 담는다

## 목적 / 배경
- `/tasks`의 `261010 목표 일감` 탭에서 담당 진우 · 상태 Closed로 걸렀는데 아무것도 안 나왔다.
- 회차 탭이 `live`(archive 밖)만 담아서, archive로 내려간 일감은 상태 필터를 걸어도 나올 수 없었다.

## 변경 내용
- `GameDesign/web/src/pages/tasks/index.astro` — 회차 탭 `items`에 `closed`까지 넣었다. 탭 옆 숫자는 `count`로 따로 둬서 남은 것만 센다.
- `GameDesign/web/사이트.md` — 탭 표 설명 갱신

## 주요 결정 / 근거
- 기본 정렬(`rank`)이 `[...live, ...closed]` 순서라 닫힌 일감은 자연히 아래로 간다 — 별도 정렬 로직 없음.
- 숫자를 전체 개수로 바꾸면 "이번 회차에 남은 일"이라는 탭의 첫 의미가 흐려져서 남은 것만 센다.
- 회차 탭 목록(`cycles`)은 여전히 `live`의 목표 + 다가오는 두 회차에서만 만든다 — 지난 회차 탭이 쌓이는 걸 막으려고.

## 후속 작업 / 주의사항
- 지난 회차(남은 일감이 없는 회차)의 Closed는 회차 탭이 없으므로 `Closed` 탭에서 목표 열 정렬로 본다.
