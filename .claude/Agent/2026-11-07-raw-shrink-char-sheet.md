# AI 원본 줄이기 · 캐릭터 시트 시험

## 목적 / 배경
- 11-06 아이콘 교체로 그림 저장소가 228MB 늘었다. 원인은 Seedream이 4096px로 준 격자 원본 20장(장당 약 10MB)이고, 게임용 결과물은 약 2.5MB다.
- 사용자 요청: 앞으로 에셋이 늘어날 테니 압축 방식과 고려할 점을 스킬로 정리한다. 이어서 캐릭터 시트를 시험하고 발굴 캐릭터 행 추가를 요청한다.

## 변경 내용
- 그림 저장소 `273c44a9`: 4096 시트 20장을 1536으로 줄였다(228MB → 37MB). `_source/shrink_raw.py`를 새로 넣었다. 견습 나무꾼 시험 시트 `characters/unity-ai-lumberjack/raw/lumberjack_sheet.png`는 다음 커밋에 넣었다.
- 메인: 새 스킬 `client/asset-compression`, CLAUDE.md 표, `Art 규칙.md`, T-148 보관(사용자 "아이콘 잘 보이고"), T-189, T-174, 이슈 #115(발굴 3종 행 추가 · 진우), 마일스톤 261121 생성.

## 주요 결정 / 근거
- 줄인 원본으로 다시 잘라도 아이콘 178개가 1픽셀도 같았다. `grid_to_icons.py`가 원래 1536으로 NEAREST 축소해 쓰기 때문이다.
- 이미지 모델 격자 시트(Seedream 4×4, 7 크레딧)는 생김새는 일관됐지만 대기 1칸, 달리기 8칸이 같은 자세로 나왔다. 첫 칸을 기준 그림으로 쓰는 쪽이 남는다.

## 함정
- `4fecd1ba`는 이미 푸시돼 있었다(요약에는 푸시 전으로 적혀 있었다). amend 후 gc했다가 `origin/main`을 보고 알았다. `reset --soft`로 되돌려 새 커밋으로 넣었다. 228MB는 GitHub 기록에 남는다. 빼려면 기록을 다시 쓰고 강제 푸시해야 한다.
- 기록을 다시 쓰기 전에 `git ls-remote origin`으로 푸시 여부를 확인한다.

## 후속 작업 / 주의사항
- 강제 푸시로 228MB를 뺄지는 사용자가 정한다. 진우가 그림 저장소를 받았다면 다시 받아야 한다.
- 1010·1014: 영상 시트 한 장 비용을 잰 뒤 진행한다. #115 TID가 오면 발굴 3종 그림을 그린다.
- `asset-compression` 스킬의 마스터 반영은 확인을 받은 뒤 한다.
