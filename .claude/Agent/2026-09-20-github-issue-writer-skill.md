# github-issue-writer 스킬 신설 · 가챠 구슬 풀 제거 이슈(#30)

## 목적 / 배경

"자원(구슬) 뽑기를 빼자"는 판단이 나왔는데 **일감·기획 어디에도 기록이 없었다.**
기록된 것은 `item/README.md` 4장의 "아이템 풀(1번)은 테스트용으로 남는다" 한 줄뿐이었다.
서버에 확인받을 사안이라 이슈로 넘기려 했으나, **이슈 작성 규칙이 스킬로 없어**
매번 형식을 새로 정하고 있었다 — 그래서 스킬부터 만들었다.

## 변경 내용

- `.claude/skills/common/github-issue-writer/SKILL.md` — 신설. `CLAUDE.md` 공용 스킬 표에 등록
- 마스터(`~/.claude/skills/unity-project-setup/templates/skills/common/`)에 범용판 승격
- `tasks/T-031` · `tasks/README.md` — 구슬 풀 버튼 제거 항목 + 이슈 #30 링크
- 이슈 [#30](https://github.com/JeongTaeWoong99/Windows_simulator/issues/30) — 서버 확인 요청

## 주요 결정 / 근거

- **제목은 `[대상 영역 종류]` 꼬리표를 앞에 묶는다.** 기존 이슈는 `서버 요청 — …` 형태라
  목록에서 대상이 왼쪽에 정렬되지 않았다. **옛 제목은 고치지 않는다** — 알림이 다시 가고
  문서에 인용된 제목과 어긋난다.
- **assignee = 요청을 받는 쪽.** 기존 이슈 6건이 전부 그 관례였다(#13·#19·#27 ↔ #22·#25).
  사용자 표현("요청하는 사람")과 반대로 읽힐 수 있어 스킬 본문에 명시해 두었다.
- **assignee·label을 필수로 못 박았다.** 둘 중 하나라도 비면 알림이 가지 않아 이슈가 잊힌다.
- **구슬 풀을 서버에서 지우지 않고 화면에서만 뺀다** — `GachaServiceTest`가 아이템 풀 동작을
  쓰고, `GachaItemTable` 시트는 상자 개봉(6·7·8)이 공유한다. 서버 답을 기다리는 중이다.

## 후속 작업 / 주의사항

- ⏸ **기획 문서(`GameDesign/design/item/README.md` 4장 · `게임기획코어.md`)는 아직 안 고쳤다.**
  서버가 #30에 답하기 전에 "폐지"로 적으면 확정되지 않은 것이 확정으로 굳는다.
  답이 오면 "화면에서는 빼고 서버 테스트용으로만 남긴다"로 갱신한다.
- ⚠️ **`GachaItemTable` 시트를 지우지 않는다** — 상자 개봉이 같은 시트를 쓴다.
- 버튼 제거는 T-067(장비 3풀)의 클라 배선과 **함께** 한다. 따로 하면 인스펙터 줄을 두 번 짠다.
- T-031은 INDEX의 「🎨 뒤로 미뤘다」에 있는데 연출이 아닌 항목이 하나 들어갔다.
  #30 답이 오면 ▶ 구간으로 올린다.

## 업데이트 (2026-09-20) — 공 넘기기 절 추가 · 열린 이슈 3건 정리

- 스킬 3장 신설: **꼬리표 마지막 칸 = 지금 공을 쥔 쪽 = assignee**, 셋이 항상 일치한다.
  처리 후 되돌려 확인을 요청하면 `[서버 확인 → 클라 확인]`으로 칸이 늘고 assignee도 함께 바뀐다.
  구분자는 후보 넷(`=>` · `→` · 꼬리표 분리 · 현재 차례만) 중 **화살표**를 사용자가 골랐다.
- 열린 이슈 3건을 형식에 맞췄다. 내용은 모두 보존하고 배치만 바꿨다.
  - #27 `[서버 요청 → 클라 확인]` · assignee 클라 — 서버가 끝나 공이 넘어왔다. 핸드오프 코멘트 등록
  - #29 `[클라 완료]` · assignee 클라 · `enhancement` — **assignee가 비어 있었다**(알림이 안 간 상태)
  - #30 이미 형식에 맞아 손대지 않았다
- 스킬에 두 줄 보강: **닫힌 이슈 제목은 고치지 않는다 / 열린 것은 사용자가 지시할 때 일괄 정리**,
  **공을 넘겨받아 본문을 갱신할 때는 마무리 문장을 "확인되면 닫겠습니다"로 바꾼다**
  (#27을 고치면서 "확인 후 처리 코멘트 부탁드립니다"가 나에게 하는 말이 되어 어긋났다).
