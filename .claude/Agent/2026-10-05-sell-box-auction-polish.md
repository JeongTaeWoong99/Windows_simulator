## 주요 결정 / 근거
- **크래시 원인**: `GachaService.OpenBox`가 DB 스레드에 넘긴 리스트(`SaveItemChangesRepository`)에 `AddRange` → `Collection was modified` → 세션 끊김 → 클라 핑 15초 타임아웃 → 치명 오류 종료. 호출처 수정 + 저장소 생성자 복사 **둘 다** 했다(방어). 다른 호출처는 넘긴 뒤 읽기만 해서 안전.
- **상자 MaxStack 50 → 1000** (사용자: 방치해 두고 돌아와 확인하는 재미 — 대부분 버려지면 안 된다). `BoxOpenMax` 50은 유지 — 한 번에 여는 패킷·연출 크기 제한이라 별개.
- **경매 상한 = 절대 10조**(`Constants.AuctionMaxUnitPrice`) — `AuctionPriceBandMultiplier` 행을 이름째 바꿨다. 10조는 단가×수량×수수료가 long을 넘지 않는 선. 하한(즉시 판매가)은 되팔이 방지로 유지.
- **상자·기타 필터는 산업 드롭다운 끝에** 붙였다(별도 드롭다운이면 "농사+상자" 같은 늘 0건 조합). 거래소·경매 검색에는 넣지 않았다 — 경매 검색은 서버 필터라 서버 작업 필요, 거래소는 이름 검색만 있어 씬 UI 추가 필요.
- **장비 일괄 담기는 인챈트 등급도 범위 안이어야** — 일반 장비에 신화 인챈트가 붙은 것을 쓸어 팔지 않게.
- **[상자 제외] Toggle은 묶음(`Exclude Box Toggle`)에 붙였다** — 체크 칸에 두면 탭 전환 때 라벨만 남고, 글자를 눌러도 안 켜진다. 설정 화면 Toggle을 복제했으니 onValueChanged는 비웠다.
- 레벨 표시는 `이름 Lv27`(산업 레벨 `농사 Lv3`과 같은 꼴). 슬롯 목록은 `CharactersChanged`도 구독해 레벨업 때 갱신.

## 업데이트 (2026-10-06) — 생성물 줄바꿈 diff
- 원인: 생성기가 머리말 "\n" + 본문 AppendLine(CRLF)으로 써서 한 파일에 섞였고, autocrlf=true 환경에서 git이 내용이 같아도 "수정됨"으로 잡았다.
- 해결: `CodeGenUtil.WriteText`(LF 고정)로 쓰기 통일 + `.gitattributes`에 생성물 경로 `eol=lf`. 파이프라인 재실행 뒤 diff 0 확인.
- 지뢰: 생성물에 `File.WriteAllText`를 직접 쓰면 재발한다. 다른 PC는 첫 pull 뒤 한 번 생성물이 수정됨으로 보일 수 있다 — 그 경로를 `git add`하면 사라진다(내용 차이 없음).
