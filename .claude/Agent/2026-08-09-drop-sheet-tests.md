# 드롭 시트 실데이터 테스트 추가

## 목적 / 배경

- T-005 2단계의 남은 항목 — 산업 5종이 각각 6등급을 전부 낼 수 있는지,
  실측 분포가 시트 가중치와 맞는지 검증하는 테스트가 없었다. → `tasks/T-005-드롭테이블.md`

## 변경 내용

- `Server/WSGameServer.Tests/Common/DropSheetTest.cs` — 신규. 산업별 `[Theory]` 2종 × 5산업 = 10케이스
- `tasks/T-005-드롭테이블.md` — 2단계 테스트 항목·완료 조건 2 체크

## 주요 결정 / 근거

- **가짜 Row가 아니라 실데이터(`.bytes`)를 적재해 검증한다.** 추첨기 정확성은
  `WeightedPickerTest`가 이미 잡고 있고, 이 테스트의 몫은 "실제 시트가 기획 요구를
  지키는가"이므로 기존 `GameTableFixture.EnsureLoaded()`(TestUserBuilder.cs)를 재사용했다.
- **6등급 검증은 시트+`ItemTable` 조인으로, 분포 검증은 `RollMany` 실측으로** 갈랐다.
  전자는 데이터 성질, 후자는 롤 경로 성질이라 실패 시 원인이 바로 갈린다.
- **분포 허용 폭은 이항분포 5σ 식으로 뒀다.** 시드(42) 고정이라 결과는 결정적이지만,
  가중치를 조정해도 테스트를 고칠 필요가 없도록 리터럴 대신 통계 경계를 택했다
  (기대값은 시트 데이터에서 계산 — 추첨기 재구현이 아니라 동어반복 아님).
- 같은 `ItemTID`가 여러 행에 있으므로(레벨별 하위 혼입) 가중치를 아이템 단위로 합쳐 비교한다.
