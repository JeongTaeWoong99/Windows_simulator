# 경매장 2차 피드백 (T-147 4단계)

## 목적 / 배경
- 3단계 실측 뒤 사용자 피드백: 후보를 눌러도 이름이 안 들어간다 · 후보를 인벤토리 검색에도 · 그래프가 점으로 보인다(막대 + 선으로) · 조건 없는 '전체' 검색은 막자. 무엇을 했는지 → `tasks/T-147` 4단계.

## 주요 결정 / 근거
- **후보 목록을 `UI/Shared/SuggestView`로** — 경매장(공용 검색창 · 등록 창)과 인벤토리가 함께 쓴다. `Suggestion.Kind`는 int — 경매 코드는 `(EAuctionKind)`로 캐스팅(Shared가 MikaProtocol을 몰라도 되게). `git mv`로 옮겨 GUID 유지.
- 인벤토리 후보는 **등급·분류 조건과 상관없이 지금 탭 전부**에서 찾는다 — 고르면 이름 조건만 바뀐다.
- **그래프는 0부터 꽉 찬 막대(그날 평균) + 꼭대기를 잇는 선**(사용자 지정). 최저~최고 정보는 버렸다. 세로 범위는 0 ~ 최고×1.1을 1·2·2.5·3·4·5·6·8×10ⁿ 눈금으로 올린다.
- **조건 = 분류 또는 이름** — 등급·단가만으로는 서버가 여전히 전부를 훑으므로 조건으로 치지 않았다. 처음 열 때의 자동 조회도 같은 규칙(안내만).

## 겪은 함정
- **Selectable의 내비게이션이 None이면 눌러도 선택되지 않는다**(`OnPointerDown`이 nav None이면 `SetSelectedGameObject`를 안 부른다). 입력 모듈은 누를 때 선택을 비우므로 포커스가 null → "한 프레임 뒤 포커스가 목록 안이면 둔다" 판정이 실패해 클릭 전에 닫혔다.
  3단계 실측은 `onClick.Invoke()`로 해서 못 잡았다 → 이번엔 **선택 비움 → pointerDown → (다음 호출) click** 흐름으로 실측.
- **`Avg Line`에 `CanvasRenderer`가 없어 선이 처음부터 안 그려졌다** — 코드로 만든 Graphic. 또 막대보다 앞 형제라 막대 밑에 깔렸다 → 맨 뒤 형제로.
- **에디터 밖에서 씬 파일을 고치면(sed) "열린 씬이 외부에서 수정됨" 대화상자가 메인 스레드를 막는다** — unity CLI가 전부 타임아웃. '무시'로 닫았다(메모리 쪽 유지 — 다음 저장에서 Unity가 다시 쓴다). 씬 문자열은 에디터 안(eval)에서 고칠 것.
- 그래프 날짜가 오늘보다 하루 뒤로 보인 것은 버그가 아니다 — 서버 `GameTimeProvider` 오프셋(테스트로 하루 당김) 기준.

## 후속 작업 / 주의사항
- ⏸ 서버 이슈 — 경매 검색이 요청마다 판매 중 전부를 훑고 정렬 · 빈도 제한 테스트 3개 하드코딩(5회) 수정. 초안만, 등록 확인 대기.
