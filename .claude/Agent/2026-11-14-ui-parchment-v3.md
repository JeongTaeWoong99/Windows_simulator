# UI 양피지 3차 — 화면 점검 제안 12개 반영

## 목적 / 배경
- 사용자: 빠진 것·스타일이 다른 것·발전시킬 것을 캡처로 판단해 제안 → "다 진행해".

## 변경
- **특성 트리 선** — 판이 켜진 프레임엔 선 영역이 기본 100×100이라 선이 왼쪽 아래에 몰렸다. `TraitPresenter.LateUpdate`가 영역 크기가 바뀌면 다시 잰다.
- 특성 노드 — 잠김 자물쇠(`lockMark`) · 최대 레벨 금테(`maxMark`) · 고름 테두리는 파랑(Accent).
- 가독성 — 위젯 ⟳·↑ 흰 아이콘 → `TextDark` · 계정 `Lv` 글씨에 붉은 밑판 · 경매 검색 안내문 TextDark · 밝은 바탕 위 밝은 글씨 전수 점검(1곳 수정).
- 아티팩트 미발견 칸 — 그림 없는 자리 네모를 `SlotView.PlaceholderColor`(검정 30%)로 · `RarityPalette.Unknown` 갈색.
- 툴팁 — 판을 창으로(액자) · 제목 굵게 · 등급 줄 바탕을 판 색과 반쯤 섞음.
- 열 제목 3개 + 우편 — 붉은 리본 → 진갈 띠 · 왼쪽 정렬 · 굵게. 붉은 리본은 덮개 화면 제목에만.
- HUD — 계정·골드·하단 상태 줄을 테두리 있는 양피지 알약 상자로 · 숫자·제목 굵게.
- 빈 화면 — 경매 4곳·우편·시세에 빈 상자 아이콘(`ui_icon_empty`, `make_slots.py`로 그림) · 글씨 18.
- 하단 메뉴 5개 — 아이콘 아래 이름.
- 상점 카드 보유 수 글씨 14 → 18 굵게.

## 결정
- 그림 없는 칸 색은 프리팹 값을 믿지 않고 코드 상수로 — SlotView 프리팹 색을 바꿔도 플레이에 들어가면 메모리의 프리팹이 옛 값(CBAF80)으로 돌아와 반영되지 않았다(원인 미확정).
