# 특성 트리 화면 · 계정 레벨 표시 · 산업 레벨 선택 칸

→ 일감 `tasks/archive/T-068` · `tasks/archive/T-043` · 이슈 #29
→ 화면 구조는 `Assets/Scripts_Client/UI/Storage/Storage 규칙.md`("특성 화면") ·
  `State 규칙.md`("계정 레벨") · `Main 규칙.md`("배치는 축이 둘이다")

## 목적 / 배경

서버에 계정 레벨·특성 트리가 섰는데(2026-09-19 · T-021) 클라에 그것을 **보여 주거나 누를 자리가
하나도 없었다.** 특성 노드 45개가 정식 경로로는 하나도 찍히지 않았고, 산업 레벨 20개를 열어도
**클라가 `C_WorkStationAssignRequest.IndustryLevel`을 아예 안 채워** 쓸 데가 없었다
(서버가 0을 Lv1로 돌린다 — `ClientPacketHandler.cs:105`).

## 주요 결정 / 근거

### 특성 탭만 격자를 쓰지 않는다 — 예외를 하나로 묶었다

창고 네 탭 중 셋은 `StorageSlotSource`를 갈아 끼워 같은 격자가 그린다. 특성은 **칸 목록이 아니라
트리**라 공급자로 표현할 수 없다. 화면을 따로 두되 **예외가 번지지 않도록** 이렇게 묶었다 —

- **판정이 갈리는 곳은 `StorageTabPresenter.HasScreen` 한 군데뿐.**
  셋은 `grid.HasSource(tab)`, 특성은 `traitScreen != null`.
- **여닫는 일은 각 Presenter가 스스로 한다.** 탭 줄이 "특성 탭에서 꺼질 것" 목록을 들면,
  화면을 하나 더할 때마다 탭 줄을 고쳐야 한다. 지금 스스로 꺼지는 것은 셋(도구 줄·격자·판매 목록).

### 트리의 모양을 데이터에서 파생시켰다 — TID 공식을 클라에 베끼지 않았다

서버 규칙은 `2000 + 산업×100 + 레벨`(레벨) / `3000 + 산업×100 + 단`(속도)이다. 이걸 클라가 알면
**엑셀이 바뀌는 날 조용히 어긋난다.** 대신 `UserTraitTableRow.EffectType == SpeedAdd` 인가로 구역을
가르고, `Industry`로 열을 가르고, TID 오름차순으로 줄을 세운다.

### 선은 노드 프리팹이 들고 있다 — 선 그리는 코드가 없다

"러프하게, 선으로만 이어 달라"는 요구에 가장 싼 답. 노드 위쪽의 `Link Image`가 격자 세로
`spacing`(20px)만큼 위로 뻗고 **각 열 첫 줄에서만 꺼진다.**

> ⚠️ **격자 세로 `spacing`과 `Link Image` 높이는 같은 값이어야 한다.** 어긋나면 선이 뜨거나 겹친다.
> 둘은 서로 다른 곳(씬의 `Content` / 프리팹)에 있어 컴파일로 잡히지 않는다.

### 산업 레벨은 슬롯마다 따로다 — 전역 일괄이 아니다

서버가 `t_user_workstation_slot.industry_level`에 슬롯별로 저장한다(`User.WorkStation.cs:226`).
**해금해도 이미 배치된 칸은 안 바뀐다** — 그 칸에서 다시 고르는 것이 정식 경로다.
그래서 UI도 "전역 표시 갱신"이 아니라 **슬롯 세팅 화면의 선택 축**으로 넣었다.

## 후속 작업 / 주의사항

- 🔴 **해제 요청에는 산업 레벨을 `1`로 보낸다.** 해제는 산업이 `None`으로 가는데 `None`에는
  Lv2 이상이 없어, 고른 레벨을 그대로 실으면 서버가 `IndustryLevelLocked`로 거절한다.
  "고른 값을 그대로 보낸다"가 통하지 않는 유일한 경로다 — 지우면 해제가 조용히 실패한다.
- 🔴 **효율 계산의 전역 배수 역산이 이제 실제로 틀릴 수 있다.** 속도 특성을 찍을 수 있게 되어
  그 몫까지 배수로 보인다. 클라에서 고칠 방법이 없다 → `tasks/T-055`(서버).
- ⚠️ **`ServerPacketHandler.cs`는 `Scripts_Server/` 아래 있지만 클라 담당**이다(커밋에 포함).
- ⚠️ **계정 곡선의 `RequiredExp`는 `long`**(캐릭터의 8배). `GameDataLoader`에 캐릭터용(`int`)과
  **별개 함수**로 두었다 — 합치면 넘치는 쪽이 조용히 잘린다.
- ⚠️ 특성 화면은 씬에 **켜진 채로 저장**돼 있고 `Start`에서 스스로 끈다. 꺼진 채 저장하면
  `Start`가 영영 안 돈다(도구 줄과 같은 함정).
- **서버 파일의 낡은 주석** — `WorkStationSlot.cs:55`가 산업 레벨의 저장·패킷·해금 검증을
  "미구현(T-017)"이라 적고 있는데 셋 다 구현돼 있다. 담당이 달라 고치지 않고 이슈 #31에 알렸다.
- **치트 「해금」으로 특성 노드를 열면 포인트가 안 빠진다** — 이슈 #31(서버). 검증은 트리에서
  직접 찍어서 한다. 클라 치트창은 서버가 방향을 정한 뒤에 맞춘다.

## 씬 작업 방법 (다음에 또 할 사람용)

씬·프리팹은 `unity cmd eval_file`로 **에디터 C#을 스크래치패드에서 실행**해 지었다
(CLI 단일 명령을 수십 번 쌓는 것보다 RectTransform·레이아웃 값이 정확하다).

- ⚠️ `eval`/`eval_file`은 **코드를 메서드 본문에 감싸므로 `using` 지시문을 쓸 수 없다.**
  `UnityEngine`·`UnityEditor`·`System.Collections.Generic`은 이미 열려 있고,
  `UnityEngine.UI`·`TMPro`·`UnityEditor.SceneManagement`는 **전부 정규화해 적는다.**
  로컬 함수 선언도 막혀서 `System.Func<>`/`System.Action<>` 람다로 헬퍼를 만든다.
- `UnityEngine.Object.DestroyImmediate` — `Object`만 쓰면 `object`와 모호하다고 거절당한다.
- 각 스크립트 머리에 **"이미 있으면 throw"** 를 넣어 두면 중복 실행이 안전하다.

## 업데이트 (2026-09-21) — 계정 경험치를 원형 진행도로

실측에서 기능은 모두 정상이었고 **상태 패널 배치만 물렸다.** 가로 띠를 줄 아래 깔면서 43px을
위아래로 나눴더니 재화 줄이 눌렸다. 사용자가 씬에서 `Profile Panel`을 끄고 `Lv Text`를
`Nick Image` 아래로 옮겨 둔 상태에서 이어받았다.

### 바꾼 것

**줄을 건드리지 않고 `Nick Image` 안으로 넣었다.** 가로도 세로도 나눠 쓰지 않는다.
`Exp Bar`·`Profile Panel`·`Right Column`/`Top Row` 껍데기를 걷어내고 원래의 가로 한 줄로 돌아갔다.

### 🔴 고리는 스프라이트가 아니라 세 겹이다

프로젝트에 **고리 스프라이트가 없다.** 그래서 원반 두 장을 겹치고 **가운데를 작은 칸이 덮는다** —

| 층 | 무엇 |
|---|---|
| `Nick Image` 자신 | 검은 원반(`Knob`). 고리의 **빈 구간 색**이다 |
| `Exp Ring Fill` | 같은 원반 + `Filled`·`Radial360` |
| `Nick Icon (임시)` | 6px 들여 그린 작은 원 — **가운데를 덮어 원반을 고리로 만든다** |

- **`Nick Icon (임시)`을 지우면 진행도가 고리가 아니라 파이 차트가 된다.** 자리표시자처럼
  보이지만 **모양을 만드는 부품**이다. 비워 둘 수 없다.
- **형제 순서가 곧 층이다** — 진행도 → 아이콘 → 문구 → `Lv Text`. 순서를 바꾸면 고리가 덮인다.
- `Nick Image`만 다른 재화 아이콘과 달리 `UISprite`가 아니라 `Knob`이고, 색도 짝이 되는
  글자색이 아니라 **검정**이다(그 색이 고리의 빈 구간이라서). `State 규칙.md`에 예외로 적었다.
- `Percent Text`는 21px 원 안에서 안 읽혀 **껐다. 배선은 살아 있다** — `StatePresenter`가
  꺼짐 여부를 분기하지 않으므로 켜면 바로 그려진다.

### 코드는 안 고쳤다

`Image.fillAmount`는 `Horizontal`이든 `Radial360`이든 같은 필드다. **`RefreshAccountLevel`은
한 줄도 안 바뀌었고** 툴팁·주석만 새 구조에 맞췄다 — 표현을 바꿔도 코드가 안 바뀌는 자리였다.
