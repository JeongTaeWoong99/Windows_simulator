# 슬롯 배치 리스트에 산업 레벨 표기 (T-080)

## 목적 / 배경

작업슬롯 목록에서 Lv1과 Lv5가 똑같이 보여 **칸을 눌러 세팅 화면까지 들어가야** 레벨을 알 수 있었다.
배경·완료 조건은 → `tasks/T-080-슬롯리스트산업레벨표기.md`.

## 변경 내용

- `Assets/Scripts_Client/UI/Main/WorkStationListPresenter/WorkStationSlotView.cs` — `Bind`의 한 줄 라벨에
  `산업 Lv{n}` 한 조각 추가. 서버·패킷·프리팹 변경 없음.
- `Assets/Scripts_Client/UI/Main/Main 규칙.md` — "배치는 축이 둘이다" 절에 목록 칸 표기 규칙.

## 주요 결정 / 근거

- **표기 형태는 `Lv{n}`만, 산업 바로 뒤에 붙인다**(2026-09-23 사용자 결정). 기각한 안:
  - `Lv2 저수지` — `IndustryLevelTable.Name`이 최대 6자(`신성한 대지`)다. `Slot Text`는
    **TMP 오토사이징(`fontSizeMin: 1`)** 이라 한 줄이 길어진 만큼 글자가 조용히 작아진다.
    잘리지 않으니 **레이아웃이 안 깨진 채로 읽기만 나빠진다** — 눈치채기 어려운 열화다.
  - 산업명을 레벨 이름으로 교체(`낚시` → `저수지`) — 길이는 그대로지만 **산업이 화면에서 사라져**
    목록에서 산업별로 훑기가 어려워진다. 이름 25개(5산업 × 5레벨)를 외우고 있어야 읽힌다.
  - 별도 배지 TMP — 정식 모양에 가깝지만 프리팹·레이아웃 작업이 붙는다. 🎨 리소스가 올 때 같이 한다.
- **`·`로 가르지 않고 `낚시 Lv2`로 붙인 이유** — 구분점으로 나누면 네 조각(`슬롯·산업·캐릭터·속도`)
  사이에 다섯 번째가 끼어 **무엇의 레벨인지가 모호**해진다.
- **레벨 0이면 적지 않는다.** 서버 기본값이 1이라 올 일이 없지만, 오면 `Lv0`이라는 없는 값을
  화면에 적는 것보다 빼는 쪽이 낫다.

## 후속 작업 / 주의사항

- **`IsRunning == false` 경로(`슬롯 N · 대기`)는 일부러 손대지 않았다** — 산업이 `None`이라 레벨에 의미가 없다.
  여기에 레벨을 넣으려 하면 `None`의 레벨을 화면에 적는 셈이 된다.
- 세팅 화면의 레벨 버튼은 여전히 `IndustryLevelTable.Name`을 쓴다(`WorkStationSelectPresenter.RefreshIndustryLevelButtons`).
  **목록과 세팅이 일부러 다른 표기**이므로 한쪽에 맞추려 들지 않는다 — 근거는 `Main 규칙.md`에 적어 뒀다.
- 실측(레벨 교체 → 목록 복귀 즉시 반영)은 사용자 확인 대기 중.
