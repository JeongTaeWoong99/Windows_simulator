# 일감 art/·later/ 폴더 + 사이트 이슈 할당자 표시

## 목적 / 배경
- 남은 일 목록에 🎨 아트만 남은 클라 일감과 먼 훗날 할 서버 일감(T-004 등)이 섞여 보였다.
- 문서 사이트(wsdocs) 홈의 GitHub 이슈에 할당자가 보이지 않았다.

## 변경 내용
- `tasks/art/`(🎨만 남음) · `tasks/later/`(먼 훗날) 신설 + 각 `README.md`. 클라 T-031·T-015·T-052·T-039를 `art/`로 `git mv`하고 링크를 고쳤다.
- `tasks/README.md` 🎨 표에서 네 건을 빼고 두 폴더를 안내한다. `task-writer`·`task-reader` 스킬, 루트 `CLAUDE.md` 폴더 표를 갱신했다.
- 사이트 0.3.0 — 로더가 폴더별로 `bucket`(open·art·later·done)을 매긴다. 홈·보드는 `open`만 보여 주고, 두 폴더는 `/tasks` 보관 위의 접힌 칸에 둔다. 이슈 카드에는 할당자 칩을 붙였다(없으면 `미할당`).

## 주요 결정 / 근거
- `later/`는 비워 두었다. 서버 담당 일감은 클라가 옮기지 않고 이슈로 요청한다(사용자 결정).
- ⏸ 일감은 폴더로 빼지 않는다. 재촉할 대상이 목록에서 사라지기 때문이다.
- T-051(공용·문서)은 아트가 아니라서, T-033은 기능 항목이 남아서 루트에 두었다.

## 후속 작업 / 주의사항
- 서버에 `later/` 이동 요청은 사용자가 직접 이슈로 올린다(푸시 후).
- 스킬 변경은 프로젝트 고유 규칙이라 툴킷 마스터에는 반영하지 않는다.
