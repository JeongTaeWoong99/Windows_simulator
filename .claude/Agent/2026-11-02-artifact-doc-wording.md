# 아티팩트 칸 표기를 인벤토리 장비 탭으로 정리 (#86)

## 목적 / 배경
- 이슈 #86(10-24)은 "인벤토리에 아티팩트를 두지 않는다"로 문서를 고쳤는데, 다음 날 "장비 탭에서 장비와 같이 다룬다"(#87)로 뒤집혔고 T-188에서 장비 칸과 한 격자가 됐다. 남은 옛 표기를 정리했다.

## 변경 내용
- 기획 `유물감정.md`(상태 줄 · 결정 체크리스트) · 목업 2개 안내 문구 · `Server/docs/경매장.md` · T-181 "정한 것" · 서버 주석 → 커밋 `6d3e1a58`

## 주요 결정 / 근거
- 용어는 **"아티팩트 칸(인벤토리 장비 탭)"** 으로 통일 — 저장은 여전히 `EStorageTab.Artifact` · `t_user_artifact_stack`이라 "칸"이라는 이름은 남기고 위치만 밝힌다.
- 새 일감을 만들지 않고 T-188에 붙였다 — 한 대화로 끝나는 표기 정리라 일감 감이 아니다.
- `Server/GameData/Constants.cs`의 `ArtifactMaxStack` 주석은 엑셀 생성물이라 손대지 않았다 — 고치려면 `Constants.xlsx` 설명 칸에서.

## 후속 작업 / 주의사항
- `MikaProtocol` 빌드 때 `Assets/Plugins/Analyzers/MikaSourceGen.dll`도 바뀌어 나오는데 코드 변경이 없으면 되돌린다(이번에도 되돌림).
