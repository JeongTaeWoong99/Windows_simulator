# 문서·스킬 토큰 효율화 + 구조 점검

## 목적 / 배경

문서 품질은 좋은데 **읽히는 방식**이 비효율적이었다. 낭비는 두 축의 곱이다 —
`(한 번 읽는 비용) × (읽히는 횟수)`. 크기만 줄이는 접근으로는 절반밖에 못 잡는다.

## 변경 내용

파일 단위 변경은 diff가 말한다. 여기엔 **어디를 건드렸는지의 지도**만 남긴다.

- 트리거: `agent-log-reader`·`game-design-reference`·`task-reader`의 `description`, 루트 `CLAUDE.md` 스킬 표
- 분할: `UI 규칙.md` → `+ UI 배치 현황.md` / `서버 동작 이해.md` → `+ 패킷 레퍼런스.md`
- 압축: `.claude/Agent/README.md` (20.8 → 10.7KB)
- 전역 마스터(`~/.claude/skills`): `clean-code-style` 분할 + `unity-skill-sync` 비교 범위 확장 — 커밋 `4ae2c00`·`6f89c7d`·`d3a0944`·`cc19826` (push 안 함)
- 서버·기획 폴더는 **한 줄도 수정하지 않았다** — 권고안을 문서로 썼다가 저장소에 두지 않기로 하고
  삭제했다. 사용자가 그 내용을 이슈로 옮긴다.

## 주요 결정 / 근거

- **스킬 발동을 정하는 건 `CLAUDE.md` 표가 아니라 `SKILL.md` frontmatter의 `description`이다.**
  표에 "필요할 때만"이라 적어도 `description`에 "모든 코드 작업 착수 시"가 있으면 항상 열린다.
  → 오타 한 글자 고쳐도 20.8KB INDEX를 먼저 읽고 있었다.
- **`agent-log-writer`의 "항상"은 그대로 뒀다** — 안 읽으면 나중에 읽으면 되지만
  안 쓰면 맥락이 영영 사라진다. 비용이 비대칭이면 무조건이 맞다.
- **스킬은 발동하면 `SKILL.md`가 전문 로드된다.** 앵커 목차로는 1바이트도 안 준다.
  줄이려면 내용을 파일 **밖으로** 빼야 한다. (일반 md 문서는 해당 없음 — 목차만으로도 효과가 있다)
- **하이브리드 분할** — 규칙 요지는 `SKILL.md`에 남기고 예시·근거만 뺀다.
  9개 장을 9개 파일로 쪼개면 `= null!` 같은 **상시 규칙이 "파일 안 열면 무시"** 상태가 된다.
- **nullable 규칙은 통합하지 않고 중복으로 뒀다.** 전역 스킬에 프로젝트 링크를 넣으면
  다른 프로젝트에서 깨진다 — **결합 비용 > 중복 비용.** (Phase 4-b, 실제로 저지르고 롤백)
- **`서버 동작 이해.md`·`UI 규칙.md`는 경로를 유지하고 새 파일을 떼어냈다.**
  원본 이름을 지키면 기존 링크가 안 깨진다.
- **공용 스킬 2개(`game-design-reference`·`excel-table-creator`)는 직접 고치지 않았다** —
  사용자 지시. 권고 문서에만 적었고 `tasks/` 등록도 하지 않았다.

## 후속 작업 / 주의사항

- ⚠️ **`Assets/Scripts_Client/패킷 레퍼런스.md`의 `.meta`가 아직 없다.**
  유니티 에디터를 한 번 켜서 생성한 뒤 원본과 함께 커밋한다.
- ⚠️ **분할한 파일은 그 파일을 다루는 자동화도 같이 봐야 한다.**
  `unity-skill-sync`가 `SKILL.md` 하나만 비교하고 있어서, 새로 뗀 `스타일 상세.md`·`nullable 상세.md`는
  어긋나도 영영 안 드러날 뻔했다. 이번에 마스터에서 고쳤다.
- ⚠️ **"참조가 없다"는 판정은 세 방식으로 틀린다** — ① 씬·프리팹의 GUID 참조
  ② 확장 메서드(호출부에 클래스명이 안 나온다) ③ 어트리뷰트 등록(호출부가 없는 게 정상).
  후보 4건 전부 오진이었고 **삭제한 파일은 없다.** 이름 grep으로 파일을 지우면 안 된다.
- **분할하면 총량은 오히려 는다** (19.6→23.5KB, 21.1→23.9KB). 줄이는 건 한 번에 읽는 양이다.
  디스크가 아니라 컨텍스트를 아끼는 작업이라는 걸 다음 사람이 오해하지 않도록.
- 전역 툴킷 저장소 커밋 4건은 **push하지 않았다** — 사용자가 직접 한다.
- 서버·기획 쪽 권고 대상(실측): `game-design-reference` 11.9KB · `excel-table-creator` 9.7KB ·
  `GameDesign/design/` 대형 문서(기획평가 47.8KB 등) · `tasks/README.md` 9.2KB.
  **서버 스킬 4종은 이미 조건부 `description`이라 손댈 것이 없다.**
