# 버튼 글씨 크기 3단 · 등급 바탕 A+B · 제목 폰트 Fantasy Warrior · 저주곰 마수

## 목적 / 배경
- 사용자: 인벤토리 도구 줄 · 산업 레벨 버튼 글자가 너무 작고 테두리에 닿는다 · 탭 글자가 테두리에 닿는다 · 작업슬롯 칸 글씨가 틀에 닿는다 — 폭·크기·여백 다시 점검.
- 사용자: 등급 프레임은 시안 A(입체 테두리)에 B(아래 계단빛)를 섞는다 · 제목 폰트는 추천대로 · 몬스터는 곰 형태 2족보행 마수.
- 사용자: 전·후를 새 폴더에 찍어 비교 · 작업슬롯 배치 화면 비주얼 발전안 HTML 몇 개.

## 변경 내용
- 버튼 글씨 — 씬 · 프리팹 일괄(에디터 C#). `ui_button` 바로 아래 꽉 찬 글씨: 높이 34 이하 16 고정 · 46 이하 22 고정 · 그 위 자동 최대 = 높이 − 22.
- 인벤토리 도구 줄 폭 다시 나눔(합 537/539) · 드롭다운 화살표 16으로 · 라벨 오른쪽 24.
- 산업 레벨 버튼 두 줄(`GetIndustryLevelName(.., separator)` — 버튼 "\n", 툴팁 " ") · 줄 46→74 · 글씨 15.
- `SlotView` 이름·개수·아이콘·적성 띠·표시들을 등급 테두리(8) 안으로 · `WorkStationSlotView` 루트 여백 5→10 · 머리·발 글씨 13→15.
- 그림 저장소: `rarity_bg` A+B(입체 테두리 · 아래 4단 계단빛 · 속 검정 반투명) · 9-slice 8→12(`ArtImportPostprocessor`도) · `claude-ursabeast/` 추가 · `claude-thornboar/` 삭제.
- 폰트: `FantasyWarrior SDF`(33pt · 4096×2048 · 완성형 2,350 + 라틴 · 폴백 Galmuri EN) — 제목 띠 Title 글자 6곳 · 단어 간격 −55.
- 바탕화면 `UI 전후 비교 2차/` — 전·후 · 비교 8장 · 저주곰 gif 3 · 크기 비교 · `작업슬롯배치_비주얼_발전안.html`(A 정돈 · B 무대 미리보기 · C 단계식 · D 2열).

## 주요 결정 / 근거
- 자동 크기(1~40)를 끈다 — 같은 줄 버튼마다 글자 크기가 달랐고(15·17·19) 좁은 버튼에서 한없이 줄었다. 글자가 안 들어가면 폭을 늘린다.
- 도구 줄은 17이면 11px 넘쳐 16으로 — 갈무리 16에서 한글 한 자 ≈ 16.
- 등급 속을 검정 반투명으로 — 검정은 등급색을 곱해도 검정이라 그림 한 장 + 색 곱하기 구조를 지키면서 속이 등급마다 같은 어둠이 된다.
- 제목 폰트는 Fantasy Warrior(가장 중세다움) — CC-BY 4.0이라 크레딧 표기 필요. 2048² 아틀라스엔 204자가 빠져 4096×2048.
- 곰의 가까운 팔은 따로 그려 외곽선을 두른다 — 같은 털빛으로 한 장에 칠하면 몸에 묻혀 통나무처럼 보였다.

## 후속 작업 / 주의사항
- 출시 크레딧에 "Fantasy Warrior Font by Douglas Vautour (Burpy Fresh), CC-BY 4.0"을 넣어야 한다.
- 저주곰은 TID(`Character.xlsx` 행 · 진우)가 있어야 굽는다.
- 상단 바 골드·계정 글자도 `ui_header` 아래라 처음 일괄에서 제목 폰트가 붙었다 — 되돌렸다. 일괄은 이름에 `itle`이 든 글자만 바꾼다.
- `ItemIconView` · `CharacterStateRowView` · `EquipPickRowView` · `WidgetMiniSlotView`의 안쪽 여백은 이번에 보지 못했다(9-slice 12로 테두리 모양만 바뀜).
