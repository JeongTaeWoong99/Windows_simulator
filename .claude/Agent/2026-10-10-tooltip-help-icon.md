# 툴팁 두 종류 — 대상 툴팁 · 도움말 아이콘

## 목적 / 배경
- 사용자 요청: 기능 설명·확률처럼 내용이 많은 툴팁은 **알아볼 수 있는 아이콘**에 올려서 보게 하고,
  버튼 같은 간단한 것은 그 위에 올리면 짧게 뜨게 — 두 종류로 나눠 지금 툴팁을 전수 조사해 맞춘다.

## 변경 내용
- `Assets/Prefabs/HelpIcon.prefab`(신규) — 22×22 원(`UI/Skin/Knob`) · `Accent` 바탕 · `?`(`TextDark`) · `TooltipTrigger`
- 뽑기 카드 프리팹 — `[P]` 배지 삭제 → 제목 바로 오른쪽 `Help Icon` (`rateTrigger`가 가리킴) · 제목 flexW 0
- 인챈트 — `Rule Text (TMP)`의 트리거 삭제 → `Rule Row`(HLG) = 문구 + `Help Icon` · 문구 꼬리 "(올리면 규칙·확률)" 삭제
- 문서: `Overlay 규칙.md` "툴팁 두 종류"(기준 표 + 전수 조사 표) · `UI 규칙.md` · `Shared 규칙.md` · `Market 규칙.md`

## 주요 결정 / 근거
- 기준은 **무엇을 설명하나** — 올린 그것 자체(이름표·수치 뜻·칸/줄/레벨 정보) = 대상 툴팁, 기능·규칙·확률 = 도움말 아이콘.
- **산업 레벨 버튼은 확률이 들어 있어도 대상 툴팁으로 남겼다** — 고르기 전에 레벨끼리 비교해야 하고,
  세팅 단계에서 레벨 버튼을 누르는 것이 곧 서버 변경 요청(`RequestIndustryLevelChange`)이라 아이콘 하나로 모으면 비교할 수 없다.
- 전수 조사 결과 기능 설명이 대상에 걸린 곳은 둘뿐(뽑기 `[P]` · 인챈트 규칙 문구) — 나머지 13곳은 대상 툴팁이 맞다.
- 아이콘 그림은 임시(내장 Knob) — 🎨 아트가 오면 프리팹 그림만 바꾼다.

## 후속 작업 / 주의사항
- 새 화면에 기능 설명이 필요하면 `HelpIcon` 인스턴스를 제목 옆에 두고 Presenter가 `SetProvider`로 내용을 넘긴다.
- 도움말 아이콘을 새로 달 만한 후보(이번에 안 함): 경매장 거래소/매물 차이 · 특성 화면 · 응축 — 사용자가 고르면 일감으로.
