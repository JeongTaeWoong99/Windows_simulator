# 작업슬롯 칸 B안 · 장비 고르기 A안 · 장착 칸 B안 · PR #120·#122 머지

## 목적 / 배경
- 사용자: 발전안 HTML에서 ① 작업슬롯 칸 B(무대 강조) · ② 장비 고르기 A(비교 목록) · ③ 장착 칸 B(이름표 띠)로 결정.
- 사용자: PR #120·#122 처리 · 폰트·아티팩트 확인 · ugui-mvp 스킬은 일반화해서 마스터 반영.

## 변경
- ① `WorkStationSlotView.prefab`: 머리·발 줄을 `ignoreLayout`으로 무대 위에 띄워 무대가 칸 전체 · 위·아래 그늘(검정 반투명) · 배율은 빨간 리본(`Speed Ribbon` — 글자 폭을 따라감). 코드 변경은 머리 주석뿐.
- ② `EquipPickRowView`: 오른쪽 `Delta Text` — 지금 낀 것 대비 이 산업 속도 차이 ▲/▼/= · `WorkStationSelectPresenter`: 이 산업에서 많이 오르는 순 정렬 · 이 산업 전용 효과는 금색 · 위에 `Current Text` '▶ 목검 · 전산업 +5%'(빈 칸은 '비어 있음').
- ③ 장착 칸 4개: `Part Ribbon`(구리 버튼 그림 · 테마 Button) 안에 부위 이름 · 바탕을 `RaritySkin`(등급 그림) · 아이콘 줄 34 → 44.
- 비교값은 `SpeedAddPermille` 중 지금 고른 산업에 붙는 것만 — 전 산업은 늘 붙는다(서버 계산과 같은 축).
- PR #122 머지 · PR #120은 main과 충돌(`Enum.xlsx`·`Gacha.xlsx` 다른 시트 · 일감 문서)을 워크트리에서 풀고 파이프라인 재생성 · 서버 테스트 1,368 통과 · CI 통과 뒤 머지.
- 이슈 #121·#112 닫음 · T-193·T-198 보관.
- 툴킷 마스터 `ugui-mvp`: "테두리 그림(9-slice 틀)을 깐 상자는 padding = 테두리 두께 + 틈 2" (커밋 안 함).
