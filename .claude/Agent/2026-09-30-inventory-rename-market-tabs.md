# 2026-09-30 창고 → 인벤토리 개명 · 거래 열 탭 3개 (T-101)

## 요약
- 왼쪽 열 STORAGE → INVENTORY. 클라 폴더·클래스·enum·필드·씬 오브젝트·문구를 전부 `Inventory`/'인벤토리'로.
- 거래 열에 탭 3개(뽑기·경매장·창고). `MarketTabPresenter`가 버튼↔화면(page)을 짝지어 켠다. 경매장·창고는 `(기능 없음)`.

## 결정 / 이유
- **전면 개명**을 골랐다 — 거래 열에 별개의 '창고'가 생겨, 코드에 `Storage`(=인벤토리)가 남으면 두 창고가 섞인다. 새 탭 코드 이름은 `Warehouse`.
- 서버 소유 이름(`StorageFull`·`StorageCapacity`)은 그대로.
- 거래 탭은 인벤토리 탭과 달리 **화면을 따로** 둔다 — 격자 하나로 갈아 끼울 만큼 모양이 같지 않다.
- 기능 없는 탭도 누를 수 있게 뒀다 — 설정 화면의 `(기능 없음)` 표기와 같게.

## 함정
- ⚠️ `[FormerlySerializedAs]`는 **도메인 리로드에서는 안 먹는다** — 리컴파일 직후 필드가 전부 null로 보였다. 씬을 디스크에서 다시 열자(`OpenScene`) 이어졌다. 씬이 dirty가 아닐 때 해야 안전하다.
- `Test Copy` 씬이 옛 필드 이름을 가질 수 있어 attribute는 남겨 둔다.
- 일괄 치환은 `newline=''`로 읽고 써야 CRLF 파일이 통째로 바뀌지 않는다.

## 후속 작업 / 주의사항
- 기획 문서(`GameDesign/design/` 7개)는 아직 인벤토리를 '창고'라 부른다 — 기획과 용어 정리(T-101에 남김).
- 플레이 확인 남음.
