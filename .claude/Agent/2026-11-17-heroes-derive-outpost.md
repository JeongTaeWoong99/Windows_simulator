# 발굴·벌목 캐릭터 4종 · 거점 지도

- T-174(1014 나무꾼 · 1032 탐험가 · 1033 드워프 · 1034 보물 사냥꾼)와 T-191(거점 바닥 + 건물 5채)의 그림을 Unity AI 크레딧 없이 만든다.
- 미리보기는 바탕화면 `아트 레퍼런스/_미리보기/`(저장소 밖). 사용자가 파생 4종을 승인("있는 거에서 바리에이션만 바꾼 거")하고 보스풍 v6(화염 군주·심연의 눈 사제)와 함께 게임에 넣으라고 했다.

## 주요 결정 / 근거
- **캐릭터를 코드로 처음부터 그리는 길(make_heroes.js, 1~4차)은 버렸다.** 사용자 반려: "짜리몽땅" → "다리가 몸통이랑 따로 논다 · 비율이 이상" → "아직도 별로". 막대 다리·글자 지도 몸통으로는 지금 게임 캐릭터(AI 원본 도트)의 비율·걸음을 못 따라간다. codixel 스킬도 달리기·공격은 "맞지 않는 것"으로 적고 있다.
- **지금 게임 캐릭터 시트에서 파생한다**(`Art/_source/characters/claude-heroes/derive_heroes.py`). 견습 나무꾼 → 나무꾼, 견습 발굴꾼 → 탐험가, 숙련 채굴꾼 → 드워프·보물 사냥꾼. 같은 화풍·같은 키·같은 동작이 그대로 온다.
  - 색 영역: 외곽 · 금속(채도 < 0.12) · 붉은 셔츠 · 피부 · 카키 · 갈색. 카키 덩어리 중 위끝이 y ≥ 67이면 바지. 카키의 어두운 그늘은 갈색으로 분류되므로 옷 영역을 그쪽으로 3번 키운다.
  - 머리 자리 = 가장 위 피부 덩어리. 팔을 머리 위로 든 프레임은 손을 고르므로 `FACE_FIX`에 눈으로 읽은 자리를 둔다.
  - 얼굴 위 영역은 갈색·카키 모두 머리카락·모자로 본다(밝은 모자가 카키로 분류돼 셔츠 색이 묻었다).
  - 금속은 8픽셀 이상 덩어리(도구 날)만 바꾼다 — 옷의 작은 회색 점이 금으로 바뀌었다.
- 거점(`Art/_source/environment/claude-outpost/make_outpost.py`)은 섬을 버리고 숲속 마을 + 판타지 중세 건물(UI 색: 양피지·진갈·붉은 깃 `#A13732`·금). 사용자 "아까보다 괜찮네". 개울이 상회 벽을 지나던 것을 옮겼다.

- **넣기:** 파생 4종은 `derive_heroes.py --sprites` → `sprites/<키>_<동작>_NN.png`(왼쪽을 본다 · `sourceFacesRight` 끔). 보스 2종은 v6 생성기를 `claude-bosses/make_bosses.js`로 옮기고 raw 프레임을 `sprites/`로(오른쪽을 본다). 레시피 6개를 `unity cmd eval`로 만들고 `ArtBaker.Bake`(internal — 리플렉션)로 굽고 `ArtCatalogSync.Sync` → 캐릭터 36. 드워프 상반신·머리 크롭은 숙련 채굴꾼 값에서 y −5, 보물 사냥꾼은 그대로. 보물 사냥꾼 배율 0.85 → 0.9(기준과 같게).
- **보스 2종은 새 TID**(1035 화염 군주 전설·사냥 9 / 1036 심연의 눈 사제 영웅·마물·사냥 7) — 서버·데이터라 main에 넣지 않고 PR #127 + 확인 이슈 #128(진우). 보조 적성·뽑기 가중치는 같은 등급 선례(#115).
- **표준(사용자 지시):** 새 캐릭터는 확실한 기준(지금 게임 캐릭터 등)에서 조금씩 바꿔 만든다 → `Art 규칙.md` "새 캐릭터 만들기".

- 거점은 아직 `Assets/Art/outpost/`에 굽지 않았다(사용자 "아까보다 괜찮네" · 게임 반영 지시 없음).
