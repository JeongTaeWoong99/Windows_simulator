# 문서 그래프 -Fix가 한글 문서 이름을 지킨다 (T-090)

## 목적 / 배경
- `check-doc-graph.ps1 -Fix`가 README 문서 이름을 영문 폴더명(`trade`)으로 써서 블록 19개를 덮어썼다 → `tasks/archive/T-090-문서그래프Fix이름.md`

## 주요 결정 / 근거
- **이름의 1순위는 블록에 이미 적힌 이름(다수결)** — 기준 이름은 개명 전 한글 폴더명(`자원채취`·`게임UI`·`진행 및 성장`)인데, 문서 제목은 `자원 채취`·`게임 UI`처럼 띄어 써 있어 제목만으로는 못 맞춘다. 제목은 블록에 아직 안 나온 새 문서용 2순위다
- **이미 맞는 블록은 `-Fix`가 건너뛴다** — 이름을 고친 뒤에도 8개 문서가 줄바꿈 위치만 바뀌었다(사람이 한 줄에 7개씩 접어 둠, 스크립트는 6개). 링크 집합이 같으면 다시 쓰지 않는다

## 후속 작업 / 주의사항
- 새 시스템 README를 만들면 제목 `# NN. <이름> (English)`에서 이름을 뽑는다 — 다른 블록에 한 번 불리면 그 뒤로는 블록 이름이 이긴다. 이름을 바꾸려면 블록들을 함께 고친다
