# 테마 상자 6종에 캐릭터 보상 추가

## 목적 / 배경
- #117에서 태웅이 상자를 1만 번씩 굴려 봤는데 캐릭터가 한 번도 안 나왔다. 서버 코드 문제가 아니라 `GachaCharacterTable`에 테마 상자 풀(9·12·15·18·21·37) 행이 없었다 → T-209

## 변경 내용
- `Gacha.xlsx` `GachaCharacterTable`에 풀마다 캐릭터 행을 추가했다(TID = 풀×1000+n). 등급 분포는 레벨테마 7.2를 따르고, 같은 등급 안에서는 같은 가중치다
- `BoxSheetTest` — "캐릭터는 뽑기권에서만" 규칙을 "뽑기권과 테마 상자에서만"으로 바꾸고, 테마 상자 6종이 전부 캐릭터를 주는지 검사하는 테스트를 추가했다

## 주요 결정 / 근거
- 캐릭터 칸 = 상자 전체의 16.33%(7.1 초안 값)다. 나머지 칸은 **지금 비율을 유지한 채 함께 줄였다** — 7.1의 다른 칸(재료 20 · 골드 20 · 장비 16.33×2 …)은 아직 확인 전이라 이번에 건드리지 않았다
- `ArtifactRewardSheetTest`가 장인의 나무 자를 **정확히 0.8%**(가중치×1000 = 합계×8)로 묶어 둔다. 캐릭터를 넣으면 비율이 0.67%로 떨어지므로 아티팩트 가중치를 다시 맞췄다: A = (아티팩트를 뺀 합계)/124. 나누어떨어지게 하려고 풀마다 **마지막 캐릭터 행 가중치를 123 이하로 올렸다**(확률 차이는 무시할 수준)

## 후속 작업 / 주의사항
- 이 풀에 행을 넣거나 빼면 아티팩트 0.8% 테스트가 다시 깨진다 — 같은 식으로 아티팩트 가중치를 맞춘다
- 7.1 칸 비율 전체 적용 · 상자 기대 가치는 T-209에 남아 있다

## 업데이트 (2026-11-25) — 왕실 상자 골드
- 왕실 상자(풀 37) 골드 행이 성주 상자 값(10,971~54,857)을 그대로 복사해 쓰고 있었다(PR #156에서 별도 풀을 만들 때). 레벨테마 7.4 값(32,805~164,511 · ×243)으로 고쳤다. 가중치는 그대로라 아티팩트 0.8%에는 영향이 없다
- `BoxSheetTest`에 "단계가 오를수록 골드 최소값이 크다" 검사를 추가했다 — 풀을 복사해 새 상자를 만들 때 같은 실수를 잡는다
- #117의 다른 두 질문: 높은 상자일수록 영웅 이상 장비가 줄어드는 건 **의도한 설계**(7.3 — 레벨이 가치를 맡는다). 아티팩트는 **테마마다 전용 하나**로 하기로 했다 — 별도 이슈
