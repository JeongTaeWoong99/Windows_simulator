# 치트 해금 일괄 열기 — 칸 · 묶음 · 산업

## 목적 / 배경
- 특성·슬롯 해금을 하나씩 [열기]로 누르던 것을 범위별로 한 번에 열게 해 달라는 요청

## 변경 내용
- `Editor/cheat-console/CheatWindow.cs` — 해금 칸 맨 위 `[해금 전부 열기]` · 묶음 머리 `[묶음 전부 열기]` · 산업 띠 끝 `[산업 전부 열기]`
- 규칙은 `cheat-console 규칙.md`의 "해금 칸은 세 묶음으로 접는다"

## 주요 결정 / 근거
- **새 치트 명령을 만들지 않고 `Unlock`을 여러 번 보낸다** — 서버 `CheatUnlock`이 조건을 보지 않아 순서 무관. 서버 변경 없음
- 잠긴 줄만 보낸다 — 열린 줄까지 보내면 로그가 `AlreadyUnlocked`로 뒤덮인다

## 후속 작업 / 주의사항
- ⚠️ 가드(`CheatGuard.CanSend`)는 일괄 전송 전에 한 번만 본다. `Send`마다 보게 두면 로그인 전 경고 팝업이 줄 수만큼 뜬다
