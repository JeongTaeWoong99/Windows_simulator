# 툴팁 압축 · 일괄 담기 분류 제외

## 목적 / 배경
- 잠금 실측 뒤 사용자 피드백: 조작 안내가 애매하다 → 입력마다 한 줄로 했더니 "세로로 너무 길다" · 일괄 담기 알림에 잠금 제외가 없다 · 자원도 잠그고 싶다 · 제외 토글이 분류가 늘면 부족하다.

## 주요 결정 / 근거
- **툴팁 조작은 마우스 버튼마다 한 줄, 조합키는 오른쪽 칸**(`좌클릭 | 응축 | Ctrl 잠그기`). 빈 장비는 `장비 | 없음` 한 줄, 잠금은 상태 줄 `· 잠김`. 캐릭터 툴팁 22 → 15줄.
- **일괄 담기 잠금은 따로 센다** — "(잠금 1명 · 배치 중 … 제외)" + 푸는 방법 한 줄.
- **자원 잠금은 서버 몫** — TID 단위 잠금 제안으로 이슈 #72 · T-159(진우). 클라만으로는 저장·거절이 안 된다.
- **[상자 제외]·[큐브 제외] → [제외 ▾] 체크 드롭다운**(사용자 승인). 분류는 아이템 표에서(큐브 → 인챈트 표 먼저, 나머지 `AuctionText.GetItemCategoryName`). 기본 체크 큐브·상자·유물 — 예전 [상자 제외]는 `IsBox`(OpenGachaId)라 유물도 함께 뺐으므로 유물을 기본에 넣어 동작을 유지. 체크는 PlayerPrefs.
- `TMP_Dropdown`은 단일 선택·선택 즉시 닫힘이라 `UI/Shared/CheckDropdownView`를 새로 만들었다. 모양은 분류 드롭다운을 복제(Template → List).

## 겪은 함정
- 복제한 드롭다운 머리가 하얗게 나왔다 — 테마가 색을 `TMP_Dropdown`의 `ColorBlock`에 넣고 바탕 Image는 흰색이다. 새 `Button`에 원본 `colors`를 복사해 해결.
- 툴팁 실측에서 일시정지를 쓰면 서버 핑이 끊겨 연결이 끊긴다 — `TooltipPresenter.enabled = false`로 Update만 멈춰 찍었다.
- `login.cs`는 입력칸이 비었을 때만 아이디를 넣어, 남아 있던 다른 계정(1234)으로 들어간 적이 있다 → 항상 덮어쓰는 스크립트로.
- bash heredoc 안의 긴 파이썬이 따옴표 해석 오류를 냈다 — 파일로 써서 실행.

## 후속 작업 / 주의사항
- 자원 잠금은 #72 서버 처리 후 클라(Ctrl+좌클릭·자물쇠·일괄 담기 제외)를 붙인다.
- 씬 저장으로 `.unity` diff가 크게 나왔다(재직렬화) — 바꾼 것은 도구 줄 하나다.
