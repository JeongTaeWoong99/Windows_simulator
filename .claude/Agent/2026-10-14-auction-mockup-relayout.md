# 경매장 목업대로 재배치 (T-147 2단계)

## 목적 / 배경
- 1단계(`2864251`)는 거래 열 시절 하위 탭을 화면 전체로 옮기기만 했다. 목업 3차(`GameDesign/design/ui/경매장목업.html`)대로 다시 짠다.
- 서버 몫(T-118 시세 · T-155 검색 확장 · T-156 거래 기록)은 13일에 끝나 있었다 → 클라 배선을 한 번에.
- 범위·결정 요약 → `tasks/T-147` 2단계 항목 · 화면 규칙 → `UI/Auction/Auction 규칙.md`.

## 주요 결정 / 근거
- **자원도 매물 줄로 검색·구매** — 목업이 메이플식 매물 표라 거래소(TID별 한 줄 + 수량 구매 `C_MarketBuyRequest`)는 화면에서 뺐다. 서버 패킷은 그대로 남아 있다.
- **분류 트리는 서버 `Category` 한 값에 맞춘다** — 목업의 자원·상자·기타 최상위 대신 아이템 ▶ 산업 5 · 상자 · 소모품 · 기타 · 유물.
- **인챈트 옵션 조건은 서버 속성(합계) 두 칸** — 목업의 산업별 세 줄은 서버 필터가 없다.
- **정렬은 서버 정렬 5종만** — 총액·최근 등록은 서버에 없어 뺐다. 정렬만 바꿀 때는 마지막 *조회한* 조건으로 다시 받는다(고치다 만 옵션을 섞지 않으려고).
- **Enter 검색 없음** — 2026-10-11 사용자 결정(인게임 키는 Shift+우클릭·Esc뿐) 유지. 공용 검색창 [검색] 버튼.
- **등록 창은 경매장 안 모달**(ignoreLayout + 딤 버튼) — 경매장이 인벤토리를 가려서. Esc는 창부터 닫는다(`registerWindow.IsOpen`).
- **'전체' 이름 검색은 네 종류 TID를 합쳐 보내고 그릴 때 이름으로 다시 거른다** — 장비·캐릭터 TID가 1001~로 겹친다.
- 표 줄은 클래스 하나(`AuctionTableRowView`) + 표마다 프리팹 — 열 구성이 달라서. 등록 창 왼쪽 목록만 옛 `AuctionRowView`.

## 겪은 함정
- **고정 높이 줄의 `LayoutElement.flexibleHeight`를 -1로 두면** 자식 레이아웃 그룹이 자식 flex를 올려 보내 머리·탭 줄이 판 절반을 먹었다 → 0으로. 왼쪽 패널 `flexibleWidth`도 같은 이유로 0.
- **복제한 버튼 템플릿 글자가 autoSize라** 크기를 정해도 무시됐다 → 경매장 안 TMP는 autoSize를 껐다(프리팹 3개 포함).
- **폰트에 `▸ ▾ ✕ ⟳`가 없다**(□로 나옴) → `▶ ▼ X ↻`. 새 기호는 `font.HasCharacter`로 먼저 본다.
- **낮은 알파 강조색(0.08)이 진한 갈색으로 보였다** — 데스크톱 투명 창이라 바탕화면이 비친다. 패널 색에 섞은 불투명 색으로.
- **9-slice 스프라이트를 `Filled`로 자르면 끝이 뾰족** → 가격대 막대는 `anchorMax.x`로 길이.
- 등록 창 `Open`은 Start 전에 불릴 수 있다(SetActive 직후) — 적어 두었다가 Start 끝에서 고른다. eval로 입력칸을 바로 채우면 Start가 덮는다.

## 후속 작업 / 주의사항
- ⚠️ **실행 중 AuctionServer 빌드가 T-155 이전**(dll에 `TotalCount` 없음)이라 건수 0 · 일별 시세 '점검 중'(AuctionUnavailable) · 5번째 등록 '반환'이 났다. 서버 다시 빌드 후 확인. 클라는 건수 0이면 받은 줄 수로 대신한다(`AuctionModel`).
