# 소모품 사용 창 · 슬롯 버프 칩 · 영약 자동 사용 칸 (T-194)

## 목적 / 배경
- 서버 PR #120(T-195)으로 열린 소모품 사용·자동 사용 패킷을 클라가 받는다 — 이슈 #111·#113. → `tasks/T-194`
- 같은 회차에 #115(드워프 종족 이름 빈칸)도 `RaceLabel`에서 처리.

## 주요 결정 / 근거
- 진입: 인벤토리 **좌클릭 → 사용 창(모달)** 에서 대상(슬롯·캐릭터)·수량을 고른다. 비약 대상은 창 안 캐릭터 목록. 묘약(특성 초기화)은 [사용] 뒤 확인을 한 번 더 받는다 — 전부 사용자 결정.
- 버프 칩은 원래 **작업슬롯 칸 머리 줄**로 정했지만, 그 줄이 ~150px라 이름·레벨과 겹쳐 **Stage Overlay 좌상단**으로 옮겼다(사용자에게 보고함).
- 자동 사용 칸은 `WorkStationSelectPresenter`에 넣지 않고 세팅 패널 안 `SlotAutoUsePresenter`가 슬롯 번호만 받아 혼자 돈다 — 그 화면이 이미 너무 많은 걸 든다.
- 칸 개수의 진실은 슬롯 캐시(`S_WorkStationSlotSyncResponse`가 응답보다 먼저 온다). 클라는 개수를 계산하지 않고 한도·자리 부족은 서버 거절에 맡긴다.
- 소모품 사용 성공은 `ItemUseCompleted`(장비 등) 대신 새 이벤트 `ConsumableUsed`로 분리 — 토스트 문구·대상이 달라서.

## 후속 작업 / 주의사항
- T-194는 사용자 실측만 남음. #111·#113·#115는 실측 후 닫는다(#115의 1032~1034 그림은 T-174 아트로 남음).
- 효율 표시는 영약 몫(`BuffAddPermille`)을 더해 `UI.WorkStation.SpeedAddNoteBuff`로 따로 적는다 — 영약이 끝나면 표시가 서버 동기로 줄어든다.
- 자동 사용 칸 셀은 배치 버튼을 복제해 만들었다 — OnClick 영속 배선은 지웠으니 다시 복제할 때 같은 처리를 한다.
