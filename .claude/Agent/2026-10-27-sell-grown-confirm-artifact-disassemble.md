# 성장 개체 판매·분해 확인 창 · 아티팩트 마석 분해 클라

## 목적 / 배경
- 사용자 지적: Lv2 이상·응축 1 이상 캐릭터를 즉시 판매했는데 경고가 안 뜬다 (T-170)
- 서버 PR #92(아티팩트 마석 분해 · T-185)를 머지하고 클라 쪽(#89)을 받았다
- T-151 남은 항목 "거래소 아티팩트 탭" 확인

## 변경 내용
- `SellCartPresenter.cs` — 성장 개체가 섞였을 때만 [판매]·[분해] 전에 `UIManager.AskConfirm`(`AskIfGrown`). 분해 요청에 `Artifacts`를 함께 싣고, 아티팩트만 담겨도 분해 가능. `UI.Sell.ArtifactNoShard` 줄 제거
- `SellCartModel.cs` — `ArtifactShards(tid)` · 합계 마석에 `ArtifactItemCount × 수량`. 아티팩트만 담겼을 때 Common 행에서 재료 TID를 빌리던 임시 코드 제거
- `Inventory 규칙.md` — "확인 모달을 두지 않는다"에 예외 절 · 분해 표 · 아티팩트 판매 목록 줄

## 주요 결정 / 근거
- **원인은 판정이 아니라 표시였다.** MCP로 Lv7 캐릭터를 담으면 `GrownCount = 1` · 머리 경고 텍스트도 들어갔다. 경고 칸이 30px 자동 축소라 두 줄이면 매우 작아지고, [판매]는 바로 나갔다
- 확인 창은 **성장 개체가 있을 때만** — 매번 띄우면 P1(팝업 최소화) 위반. 상위 등급만은 묻지 않는다(기존 결정 유지)
- 문구는 기존 키 조합(`UI.Sell.GrownWarning` + 버튼 글자) — 로컬라이즈 엑셀을 건드리지 않으려고. 문구를 바꾸려면 `excel-table-creator` 절차로 새 키를 만든다
- 거래소 아티팩트는 이미 T-147에서 들어가 있었다 — 코드 변경 없음, 일감 체크만 갱신

## 후속 작업 / 주의사항
- `UI.Sell.ArtifactNoShard` 키가 코드에서 안 쓰인다(엑셀에 남음)
- 테스트 중 1234 계정 아티팩트 9번 1개를 분해했다(마석 +2). 6번은 등록 → 취소했다(돌려받는 경로는 확인하지 않았다)
- 실수로 `test` 계정이 하나 생겼다(로그인 자동화 중)
- 다른 계정의 아티팩트 구매는 확인하지 않았다
