# 경매 검색 — 조건 없는 검색 거절 문구 · "1,000건 이상" 표시

## 목적 / 배경
- 서버가 #71 후속(`8543e2a`)으로 조건 없는 검색을 `AuctionSearchNoCondition`(1016)으로 거절하고, `TotalCount`를 1,000에서 세다 멈추게 했다. 클라에 문구 두 개를 부탁받았다.

## 주요 결정 / 근거
- 상한 판정은 모델의 `IsSearchCountCapped`(`TotalCount >= SearchCountCap`) 하나로 둔다. 화면이 1000을 직접 비교하지 않는다.
- 상한에 걸리면 전체 쪽 수를 모르므로 쪽 표시는 `n 쪽`만 쓴다(`pageCount = 0` — 완료 탭과 같은 방식).
- 상한에 걸린 건수는 하한이라, 즉시구매로 줄이 빠져도 건수를 줄이지 않는다. 줄이면 999가 되어 "이상"이 사라진다.
- 옛 `Math.Max(TotalCount, 받은 줄 수)` 보정은 상한이 아닐 때만 쓴다. 상한일 때 쓰면 뒤 쪽에서 1,000 넘는 숫자가 나온다.

## 후속 작업 / 주의사항
- 1016은 클라가 조건 없는 검색을 미리 막아서 평소에는 나오지 않는다. 화면이 낡았을 때를 대비한 문구다.
- 1,000건 이상은 매물이 1,000개 넘게 있어야 실제로 보인다. 아직 실플레이로 확인하지 않았다.
