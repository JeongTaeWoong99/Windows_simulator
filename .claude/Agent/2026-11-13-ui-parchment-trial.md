# UI 양피지 시험

## 목적 / 배경
- 사용자: 양피지 퀘스트 창 이미지(밝은 양피지 창 · 진갈색 나무 테 · 붉은 리본 제목 · 어두운 아이템 칸)를 주고 "이 스타일로 UI 싹 입혀보고 싶다". 무료로(Claude 토큰만) — 코드 그리기로 한다.

## 변경
- 그림 저장소: `make_ui.py`에 `STYLE="parchment"` — 패널(나무 액자 + 홈 + 놋쇠 귀퉁이 + 종이 얼룩) · 버튼 · 입력칸 · 제목 리본(금실). 경계값은 Taskbar와 같아 `UiBorders`는 그대로.
- 팔레트: 양피지 창·버튼 / 어두운 칸 `#4A3524` / 진홍 제목 / 글씨는 크림(`TextMain`)과 진갈(`TextDark`) 두 벌.
- `UIThemeRole.HighlightDark`(22) 추가 — 밝은 바탕 위 금색. Presenter의 `Paint(…, Highlight)` 중 밝은 바탕 위 것(경매·유물·판매·강화·작업 고르기·장비 설명)을 `HighlightDark`로. 뽑기 가격·작업슬롯 MAX는 어두운 바탕이라 그대로.
- 씬·프리팹: 밝은 바탕(조상 Image 태그가 PanelBg·PanelSub·Button 계열) 위 글씨 태그를 `TextDark`로(보조 0.72·흐림 0.45 투명도). 작업슬롯 아래 띠·잠긴 칸 글씨는 어두운 바탕이라 `TextMain`으로 되돌림.
- 씬 안 프리팹 인스턴스의 색 덮어쓰기 120곳(`m_Color`·TMP `m_fontColor`) 걷어냄 — 뽑기 카드·거점 건물·잠긴 칸이 프리팹 색을 안 따라오던 원인.
- 문서: Art 규칙(양피지 시험 · 되돌리기) · Shared 규칙(글씨 역할 기준) · `make_ui.py` 머리말.

## 결정
- 글씨는 바탕 밝기로 역할을 고른다 — 한 팔레트에 밝은 창과 어두운 칸이 섞여 글씨 한 벌로는 어느 한쪽이 묻힌다.

## 확인
- 플레이 캡처: 메인 · 뽑기 · 상점 · 창고 · 우편 · 설정 · 경매 · 거점 · 유물 — 바탕화면 `UI 전후 비교 5차`.

## 남은 일
- 시험이다 — 사용자가 계속 쓸지 정한다. 되돌리기는 Art 규칙 "UI 양피지 시험".
- 덜 본 화면(강화·판매 카트·특성 트리·팝업)은 실사용 중 묻히는 글씨가 나오면 같은 기준으로 고친다.
