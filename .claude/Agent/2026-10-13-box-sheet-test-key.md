# 상자 테스트가 황금 열쇠를 상자로 세던 문제

## 목적 / 배경
- T-112(`a032487`)가 황금 열쇠 `100012`에 `OpenGachaId = 24`(비밀 금고)를 줬다. 그 뒤로 `BoxSheetTest`가 열쇠를 상자로 세서 2건이 실패했다(16종 · 황금 상자 → 열쇠를 루프로 판정)
- 데이터는 의도대로다. 금고 풀은 큐브·비약만 줘서 끝이 있다

## 변경 내용
- `Boxes`는 레벨 상자 TID 범위(100019~100033)로 좁히고, 여는 아이템 전체는 `Openables`로 따로 둔다
- 비용 None · 캐릭터 없음 검사는 `Openables` 전체에 건다(금고 풀도 골드로 사면 안 된다)
- `상자_풀에서_상자가_나오지_않는다` → `여는_아이템을_열고_또_열어도_처음_것으로_돌아오지_않는다` — 여는 아이템 사이의 실제 순환만 잡는다

## 후속 작업 / 주의사항
- 레벨 상자 TID 범위가 바뀌면 `FirstBoxTid`·`LastBoxTid`를 함께 고친다
