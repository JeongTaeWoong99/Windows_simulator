# 거점 화면 UI 폴리싱

## 목적 / 배경
- 사용자: 거점 쪽 UI가 지금 스타일(양피지 2·3차)에 안 맞는다 — 한동안 안 건드렸다. 스크린샷 4장(지도 · 메뉴 · 업그레이드 · 특성).
- 원인: 거점은 `#Outpost Canvas (MAIN VIEW)` 안이라 `UiSkin`이 안쪽 상자에 액자·덧테를 두르지 않는다(`IsInsideColumn`). 지도 위 상자들은 스프라이트 없는 단색 판, 메뉴·건물 창은 옛 다크 테마 글씨색(크림)이 양피지 위에 남아 안 읽혔다.

## 주요 결정 / 근거
- 새 그림을 만들지 않고 **이미 있는 틀 그림·역할로만** 맞췄다 — 상자 = `ui_input` + `Ui Trim`, 배지 = `ui_button` + 덧테, 창 = `ui_panel` + `Ui Paper` + `Ui Frame`, 머리 띠 = `ui_header` + `Border`(열 제목과 같은 진갈 띠).
- 건물 이름판은 두 줄 202×50이 건물 아랫부분(문)을 가렸다 → 한 줄 간판 + 글자 너비. 아래 줄 건물(숙소·감정소)은 지도 끝이라 간판을 밑으로 내릴 수 없다.
- 특성 탭 바깥 상자는 `ui_button` 그림을 창처럼 쓰던 겹상자라 지웠다(Image 끔 · 덧테 끔).
- 플레이 모드에서 로그인 → `UIManager.ShowOutpost` → 건물 버튼 → 탭 순으로 캡처해 확인했다.

## 후속 작업 / 주의사항
- **보유 포인트 −34**(작업장 Lv2인데 특성 40점 찍힘)는 UI가 아니라 데이터 상태다 — 옛 인벤토리 특성 탭·치트로 찍은 값이 건물 레벨 포인트를 넘는다. 손대지 않았다.
- 씬을 한 번 저장하면 기존 파일이 Unity 직렬화 순서와 달라 788줄이 자리만 바뀐다(정렬 비교로 내용 동일 확인). 이번 diff에 섞여 있다.
- `OutpostBuildingView`는 프리팹이다 — 씬에서 고치면 인스턴스 덮어쓰기가 대량으로 생긴다. 처음 그렇게 했다가 되돌리고 프리팹 원본을 고쳤다.
- `capture_game_view --save_path`는 `Assets/` 아래에 쓴다(`Temp/x.png` → `Assets/Temp/`). 확인 뒤 지웠다.
