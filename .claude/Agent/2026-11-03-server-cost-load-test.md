# 서버 비용 측정

## 목적 / 배경
- 사용자 요청: 서버 비용 계산 일감을 이슈로 등록하고, 1달 기준 AWS 동접 100명당 비용을 측정. 회차마다 갱신한다.
- 일감이 없어서(이슈 #107 메모의 댓글 한 줄뿐) T-192를 새로 등록했다.

## 변경 내용
- `Server/MikaLoadTest/` — 부하 봇 콘솔. heavy: 치트로 슬롯 7칸·캐릭터 6장 → 전부 배치, 5초 핑. 서버 프로세스 CPU·작업 집합·받은 바이트를 잰다
- `Server/docs/서버-비용.md` — 방법 · AWS 서울 단가(공식 가격 API) · 회차별 표 · 원자료
- `Server/CLAUDE.md` · `WSGameServer2.slnx` — 프로젝트·문서 등록
- `tasks/T-192-서버비용계산.md`

## 주요 결정 / 근거
- 결과(261107): 동접 100명 = 송신 10.6GB/월, CPU 미미 → t4g.small 한 대 약 $20.7/월. 송신은 100GB/월까지 무료라 동접 1000명 근처까지 고정비가 거의 전부다.
- **진짜 한계는 SQLite다.** 기본 rollback 모드에서 heavy 500명부터 `database is locked` → 세션 끊김, 1000명은 로그인조차 124명. 측정 DB만 WAL로 바꾸니 500명 끊김 0 · CPU 1/4. 코드 변경은 하지 않고 T-192 할 일로 남겼다.
- 첫 측정에서 59명이 끊긴 것은 봇 버그(핑 타이머가 전원 접속 뒤 시작) — 접속 전부터 핑을 돌리게 고치고 다시 쟀다.
- 측정 DB는 스크래치패드 임시 파일 — git의 game.sqlite3는 건드리지 않았다.

## 후속
- WAL로 열기 · 운영 로그 수준 설정 · MikaDummyClient 빌드 깨짐(무관 · 발견만).
- 회차마다 같은 명령으로 재고 표 갱신 + 이슈 본문 표 갱신.
