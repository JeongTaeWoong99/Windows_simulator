# T-214 스팀 업적 구조 (같은 날)
- `Managers/SteamAchievementManager` — 게임 사건이 부를 단일 창구 `Unlock(키)`. 매 프레임 `RunCallbacks`, 바뀐 업적이 있으면 프레임 끝에 `StoreStats` 한 번. 스팀이 없으면 조용히 지나간다. 씬 루트에 `Steam Achievement Manager` 오브젝트.
- 이 Steamworks.NET 판(2025.165)에는 `RequestCurrentStats`가 없다 — SDK 1.61부터 스팀이 시작할 때 통계를 받아 둔다. 바로 `GetAchievement`·`SetAchievement`를 쓴다.
- 시험 메뉴 `Window/DesktopWindowControl/스팀 업적 시험/` — 480 `ACH_WIN_ONE_GAME` 되돌리기 → 저장 성공 → 걸기 → 저장 성공(실제 스팀 계정). 시험 업적은 걸린 채로 두었다.
- 업적 목록 · 판정 위치(클라 vs 서버)는 아직 — 게임 사건 연결은 하지 않았다.
