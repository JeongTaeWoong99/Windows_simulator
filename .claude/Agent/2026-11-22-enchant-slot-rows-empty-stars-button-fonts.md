# 큐브 자동 칸마다 고르기 · 캐릭터 칸 빈 ★ · 버튼 글씨 다시 맞춤

## 목적 / 배경
- 어제 시안(https://claude.ai/artifact/X1ZAmppDMf73CpEXMfW9ND) 중 사용자가 A '칸마다 고르기'를 골랐다. 조건: 칸마다 한 줄(최대 3줄) · 줄마다 7개 · 기본 `전체 전체 전체` · `전체`와 나머지는 서로 끈다 · 글씨를 키운다 · 상한 줄과 안내 사이 빈칸 없앰 · 안내에 나올 수 있는 결과를 적는다.
- `전체`의 뜻을 물어 **"아무거나"** 로 정했다(사용자 답). 옵션 '전 산업 속도'를 따로 노리는 칩은 없어졌다.
- 캐릭터 칸 ★0도 빈 ★ 4개를 계속 보인다(사용자).
- 버튼 글씨를 KR/EN을 보고 직접 맞춘다(어제는 보고만 했다).
- 커밋하지 말라는 지시가 이어진다 — 변경만 해 둠.

## 변경 내용
- `EnchantAutoTarget` — `Focus`·조합 배열 → 줄마다 비트 마스크(`_picks`, 0 = 전체). `IsPicked`·`TogglePick`·`ResetPicks`·`UsesSlots(slotCount)`·`Fits`(결과 칸을 줄에 짝짓는 순열 ≤6개)·`KindOf`·`DescribeOutcomes`(나올 수 있는 결과 묶음 앞 3개 + `+n`). `PreferNew`는 '전체'가 아닌 줄을 더 많이 채운 쪽.
- `EnchantForecast.SlotChanceAt` — 칸 종류(칩 6 + 그 밖 1) 묶음 7ⁿ을 다 세어 `Fits`인 것의 확률 합. 이항식·`ReadShares`·`Choose` 삭제.
- `EnchantAutoPanelView` — `focusChips`·`comboChips` → `slotRows[3]`(줄 · 이름 · 칩 7). 이벤트 `PickClicked(row, focus)`. 칸 수보다 뒤 줄은 끈다.
- `EquipEnchantPresenter` — 배선 · `AlreadyMythic` 조건 · `NeedCombo` 막기 삭제(빈 줄이 없다) · 규칙 줄 둘째 줄 = `DescribeOutcomes`.
- 씬 Auto Panel — `Focus Row` → `Slot Row 1`(LocalizedText 뗌), 복제로 2·3, `Combo Row` 삭제. 줄 높이 30 → 38 · 칩 글씨 22(최소 11) · 칩 글자 여백 칸 줄 6 / 나머지 10 · 줄 이름 폭 100 · 세로 배치 아래 정렬 + `flexibleHeight 1`(빈칸이 상한 아래로 안 생기게) · 큐브 창 `Window` 500 → 535.
- `Loc_UI.xlsx` — `UI.Enchant.SlotRow`(`칸 {0}` / `Slot {0}`) 추가 · `UI.Enchant.AlreadyMythic` 문구. 파이프라인 돌림.
- `SlotView.SetStars(int?)` — null이면 끄고, 값이 있으면 ★0이어도 빈 ★ 4개. 격자는 캐릭터 탭이 아니면 null.
- 버튼 글씨 — 씬 버튼 30개를 `UI 규칙.md` 높이 표대로(자동 축소 최대 = 표 · 최소 = 절반). 프리팹 변경 없음.
- 문서 — `Inventory 규칙.md`(자동 설정 줄 표 · 규칙 줄 예 · ★) · `Shared 규칙.md`(★) · `UI 규칙.md`(다시 맞춤 · 뺀 것).

## 주요 결정 / 근거
- 매칭은 순서를 보지 않는다(기존과 같다) — 결과 칸 ↔ 줄 순열 중 하나라도 맞으면. 에디터에서 시험: {농},{경},{농,경}이면 농경농·경경농·농농경·경농경만 참, 농농농·경경경·농경+기타 거짓.
- 칸이 1·2칸이면 빠진 줄 자리는 위(머리 줄 아래)에 빈다 — 사용자가 짚은 "상한과 안내 사이"는 늘 붙는다.
- 버튼 높이는 **꺼진 창까지 미리보기 씬에 복제·전부 켜고 레이아웃을 다시 돌린 크기**로 쟀다. 저장된 rect는 꺼진 창에서 낡았다(인챈트 칩 38 → 48로 저장, 아티팩트 버튼 폭 623).
- 일부러 뺀 버튼: 상태 줄 작은 버튼(폭 41 — 측정 의심) · 우편 뒤로 `X`(측정 24 — 의심) · 판매 팝업 탭 줄(높이 34라 표대로면 22 → 16으로 작아짐 — 높이를 40으로 올리는 쪽이 맞다) · 판매/분해 두 줄 버튼.

## 후속 작업 / 주의사항
- 플레이 실측 남음 — 큐브 창 자동(1·2·3칸 장비, KR/EN), 규칙 줄 길이, 캐릭터 탭 ★0 칸.
- 판매 팝업 탭 줄 높이 34 → 40은 사용자 결정 뒤.
- 씬 저장으로 직렬화 순서가 바뀐 줄이 diff에 섞여 있다(줄 복제 2개가 대부분).
- 마을 성장(건물 단계 · 바탕 단계 · 거점 → 마을 이름)은 초안만 답했다 — 그림·코드 변경 없음.
