# T-117 클라 — 치트 창 특성 레벨 묶음

> 2026-10-06 ⏸ 풀림 — 서버 `SetTraitLevel = 11`이 섰다([T-115](T-115-특성레벨치트.md)). 인자·동작은 [`치트.md`](../Server/docs/치트.md) 2장.

## 배경

[T-116](archive/T-116-클라레벨형특성화면.md)에서 특성 화면을 레벨형으로 바꾸며, 치트 창의 옛 특성 묶음
(산업 속도 · 산업 레벨 · `[해금 전부 열기]`)은 **코드는 두고 숨겼다**(`CheatWindow.ShowTraitUnlockGroups = false`).
옛 해금 치트로는 특성이 안 오르기 때문이다. 지금 치트 창에는 "서버 치트가 열리면 추가 예정" 안내만 보인다.

서버 특성 레벨 치트([T-115](T-115-특성레벨치트.md) · [이슈 #51](https://github.com/JeongTaeWoong99/Windows_simulator/issues/51))가 오면
그 명령으로 특성 레벨을 올리고 내리는 묶음을 다시 붙인다. 이게 없으면 산업 Lv5 확인에 계정 Lv50이 필요하다.

## 할 일

- [x] 서버 특성 레벨 치트 도착 — [T-115](T-115-특성레벨치트.md) · `ECheatCommand.SetTraitLevel`(`Arg1` = `UserTraitTID`, 0이면 전부 · `Arg2` = 레벨, 기본~최대로 잘림) · 결과는 `S_UserTraitListResponse` 재전송
- [ ] 치트 창 특성 묶음 — 산업 × (개척 · 속도 · 산출량) 레벨 지정 · 전부 최대 · 기본으로 되돌리기
- [ ] 옛 묶음 코드(`ShowTraitUnlockGroups`) 정리 · 안내 문구 삭제
- [ ] `cheat-console 규칙.md` 갱신
- [ ] 실측 — 치트로 올린 레벨이 특성 화면 · 산업 레벨 잠금에 바로 반영

## 완료 조건

치트 창에서 특성 레벨을 바꾸면 특성 표와 작업슬롯 산업 레벨 잠금이 그 자리에서 바뀐다.
