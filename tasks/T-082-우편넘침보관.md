# T-082 서버 — 우편 넘침 보관

## 배경

창고가 가득 차면 서버가 주는 보상(상자 개봉 · 퀘스트 보상)을 버리거나 거절하지 않고 **우편에 맡긴다.**
대신 우편함이 두 번째 창고가 되지 않도록 **안 받은 우편 100통**에서 멈춘다 → [우편](../GameDesign/design/mail/README.md) 2.4.

## 할 일

- [ ] 상자 개봉 — 창고에 안 들어가면 **보상 전체를 우편 1통**으로(넘침 템플릿 + 실제 첨부). 쪼개지 않는다
- [ ] 우편함 상한 — **안 받은 우편만** 센다. 100통이면 원래대로 거절(상자 개봉 거부). 운영 우편은 상한과 무관
- [ ] 상한 값 100 → 공용 상수 시트([T-077](T-077-공용상수시트.md))
- [ ] 퀘스트 보상 — 퀘스트 지급이 구현될 때 같은 경로를 태운다 (지금은 퀘스트 보상 지급 코드가 없다)
- [ ] 가챠는 **대상이 아니다** — [T-063](archive/T-063-창고한도뽑기거부.md)대로 거부 유지. 채취 산출도 대상이 아니다
- [ ] 테스트 — 넘침 시 우편 1통 · 상한에서 거절 · 받은 우편은 상한에 안 셈

## 완료 조건

창고가 가득 찬 상태에서 상자를 열면 우편이 1통 생기고, 안 받은 우편이 100통이면 개봉이 거절된다.
