# T-004 채취 전역 배수를 1.0으로 되돌리기

## 배경

동작 확인이 어려워서 `Global.GatherSpeedMultiplier`를 **6.0배**로 올려 뒀다.
기준 주기가 30초 → 5초가 된다.

기획 수치(30초)는 건드리지 않았으므로 이 값만 되돌리면 끝나지만,
**켜 둔 채로 배포하면 재화 산출량이 6배가 된다.** 잊기 쉬운 종류의 설정이라 일감으로 남긴다.

서버 시작 시 배수가 1.0이 아니면 경고 로그를 찍도록 해 뒀다:

```
WRN [설정] 채취 전역 배수 6.0배 — 기준 주기 30.0초 → 5.0초 (확인용 설정)
```

## 완료 조건

서버 시작 로그가 `INF [설정] 채취 전역 배수 1.0배 — 기준 주기 30.0초`로 나온다.

  확인하려면 빠른 주기가 필요하다.

  (무응답 판정 5초 → 15초)이 채택됐다. 판정을 늘리면 좀비 세션이 그만큼 오래 사는데,
  **배수 6.0이면 실효 채취 주기가 5초라 그 구간에 판정 3회가 부당 적립된다.**
  판정 시간이 채취 주기보다 짧아야 한다는 설계가 깨지는 지점이라 **두 값을 함께 정한다.**
