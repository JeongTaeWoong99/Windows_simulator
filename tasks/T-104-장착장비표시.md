# T-104 클라 — 장착 장비를 슬롯 목록 · 인벤토리 캐릭터 칸에 표시

## 배경

장비를 끼워도 **작업슬롯 목록**(`WorkStationSlotView`)과 **인벤토리 캐릭터 탭**(`CharacterSlotSource` → `SlotView`)에는
아무 표시가 없다. 무엇을 끼웠는지는 슬롯 설정을 열어 장비 칸 4개를 봐야만 안다 (사용자 제기 2026-09-30).
장비 쪽은 인벤토리 장비 탭에서 '배' 마크·착용자 툴팁으로 보이지만 **캐릭터 쪽에서 거꾸로 보는 길이 없다.**

## 할 일

- [ ] 표시 모양 확정 (착수 전 사용자 확인) — 제안: 장비 칸 4개(무기·장신구1·장신구2·보석)를 **작은 네모 4개**로,
      비었으면 빈 테두리 · 끼웠으면 **등급 색**. 능력치 칸 줄(T-095)과 같은 문법이라 새로 배울 표시가 없다
- [ ] 슬롯 목록 칸(`WorkStationSlotView`) — 배치된 캐릭터 옆에 네모 4개
- [ ] 인벤토리 캐릭터 칸(`SlotView` · `CharacterSlotSource`) — 칸 가장자리에 네모 4개 · 툴팁에 장착 장비 이름·등급 줄
- [ ] 장비가 바뀌면 갱신 — `PlayerDataModel.EquipsChanged` 구독
- [ ] 문서 — `UI 배치 현황.md` · 해당 폴더 규칙

## 완료 조건

슬롯 목록과 인벤토리 캐릭터 탭만 보고도 어느 캐릭터가 장비를 몇 개, 어떤 등급으로 꼈는지 알 수 있다.

## 막고 있는 것 / 선행 일감

- 없음 — 캐릭터별 장착 정보는 이미 클라에 있다(슬롯 설정의 장비 칸 4개가 쓰고 있다)
- 모양은 [T-103](T-103-목록줄카드화.md)의 `ItemIconView`와 맞춘다 (먼저 하면 좋은 것 — 선행은 아님)
