# T-118 서버 — 장비·캐릭터 경매 TID별 시세 요약

## 배경

자원 거래소는 `MarketItemInfo`(최저가 · 판매 중 수량 · 최근가 · 전일 평균)로 "지금 얼마에 팔리나"를 한 줄로 본다.
장비·캐릭터 경매에는 그런 요약이 없어, 등록할 때 단가를 정할 기준이 **즉시 판매가 · 가격 밴드**뿐이다.
검색 결과 20개를 받아 봐야 짐작할 수 있다. (2026-10-03 경매장 개선안 P1 — 태웅 채택)

요청 이슈: [#52](https://github.com/JeongTaeWoong99/Windows_simulator/issues/52)

## 할 일

- [x] 장비·캐릭터 TID별 요약 패킷 — **새 패킷 없이 `C_MarketItemsRequest.Kind`에 `Equip`·`Character`** → `MarketItemInfo` 그대로 (수량 구매만 자원·아티팩트로 막는다)
- [x] 요청한 TID는 매물이 없어도 줄이 오게(값 0) — 거래소와 같은 경로라 그대로
- [x] 빈도 제한 — 거래소 조회·검색과 **같은 통** (창을 바꿔 가며 긁는 매크로를 한 통으로)
- [x] 장비를 인챈트 등급별로 쪼갤지 판단 → **쪼개지 않는다** — TID 하나의 참고값. 등급별 비교는 검색(인챈트 등급 필터)으로 본다
- [x] (목업 시세 탭 · [T-147](archive/T-147-경매장전체화면목업.md)) **일별 시세 14일** — `C_MarketPriceHistoryRequest { Kind, Tid }` → `S_MarketPriceHistoryResponse { Days }` (날마다 수량 · 가중 평균 · 최저 · 최고 · 체결 없는 날도 0 · 한국 자정 경계)
- [x] (목업 시세 탭) **단가별 수량** — `C_MarketPriceRequest.Kind`에 장비·캐릭터
- [x] 테스트 · 프로토콜 미러 — 경매장 `PriceHistoryEngineTest` · gRPC · 메인 `UserMarketTest`

## 완료 조건

장비·캐릭터 TID 목록을 보내면 TID마다 시세 한 줄이 온다.
