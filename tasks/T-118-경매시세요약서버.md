# T-118 서버 — 장비·캐릭터 경매 TID별 시세 요약

## 배경

자원 거래소는 `MarketItemInfo`(최저가 · 판매 중 수량 · 최근가 · 전일 평균)로 "지금 얼마에 팔리나"를 한 줄로 본다.
장비·캐릭터 경매에는 그런 요약이 없어, 등록할 때 단가를 정할 기준이 **즉시 판매가 · 가격 밴드**뿐이다.
검색 결과 20개를 받아 봐야 짐작할 수 있다. (2026-10-03 경매장 개선안 P1 — 태웅 채택)

요청 이슈: [#52](https://github.com/JeongTaeWoong99/Windows_simulator/issues/52)

## 할 일

- [ ] 장비·캐릭터 TID별 요약 패킷 — 최저가 · 판매 중 매물 수 · 최근 체결가 · 전일 평균 (줄 모양은 `MarketItemInfo` 재사용 가능)
- [ ] 요청한 TID는 매물이 없어도 줄이 오게(값 0)
- [ ] 빈도 제한 — 거래소 조회와 같은 통에 넣을지
- [ ] 장비를 인챈트 등급별로 쪼갤지 판단
- [ ] 테스트 · 프로토콜 미러

## 완료 조건

장비·캐릭터 TID 목록을 보내면 TID마다 시세 한 줄이 온다.
