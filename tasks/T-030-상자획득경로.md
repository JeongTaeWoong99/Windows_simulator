# T-030 상자 획득 경로 — 채취 공통 보상 롤

## 배경

**T-029로 상자를 깔 수 있게 돼도, 상자를 얻는 길이 없다.**
기획에는 채취 판정 1회마다 **별도로 도는 공통 보상 롤**이 이미 설계돼 있으나
`CommonRewardTable`이 **미작성**이다 → [아이템](../GameDesign/design/item/README.md) 1.4.

이 일감이 루프를 닫는다:

```
채취 → 상자 → 개봉 → 아이템 → 판매 → 골드 → 캐릭터 뽑기 → 배치 → 채취
```

**띄워 두기만 해도 상자가 쌓이고, 들여다볼 때 깔 것이 있다** — P3(하루에 한 번 들여다볼 이유)에
맞는 장치이며, 놓쳐도 사라지지 않으므로 P1을 어기지 않는다.

## 할 일

- [x] **엑셀** — `CommonRewardTable`(`DropCommon.xlsx`) 전 산업 공통 1벌 · `ItemTID` · `Count` · **`ChancePerMillion`**
      — 미당첨 가중치 대신 **행마다 독립 확률**로 바꿨다(사용자: "판정 1회당 각각 엄청 낮은 확률"). 한 판정에 둘 이상 나올 수 있다
- [x] 산업 레벨별 차등 — **당분간 공통**
- [x] **서버** — 정산에 별도 롤(`CommonRewardCatalog.Roll`) · 결과는 그 슬롯의 `S_GatherResultResponse`에 얹는다
- [x] 테스트 — 확정(백만분율 100만)이면 판정마다 · 행마다 따로 · 없으면 드롭만
- [x] **기획 문서** — 아이템 1.4 · 4.1 · 자원채취 · 게임기획코어 5장
- [ ] 실측 — 확률이 낮아(0.2%) 실서버에서는 보지 못했다. 필요하면 확률을 잠시 올려 확인
- [ ] **프로토콜 미러 커밋**

## 완료 조건

캐릭터를 배치해 두면 **아무 조작 없이 상자가 인벤토리에 쌓이고**,
그 상자를 T-029로 까서 나온 아이템을 T-028로 팔아 T-027의 가챠를 돌릴 수 있다.
**루프 한 바퀴가 실제로 돈다.**
