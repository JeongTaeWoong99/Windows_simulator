# T-081 서버 — 우편 (운영 우편)

## 배경

운영자가 점검·사과·이벤트 보상을 보낼 통로가 없다. 기획은 확정됐다 → [우편](../GameDesign/design/mail/README.md).
수령할 때 "창고에 들어가는가"를 판정해야 해서 **창고 칸 계산([T-063](T-063-창고한도뽑기거부.md))이 먼저다** (2026-09-22 결정).

## 할 일

- [ ] **엑셀 우편 템플릿** — 제목·본문·발신자·첨부 여러 줄·`PeriodDays`. **파일·시트·컬럼 이름은 만들기 전에 확인받는다** ([`excel-table-creator`](../.claude/skills/common/excel-table-creator/SKILL.md))
- [ ] **상수** — 받은 우편 보관 7일 ([T-077](T-077-공용상수시트.md)이 먼저 섰으면 그 시트로, 아니면 임시 서버 상수 + 주석)
- [ ] DB — 개인 우편 · 전체 우편 · 전체 우편 복사 기록 ([우편](../GameDesign/design/mail/README.md) 3.3)
- [ ] 패킷 — 목록 · 새 우편 도착 · 수령 · 모두 받기 · 삭제. 결과 코드에 **인벤토리 부족**
- [ ] 수령 — **원자적**: 첨부가 전부 들어가야 지급, 아니면 아무것도 안 준다. 첨부 종류 = 아이템·장비·캐릭터·골드·다이아
- [ ] 모두 받기 — 오래된 순, 처음 막힌 우편에서 멈춤, 받은 수·남은 수
- [ ] 삭제 — 받은 우편만. 받은 지 7일 지난 우편 정리
- [ ] 전체 우편 — 로그인 때 기간 안의 미복사분 복사 + 발송 순간 접속자에게 즉시. 같은 우편을 두 번 받지 않는다
- [ ] 치트 — `Arg1 = 템플릿 TID` · `Arg2 = UID(0이면 전체)` · [`Server/docs/치트.md`](../Server/docs/치트.md) 2장 갱신
- [ ] 테스트 — 원자적 수령(부족 시 아무것도 안 변함) · 모두 받기 멈춤 · 전체 우편 중복 방지 · 안 받은 우편 삭제 거절

## 완료 조건

치트로 개인·전체 우편을 보내고, 클라(또는 더미 클라)에서 목록·수령·모두 받기·삭제가 돈다.
창고가 모자라면 **인벤토리 부족**으로 거절되고 재화·보유가 그대로다.
