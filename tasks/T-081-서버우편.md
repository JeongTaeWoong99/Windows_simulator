# T-081 서버 — 우편 (운영 우편)

## 배경

운영자가 점검·사과·이벤트 보상을 보낼 통로가 없다. 기획은 확정됐다 → [우편](../GameDesign/design/mail/README.md).
수령할 때 "창고에 들어가는가"를 판정해야 해서 **창고 칸 계산([T-063](archive/T-063-창고한도뽑기거부.md))이 먼저다** (2026-09-22 결정).

- [ ] **실측** — 실서버 + 클라(또는 더미 클라)에서 치트 발송 → 목록 → 수령·모두 받기·삭제 왕복. 클라 화면은 [T-083](T-083-클라우편함.md)

## 완료 조건

치트로 개인·전체 우편을 보내고, 클라(또는 더미 클라)에서 목록·수령·모두 받기·삭제가 돈다.
창고가 모자라면 **인벤토리 부족**으로 거절되고 재화·보유가 그대로다.
