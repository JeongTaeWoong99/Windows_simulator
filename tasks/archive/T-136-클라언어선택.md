# T-136 클라 — 설정에서 언어 선택 (KR·EN) · 화면 문구 교체

## 배경

- 설정 화면에서 언어를 KR·EN 중에 고르면 화면 문구가 바뀌게 한다 (2026-10-09 태웅).
- 문구 대부분이 엑셀 데이터라, 시트가 언어별 값을 갖는 구조([T-135](T-135-다국어시트구조.md))가 먼저 와야 한다.
- 폰트는 [T-100](T-100-폰트교체.md)에서 KR·EN 에셋으로 나눠 둔다.
