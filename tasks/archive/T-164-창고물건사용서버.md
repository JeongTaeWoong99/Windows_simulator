# T-164 서버 — 창고 물건도 인벤토리와 똑같이 쓴다

## 배경

창고가 "꺼내야 쓰는 보관소"라(`인벤토리-창고.md` 1장), 쓰는 것은 창고에 둘 수 없고 창고에 둔 것은 쓸 수 없다.
창고는 **놓인 자리일 뿐**이고, 실수를 막는 안전장치는 잠금(T-137)이 맡는다(2026-10-15 사용자 결정). → [이슈 #74](https://github.com/JeongTaeWoong99/Windows_simulator/issues/74)

## 할 일

- [x] 창고로 옮기기 — 배치·착용·장착 중이어도 허용(`StorageEntityBusy` 판정 제거) · 상태를 그대로 들고 간다
- [x] `TryGetCharacter`·`TryGetEquip`가 양쪽 보관함을 본다 — 장착·배치·큐브·응축·잠금·판매·경매가 함께 풀린다
- [x] 자원 소모(큐브·상자 개봉·판매·경매)는 인벤토리 먼저, 모자라면 창고에서
- [x] 로그인 착용 복원(`User.Equip.cs` 44) · 작업 슬롯 고아 정리(`User.WorkStation.cs` 80) · 정산·속도가 창고 캐릭터를 놓치지 않게
- [x] 마지막 캐릭터 판정(`User.Shop.cs` 95 · `User.Auction.cs` 206)에 창고 캐릭터도 센다
- [x] `인벤토리-창고.md` 1장 "창고의 역할" 결정 갱신
- [x] 창고에서 경매에 올린 개체가 우편으로 돌아오면 인벤토리로 들어온다(`UnlockEquipAsync`·`UnlockCharacterAsync`가 `container = 0`) — 안 하면 창고 칸 번호와 인벤토리 칸 번호가 섞여 겹친다

## 완료 조건

창고에 있는 캐릭터·장비·자원을 꺼내지 않고 모든 기능에 쓸 수 있고, 장착·배치한 채 맡겨도 재로그인 뒤 상태가 그대로다.
