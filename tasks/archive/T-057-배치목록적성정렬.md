# T-057 클라 — 캐릭터 배치 목록을 적성 높은 순으로 정렬

## 배경

작업슬롯 선택 화면의 캐릭터 줄은 적성 5칸을 숫자로 보여 주지만([T-053](T-053-선택화면목업구조.md)),
목록 순서는 **보유 목록 순서 그대로**다(`WorkStationSelectPresenter.RefreshRows`).
캐릭터가 늘면 적성이 높은 캐릭터를 찾으려고 목록을 훑어야 한다.

## 할 일

- [x] 5개 적성(산업) 중 하나를 누르면 캐릭터 목록을 **그 적성 높은 순**으로 다시 그린다 (2026-09-16 · `CompareRows`)
- [x] 누를 자리를 정한다 → **위 산업 탭 그대로.** 산업 버튼이 이미 필터라 정렬 기준까지 겸한다 — 새 UI 없음
- [x] 동점일 때 순서 → **등급 높은 순 → 개체 번호 순.** 안정 정렬 대신 끝까지 동점이 없게 짰다(`List.Sort`는 불안정)
- [x] 현재 정렬 기준 표시 → **고른 산업 버튼(노랑)과 줄의 강조 칸이 곧 기준**이라 따로 두지 않는다
- [x] (추가) 줄 바탕을 **등급 색**으로 — 목록 줄 · 세팅 카드 공통(`CharacterStateRowView.SetRarity`). 🎨 테두리 스프라이트는 나중에
- [x] 플레이 확인 — 산업마다 순서 · 줄 색 · 캐릭터가 늘 때 갱신 (2026-09-16 통과)

## 완료 조건

배치 단계에서 적성 하나를 누르면 목록이 그 적성 내림차순으로 바뀌고,
배치·해제 뒤 목록이 다시 그려져도 고른 정렬이 유지된다.
