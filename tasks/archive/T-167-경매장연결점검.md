# T-167 클라 — 경매장 판매 등록·수령 후 회색 화면에서 안 넘어간다 · 원인 찾기

> 2026-10-16 진우 → 태웅: 서버 연결 점검·성공 로그까지 하고 넘김. 증상이 클라 대기 화면이라 클라에서 먼저 본다 — [이슈 #76](https://github.com/JeongTaeWoong99/Windows_simulator/issues/76)

## 배경

- **증상 (2026-10-16 진우):** 로컬에서 경매장 판매 등록 · 수령 등 동작을 하면 회색 화면(대기 가림막)에서 넘어가지 않는다.
- 경매장이 안 붙으면 등록은 메인 DB outbox에 쌓이기만 하고, 검색·내 매물·거래소 조회가 전부 `AuctionUnavailable`(점검 중)로 온다.
- 연결 경로
  - 로컬: 메인 `appsettings.json` `Game.Auction.Address = http://127.0.0.1:10060` · 경매장 `ListenPort 10060` · 에디터 서버 콘솔(`ServerRunner`)이 둘을 함께 띄운다
  - 원격(Docker): `Game__Auction__Address = http://auction:30330` · 경매장 `ListenAddress 0.0.0.0`
- 설계: [`Server/docs/경매장.md`](../../Server/docs/경매장.md) · 원격: [`Server/docs/도커.md`](../../Server/docs/도커.md)

### 2026-10-16 첫 점검 (로컬)

- 경매장 단독 기동 정상(`127.0.0.1:10060`) · 메인 기동 시 `[경매] 경매장 http://127.0.0.1:10060 — 릴레이 시작`까지 오류 없음
- 같은 날 22:01 등록(trade 2)이 outbox → 경매장 `t_listing`까지 넘어가 있다 — **둘 다 떠 있을 때 메인→경매장 호출은 됐다**
- 에디터 서버 콘솔 로그(`Temp/WSGameServer.log` · `Temp/AuctionServer.log`)가 없다 — 콘솔 말고 다른 방법(IDE·`dotnet run`)으로 메인만 띄웠다면 경매장이 안 떠 있어 `AuctionUnavailable`이 난다
- 남은 것: 회색 화면이 응답을 받고도 안 풀리는지, 응답 자체가 안 오는지 — 클라 수신 로그로 가른다

### 2026-10-16 원인 (태웅 · 클라)

- **회색 화면 = 알림 창(`Notice Presenter`)의 차단막.** 창(`Panel`)이 `stretch` 앵커 + `sizeDelta(-1720, -680)`이라 캔버스 폭이 1720보다 좁으면 폭이 음수가 되어 **가운데 세로줄로 접혔다**(스크린샷 가운데의 `|`).
  `Canvas Scaler`가 세로 맞춤이라 캔버스 폭 = 화면 폭 × 1080 / 화면 높이 — 진우 화면 1221×842 → 1566. 1920×1080에서만 200×400으로 보였다.
- 등록·수령 성공 뒤 "등록했습니다" 같은 알림이 뜨는데 [알림 닫기]가 안 보여 가림막이 걷히지 않았다. 서버·대기(`ServerWaitManager` 5초 타임아웃)·경매장 연결은 문제 없었다 — 테스트 계정으로 등록 재현, 응답·알림 문구까지 정상.
- 수정: 알림 `Panel`을 가운데 고정 앵커 · 200×400(1920에서 보이던 크기 그대로). 다른 오버레이 창(결과·수량·확인·로그인·툴팁)은 이미 가운데 고정이다.
