# T-053 클라 — 작업슬롯 선택 화면을 목업 구조로

## 배경

작업슬롯 선택 화면은 산업 탭 · 캐릭터 줄(이름 한 줄) · 세팅(이름·적성 두 줄 + 해제)뿐이라
**무엇이 속도를 정하는지, 장비가 어디 붙는지가 화면에 없다.**
목업([`게임UI목업(2026-07-30 업데이트).html`](../../GameDesign/design/ui/게임UI목업(2026-07-30%20업데이트).html)의 `drawDetail`)은
산업 선택 · 캐릭터 선택 · 장비 · 효율 계산 네 칸으로 이 화면을 그린다. **구조만** 가져온다.

| 갈림길 | 결정 (2026-09-14) |
|--------|------------------|
| 색 | **지금 게임 팔레트.** 목업의 어두운 테마는 따르지 않는다 — 한 화면만 따로 논다 |
| 스크롤 | **효율 계산 영역만.** 값은 기존 스크롤 뷰와 같게 · 스크롤바는 판매 목록처럼 **항상 표시**(`Permanent`) |
| 적성 표시 | **숫자 5칸만** (창고 스트립과 같은 표기). 순서가 바로 위 산업 탭과 같아 위치로 읽힌다 |
| Lv·경험치 | **넘긴다** → [T-052](../T-052-클라캐릭터성장반영.md) |
| 데이터가 없는 곳 | **임시** — 흰 네모 이미지 · `추가 예정` 문구 · 주석에 "엑셀·기획·리소스가 나오면 추가 예정" |
| 전역 배수 | 가산이 아직 없어 `현재 ÷ 적성 기본값`이 곧 전역 배수다 → 1이 아니면 안내 문구, 1이면 숨김 |
