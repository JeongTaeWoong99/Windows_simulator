# T-139 클라 — 프레임 여유 구조 정리

## 배경

T-138 뒤 에디터 실측(2026-10-10, 인벤토리 캐릭터 탭 열어 둔 상태). 평균 PlayerLoop 3.4ms는 괜찮지만 **튀는 프레임**이 144fps(6.94ms)를 깬다.
기능이 늘수록 같은 구조에서 더 나빠지므로 **지금 구조 규칙 안에서** 튀는 원인을 걷는다.

| 증상 | 원인 (실측) |
|---|---|
| 수확마다 8~9ms | 획득 연출을 칸마다 첫 수확 때 만든다(컴포넌트 120개·`Instantiate`) · 수신 로그 4줄/수확(스택 추적 1.6~2.3ms) |
| 탭 전환 20~40ms | 탭 안 레이아웃 변경이 `!Horizental Columns`까지 올라가 화면 전체(7천여 사각형)를 다시 계산 · 특성 탭을 오갈 때 격자를 `SetActive`로 껐다 켜 200칸 전부 다시 그림 |
| 매 프레임 | 레이캐스트 2회(1회 0.25ms) · 남은 시간 글자 문자열 매 프레임 생성 · 넘침 검사 10프레임마다 4ms(에디터·개발 빌드) |

검증으로 **뺀 것**: Mask→RectMask2D(그리기 −50호출인데 CPU +1.2ms) · 진행 바마다 Canvas(악화) · 인벤 칸 재구성 합치기(0.3ms뿐) · 작업대 목록 재구성 합치기(0.05ms) · 진행 바 갱신 주기 낮추기(사용자 결정 — 설정 FPS를 따른다).
