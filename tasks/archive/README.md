# 보관 — 끝난 일감

**완료된 일감이 여기로 내려온다.** [`tasks/README.md`](../README.md)의 INDEX는
**지금 굴러가는 것만** 담고, 끝난 것은 이 폴더가 받는다.

- 파일은 **삭제하지 않는다** — 왜 그렇게 했는지의 기록이다.
- 평소에는 **열어 볼 필요가 없다.** 과거 결정의 근거를 되짚을 때만 들어온다.
- 취소·폐기된 일감도 여기로 내린다 (`상태`에 사유를 남긴다).
- INDEX 아래 쌓였던 경위·이력 메모도 여기 있다 → [`순서 메모 이력.md`](순서%20메모%20이력.md) (2026-09-13).

## 남은 조각이 있으면 새 일감으로 올린다

완료 처리했지만 잘린 조각이 남는 경우가 있다. **보관된 파일 안에 적어 두고 끝내지 않는다** —
여기까지 들어와 읽지 않으므로 잊힌다. 필요해지는 시점에 [`tasks/`](../README.md)에 새 번호로 등록한다.

> 예: T-006의 "적성 0 사전 차단 · 캐릭터 선택 UI · 희귀도 색상"은 아직 일감이 아니다.
