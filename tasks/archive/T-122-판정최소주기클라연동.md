# T-122 클라 — 판정 최소 주기를 공용 설정값으로 받기

## 배경 (태웅, 2026-10-04)

지금은 **산업마다 판정 1회의 최소 시간이 없다.** 서버에는 속도 하한(`WorkStationSlot.MinWorkSpeed = 1`)만 있고,
클라 `WorkStationProgress.CalculateCycleSeconds`도 같은 식을 그대로 따른다.

하한을 둔다면 서버·클라가 **같은 값**을 알아야 한다 — 한쪽만 걸면 진행 바와 실제 판정이 어긋난다.
그래서 값은 코드 상수가 아니라 **엑셀 설정값**(`Constants` 계열)으로 두고 양쪽이 같은 데이터에서 읽는다.
도입 여부·값은 [T-102](../T-102-판정최소주기.md)(진우 검토)가 정한다. 그때까지 **지금처럼 하한 없이** 둔다.

## 할 일

- [x] [T-102](../T-102-판정최소주기.md) 결론 — 전역 2.1초 · `Constants.MinCycleMs` (2026-10-09 태웅 결정)
- [x] `WorkStationProgress` — 진행도·남은 초·주기를 `GetEffectiveSpeed`(상한으로 자른 속도)로 계산
- [x] 효율 계산 실효 주기 줄에 "최소 주기 2.1초" 상시 · 닿으면 "(최소)" + 속도 상한 · 슬롯 목록 속도에 "(최대)"
- [x] `SlotStageSettings.RequiredCycleSeconds` — 연출 시간이 `MinCycleMs`보다 길어지면 플레이 시작 때 경고
- [x] 클라 몫 끝 (2026-10-09). **연출 실측은 서버 반영 뒤에야 의미가 있어** [T-102](../T-102-판정최소주기.md) 완료 조건으로 옮겼다 — 지금은 클라가 주기를 잘라도 서버 판정·푸시가 원래 속도로 와서 치트 배속 시 여전히 어긋난다(태웅 확인)
