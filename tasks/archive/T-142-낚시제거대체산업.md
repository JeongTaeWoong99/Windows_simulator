# T-142 낚시 산업 제거 · 유적 발굴로 교체

> **엑셀·서버·DB·기획 문서 교체 완료 (2026-10-12).** 클라 몫(화면 글자·클라 문서·아트)은
> [T-148](../art/T-148-클라발굴교체반영.md)로 떼어 [이슈 #66](https://github.com/JeongTaeWoong99/Windows_simulator/issues/66)으로 태웅에게 넘겼다.

## 배경

채집 흐름은 **"대상에게 달려가서 공격한다"** 이고 캐릭터 모션은 대기(IDLE) · 공격(ATTACK) · 달리기(RUN)뿐이다.
농사 · 채굴 · 사냥 · 벌목은 이 모션으로 자연스럽다.
**낚시는 전용 모션(던지기 · 기다리기 · 당기기)이 필요하다** — 공격으로 대신하면 물고기를 칼로 치는 그림이 되고, 맞는 에셋도 구하기 어렵다.

## 완료 조건

`fishing`·`낚시`가 코드·데이터·UI에 남지 않고(Agent 로그·보관 일감·옛 제안 문서 제외), 발굴로 배치 → 채취 → 획득이 실서버에서 돈다.
UI 글자·아트는 [T-148](../art/T-148-클라발굴교체반영.md)이 끝내야 다 닫힌다.

## 알아둘 점

- 경매장 DB(`auction.sqlite3`)에 걸려 있던 낚시 매물은 남는다 — 사면 메인 정산이 0행이라 실패하고 만료로 사라진다. 로컬에서 거슬리면 경매장 DB를 지운다.
- 원격 DB에 친구 데이터가 생긴 뒤라면 0002는 데이터를 지우는 마이그레이션이라 공지가 필요하다.
- 테스트 850개 중 `BoxSheetTest` 2개가 실패한다 — 이 작업 전부터다([T-112](../T-112-아이템다양화.md) 상자 개편 `a032487`에서 상자가 16종이 됐다).
