# T-170 클라 — 성장한 개체 즉시 판매 경고

> ⏸ → ▶ (2026-10-25) — 기다리던 T-169 결정이 났다: 자동 응축·판매는 하지 않는다

> ⏩ 261024 회차에 못 끝내 261107로 자동 이월 (2026-10-25)

## 배경

- 2026-10-17 태웅 — 응축(★)한 캐릭터나 인챈트한 장비를 즉시 판매할 때 실수로 날리기 쉽다. 일괄 담기로 함께 담기면 더 그렇다.
- 잠금(T-137)은 미리 걸어 둔 것만 막는다 — 잠그지 않은 성장 개체는 경고가 없다.
- 중복 처리 방향(T-169 · [이슈 #78](https://github.com/JeongTaeWoong99/Windows_simulator/issues/78))과 상관없이 필요한 UI 보충이다.

- [x] [판매] 확인 단계에서 성장 개체가 섞여 있으면 경고 문구 (몇 개인지)

## 한 것 (2026-10-20)

- 판매 목록 줄 이름 뒤 ★ · 인챈트 등급, 줄 툴팁에 응축·인챈트 줄 · 경고 줄에 "성장한 개체 N개 포함"(`SellCartModel.IsGrown`)
- 함께 — 응축 확인 팝업에 "응축을 쌓은 재료 N마리" 경고. 재료의 레벨·응축 계승은 [이슈 #84](https://github.com/JeongTaeWoong99/Windows_simulator/issues/84)
- 사용자 실측 확인. 자동 응축·판매는 취소돼 남은 것이 없다 (2026-10-25)

## 고친 것 (2026-10-27)

- 사용자 지적 — "성장한 캐릭터 판매 경고가 안 뜬다". **★만 성장으로 봐서** 일하며 레벨이 오른 캐릭터와 ★ 전까지 응축을 쌓은 캐릭터가 경고 없이 팔렸다.
- 기준을 **Lv2 이상 · 응축 누적 1 이상**으로 넓혔다 — 응축 재료 확인 팝업과 같은 기준(`SellCartModel.GrownCharacterLevel`). 판매 목록 줄 이름 뒤에 `Lv5 ★★` · 툴팁에 레벨·응축 줄
- [x] 사용자 실플레이 확인

## 고친 것 (2026-10-27 · 2차)

- 사용자 지적 — "Lv2 이상 · 응축 1 이상을 팔았는데 경고가 안 뜬다". **판정은 맞았다**(MCP 실측: Lv7 캐릭터 → `GrownCount = 1`, 머리 경고 줄에 "주의! 성장한 개체 1개 포함"). 경고가 목록 머리 30px 자동 축소 한 줄이라 두 줄이 되면 글씨가 작아져 안 보였고, [판매]는 묻지 않고 바로 보냈다.
- **성장 개체가 섞이면 [판매]·[마석으로 분해] 전에 확인 창** — 문구 = 경고 줄 + 누른 버튼 글자(새 문구 키 없음 · 엑셀 무변경). 성장 개체가 없으면 지금처럼 바로 판다(P1)
- MCP 확인: 성장 캐릭터를 담고 [판매] → 확인 창 "주의! 성장한 개체 1개 포함 / 골드로 판매 · 총 1,500 골드 획득" · 취소하면 그대로 남음
- [x] 사용자 실플레이 확인 (2차 · 2026-10-27)
