# T-087 경매장 서버 — 즉시구매

## 배경

기획 [거래](../../GameDesign/design/trade/README.md)의 거래소(D안)가 미착수였다.
경매장을 메인과 **다른 프로세스·머신**에 두고, 메인이 소유권 원천을 쥔 채 gRPC로만 대화한다.
설계 근거는 [`Server/docs/경매장.md`](../../Server/docs/경매장.md).

결정 (2026-09-23 사용자 확인):
- 스택 자원은 **매물 통째로만** 산다
- 검색은 **메인이 중계**한다(클라 → TCP → 메인 → gRPC). 경매장은 외부 포트가 없다
- 서버 간 전송은 설정으로 h2c·mTLS — 기본 h2c
- 등록비는 **만료 환급 · 취소 미환급**

- 메인·경매장 양쪽 테스트가 등록 → 검색 → 구매 → 우편 수령, 취소·만료 → 반환을 실제 경로로 검증한다
- 메인·경매장을 띄워 더미 클라로 한 바퀴 돈다
