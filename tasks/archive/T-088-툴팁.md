# T-088 클라 — 공용 툴팁 · 산업 레벨 정보를 툴팁으로 · 아이콘 버튼 툴팁

## 배경

슬롯 설정 화면의 산업 레벨 버튼을 누르면 그 레벨 정보(기준 주기·경험치·나오는 자원)가
**레이아웃 안에서 펼쳐졌다 접혔다** 하며 아래 목록을 밀었다([T-078](T-078-산업레벨정보표시.md)).
고르는 동작과 보는 동작이 한 버튼에 묶여 있어 거슬린다(2026-09-25 사용자).

**부가·세부 정보는 마우스를 올렸을 때 뜨는 툴팁으로 뺀다.** 앞으로 이미지로 바뀔 버튼
(세팅·종료 등)도 같은 툴팁으로 이름을 알린다. 툴팁은 계속 쓸 공용 부품이다.

| 갈림길 | 결정 |
|---|---|
| 자리 | 대상 요소의 **오른쪽 옆**에 붙는다. 창 밖으로 넘치면 **왼쪽으로 뒤집고**, 세로는 창 안으로 밀어 넣는다 — 커서를 따라다니지 않는다 |
| 지연 | 올린 뒤 **0.3초** · 숨김은 즉시 · 대상 사이를 바로 옮기면 지연 없이 교체 |
| 호버 감지 | Win32 커서 폴링 + `RaycastAll` — 창에 포커스가 없을 때도 떠야 한다(클릭스루 판정과 같은 이유) |
