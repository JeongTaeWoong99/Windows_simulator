# T-115 서버 — 특성 레벨 치트

> 2026-10-06 — ✅ **완료.** 클라 치트 창 특성 레벨 칸([T-117](T-117-치트창특성레벨.md))이 붙어 실서버에서 함께 확인했다(사용자 실측) — [이슈 #51](https://github.com/JeongTaeWoong99/Windows_simulator/issues/51) 닫음.
> 2026-10-06 서버 완료 — `ECheatCommand.SetTraitLevel = 11`. 클라 치트 창 묶음은 [T-117](T-117-치트창특성레벨.md)로 넘긴다([이슈 #51](https://github.com/JeongTaeWoong99/Windows_simulator/issues/51)).

## 배경

특성이 레벨형으로 바뀌면서([T-108](T-108-레벨형특성산출량.md)) 특성 노드가 `UnlockTable`에서 빠졌다.
`ECheatCommand.Unlock`은 해금 행만 열어 **특성(`t_user_trait`)에 닿지 않는다** — 치트 창의 특성 묶음이 먹통이 됐다.
정상 경로로만 올리면 산업 Lv5 확인에 계정 Lv50이 필요하다.

## 할 일

- [x] `ECheatCommand`에 특성 레벨 치트 (뒤에 추가) — `SetTraitLevel = 11` · `Arg1` = `UserTraitTID`(0이면 전 특성) · `Arg2` = 레벨. 계정 레벨 조건·포인트를 보지 않는다
- [x] 기본 레벨까지 내리기 · 최대 레벨을 넘으면 최대로 자르기 — 내린 레벨도 저장하고, 기본 레벨 행은 로그인 목록에 싣지 않는다
- [x] 속도·산출량 특성은 정상 경로처럼 바꾸기 전에 정산 · 속도 특성이면 슬롯 속도 재계산
- [x] 결과를 클라에 — `S_UserTraitListResponse` 재전송 (내린 특성은 목록에서 빠진다 = 기본 레벨)
- [x] 테스트(`UserCheatTraitTest` 13개) · 프로토콜 미러 커밋 · [`치트.md`](../Server/docs/치트.md) 2장 · 더미 클라 메뉴
- [x] 치트: 이 일감 자체가 치트다 — 영향받는 기존 `Unlock` 행(특성을 연다던 설명)을 문서에서 정정
- [x] 실서버 확인 (2026-10-06 · 사용자 실측) — 클라 치트 창 묶음([T-117](T-117-치트창특성레벨.md))이 붙으면 함께 본다

## 완료 조건

치트로 특성 레벨을 올리고 내릴 수 있고, 클라 특성 화면이 그 자리에서 바뀐다.
