# T-140 클라 — 루트 UI를 두 축으로

## 배경

`Root Canvas` 아래가 세 갈래(`!System Canvas` · `!Login Canvas` · `!Horizental Columns`)라 축이 흐리다.
늘 떠 있는 3열과 **그 위에 겹쳐 뜨는 것**, 두 축으로 줄인다(2026-10-10 사용자 결정).
기능은 그대로 두고 **사람이 봤을 때 형태가 같은 것은 같게** 맞춘다.

| 지금 헷갈리는 점 | 맞추는 방법 |
|---|---|
| 하이라키 순서가 그리는 순서와 반대 — 오버레이가 맨 위인데 실제로는 맨 앞에 그려진다(Sorting Order로 뒤집음) | 열을 첫 형제, 오버레이를 마지막 형제로 — 위에서 아래로 읽는 순서 = 깔리는 순서 |
| 오버레이 아래에 로그인만 **캔버스**, 나머지는 전부 **Presenter** | 로그인을 `Login Presenter`로 — 오버레이 캔버스가 Presenter를 담는다("캔버스에는 Presenter를 담는다" 규칙 그대로) |
| 로그인만 껍데기(어두운 판)와 상자의 층이 다르다 — 캔버스 = 어두운 판, Presenter = 상자 | 다른 팝업과 같게: `Login Presenter`(꽉 찬 어두운 판) → `Panel`(상자 · 세로 정렬) |
| 로그인 캔버스만 가운데 앵커 + 1920×1080 고정, 나머지는 꽉 채움 | 꽉 채움으로 |
| 두 축의 표기가 다르다 — 열은 표기 없음, 시스템은 `(MAIN VIEW)` + 호출처 없는 예약 `SystemCanvasView` | 오버레이도 표기 없는 축으로 — 예약 View 삭제 |
| Sorting Order가 0·1·2 — 규칙 문서는 "띄엄띄엄(100·200·300)" | 열 0 · 오버레이 100 · 끌리는 그림 200 |
| `Horizental` 오타 | `Horizontal` |
