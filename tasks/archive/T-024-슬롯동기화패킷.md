# T-024 슬롯 1칸 동기화 패킷 추가

## 배경

클라이언트가 슬롯 상태를 받는 시점이 **로그인(전체 스냅샷)과 배치 변경(1칸)** 두 곳뿐이었다.
채취 결과(`S_GatherResultResponse`)에는 슬롯 상태가 없어서:

1. **시각 오차가 교정되지 않았다** — 정산 후 서버의 `LastTickAt`이 갱신되지만 클라는 옛 값으로 외삽
2. **속도 변화를 클라가 몰랐다** — 버프·스탯으로 `CurrentWorkSpeed`가 바뀌어도 반영 안 됨

→ GitHub 이슈 #12

## 결정

`S_GatherResultResponse`에 슬롯을 합치지 않고 **별도 패킷으로 분리**했다.
채취 결과는 "뭐가 나왔다"이고 슬롯 동기화는 다른 관심사다.
분리하면 정산·속도 변경·이후 새 트리거에서 모두 같은 패킷 하나로 1칸씩 내려줄 수 있다.
