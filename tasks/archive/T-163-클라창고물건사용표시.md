# T-163 클라 — 창고 물건 사용 열기 · 창고 표시

## 배경

서버가 창고 물건도 인벤토리와 똑같이 쓰게 바꾼다([T-164](T-164-창고물건사용서버.md) · [이슈 #74](https://github.com/JeongTaeWoong99/Windows_simulator/issues/74)).
T-126에서 넣은 "창고 것 제외"를 걷고, 섞여 보이는 목록에서 창고 것임을 알아보게 한다.

## 할 일

- [x] [T-164](T-164-창고물건사용서버.md) — 서버 규칙 변경 (`383657d`)
- [x] 제외 처리 걷기 — 경매 등록 목록(`AuctionRegisterPresenter`) · 배치 목록(`WorkStationSelectPresenter`) · 응축 재료 · `EntityBlockText.InWarehouseText` 삭제 · `PlayerDataModel.GetItemCount(itemId)`가 양쪽 합산
      — 같은 TID가 두 보관함에 한 줄씩 있어도 목록은 TID당 한 줄(`PlayerDataModel.CollectOwnedItemIds`)
- [x] 창고 격자 클릭 조작 열기 — 판매 담기 · 큐브 · 응축 · 잠금 · 개봉 · 경매. 창고 격자의 큐브 창·응축 창 참조를 인벤토리 열의 같은 창으로 씬에 연결 · 툴팁 상태 줄(일하는 곳 · 착용자 + `창고 보관`)
- [x] **창고 표시 — 칸 좌하단 작은 상자 아이콘** (2026-10-15 사용자 결정). 우상단 상태 글자(배·장·잠)와 자리를 나눈다 — 위치와 상태가 겹쳐 생기므로.
      창고 격자 안에서는 띄우지 않고, 섞여 보이는 곳(배치 목록 · 장착 후보 · 큐브·응축 창 · 판매·경매 목록)에만. 그림은 PNG(임시 → 같은 이름 덮기)
      — `Sprites/ui/warehouse.png`(16px 🎨 임시) · `ItemIconView`(판매·경매·장착 후보·큐브 창) · `CharacterStateRowView`(배치 목록·배치 카드) · 응축 창 상반신
- [x] 판매 일괄 담기(`InventoryToolPresenter`)는 창고 것을 **계속 뺀다** — 범위 판매에 남겨 둔 것이 끼지 않게(2026-10-16 실측 뒤 사용자 결정). 창고 칸 우클릭 담기는 된다
- [x] 창고 격자에서 판매 담기·큐브·응축을 하면 인벤토리 열을 연다(`RevealInventoryColumn` · 2026-10-16 사용자 지적)
- [x] 칸 툴팁 줄 순서 통일 — 등급 → 고유 정보 → `보관` → `상태` → 가격 → 조작 (세 탭 · 2026-10-16 사용자 지적)
- [x] 치트: 기존 지급 치트로 확인 — 받은 것을 창고로 끌어 넣고 시험한다
- [x] 실측 — 장착·배치한 채 맡기기 · 창고 것으로 큐브·응축·판매·경매 · 재로그인 유지 · 상자 아이콘 위치

## 완료 조건

창고에 있는 것을 꺼내지 않고 모든 기능에 쓸 수 있고, 섞인 목록에서 창고 것이 좌하단 상자 아이콘으로 구분된다.
