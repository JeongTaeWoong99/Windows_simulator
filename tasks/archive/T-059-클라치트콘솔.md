# T-059 클라 — 치트 에디터 창 (admin 전용 개발 도구)

> 2026-09-16 — T-053으로 등록됐다가 번호가 겹쳐(보관된 T-053 선택화면 목업) T-059로 옮겼다. 해금 명령 `Unlock = 7`이 추가됐다.
> 2026-09-17 — 범위 변경: 게임 안 입력창(개발 빌드) → **에디터 창**(서버 콘솔과 분리, 도킹). 치트가 늘어도 한눈에 보이게. 안전장치 팝업 추가.
> 2026-09-19 — 서버 T-060 반영: **장비 지급 `GiveEquip = 8`** 칸 추가 · 정산에 **판정 횟수**(`Arg1`, 1~100) 입력칸.

## 배경

서버에 치트 명령이 들어왔다 (2026-09-16 → [`Server/docs/치트.md`](../../Server/docs/치트.md)).
`C_CheatRequest{Command, Arg1, Arg2}` 하나로 골드·다이아·아이템·캐릭터·캐릭터 경험치 지급과 즉시 정산·해금을 할 수 있고,
결과는 기존 동기화 패킷(재화·인벤·캐릭터·슬롯)으로 온다. Unity 쪽 핸들러·이벤트(`ServerPacketHandler.CheatResponded`)까지 있다.

## 할 일

- [x] 에디터 창 `Assets/Scripts_Client/Editor/cheat-console/` — 재화·아이템·캐릭터·경험치·정산·해금 칸 + 결과 로그. 툴바 '치트' 버튼 · `Window/DesktopWindowControl/치트`
- [x] TID는 테이블 목록(검색)에서, 경험치 대상은 보유 캐릭터 목록에서 고른다. 문자열 파싱은 두지 않는다
- [x] 안전장치 팝업 — Play 아님 · 서버 꺼짐 · 로그인 전 · 3초 응답 없음 · `NoPermission`
- [x] 서버 T-060 반영 — `장비 지급` 칸(`GiveEquip`, 개수 없음 · 개체 1개) · `정산`에 판정 횟수 슬라이더(1~100)
- [x] 실플레이 확인 (2026-09-19) — 서버 켜고 로그인해 골드·다이아·자원·캐릭터·경험치·해금·정산(판정 3회)·장비 지급까지 즉시 반영 확인

> `ResultMessages` 문구는 뺐다 — 게임 화면에서 치트를 보내지 않는다. 결과는 창 로그와 팝업으로 본다.
> 개발 빌드(exe)에서 치트가 필요해지면 게임 안 패널을 새 일감으로 연다.

## 완료 조건

에디터에서 로그인해 골드 1,000을 주면 재화 표시가 바로 바뀌고, 자원 지급·장비 지급이 **즉시** 창고에 보이며,
정산은 고른 판정 횟수만큼 앞당겨진다. 서버를 끈 채 누르면 사유 팝업이 뜬다.

> ⚠️ **"일반 계정이면 admin 아님 팝업"은 지금 재현할 수 없다** — 서버 `User.CheatAdminLevel = 0`이라
> 모든 계정이 통과한다(T-060의 결론). **배포 전 1로 되돌릴 때** 함께 확인할 항목으로 미룬다.

## 막고 있는 것 / 선행 일감

- 없음 — 패킷·핸들러가 다 있고, admin도 개발 기간엔 필요 없다(`CheatAdminLevel = 0`).
