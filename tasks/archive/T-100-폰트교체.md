# T-100 클라 — 폰트 교체 · KR·EN 폰트 에셋 분리 (자모 깨짐 · 흐림 · diff 노이즈)

> 2026-10-09 범위 확장 — 폰트 교체에 **KR·EN 에셋 분리**를 더했다. 언어 전환은 시트 다국어 구조([T-135](../T-135-다국어시트구조.md))가
> 먼저라 화면 쪽은 [T-136](../T-136-클라언어선택.md)으로 뗐다. 이 일감은 **폰트만** 다룬다.

## 배경

- 인벤토리 찾기(검색) 입력칸에 `ㅁ` `ㅇ` `ㅓ` `ㅏ`처럼 **낱자모**를 치면 글자가 깨져(□) 보인다 (사용자 보고 2026-09-30).
  한글 입력은 조합 중에 낱자모가 먼저 들어오므로 검색·이름 입력에서 늘 보인다.
- 일부 글자가 **선명하지 않다**(흐릿하게 번진다).
- 원인 확인 (2026-10-09):

| 문제 | 원인 |
|---|---|
| 자모 □ | 아틀라스 11,632자 중 완성형 11,172자는 있으나 **호환 자모(U+3131~318E) 0자** — 구울 때 문자 범위에 `3130-318F`가 빠졌다. `→`·`★`·`☆`도 없다 |
| 흐림 | neodgm은 16px 격자 **픽셀 폰트**인데 32pt SDF · Bilinear로 구웠고, 씬의 글자 크기가 12·13·14·15·17·20·22…로 제각각이다 — 16 배수가 아니면 번진다 |
| diff 노이즈 | Static이라 평소엔 없지만, 영문·한글이 **48MB `.asset` 한 파일**이라 글자 하나만 더해도 48MB가 통째로 다시 써진다 |

- 결정 (2026-10-09 사용자): **픽셀 폰트를 버리고 선명한 일반 폰트(SDF)로 교체한다.** 언어는 **KR·EN 둘만** 본다.
