# T-027 가챠 비용 — 골드를 내고 뽑는다

## 배경

**지금 가챠는 공짜다.** `GachaService.Draw`가 횟수와 풀 존재만 검사하고 바로 지급한다.
비용이 없으면 캐릭터를 무한히 뽑을 수 있어 **적성·배치·산업 레벨 해금이 전부 무의미해진다.**

기획의 sink 3종은 *거래 수수료 · 슬롯 확장권 · 가챠 티켓*이었으나
**가챠 비용은 골드 직접으로 확정한다(2026-08-17).** 티켓 획득 경로를 만들지 않아도
`판매 → 골드 → 뽑기`가 곧바로 이어지고, 즉시 판매(T-028)가 만든 골드에 **첫 출구**가 생긴다.

## 완료 조건

골드가 모자라면 뽑기가 거절되고, 뽑으면 **골드가 줄어든 잔액이 클라에 내려온다.**
공짜로 뽑히는 경로가 하나도 남지 않는다.

> ⏳ **실물 확인은 남았다** — 더미 클라로 돌리려면 골드를 벌 수단이 필요하다
> → [T-028](../T-028-즉시판매.md) 즉시 판매.
