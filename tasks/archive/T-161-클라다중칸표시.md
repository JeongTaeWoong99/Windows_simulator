# T-161 클라 — 같은 자원이 여러 칸에

## 배경

서버가 자원을 칸별 묶음으로 바꾸면([T-160](T-160-자원칸별묶음서버.md)) 한 아이템이 여러 칸에 온다.
지금 클라 캐시·공급자는 `ItemId` 하나 = 칸 하나를 전제한다(`PlayerDataModel.GetItemCount` 첫 줄만 읽음 등). → [이슈 #73](https://github.com/JeongTaeWoong99/Windows_simulator/issues/73)

## 할 일

- [x] [T-160](T-160-자원칸별묶음서버.md) — 서버 칸별 묶음 · 패킷 모양 (`1e58479`)
- [x] `PlayerDataModel` 자원 캐시를 `(Container, Slot)` 기준으로 덮어쓰기(`SetItemSlot` · 0개 칸은 지움) · `GetItemCount`는 칸들의 합 · `FindItemAt(container, slot)`
- [x] `ResourceSlotSource` — 칸마다 그리기 · 툴팁 `보유`는 이 칸 수량 + `전체 N 개`(칸 번호는 `InventorySlotSource.SlotNumberAt`)
- [x] 판매 담기 · 경매 등록 · 일괄 담기 · 상자 개봉의 보유량 판정을 합계로 (T-163에서 이미 `GetItemCount(itemId)`)
- [x] 끌어 놓기 — 정렬·칸 이동은 `S_StorageSlotsResponse.Items`, 창고 이동은 칸마다 `WarehouseChangeInfo` · 창고 이동 수량 팝업은 끈 칸 하나의 묶음
- [x] `StorageOverMaxStack` 문구 — "그 칸은 이미 가득 찼습니다. 빈 칸에 놓아 주세요." (이제 가득 찬 같은 자원 칸에 놓을 때만 난다)
- [x] 실측 — 9,999 넘게 수확 → 새 칸 · 칸이 다 찼을 때만 "가방 가득"

## 완료 조건

같은 자원이 여러 칸에 보이고, 판매·경매·개봉이 합계 기준으로 돈다.
