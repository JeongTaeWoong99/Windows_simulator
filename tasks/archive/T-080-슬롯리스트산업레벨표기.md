# T-080 클라 — 슬롯 배치 리스트에 산업 레벨 표기

## 배경

작업슬롯 목록의 칸은 지금 이렇게 적힌다.

```
슬롯 3 · 낚시 · 아무개 · 1.24배
```

**산업만 보이고 몇 레벨인지가 없다.** 레벨은 슬롯마다 따로이고(전역이 아니다)
판정 주기·드롭·경험치가 전부 레벨로 갈리는데, **목록에서는 Lv1과 Lv3이 똑같아 보인다.**
확인하려면 칸을 눌러 설정 화면까지 들어가야 한다.

## 조사 결과 — 이미 다 와 있다

**서버·패킷 변경이 필요 없다.** 값이 이미 목록 뷰의 손에 있다.

- `WorkStationSlotInfo.IndustryLevel`(byte)이 패킷에 **이미 실려 온다** (`Server/MikaProtocol/PacketInfo.cs`).
- `WorkStationSlotView.Bind(slot, characterName)`가 그 `slot`을 통째로 받는다 — **조회가 필요 없다.**
- 레벨 이름(`Lv2 밭` 같은)이 필요하면 `GameDataLoader.TryGetIndustryLevel(산업, 레벨, out row).Name` —
  슬롯 설정의 레벨 버튼 라벨이 이미 쓰는 경로다.

## 수정 필요 파일

| 파일 | 무엇 |
|------|------|
| `Assets/Scripts_Client/UI/Main/WorkStationListPresenter/WorkStationSlotView.cs` | `Bind`의 `slotText` 조립에 레벨 한 조각 추가 |
| 씬 `WorkSlotFrame` 프리팹 | **한 줄에 덧붙이면 손댈 것이 없다.** 별도 배지로 뺄 때만 프리팹 수정 |
| `Assets/Scripts_Client/UI/Main/Main 규칙.md` | 칸 표시 규칙에 한 줄 |

## 영향 범위

- `WorkStationSlotView` 한 파일이면 끝난다. 목록 Presenter·서버·패킷 변경 없음.
- **한 줄이 길어진다.** 지금도 `슬롯 N · 산업 · 캐릭터 · n.nn배` 넷이다.
  `Lv2`만 붙일지 `Lv2 밭`까지 쓸지, 한 줄을 유지할지 배지로 뺄지 정해야 한다
  (칸 폭은 `#Main Canvas` 고정 — 넘치면 TMP가 줄인다).
- **배치 없는 칸(`대기`)에는 레벨을 적지 않는다** — 산업이 `None`이라 의미가 없다.
