# T-141 클라 — 오버레이 캔버스 이름·순서

## 배경

T-140 뒤 사용자 질문(2026-10-10) 세 가지.

| 질문 | 결정 |
|---|---|
| Presenter를 담는 것은 늘 `Canvas (MAIN VIEW)`인데 `!Overlay Layer`만 다르다 | `!Overlay Canvas`로 — 이름이 "Presenter를 담는 캔버스"임을 말한다. `(MAIN VIEW)`는 **여닫는 캔버스(`...CanvasView`)** 표기라 상주하는 이 캔버스엔 붙이지 않는다 |
| 캔버스 하나에 Presenter 8개 — 병목인가, 나눠야 하나 | **하나로 둔다.** 켜진 그래픽 49개(열 1,333) · 자주 바뀌는 것은 FPS 글자 하나(다시 묶는 비용 0.01ms 차이) |
| 순서 — 로딩·툴팁·알림·FPS·로그인·팝업 | UGUI는 **아래 형제가 앞**이다. 앞→뒤: 툴팁 · 알림 · 로딩 · FPS · 로그인 · 확인 · 수량 · 결과. 사용자 안에서 **알림을 로딩 위로**(연결 끊김은 대기를 끝내지 않아 종료 안내가 덮인다) |
