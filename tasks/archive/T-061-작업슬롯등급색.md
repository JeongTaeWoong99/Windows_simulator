# T-061 클라 — 작업슬롯 칸 바탕을 캐릭터 등급 색으로

## 배경

창고 칸(`SlotView`)과 배치 화면 줄(`CharacterStateRowView`)은 이미 등급 색을 칠한다 (`RarityPalette.Get`).
그런데 작업슬롯 목록(`WorkStationSlotView`)과 위젯 미니 칸(`WidgetMiniSlotView`)은 등급이 안 보여서,
어떤 등급 캐릭터가 일하는지 글자를 읽어야 안다.
나중에 등급 이미지로 바뀔 예정이지만, 지금은 **색으로 가시성만** 올린다.

## 할 일

> 2026-09-17 — 코드·프리팹 배선이 들어갔고 플레이 눈 확인까지 통과해 보관했다.

- [x] `WorkStationSlotView`에 바탕 `Image` 참조 추가 (`= null!` + `RequireRef`) · 등급 색 적용
      — 선례(`CharacterStateRowView.SetRarity`)를 따라 `Bind` 뒤에 부르는 `SetRarity`로 뒀다
- [x] `WidgetMiniSlotView`도 같은 방식 — `characterImage`(스프라이트 자리)가 아니라 **프리팹 루트 Image**를 바탕으로 골랐다
- [x] 등급 출처: `slot.CharacterId`(개체 번호) → `PlayerDataModel.GetCharacterTid` → `GameDataLoader.GetCharacterRarity`.
      뷰가 직접 조회하지 않고 **패널(Presenter)이 등급을 넘긴다**
- [x] 캐릭터가 없는 칸은 `RarityPalette.Unknown` — 두 화면 모두 **배치된 칸에만 뷰를 만들어** 빈 칸은 뷰 자체가 없다.
      모르는 개체면 `None` → `Unknown`
- [x] 잠긴 칸(T-039)의 기존 표시와 겹치지 않는지 확인 — 잠긴 칸은 프레임 라벨만 쓰고 슬롯 뷰가 생기지 않는다
- [x] 바탕 `Image` 연결 — 칸은 런타임에 프리팹에서 만들어지므로 씬이 아니라 **프리팹**에 연결했다
      (`WorkStationSlotView.prefab` · `WidgetMiniSlotView.prefab` 루트 Image)
- [x] 배치 → 등급 색, 해제 → 칸이 사라지는지 플레이로 확인
- [x] 칸 글자(흰색)가 밝은 등급색(일반·고급·신화) 위에서 읽히는지 눈으로 확인

## 완료 조건

작업슬롯 목록과 위젯에서 캐릭터를 배치하면 칸 바탕이 그 캐릭터 등급 색으로 바뀌고, 해제하면 그 칸의 뷰가 사라진다(빈 프레임으로 돌아간다).
