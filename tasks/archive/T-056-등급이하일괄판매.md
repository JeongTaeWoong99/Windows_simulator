# T-056 클라 — 지정 등급 이하 자원 일괄 판매

## 배경

판매는 지금 **창고 자원 탭에서 우클릭으로 한 종류씩 장바구니에 담은 뒤** 판다([T-032](T-032-클라판매UI.md)).
방치형이라 채취 자원이 종류별로 계속 쌓이는데, 흔한 등급을 정리하려면 칸마다 우클릭을 반복해야 한다.
T-032에서 "희귀도/산업 단위 일괄 선택 — 필요해지면 새 번호로 등록"으로 남겨 둔 조각이다.

**서버는 이미 받는다** — `C_ItemSellRequest`가 `List<ItemInfo>`라 "Common 일괄 판매"가 요청 1번으로 끝난다([T-028](T-028-즉시판매.md)).
그래서 이 일감은 **클라만으로 끝난다.**

## 할 일

- [x] 등급을 고르는 UI → **창고 도구 줄**(탭 줄 아래 `Tool Presenter`)의 `○○ 이하` 드롭다운 + [판매] (2026-09-16)
- [x] 고른 등급 이하 보유 자원을 **보유 수량 전부** `SellCartModel`에 담는다 (`GameDataLoader.GetItemRarity`로 거른다)
- [x] 이미 담긴 항목과 겹칠 때의 규칙 → **누를 때마다 비우고 고른 범위만 다시 담는다** (2026-09-16 수정)
      처음엔 덮어쓰기만 했는데, 영웅 이하 → 일반 이하로 눌러도 **영웅·희귀가 남아** 있었다.
      `SellCartModel.Clear()` 후 담는다 — 우클릭으로 담아 둔 것도 함께 빠진다
- [x] 캐릭터·장비 탭에서는 잠그지 않고 이유를 알린다 — 서버 패킷·`BasePrice`가 없다(`RaiseNotice`)
- [x] 플레이 확인 — 담기는 종류·수량 · Rare 이상 포함 시 `HasHighRarity` 경고 · 판매까지 성공
      → **2026-09-20 사용자 확인 완료.** 등급을 고르고 [판매]를 누르면 그 등급 이하 자원이 담기고 판매까지 성공한다

## 완료 조건

등급을 하나 고르고 버튼을 누르면 그 등급 이하 자원이 전부 장바구니에 담기고,
판매 버튼 한 번으로 서버 판매가 성공해 골드가 들어온다.
