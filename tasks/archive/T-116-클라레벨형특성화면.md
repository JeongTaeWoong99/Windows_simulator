# T-116 클라 — 특성 화면을 레벨형으로

## 배경

서버가 특성을 노드 사슬에서 레벨형으로 바꿨다([T-108](../T-108-레벨형특성산출량.md) · [이슈 #50](https://github.com/JeongTaeWoong99/Windows_simulator/issues/50)).
클라는 옛 구조를 읽어 **특성이 전부 안 배운 것으로, 상위 산업 레벨은 잠금 판정 없이** 보인다.
화면은 **A안 — 산업 × 종류 표**(줄 = 공통·산업 5 · 열 = 개척·속도·산출량, 탭 없음)로 정했다(2026-10-02 · 사용자).
