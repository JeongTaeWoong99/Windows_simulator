# T-132 문서 사이트에 게임 데이터 뷰어(/data)를 단다

## 배경

판정 1회당·레벨별 드롭 테이블 같은 수치를 보려면 엑셀을 열거나 `DataLog/*.json`을 직접 읽어야 했다.
wsdocs에서 탭 하나로 모든 테이블을 볼 수 있게 한다.

## 할 일

- [x] `DataLog/*.json`을 읽어 테이블 하나 = 페이지 하나(`/data/<테이블>`) — 테이블별 코드 없이 범용
- [x] 검색 · 거르기 상자 · 열 정렬 · TID 이름표 · 단위(‰ 등) 환산 · Weight 묶음 비율
- [x] 상단 내비에 `데이터` 탭
- [x] 배포 트리거에 `GameDesign/DataLog/**` 추가
- [x] [`사이트.md`](../GameDesign/web/사이트.md) 갱신 · 버전 0.5.0
- 치트: 해당 없음 (문서 사이트)

## 완료 조건

배포된 wsdocs의 `데이터` 탭에서 낚시 드롭 테이블을 `IndustryLevel`로 거르면 레벨별 아이템·확률이 보인다.
