# T-038 작업슬롯 해금 — 잠긴 칸 정보 하달 · 해금 요청 처리

## 배경

**슬롯을 여는 경로가 서버에 아예 없다.** 기획은 2026-08-01에
**시작 2개 · 상한 8개 · 계정 레벨(자물쇠) × 골드(열쇠)** 로 확정됐는데, 서버는 그 이전 상태다.

```csharp
// Server/WSGameServer/User/User.WorkStation.cs:9
/// <summary>신규 유저에게 기본으로 열어 주는 작업슬롯 수. 시작 슬롯 수가 미확정이라 1개로 둔다.</summary>
public const int DefaultSlotCount = 1;   // ⚠️ 확정값은 2. 주석도 낡았다
```

그리고 **패킷이 잠긴 칸을 표현하지 못한다.**
`S_WorkStationSlotsResponse`는 `List<WorkStationSlotInfo> Slots` 하나뿐이고
여기엔 **열린 슬롯만** 담긴다. 상한도, 칸별 잠김 여부도, 여는 조건도 전달되지 않는다.

그래서 클라는 1~7번 칸을 **열린 빈 칸과 구분하지 못하고** "비어있음."으로 그린 뒤,
눌러서 배치를 시도하면 서버가 `InvalidSlotIndex`로 거절해
*"아직 열리지 않은 작업 슬롯입니다"* 알림만 뜬다. **여는 방법을 보여 줄 수가 없다.**

> **이 일감이 클라의 유일한 입구다.** 잠긴 칸 정보를 패킷에 싣지 않는 한
> [T-039](T-039-클라슬롯해금UI.md)는 한 줄도 못 쓴다.

## 할 일

곡선(T-012)을 **안 기다려도 되는 것**과 **기다려야 하는 것**이 갈린다.

### 곡선 없이 지금 가능

- [ ] `DefaultSlotCount` **1 → 2** + 낡은 주석 정정 (확정값은 2)
- [ ] **상한 8 강제** — 지금은 상한을 검사하는 코드가 없다
- [ ] `S_WorkStationSlotsResponse`에 **잠긴 칸 정보**를 싣는다
      — 전체 슬롯 수(상한) · 칸별 잠김 여부 · 그 칸을 여는 조건(필요 계정 레벨 / 필요 골드)
- [ ] 해금 요청 패킷 신설 — `C_WorkStationUnlockRequest` / `S_WorkStationUnlockResponse`
      ([`packet-creator`](../Server/.claude/skills/packet-creator/SKILL.md) 절차)
- [ ] `EResultCode` 200번대(작업슬롯 구역)에 결과 코드 추가
      — 계정 레벨 미달 · 골드 부족 · 이미 해금된 칸 · 상한 초과
- [ ] 해금 성공 시 **골드 차감 + 슬롯 개방 + DB 반영**이 한 덩어리로 돈다
- [ ] 테스트 ([`server-tdd`](../Server/.claude/skills/server-tdd/SKILL.md))
      — 상한 초과 거절 · 레벨 미달 거절 · 골드 부족 거절 · 정상 해금 시 골드 차감
- [ ] **프로토콜 미러 커밋** (T-025로 터진 사고 재발 방지 — 서버 일감 공통 완료 조건)

### 곡선(T-012)이 와야 가능

- [ ] ⏸ 레벨별 상한 곡선을 데이터로 넣는다 (레벨 N에 몇 칸까지)
- [ ] ⏸ 슬롯별 구매 비용 곡선을 데이터로 넣는다

> 📌 **곡선이 없어도 패킷 모양과 검증 골격은 먼저 세울 수 있다.**
> 임시값으로 돌려 두면 클라가 화면을 만들 수 있고, 곡선이 오면 값만 갈아 끼운다.
> 다만 **임시값인 것을 로그·주석에 남긴다** — `GatherSpeedMultiplier`가 확인용 값인 채로
> 잊혀 [T-004](T-004-전역배수복귀.md)가 된 전례가 있다.

## 완료 조건

클라가 로그인 직후 받은 스냅샷만으로 **8칸 각각이 열렸는지, 잠겼다면 무엇이 필요한지**를
알 수 있고, 해금 요청을 보내면 서버가 조건을 검증해 열거나 사유를 담아 거절한다.
신규 계정은 2칸으로 시작한다.

## 막고 있는 것 / 선행 일감

- **없음** — 위의 "곡선 없이 지금 가능" 항목은 선행 없이 착수할 수 있다.
- 곡선 값 자체는 [T-012](T-012-슬롯증가곡선.md) 대기. 그 안에서도
  **계정 레벨 곡선 미정**이 가장 안쪽 매듭이다.
