# T-137 기획·서버 — 캐릭터·장비 잠금 · 판매·경매·응축 재료에서 제외

## 배경

- 응축한 캐릭터·높은 등급 캐릭터·장비를 판매·경매 등록·응축 재료로 **실수로 날리지 않게** 잠금을 건다 (2026-10-09 태웅).
- 잠긴 칸에는 클라가 자물쇠를 그려 구분한다.
- 급하지 않다. → [이슈 #65](https://github.com/JeongTaeWoong99/Windows_simulator/issues/65)

## 할 일

- [x] 기획 — 잠금 대상 확정 → **캐릭터·장비만** (2026-10-13 진우). 자원(쌓이는 아이템)은 걸지 않는다 — TID 하나 = 칸 하나라 개체 단위 잠금이 맞지 않는다
- [x] 서버 — 개체마다 `IsLocked` 저장 — 마이그레이션 `0005-entity-lock` (`t_character`·`t_user_equip`.`is_locked`)
- [x] 서버 — 잠금/해제 요청 패킷 `C_EntityLockRequest { Target(ELockTarget), Id, Locked }` → `S_EntityLockResponse { Result, Target, Id, Locked }` (같은 상태여도 Ok)
- [x] 서버 — `CharacterInfo`·`EquipInfo`에 `IsLocked`
- [x] 서버 — 즉시 판매 · 경매 등록 · 응축 재료에서 `EntityLocked`(1200)로 거절 · 장비 분해는 [T-131](T-131-장비분해.md) 구현 때 같은 검사를 넣는다
- [x] 클라(태웅) — 칸 오른쪽 위 자물쇠 · **Ctrl+좌클릭** 잠금 토글(2026-10-15 사용자 결정) · 잠긴 개체는 판매 담기·일괄 담기·경매 등록·응축 재료에서 제외 — 2026-10-15 자동 실측(토글은 리플렉션 호출)
- [ ] 사람 손 실측 — 실제 Ctrl+좌클릭 입력 (키는 자동 입력이 닿지 않는다)

## 주의

- 최종 판정은 서버 — 클라만 막으면 뚫린다.
- 장착 · 작업슬롯 배치는 잠가도 된다. 잠금은 "없애는 동작"만 막는다.
