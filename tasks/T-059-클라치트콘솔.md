# T-059 클라 — 치트 입력 콘솔 (admin 전용 개발 도구)

> 2026-09-16 — T-053으로 등록됐다가 번호가 겹쳐(보관된 T-053 선택화면 목업) T-059로 옮겼다. 해금 명령 `Unlock = 7`이 추가됐다.

## 배경

서버에 치트 명령이 들어왔다 (2026-09-16 → [`Server/docs/치트.md`](../Server/docs/치트.md)).
`C_CheatRequest{Command, Arg1, Arg2}` 하나로 골드·다이아·아이템·캐릭터·캐릭터 경험치 지급과 즉시 정산을 할 수 있고,
결과는 기존 동기화 패킷(재화·인벤·캐릭터·슬롯)으로 온다. Unity 쪽 핸들러·이벤트(`ServerPacketHandler.CheatResponded`)까지 있다.

**보내는 곳이 없다.** 지금은 더미 클라(`MikaDummyClient`) 메뉴로만 보낼 수 있다.
Unity에서 테스트하려면 입력창이 필요하다.

## 서버가 준 것

| 것 | 위치 |
| --- | --- |
| `ECheatCommand` (1~7) · `EResultCode` 400대 | `Assets/Scripts_Server/Protocol/PacketEnum.cs` |
| `C_CheatRequest` · `S_CheatResponse` | `Assets/Scripts_Server/Protocol/MikaPacket.cs` |
| `CheatResponded` 이벤트 | `Assets/Scripts_Server/Network/MikaNetwork.Unity/ServerPacketHandler.cs` |

## 할 일

- [ ] **개발 빌드에서만 보이는 입력창** (`#if DEVELOPMENT_BUILD || UNITY_EDITOR`). 위치는 큰 창의 구석 — 상시 위젯에는 올리지 않는다
- [ ] 명령 드롭다운(`ECheatCommand`) + `Arg1`·`Arg2` 숫자 입력 → `_network.Send(new C_CheatRequest{…})`.
      문자열 파싱은 두지 않는다 — 서버 규칙과 같다
- [ ] `CheatResponded` 결과를 토스트 한 줄로. `NoPermission`이면 "admin 계정이 아닙니다"
- [ ] `ResultMessages`에 `NoPermission` · `InvalidCheatCommand` · `InvalidCheatArgs` 문구

## 완료 조건

에디터에서 admin 계정으로 로그인해 골드 1,000을 주면 재화 표시가 바로 바뀌고,
일반 계정으로는 거절 문구가 뜬다.

## 막고 있는 것 / 선행 일감

- 없음 — 패킷·핸들러가 다 있다.
- admin 계정: `t_user.admin_level`을 1로 올린 계정이 필요하다 (DB에서 직접).
