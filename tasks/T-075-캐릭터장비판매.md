# T-075 캐릭터·장비 판매

## 배경

지금 **팔 수 있는 것은 자원뿐이다.** 인벤토리 캐릭터·장비 탭에서 우클릭하면
"판매는 자원 탭만 지원합니다"로 끝난다(`StorageGridPresenter`·`SellCartPresenter`).

막고 있는 것은 클라가 아니라 **판매 패킷의 축**이다.

```csharp
// 지금 — 아이템 TID 축. 종류 + 개수만 나른다
C_ItemSellRequest { List<ItemInfo> Items }      // ItemInfo = { ItemTID, Count }
```

캐릭터·장비는 **개체**다(`CharacterId` · `EquipId` — `long` PK). 같은 TID의 개체가 여러 개이고
레벨·경험치·장착 상태가 개체마다 다르므로 "TID를 N개 판다"로는 **어느 개체인지 지정할 수 없다.**

가격 쪽 상태도 갈린다.

| 축 | 가격 컬럼 | 상태 |
| --- | --- | --- |
| 아이템 | `ItemTable.BasePrice` | ✅ 162행 전부 채워져 있다 |
| 장비 | `EquipTable.BasePrice` | ✅ 69행 전부 채워져 있다(70~360 등) — **컬럼은 이미 있다** |
| 캐릭터 | `CharacterTable.BasePrice` | ✅ 2026-09-30 추가 — 등급별 고정값 Common 50 · Uncommon 100 · Rare 250 · Epic 600 · Legendary 1500 · Mythic 4000 (뽑기 1회 1000 G의 기대 판매가 약 216 G) |

즉시 판매가 = `BasePrice`의 100%는 [거래](../GameDesign/design/trade/README.md) 3.1에서 확정됐다.
**장비는 이 규칙을 그대로 쓰면 되고, 캐릭터만 새로 정해야 한다.**

## 할 일

### 기획

- [x] **캐릭터를 팔 수 있게 할지 정한다.** → **판다**(2026-10-01 · #47). 경매장에도 올린다 캐릭터는 [character](../GameDesign/design/character/README.md) 1.1에서
      "중복은 개체를 늘린다 · 조각·강화로 바꾸지 않는다"로 확정돼 **중복 개체의 출구가 하나도 없다.**
      판매를 열거나, 다른 출구([T-076](T-076-성장재료소비처.md))를 열거나 둘 중 하나는 필요하다
- [x] **캐릭터 판매가** — 등급별 고정값으로 `CharacterTable.BasePrice`에 넣었다(2026-09-30 태웅). 레벨 반영은 하지 않는다(필요하면 다시 연다)
- [x] **레벨이 오른 캐릭터·장착 중인 장비를 팔 수 있는지** → 레벨은 막지 않는다. **착용 중인 장비 · 배치됐거나 장비를 낀 캐릭터 · 마지막 남은 캐릭터**는 막는다 (2026-10-01)
- [x] 장비 판매가는 `EquipTable.BasePrice` × `SellRatePermille`(100%) — 아이템과 같은 비율

- [x] `ResultMessages`에 새 거절 코드 문구 · Ok면 판 개체를 지운다(`PlayerDataModel`)

## 완료 조건

인벤토리 장비 탭에서 장비를 우클릭해 담고 판매하면 `EquipTable.BasePrice`만큼 골드가 들어오고
인벤토리에서 사라진다. 장착 중인 장비는 담기지 않는다. 캐릭터도 기획이 판매를 열기로 했다면 같게 동작한다.
