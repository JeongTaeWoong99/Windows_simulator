# T-075 캐릭터·장비 판매

## 배경

지금 **팔 수 있는 것은 자원뿐이다.** 창고 캐릭터·장비 탭에서 우클릭하면
"판매는 자원 탭만 지원합니다"로 끝난다(`StorageGridPresenter`·`SellCartPresenter`).

막고 있는 것은 클라가 아니라 **판매 패킷의 축**이다.

```csharp
// 지금 — 아이템 TID 축. 종류 + 개수만 나른다
C_ItemSellRequest { List<ItemInfo> Items }      // ItemInfo = { ItemTID, Count }
```

캐릭터·장비는 **개체**다(`CharacterId` · `EquipId` — `long` PK). 같은 TID의 개체가 여러 개이고
레벨·경험치·장착 상태가 개체마다 다르므로 "TID를 N개 판다"로는 **어느 개체인지 지정할 수 없다.**

가격 쪽 상태도 갈린다.

| 축 | 가격 컬럼 | 상태 |
| --- | --- | --- |
| 아이템 | `ItemTable.BasePrice` | ✅ 162행 전부 채워져 있다 |
| 장비 | `EquipTable.BasePrice` | ✅ 69행 전부 채워져 있다(70~360 등) — **컬럼은 이미 있다** |
| 캐릭터 | 없음 | ❌ `CharacterTable`에 가격 컬럼 자체가 없다 |

즉시 판매가 = `BasePrice`의 100%는 [거래](../GameDesign/design/trade/README.md) 3.1에서 확정됐다.
**장비는 이 규칙을 그대로 쓰면 되고, 캐릭터만 새로 정해야 한다.**

## 할 일

### 기획

- [ ] **캐릭터를 팔 수 있게 할지 정한다.** 캐릭터는 [character](../GameDesign/design/character/README.md) 1.1에서
      "중복은 개체를 늘린다 · 조각·강화로 바꾸지 않는다"로 확정돼 **중복 개체의 출구가 하나도 없다.**
      판매를 열거나, 다른 출구([T-076](T-076-성장재료소비처.md))를 열거나 둘 중 하나는 필요하다
- [ ] 판다면 **캐릭터 판매가 산식** — 등급별 고정값인가, 레벨 반영인가.
      정하면 `CharacterTable`에 `BasePrice` 컬럼을 더한다(`excel-table-creator`)
- [ ] **레벨이 오른 캐릭터·장착 중인 장비를 팔 수 있는지** — 실수로 파는 사고를 막을 방침
- [ ] 장비 판매가는 `EquipTable.BasePrice` 100%를 그대로 쓸지 확인(거래 3.1과 같게)

### 서버

- [ ] **개체 축 판매 패킷을 판다.** 기존 `C_ItemSellRequest`를 고치지 않고 따로 둔다 —
      아이템은 TID·수량 축이 맞고, 개체는 PK 목록 축이 맞다

      ```csharp
      C_EntitySellRequest { List<long> CharacterIds, List<long> EquipIds }
      S_EntitySellResponse { EResultCode Result, long GainedGold }
      ```

- [ ] 거절 코드 — 미보유 개체 · **장착 중인 장비** · 배치 중인 캐릭터 · 빈 요청
- [ ] **전부 성공하거나 전부 실패한다** — `S_ItemSellResponse`와 같은 원칙
- [ ] 판매 후 `S_CharacterSyncResponse`·`S_EquipSyncResponse`·`S_CurrencyResponse`로 갱신을 내린다
- [ ] 테스트(`server-tdd`) · 프로토콜 미러 커밋

### 클라

- [ ] `SellCartPresenter` 담기를 캐릭터·장비 탭으로 넓힌다 — 지금 막아 둔 안내 문구를 걷어낸다
- [ ] 담긴 것이 아이템/개체 두 축으로 갈리므로 **요청도 두 패킷으로 나뉜다** — 담기 목록이 섞이면 둘 다 보낸다
- [ ] 장착 중·배치 중인 개체는 **담기 단계에서 막는다** (서버 거절에만 기대지 않는다)
- [ ] `ResultMessages`에 새 거절 코드 문구

## 완료 조건

창고 장비 탭에서 장비를 우클릭해 담고 판매하면 `EquipTable.BasePrice`만큼 골드가 들어오고
창고에서 사라진다. 장착 중인 장비는 담기지 않는다. 캐릭터도 기획이 판매를 열기로 했다면 같게 동작한다.
