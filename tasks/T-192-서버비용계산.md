# T-192 서버 비용 계산

> ⏩ 261107 회차에 못 끝내 261121로 자동 이월 (2026-11-08)

## 배경

원격 서버는 지금 집 PC의 Docker에서 돈다([도커.md](../Server/docs/도커.md)). AWS로 옮길 때 한 달에 얼마가 드는지,
동접이 늘면 어디서 비용이 커지는지 알아야 한다 (2026-11-02 사용자 요청 · 이슈 #107 메모 "서버 비용 계산").
기능이 붙을 때마다 서버 부하가 바뀌므로 **회차(릴리즈)마다 다시 재서 표에 한 줄씩 쌓는다.**
[이슈 #109](https://github.com/JeongTaeWoong99/Windows_simulator/issues/109) 본문 표도 같이 갱신한다.

## 할 일

- [x] 부하 봇 `Server/MikaLoadTest` — N명 로그인 · 슬롯 배치 · 5초 핑, 서버 CPU·메모리·송신량 측정
- [x] 첫 측정 (261107 회차) — 결과는 [서버-비용.md](../Server/docs/서버-비용.md)
- [ ] 회차마다 같은 명령으로 다시 재고 표에 한 줄 추가 · 이슈 본문 표 갱신
- [ ] **DB를 WAL로 연다** — 기본(rollback) 모드는 heavy 동접 500명에서 `database is locked`로 세션이 끊긴다. 같은 DB를 WAL로만 바꾸면 500명이 깨끗하고 CPU가 1/4로 준다(261107 측정). 1000명에서도 잠금 오류 11건이 남는다 — 쓰기 묶기는 그다음
- [ ] 운영 로그 수준 — 지금은 패킷마다 Debug 로그(5분에 70MB). `ServerLog.MinLevel`을 설정으로 뺀다
- [ ] `MikaDummyClient` 빌드 깨짐 — `S_AccountLevelResponse.TraitPoint`가 없다 (이 일감과 무관, 발견만)

## 완료 조건

이 일감은 회차마다 되풀이한다 — 배포 준비(AWS 이전)를 결정할 때 닫는다.
