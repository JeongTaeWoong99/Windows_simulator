# T-051 문서 토큰 효율화 — 이슈 #18 권고의 서버·기획 쪽 적용

## 배경

클라이언트 담당이 [이슈 #18](https://github.com/JeongTaeWoong99/Windows_simulator/issues/18)에
**문서 토큰 효율화 권고**를 남겼다(2026-08-15). 요지는 둘이다 —
**트리거(읽히는 횟수)부터 보고**, 스킬은 전문 로드되니 **요지는 남기고 설명만 밖으로 뺀다.**
클라 쪽(`clean-code-style` 분할 · Agent 로그 INDEX 압축 · 스킬 트리거 정비)은 이미 적용됐다.

2026-09-13에 서버·기획 쪽 대상을 다시 재 보니 **하나도 처리되지 않았고**, 하나는 오히려 커졌다.

| 대상 | 이슈 시점 | 2026-09-13 |
|---|---|---|
| `.claude/skills/common/game-design-reference/SKILL.md` | 11.9KB | 11.9KB, 단일 파일 |
| `.claude/skills/common/excel-table-creator/SKILL.md` | 9.7KB | 9.5KB, 단일 파일 |
| `GameDesign/design/게임기획코어.md` | 38.7KB | 39.9KB, 앵커 목차 없음 |
| `GameDesign/design/기획평가.md` · `research/` | 36~48KB | 동일, "평소 열지 않는다" 표시 없음 |
| `tasks/README.md` | 9.2KB | **36.9KB — 4배** |
| `GameDesign/design/문서관계도.md` | 16.9KB | 17.0KB |

**우선순위는 이슈와 다르게 잡는다.** `tasks/README.md`는 T-0XX가 언급될 때마다
`task-reader`가 통째로 여는 파일이라, 지금은 저장소에서 **가장 자주 읽히는 큰 파일**이다.
이슈에서는 3순위였지만 여기서는 1순위로 올린다.

## 할 일

### A. 1순위 — 자주 읽히는 것

- [x] **`tasks/README.md` 압축** ✅ 2026-09-13 — **36.9KB → 12.8KB (−65%)**. 이력 메모 26.8KB는
      [`archive/순서 메모 이력.md`](archive/순서%20메모%20이력.md)로 내렸고, 살아 있던 사실 두 건은 T-002·T-029 파일로 옮겼다.
      행마다 한 줄 + 짧은 괄호 메모로. 2026-09-05의 **표 셋 구조는 유지**한다
      (가르는 축이 의도된 설계다). 표 밖의 긴 설명·순서 메모는 별도 절로 내리거나 일감 파일로 옮긴다.
      목표는 이슈 3-2절 실측(−49%) 수준
- [x] **`game-design-reference` 하이브리드 분할** ✅ 2026-09-13 — **11.9KB → 8.5KB**, 상세는 `전파 상세.md`(4.3KB).
      트리거·"읽지 않아도 되는 경우"는 이미 정비돼 있었다.
      분량의 절반인 **"재귀 전파" 장(109~183행)** 을 같은 폴더 `전파 상세.md`로 빼고,
      `SKILL.md`에는 규칙 요지(표 한 줄)와 "판단이 서면 열지 않아도 된다" 문장만 남긴다
- [x] **`excel-table-creator` 하이브리드 분할** ✅ 2026-09-13 — **9.5KB → 6.5KB**, 상세는 `컬럼 레퍼런스.md`(4.6KB).
      **절차·하드 규칙·체크리스트**는 `SKILL.md`에 남기고,
      **마커 행 구조·시트 병합·`Ref`·`Description`·Enum 시트** 레퍼런스를 `컬럼 레퍼런스.md`로 뺀다

### B. 2순위 — `GameDesign/design/`

- [ ] `게임기획코어.md` 상단에 **7개 장 앵커 목차** 추가. 규범·배경 분리는 **하지 않는다** —
      최상위 진입점을 쪼개면 링크 16곳과 클라 참조가 흔들리고, 테스트 단계라 수치가 자주 바뀐다
- [ ] `기획평가.md` · `research/` 는 **완결된 기록**이다. `GameDesign/CLAUDE.md` 폴더 표에
      "평소 열지 않는다 — 과거 평가·사례조사"를 한 줄 적는다

### C. 🎨 후순위

- [ ] 🎨 `문서관계도.md` INDEX 압축 — 자동 로드되지 않는 문서라 급하지 않다

## 완료 조건

A·B가 끝나고, 각 대상의 **한 번에 읽히는 양**(발동 시 로드되는 파일 크기)이 이슈 시점 대비 줄었음을
`wc -c`로 확인해 이 파일에 적는다. 이슈 #18에 결과 수치를 댓글로 남기고 닫는다.

**총량이 느는 것은 정상이다** — 아끼는 것은 디스크가 아니라 컨텍스트다(이슈 2절).
