# T-096 클라 — 거래소 · 경매장 화면

> **번호 변경 (2026-09-25)** — 처음엔 **T-088** 이었다. 원격에 같은 번호의 다른 일감(툴팁)이 먼저 올라가 T-096으로 옮겼다.
> 다른 문서·로그에 남은 `T-088` 가운데 **경매장·거래소 클라 화면**을 가리키는 것은 이 일감이다.

## 배경

서버 쪽 경매장(장비 즉시구매, [T-094](archive/T-094-경매장서버.md))과 거래소(자원 수량 구매·시세, [T-091](archive/T-091-거래소수량구매.md))가 섰다.
패킷은 Unity로 미러링돼 있고 클라 구독자가 0건이다. 클라 요청: [이슈 #37](https://github.com/JeongTaeWoong99/Windows_simulator/issues/37)
플레이어 규칙은 [거래](../GameDesign/design/trade/README.md) 4장, 패킷 계약은 `MikaPacket.cs`의 `C_/S_Auction*`·`C_/S_Market*` 주석.

### 클라가 알아야 할 구조

```
Unity 클라 ──TCP(기존 MikaNetwork)──▶ 메인 서버 ──gRPC──▶ 경매장 서버
```

- **클라는 메인 서버에만 붙는다.** 경매장 서버는 클라에 보이지 않는다 — 새 접속·주소·인증이 없다.
- 산 물건 · 판매 대금 · 취소/만료 반환은 **전부 우편**으로 온다(`S_MailArrivedResponse`). 거래 응답에는 물건이 실리지 않는다.
- 골드는 `S_CurrencyResponse`로 따로 온다. 등록하면 인벤토리 변화가 `S_AuctionRegisterResponse`에 실린다.
- 경매장이 점검 중이면 조회·구매가 `AuctionUnavailable`(1000)로 온다 — 게임은 그대로 돈다.
