# T-033 클라 — 상자 개봉 UI · 연출

## 배경

**상자는 "쌓아 뒀다가 한꺼번에 까는 맛"이 전부다.**
서버(T-029)가 개봉 결과를 가챠와 **같은 모양**(`GachaRewardInfo`)으로 내려주므로,
연출 코드를 두 벌 만들지 않고 T-031의 결과 연출을 재사용한다.

## 할 일

- [ ] 인벤토리에서 상자 사용 — 1개 / 보유분 전부 개봉
- [ ] 개봉 연출 — **T-031의 결과 연출을 공유한다.** 상자 전용으로 새로 만들지 않는다
- [ ] 대량 개봉(수십 개) 시 연출을 건너뛰고 **요약으로 보여주는 경로**를 둔다
      (하나씩 재생하면 몇 분간 화면이 잠긴다 — P1 위반)
- [ ] 개봉 후 인벤토리 갱신
- [ ] 상자가 쌓였다는 것을 **재촉하지 않고** 알리는 표현을 고른다
      (⚠️ 위젯 배지·타이머·"오늘까지"는 P3에서 **금지**다)

## 완료 조건

인벤토리에서 상자를 전부 까면 **결과가 요약으로 보이고** 아이템이 들어온다.
연출 로직이 가챠 화면과 하나의 코드다.

## 막고 있는 것 / 선행 일감

- `T-029` — 개봉 패킷
- `T-031` — 결과 연출을 공유하므로 먼저 있어야 한다
