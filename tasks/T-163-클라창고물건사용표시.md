# T-163 클라 — 창고 물건 사용 열기 · 창고 표시

## 배경

서버가 창고 물건도 인벤토리와 똑같이 쓰게 바꾼다([T-164](T-164-창고물건사용서버.md) · [이슈 #74](https://github.com/JeongTaeWoong99/Windows_simulator/issues/74)).
T-126에서 넣은 "창고 것 제외"를 걷고, 섞여 보이는 목록에서 창고 것임을 알아보게 한다.

## 할 일

- [ ] ⏸ [T-164](T-164-창고물건사용서버.md) — 서버 규칙 변경
- [ ] 제외 처리 걷기 — 판매 일괄 담기(`InventoryToolPresenter`) · 경매 등록 목록(`AuctionRegisterPresenter`) · 배치 목록(`WorkStationSelectPresenter`) · `EntityBlockText.InWarehouseText` · `PlayerDataModel.GetItemCount`가 양쪽 합산
- [ ] 창고 격자 클릭 조작 열기 — 판매 담기 · 큐브 · 응축 · 잠금 · 개봉 (`InventoryGridPresenter`의 `IsInventory` 막기)
- [ ] **창고 표시 — 칸 좌하단 작은 상자 아이콘** (2026-10-15 사용자 결정). 우상단 상태 글자(배·장·잠)와 자리를 나눈다 — 위치와 상태가 겹쳐 생기므로.
      창고 격자 안에서는 띄우지 않고, 섞여 보이는 곳(배치 목록 · 장착 후보 · 큐브·응축 창 · 판매·경매 목록)에만. 그림은 PNG(임시 → 같은 이름 덮기)
- [ ] 실측 — 장착·배치한 채 맡기기 · 창고 것으로 큐브·응축·판매·경매 · 재로그인 유지

## 완료 조건

창고에 있는 것을 꺼내지 않고 모든 기능에 쓸 수 있고, 섞인 목록에서 창고 것이 좌하단 상자 아이콘으로 구분된다.
