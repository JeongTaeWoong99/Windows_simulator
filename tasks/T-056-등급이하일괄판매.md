# T-056 클라 — 지정 등급 이하 자원 일괄 판매

## 배경

판매는 지금 **창고 자원 탭에서 우클릭으로 한 종류씩 장바구니에 담은 뒤** 판다([T-032](archive/T-032-클라판매UI.md)).
방치형이라 채취 자원이 종류별로 계속 쌓이는데, 흔한 등급을 정리하려면 칸마다 우클릭을 반복해야 한다.
T-032에서 "희귀도/산업 단위 일괄 선택 — 필요해지면 새 번호로 등록"으로 남겨 둔 조각이다.

**서버는 이미 받는다** — `C_ItemSellRequest`가 `List<ItemInfo>`라 "Common 일괄 판매"가 요청 1번으로 끝난다([T-028](archive/T-028-즉시판매.md)).
그래서 이 일감은 **클라만으로 끝난다.**

## 할 일

- [ ] 등급을 고르는 UI — "이 등급 이하 전부 담기" (자원 탭 판매 정보 칸 근처)
- [ ] 고른 등급 이하 보유 자원을 **보유 수량 전부** `SellCartModel`에 담는다 (`GameDataLoader.GetItemRarity`로 거른다)
- [ ] 이미 담긴 항목과 겹칠 때의 규칙 — 보유량 전부로 덮는다
- [ ] 오판매 방지 — Rare 이상이 포함되면 기존 `HasHighRarity` 경고가 그대로 뜨는지 확인

## 완료 조건

등급을 하나 고르고 버튼을 누르면 그 등급 이하 자원이 전부 장바구니에 담기고,
판매 버튼 한 번으로 서버 판매가 성공해 골드가 들어온다.
