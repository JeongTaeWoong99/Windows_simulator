# T-040 하트비트 끊김 — 해결 방향 결정 (이슈 #19)

## 배경

**독립된 문제가 둘이다. 각각 하나씩, 총 두 개를 골라야 한다.**

| | 증상 | 원인 | 빈도 |
|---|---|---|---|
| **A** | 아무 조작도 안 했는데 연결이 끊긴다 | 서버 판정(5초)과 클라 핑 주기(5초)의 **여유가 0** | 수십 분에 한 번 |
| **B** | 창을 **5초 이상** 끌면 끊긴다 | **소켓 루프가 Unity 메인 스레드에 묶여 있다** | **확정적** |

> **A와 B는 서로를 풀어 주지 않는다.** 둘 다 결정이 필요하다.
> ⚠️ **에디터에서는 B가 재현되지 않는다** — 창 제어 코드가 `#if !UNITY_EDITOR`다. **빌드에서만** 나온다.

### ⚠️ 전제 — 창 드래그는 없앨 수 없다

B를 볼 때 "드래그를 빼면 되지 않나"가 먼저 떠오르는데, **그게 안 되는 것이 이 문제의 본질**이다.

- 이 게임은 **데스크톱 위에 상주하는 방치형**이라 창이 배경에 얹혀 보여야 한다.
  그래서 **OS 타이틀바를 지웠다**(보더리스 + 투명).
- 타이틀바를 지우면 **창을 옮길 손잡이도 사라진다.** 그래서 **UI 패널(`WindowDragArea`)이 타이틀바 역할**을 한다.
  창 이동은 빼도 되는 기능이 아니라 **타이틀바를 포기한 대가로 반드시 있어야 하는 기능**이다.
- 이동은 직접 좌표 계산 대신 `WM_SYSCOMMAND(SC_MOVE_HTCAPTION)`으로 **OS 이동 루프에 위임**한다 —
  **스냅 · 더블클릭 최대화 · 모니터 간 이동 · DPI 전환**이 전부 공짜로 따라오기 때문이다.
  ([`DesktopWindow 규칙.md`](../Assets/Scripts_Client/DesktopWindow/DesktopWindow%20규칙.md) §5-7)
- **이 위임은 데스크톱 상주형의 특수 사정이다.** 전체화면 게임은 타이틀바가 있어 이 코드도, 이 문제도 없다.

**대가가 이번 문제다.** OS 이동 루프가 도는 동안 **Unity 메인 스레드만** 멈추는데
(다른 스레드는 멀쩡하다), 하필 **소켓 송수신이 메인 스레드에 얹혀 있어** 같이 멈춘다.

> 그래서 B의 선택지는 "드래그를 없앤다"가 아니라
> ① **메인 루프가 멈춰도 소켓은 살아 있게 한다**(B-1) ② **OS 위임을 포기하고 직접 구현한다**(B-2) 둘 중 하나다.

## 왜 보류인가

**클라가 시험 적용해 증상이 사라지는 것까지 실측 확인했지만, 되돌렸다.**

효과를 낸 수정(`Task.Run` + `ConfigureAwait(false)`)이 **서버 담당 폴더**
(`Assets/Scripts_Server/Network/MikaNetwork.Client/`)에 있었고, **그 방식이 유일한 답도 아니다.**
후보마다 **경제 밸런스**(좀비 부당 적립) · **창 제어 설계**(OS 위임을 버릴 것인가) · **패킷 추가**와 얽힌다.
**클라 단독으로 정할 문제가 아니다.**

- 되돌린 커밋 `45b55c6` → 되돌림 커밋 `2fb9dcb`. **revert의 revert로 그대로 되살릴 수 있다.**
- **지금 `main`은 수정 전 상태이고 증상이 그대로 재현된다.**

## 할 일

### ⏸ 결정 대기 (이슈 #19)

- [ ] **A — 여유를 만든다. 하나 고른다**
  - `A-1` 서버 판정을 늘린다 (5초 → 15초) — ⚠️ **[T-004](T-004-전역배수복귀.md)와 함께 봐야 한다**
  - `A-2` 클라 핑 주기를 줄인다 (5초 → 2초) — 서버 무수정, 여유 3초, 트래픽 2.5배
  - `A-3` 서버가 판정 시간을 로그인 응답에 실어 내리고 클라가 주기를 계산 — 어긋날 수 없다, 패킷 필드 추가
- [ ] **B — 창을 끄는 동안에도 살아 있게 한다. 하나 고른다**
  - `B-1` 소켓 루프를 스레드풀로 (`Task.Run` + `ConfigureAwait(false)`) — **근본·실측 확인. 단 서버 폴더**
  - `B-2` OS 위임을 포기하고 창 이동을 직접 좌표 계산으로 — 클라 단독. 스냅·최대화·다중 모니터 재구현
  - `B-3` 서버 판정을 드래그보다 길게(30~60초) — 부당 적립 구간 증가
  - `B-4` 드래그 중 "일시 정지" 통보 패킷 — 클라가 유휴 판정을 회피할 수 있다
- [ ] 📌 **어느 걸 고르든 함께** — **"핑 주기 ≤ 판정 시간 ÷ 3"** 을 규칙으로 문서에 못 박는다.
      이번 사고는 두 값이 **각각은 멀쩡한데 짝이 안 맞아서** 났다. 값만 바꾸면 다음에 또 난다.
