# T-147 클라 — 경매장 UI 목업 · 화면 전체를 쓰는 경매장

## 배경

지금 경매장은 오른쪽 거래 열(`#Market Canvas`, 폭 603)의 **탭 하나**다 — 뽑기 · 경매장 · 창고 ([T-096](archive/T-096-클라경매장화면.md)).
그 안에 구매·등록·내 매물 하위 탭, 구매 안에 자원·장비·캐릭터 축 줄까지 탭이 세 겹이라 좁다.
장비 검색 줄은 열 폭을 넘어 두 줄로 쪼갰다(`Market 규칙.md` — min 폭 합 685 > 열 폭 603).

**경매장은 사이드 열의 탭 하나가 아니라 화면 전체를 쓰게 한다** (2026-10-11 사용자 결정).
구조를 바꾸기 전에 목업으로 모양을 정한다.

**목업은 진우가 직접 만들어 태웅에게 넘긴다** (2026-10-11). 넘길 때 담당을 `태웅`으로 바꾸고 이슈로 알린다.

## 할 일

### 진우 — 목업

- [ ] 목업 — 화면 전체 경매장의 배치를 정한다
  - 넓어진 폭에 무엇을 두나 — 분류(자원·장비·캐릭터) · 검색·필터 · 목록 · 고른 매물 상세·구매 · 등록 · 내 매물
  - 탭 세 겹(구매·등록·내 매물 / 자원·장비·캐릭터)을 그대로 둘지, 넓은 폭에 맞게 줄일지
- [ ] 여는 법·닫는 법 — 거래 열의 [경매장] 탭이 전체 화면을 여는지 · 하단 메뉴에 따로 두는지 · 거래 열에는 뽑기·창고만 남는지
- [ ] 전체 화면일 때 3열(인벤토리 · 작업슬롯 · 거래)을 가리는지 닫는지 — `!Horizontal Columns` 위 `!Overlay Canvas` 층에 띄울지 함께 정한다
- [ ] 인벤토리 칸 **Shift+우클릭 → 등록**(`MarketCanvasView.OpenAuctionRegister`) — 전체 화면이 인벤토리를 가리면 이 흐름이 어떻게 이어지는지
- [ ] 목업을 태웅에게 넘긴다 — 이슈 등록 · 담당 `태웅`으로

### 태웅 — 구현

- [ ] 목업대로 씬 재배치 · `Market 규칙.md` · `UI 배치 현황.md` 갱신

## 완료 조건

진우의 목업이 넘어갔고, 경매장이 거래 열 탭이 아니라 화면 전체로 열려 구매·등록·내 매물이 전처럼 동작한다.
