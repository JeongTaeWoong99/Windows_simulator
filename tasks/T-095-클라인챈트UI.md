# T-095 클라 — 장비 능력치 칸 UI

> **기획이 바뀌었다 (2026-09-29).** 처음에는 T-092 인챈트(장비 하나에 등급 하나 · 2~3줄 · 아이템 5종)의 화면이었다.
> 인챈트가 장비 등급과 따로 돌아 "좋은 장비에 큐브를 돌린다"는 동기가 없어서,
> **장비 등급 = 능력치 칸 수 · 큐브 1종으로 칸 하나씩 뽑기**로 바꾸자고 서버·기획에 요청했다 →
> [이슈 #46](https://github.com/JeongTaeWoong99/Windows_simulator/issues/46) (규칙·수치·패킷 제안은 이슈 본문).
> 옛 인챈트 화면 요청 [#38](https://github.com/JeongTaeWoong99/Windows_simulator/issues/38)은 #46이 처리되면 새 구조로 고쳐 쓴다.

> **⏸ → ▶ (2026-10-03).** #46 서버·데이터 처리가 도착했다(`ac9a8e3`). 요청과 규칙이 다르다 — **칸 수 = 장비 등급**(일반·고급 1 · 희귀·영웅 2 · 전설·신화 3, `EnchantGradeTable.SlotCount`),
> **인챈트 등급은 장비당 하나**, 큐브 2종(`100015` · 상급 `100018`)이 **칸 전부를 다시 뽑는다**(칸 선택 없음), 착용 중 불가. 아래 요약은 옛 제안이다 — 상세는 이슈 #46 서버 코멘트.

## 한 줄 요약

장비 등급이 능력치 칸 수를 정하고(일반·고급 1 · 희귀·영웅 2 · 전설·신화 3), 큐브를 쓰면 **칸 전부**를 다시 뽑는다.
첫 사용은 일반 등급으로 채우고, 그다음부터는 확률로 인챈트 등급이 **한 단계** 오른다(내려가지 않는다 — 메이플 잠재능력 큐브).
장비 칸 **좌클릭**이 판매 목록 자리에 큐브 창을 연다.

**결정 (2026-10-03 사용자)** — D1 장비 탭 좌클릭으로 연다 · D2 쓴 뒤 창 유지 [한 번 더] · D3 큐브 버튼에 상승 확률 표시 ·
D4 착용 중이면 [해제하고 사용] · D5 덮어쓰기 경고 없음 · D6 큐브 설명문(`ItemTable` 100015·100018)을 엑셀에서 고친다 ·
열리면 판매 목록은 비워지며 물러난다 · 규칙·확률 설명을 화면(규칙 줄)과 툴팁에 둔다.
