# T-095 클라 — 장비 인챈트 UI

## 배경

서버 쪽 장비 인챈트가 [T-092](archive/T-092-인챈트.md)로 끝났다(2026-09-23 · 실서버 확인까지).
패킷은 다 있는데 **클라 구독자가 0건**이다. 장비는 인챈트를 가질 수 있지만 화면에는 보이지 않고, 쓸 방법도 없다.

- 설계: [`docs/superpowers/specs/2026-09-23-equip-enchant-design.md`](../docs/superpowers/specs/2026-09-23-equip-enchant-design.md)
- 기획: [캐릭터 1.4](../GameDesign/design/character/README.md) · [아이템 4.2](../GameDesign/design/item/README.md)

**한 줄 요약** — 장비 개체가 `(인챈트 등급 Rare·Epic·Legendary, 옵션 줄 2~3개)`를 가진다.
옵션은 **속도 가산**(특정 산업 또는 전 산업)과 **캐릭터 경험치** 둘뿐이다. 아이템 3종으로 바꾼다:

| 아이템 | TID | 하는 일 |
| --- | --- | --- |
| 인챈트 원석 · 정제된 인챈트 원석 | 100013 · 100014 | 부여 — 인챈트 없음 → Rare 2줄 (50% · 확정) |
| 인챈트 큐브 | 100015 | 등급 상승 판정 → **줄 전부 재롤**(실패해도 재롤) |
| 인챈트 확장석 · 정제된 인챈트 확장석 | 100016 · 100017 | 2줄 → 3줄 (30% · 확정) |

## 할 일

- [ ] **받기** — `EquipInfo.EnchantGrade`(0 = 없음, 그 외 `GlobalRarity`) · `EnchantOptions`(`EnchantOptionTID` 목록)를
      `S_EquipListResponse`·`S_EquipSyncResponse`에서 받아 장비 모델에 싣는다
- [ ] **표시** — 창고 장비 칸·상세에 인챈트 등급(등급 색)과 옵션 줄. 줄 문구는 `EnchantOptionTable`의
      `Industry`·`OptionType`·`Value`(천분율)로 만든다 — 예: `낚시 +4%` · `전 산업 +2%` · `경험치 +3%`
- [ ] **사용** — 인챈트 아이템 + 대상 장비를 골라 `C_EquipEnchantRequest { EquipId, ItemTid }`
- [ ] **결과** — `S_EquipEnchantResponse`
      - `Result == Ok`: `Success` · `BeforeGrade`→`AfterGrade` · `Options`(동작 후 줄)를 보여 준다
      - **거절이면 `Result`·`EquipId`만 유효하다** — 나머지는 기본값이니 그리지 않는다(등급 0 · 빈 줄을 그리면 인챈트가 날아간 것처럼 보인다)
- [ ] **거절 문구** — `ResultMessages`에 추가: `ItemNotUsable`(302, 인챈트 아이템이 아님) ·
      `EnchantItemNotOwned`(610) · `EnchantAlreadyRolled`(611) · `EnchantNotRolled`(612) · `EnchantLineMax`(613) · `EnchantEquipped`(614)
- [ ] **착용 중이면 막는다** — 서버가 `EnchantEquipped`로 거절한다. 캐릭터가 착용한 장비는 고를 수 없게 하거나 "벗긴 뒤 인챈트" 안내
- [ ] 🔴 **효율 계산에 인챈트 줄을 넣는다** — `WorkStationSelectPresenter.GetEquipSpeedAdd`(지금 `:1161`)가 장비 가산을
      `EquipTable.SpeedAddPermille`만으로 더하고, **장비 자체의 산업이 슬롯과 다르면 장비를 통째로 건너뛴다.**
      이 메서드는 주석대로 서버 `User.GetEquipSpeedAdd`의 사본인데, **서버 쪽은 인챈트 반영으로 이미 바뀌었다**(2026-09-23)
      인챈트 줄은 **줄마다 자기 산업**을 가지므로(낚싯대에 `농사 +4%` 줄이 붙을 수 있다) 판정이 장비 안으로 들어가야 한다.
      서버의 규칙은 `Equip.SpeedAddPermilleFor`(`Server/WSGameServer/User/Equip/Equip.cs`) — 같은 식으로 맞춘다

## 완료 조건

- 인챈트 아이템으로 부여 → 큐브 → 확장을 화면에서 끝까지 할 수 있다
- 창고에서 장비의 인챈트 등급·옵션이 보이고, 재접속해도 그대로다
- 인챈트 장비를 장착한 슬롯에서 **효율 계산 화면의 속도가 서버가 보낸 슬롯 속도와 같다**

## 알아둘 것

- 인챈트 수치(옵션 값·가중치·아이템 확률)는 **테스트값**이다. 등급 상승 확률만 확정(Rare→Epic 5% · Epic→Legendary 0.5%)
- 인챈트 아이템은 **상자 3종을 열면** 나온다. 치트는 기존 `GiveItem`으로 준다(전용 치트 없음)
