# T-105 기획 — 남는 자원의 사용처

## 배경

채취로 쌓이는 자원의 출구가 **판매(골드)뿐**이다. 확정된 sink 3종(수수료 · 슬롯 확장권 · 가챠 비용 —
[게임기획코어](../GameDesign/design/게임기획코어.md))은 전부 **골드**를 먹고 **자원은 직접 먹지 않는다.**
결국 자원은 인벤토리를 채우다 팔리는 것 말고 쓸 데가 없다 — 모을 이유가 골드 환산뿐이다.
사용자 아이디어(2026-09-30): **팰월드의 건물 업그레이드처럼** 자원을 먹여 무언가를 키운다. 다만 건물에 캐릭터를
배치하면 **작업슬롯과 콘텐츠가 겹친다**는 고민이 함께 나왔다.

## 방향 후보 (디벨롭 — 결정은 기획)

| 안 | 내용 | 작업슬롯과의 관계 | 장단 |
|---|---|---|---|
| **A. 슬롯 = 건물** (통합) | 작업슬롯 자체를 산업 건물로 본다(농장·어장·광산…). **자원을 먹여 슬롯 레벨을 올리고**, 레벨이 속도·산출·등급 가산을 준다 | **겹침이 사라진다** — 배치 대상은 여전히 슬롯 하나 | 새 화면이 거의 없다 · 슬롯 확장권(골드)과 역할 구분 필요 |
| **B. 배치 없는 시설** (패시브) | 캠프·창고·작업대 같은 시설을 자원으로 올린다. 캐릭터 배치는 **없다** — 전역 보너스만(인벤토리 칸 수 · 우편 한도 · 오프라인 정산 한도 · 산업 전체 속도) | 겹치지 않는다 — 배치는 슬롯만 | 특성(산업 속도)과 보너스가 겹치지 않게 축을 나눠야 한다 |
| **C. 제작** | 자원 → 장비 · 인챈트 재료 · 상자 · 소모품 | 무관 | 가챠·상자와 획득 경로가 겹친다 — 확률 대신 **확정 제작**이라는 차별점 필요 |
| **D. 납품 퀘스트** | 자원 N개 납품 → 경험치·골드·해금 | 무관 | [퀘스트](../GameDesign/design/quest/) 기획과 합친다 · 반복 sink로 쓰기 쉽다 |

- 사용자가 걸린 지점("건물에 캐릭터를 배치하면 슬롯과 겹친다")은 **A 또는 B로 풀린다** — A는 건물과 슬롯을 하나로 합치고,
  B는 건물에서 배치를 빼 버린다. **배치형 건물을 슬롯과 따로 두는 안은 권하지 않는다.**
- 추천 조합: **A(주력 sink · 성장감) + D(반복 sink)**. B는 인벤토리·우편 한도 같은 편의 보너스가 필요해질 때 보탠다.
- 데스크톱 상주형 원칙(P1 — 재촉하지 않는다)과 맞게 **업그레이드는 즉시 완료**(대기 타이머 없음)를 기본으로 본다.

## 결정할 것

- [ ] 비용 곡선 — 어느 자원을 얼마나 (산업별 자원을 그 산업 건물에 쓰는지 · 교차하는지)
