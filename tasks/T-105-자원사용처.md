# T-105 검토 요청 — 남는 자원의 사용처

> ⏩ 261024 회차에 못 끝내 261107로 자동 이월 (2026-10-25)

> **작업 지시가 아니라 고민 요청이다.** 아이디어와 걸리는 점을 적어 둔 것이고, 아래 후보도 **참고용 생각 정리**일 뿐이다.
> 검토 결과가 "지금은 필요 없다" · "다른 방향"이어도 이 일감은 끝난다.

## 떠오른 생각 (태웅, 2026-09-30)

채취로 쌓이는 자원의 출구가 **판매(골드)뿐인 것 같다.** 확정된 sink 3종(수수료 · 슬롯 확장권 · 가챠 비용 —
[게임기획코어](../GameDesign/design/게임기획코어.md))은 전부 골드를 쓰고, 자원을 직접 쓰는 곳은 없어 보인다.
그러면 자원을 모을 이유가 골드 환산뿐이지 않을까?

아이디어: **팰월드의 건물 업그레이드처럼** 자원을 먹여 무언가를 키우는 것. 그 건물에 캐릭터를 배치한다면?
— 그런데 그러면 **작업슬롯과 콘텐츠가 겹치는 것 같아** 고민이다.

## 참고용 생각 정리 (결정 아님)

| 후보 | 내용 | 작업슬롯과의 관계 | 떠오르는 장단 |
|---|---|---|---|
| **A. 슬롯 = 건물** | 작업슬롯 자체를 산업 건물로 보고, 자원으로 슬롯 레벨을 올려 속도·산출·등급 가산 | 겹침이 사라진다 — 배치 대상은 여전히 슬롯 | 새 화면이 적다 · 슬롯 확장권(골드)과 역할 구분 필요 |
| **B. 배치 없는 시설** | 자원으로 시설을 올려 전역 보너스만 (인벤토리 칸 · 우편 한도 · 오프라인 정산 한도 등) | 겹치지 않는다 | 특성(산업 속도)과 보너스 축이 겹치지 않게 해야 |
| **C. 제작** | 자원 → 장비 · 인챈트 재료 · 상자 · 소모품 | 무관 | 가챠·상자와 획득 경로가 겹친다 |
| **D. 납품 퀘스트** | 자원 N개 납품 → 경험치·골드·해금 | 무관 | [퀘스트](../GameDesign/design/quest/) 기획과 합칠 수 있다 |

- "건물에 배치하면 슬롯과 겹친다"는 걱정은 A(건물과 슬롯을 합친다)나 B(건물에서 배치를 뺀다)로 풀릴 수도 있겠다는 정도의 생각.
- 태웅 개인 의견은 A + D 쪽이 끌린다 — 판단은 기획에 맡긴다.
- 데스크톱 상주형 원칙(P1 — 재촉하지 않는다)을 생각하면 업그레이드 대기 타이머는 없는 편이 맞을 것 같다.

## 같이 고민해 볼 것

- [x] 자원 사용처가 **지금 정말 부족한가** — 판매·거래소(경매장)만으로 충분하다고 볼 수도 있다
- [x] 필요하다면 어떤 방향이 이 게임에 맞나 (위 후보 · 전혀 다른 안)
- [x] 작업슬롯 · 특성 · 장비와 **역할이 겹치지 않게** 할 수 있나
- [ ] 언제쯤 필요한가 — 지금 회차 / 콘텐츠가 더 선 뒤

## 결론 — 방향 결정: 섬 산업 건물 (진우, 2026-10-16)

후보 B(배치 없는 시설)에 가깝다. **섬에 1차 산업 건물을 짓고 자원으로 레벨을 올리며, 건물마다 선행 노드가 있는 기술 트리를 연다.**
구조는 Escape from Duckov 은신처를 참고했다. 상세는 [건물](../GameDesign/design/building/README.md).

- 캐릭터를 배치하지 않는다 — 작업슬롯과 겹치지 않는다
- 노드는 **수치(속도·산출량 가산)와 기능**을 모두 연다. 계정 특성 · 슬롯 시설 개량(T-125)은 그대로 둔다 — 붙는 곳이 계정 · 칸 · 산업으로 다르다
- 대기 타이머 없음(P1)
- **비용은 자원만** — 골드를 받지 않는다. 구현은 `UnlockTable` 재사용 + 자원 비용 컬럼을 제안했다
- 희귀도 확률 노드도 둔다 — 공통값(#42)은 기본값이고 노드는 특성 같은 보너스라 별개다

**남은 결정** (건물 문서 4장): 건물 수(산업당 1 · 5개 안) · 비용 구성 · 최대 레벨·노드 목록 · 갈래 선택 · 희귀도 노드 적용 방식 · TID 대역.
정해지면 구현 일감을 새로 등록한다.
