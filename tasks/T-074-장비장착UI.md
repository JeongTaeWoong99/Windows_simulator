# T-074 클라 — 장비 장착 · 해제 UI

> [T-043](archive/T-043-창고장비특성탭.md)에서 "별도 일감"으로 미뤄 두고 **등록되지 않은 채 남아 있던 조각**이다
> (2026-09-20 발견). 장비 탭은 열렸지만 **장비를 낄 방법이 없다.**

## 배경

**서버는 다 서 있는데 클라에 누르는 자리가 없다.** 장착·해제 패킷은 [T-002](archive/T-002-장비슬롯.md)에서
들어왔고(`e860066`), 클라에는 **구독자가 하나도 없다**(2026-09-20 전수 확인 — `C_EquipRequest`·
`C_UnequipRequest`를 쓰는 클라 코드 0건).

그래서 지금 이런 상태다:

| | 상태 |
|---|---|
| 장비를 **얻는** 길 | 치트 `GiveEquip` · **장비 뽑기**(서버 완료 → 클라 배선은 [T-067](archive/T-067-장비뽑기.md)) |
| 장비를 **보는** 곳 | 창고 장비 탭 ✅ ([T-043](archive/T-043-창고장비특성탭.md), 2026-09-19) |
| 장비를 **끼우는** 곳 | **없다** |

> ⚠️ **T-067 배선이 끝나는 순간 이게 드러난다** — 정식 경로로 장비가 쏟아지는데 낄 데가 없다.
> 창고 장비 탭의 **'배' 마크는 켜지는 것까지 확인됐다**(2026-09-21). **꺼지는 쪽은 해제 경로가
> 이 일감에서 생겨야 볼 수 있다.**

## 서버가 주는 것 (2026-09-20 미러 확인)

| | 내용 |
|---|---|
| 요청 | `C_EquipRequest { long CharacterId, long EquipId, EEquipSlot Slot }` · `C_UnequipRequest { long CharacterId, EEquipSlot Slot }` |
| 응답 | `S_EquipResponse { Result, CharacterId, Slot }` |
| 칸 | `EEquipSlot` — `Weapon=1` · `Accessory1=2` · `Accessory2=3` · `Gem=4` (`None=0`) |
| **세팅 정보** | `EquipInfo.EquippedCharacterId`(**0 = 창고**) · `EquippedSlot`(창고면 `None`) — **개체마다 실려 온다** |
| 반영 | 바뀐 개체는 `S_EquipSyncResponse`로 온다(**최대 3개** — 교체로 밀려난 것 포함). 속도 변화는 `S_WorkStationSlotSyncResponse`로 따로 |
| 결과 코드 | `EquipNotOwned(600)` · `InvalidEquipSlot(601)` · `EquipKindMismatch(602)` · `EquipSlotEmpty(603)` |

- **칸은 클라가 고른다** — 장신구는 `Accessory1`·`Accessory2` 어디든 된다(서버 주석).
- **다른 캐릭터가 이미 끼고 있으면 서버가 옮긴다** — 클라가 먼저 해제 요청을 보낼 필요가 없다.
- 받는 그릇도 이미 있다 — `PlayerDataModel.Equips`·`EquipsChanged`가 `S_EquipSyncResponse`를 반영한다.

## 할 일

- [ ] **어디에 붙일지 먼저 정한다** — 캐릭터 상세 화면인가 · 작업슬롯 세팅 화면인가 · 창고 장비 탭에서 캐릭터를 고르는 쪽인가.
      ⚠️ **이 판단이 폴더와 문서 자리를 정하므로 코드보다 먼저다**([`ugui-mvp`](../.claude/skills/client/ugui-mvp/SKILL.md) · [`UI 배치 현황.md`](../Assets/Scripts_Client/UI/UI%20배치%20현황.md))
- [ ] **장착 칸 4개를 그리는 뷰** — 캐릭터 하나의 `Weapon` · `Accessory1` · `Accessory2` · `Gem`.
      빈 칸과 낀 칸이 구분돼야 한다. 칸 표시는 창고 장비 탭과 **같은 읽기**(이름 · 효과 한 줄 · 등급색)를 쓴다
- [ ] **낄 장비를 고르는 흐름** — 칸을 누르면 그 칸에 맞는 창고 장비만 고를 수 있게 한다.
      ⚠️ 클라가 걸러도 **거절은 서버가 한다**(`EquipKindMismatch`) — 클라 판단은 표시용이다
- [ ] **해제** — `C_UnequipRequest`. 빈 칸을 해제하면 `EquipSlotEmpty`
- [ ] **`S_EquipSyncResponse` 반영** — 한 번에 **여러 개**가 온다(교체로 밀려난 개체 포함).
      `EquipId`로 찾아 덮어쓰고, 장착 칸 뷰와 **창고 장비 탭이 함께** 갱신되는지 본다
- [x] **'배' 마크 — 켜지는 것은 확인됐다** (사용자 실측 2026-09-21 · [T-043](archive/T-043-창고장비특성탭.md)에서 넘어온 항목).
      **꺼지는 쪽은 여기서 본다** — 해제 경로가 이 일감에서 생기기 때문이다
- [ ] **속도가 실제로 바뀌는지** — 장착 후 `S_WorkStationSlotSyncResponse`가 와서 슬롯 주기가 짧아지는지
- [ ] `ResultMessages`에 `EquipNotOwned` · `InvalidEquipSlot` · `EquipKindMismatch` · `EquipSlotEmpty` 문구 추가

## 완료 조건

캐릭터 하나에 무기·장신구 2개·보석을 끼우고 뺄 수 있고,
창고 장비 탭의 '배' 마크가 따라 바뀌며, 그 캐릭터가 배치된 슬롯의 채취 주기가 실제로 짧아진다.
