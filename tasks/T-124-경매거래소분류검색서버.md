# T-124 서버 — 거래소·경매 검색에 상자 · 기타 분류

## 배경 (태웅, 2026-10-05)

인벤토리 자원 탭 분류 드롭다운에 **상자 · 기타**를 붙였다(클라만으로 거른다 — `InventoryItemGroup`).
같은 분류를 거래 쪽에서도 쓰고 싶은데, 거래소 목록·경매 검색은 **서버가 거른다** — 클라가 못 붙인다.

- `C_MarketItemsRequest.Category` · `C_AuctionSearchRequest.Category`는 `ItemType`이다. 상자는 `ItemType.Special`이라
  **상자만** 고를 축이 없다(상자 판정은 `ItemTable.OpenGachaId` — 클라 `GameDataLoader.IsBox`).
- 기타 = 산업 자원도 상자도 아닌 것(인챈트 큐브 · 구슬 · 상자 전용 아이템).

요청 이슈: [#57](https://github.com/JeongTaeWoong99/Windows_simulator/issues/57)

## 할 일

- [ ] 서버 — 거래소 목록·경매 검색 요청에 **상자 · 기타** 분류(필드를 새로 둘지, `Category`에 값을 더할지는 서버 판단)
- [ ] 테스트 · 프로토콜 미러
- [ ] 클라 — 거래소 화면에 분류 드롭다운(지금은 이름 검색뿐) · 인벤토리와 같은 목록(산업 5 + 상자 · 기타) (태웅)

## 완료 조건

거래소에서 "상자"를 고르면 상자 15종만, "기타"를 고르면 큐브·구슬·전용 아이템만 나온다.
