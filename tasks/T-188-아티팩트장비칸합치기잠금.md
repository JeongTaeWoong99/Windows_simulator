# T-188 아티팩트 장비 칸 합치기 · 잠금

## 배경

클라는 아티팩트를 장비 탭에 장비와 함께 그리는데([T-151](T-151-클라유물감정보관함.md)), 서버의 아티팩트 칸은 장비와 번호가 따로라
끌어 옮기기·[정렬]·Ctrl+좌클릭 잠금이 막혀 있다 ([이슈 #87](https://github.com/JeongTaeWoong99/Windows_simulator/issues/87)). 마석 분해는 [T-185](archive/T-185-아티팩트마석분해.md)에서 끝났다.

## 결정 (2026-10-28 진우)

- **칸 공간** — 아티팩트 칸과 장비 칸이 인벤토리 장비 탭 한 격자(`StorageCapacity`)를 함께 쓴다. 칸 하나 = 장비 1개 또는 아티팩트 번호 하나 + 수량
- **요청** — 칸 이동·정렬은 `Tab = Equip` 하나로 둘 다 다룬다(`Tab = Artifact`도 같은 격자로 받는다). 합치기(`C_StorageMergeRequest { Tab = Artifact }`)는 그대로
- **응답** — 장비 자리는 지금처럼 `S_StorageSlotsResponse.Slots`(응답 `Tab = Equip`), 아티팩트 자리는 `S_ArtifactInventoryResponse` 스냅샷(`Slot`이 공유 번호)
- **[정렬]** — 장비를 지금 기준으로 앞에, 그 뒤에 아티팩트를 같은 기준(등급·이름·수량)으로
- **창고** — 창고 장비를 아티팩트가 선 인벤토리 칸에 놓으면 `StorageSlotArtifact`(1107). 아티팩트는 창고에 못 간다
- **잠금** — 번호 단위 · `ELockTarget.Artifact`(4 · Id = 아티팩트 번호) · `t_user_artifact_lock` · 잠긴 번호는 `S_ArtifactInventoryResponse.LockedArtifactTids`. 잠기면 즉시 판매·경매 등록·분해에서 빠진다(`EntityLocked`). 도감 장착은 된다
