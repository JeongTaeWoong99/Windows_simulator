# T-155 서버 — 경매 검색 확장 · 정렬 · 결과 건수 · 상세 옵션 필터 · 단가 범위

## 배경

경매장 전체 화면 목업([T-147](archive/T-147-경매장전체화면목업.md) · [`경매장목업.html`](../GameDesign/design/ui/경매장목업.html))의 검색 탭은
왼쪽 옵션(분류 → 등급 → 분류별 상세 옵션 → 단가 범위) + 오른쪽 결과(정렬 드롭다운·열 머리 · "N건")다.
지금 서버 검색은 **단가 낮은순 하나**에 필터가 이름·분류·등급·인챈트 등급·옵션 TID 포함·단가 상한뿐이고, 건수 없이 `HasMore`만 준다.
목업 "아직 정할 것 · 서버가 바뀌어야 하는 것"의 정렬 · 결과 건수 · 상세 옵션 검색이 이 일감이다.
