# T-099 클라 — 항상 위를 끈 작업표시줄 맞춤 창은 작업표시줄을 침범하지 못하게

## 배경

`작업표시줄 맞춤` 배율은 위젯 높이를 작업표시줄과 똑같이 만든다. 항상 위가 꺼져 있을 때 창을
작업표시줄 위에 겹쳐 두면 작업표시줄이 창을 통째로 덮어 **잡아 올릴 곳이 없어진다**
(사용자 보고 2026-09-30).

## 할 일

- [x] 항상 위 off + 작업표시줄 맞춤이면 아래 한계를 작업 영역 바닥(`wa.bottom`)으로 (`WindowManager.AvoidTaskbar`·`BottomLimit`)
- [x] 드래그를 놓을 때 — 작업표시줄에 걸치면 그 위로 튀어 오른다 (`ClampIntoMonitor`)
- [x] 항상 위를 끈 순간 — 걸쳐 있으면 올리고 손 좌표 저장 (`SetTopmost`)
- [x] 부팅 복원 — 저장 좌표가 걸쳐 있어도 그 위로 (`ResolvePosition`)
- [x] 문서 — `Managers 규칙.md` 5장 예외 · `DesktopWindow 규칙.md`
- [ ] 빌드 실측 — 에디터에선 Win32 경로가 돌지 않는다
