# T-055 작업속도 보정 내역을 클라에 전달

## 배경

[T-053](archive/T-053-선택화면목업구조.md)의 효율 계산은 `WorkStationSlotInfo.CurrentWorkSpeed`(확정값) 하나만 받는다.
보정이 무엇으로 이뤄졌는지는 내려오지 않는다.

지금은 가산(장비·특성·액티브)이 **하나도 없어서** `현재 ÷ 적성 기본값`이 곧 `Global.GatherSpeedMultiplier`다.
클라는 이 역산으로 "개발용 전역 배수 적용 중"을 띄운다.

**가산이 하나라도 붙는 순간 이 역산은 틀린다** — 장비 +35%가 전역 배수로 보인다.

## 할 일

- [ ] 전역 배수를 명시 필드로 내린다 (로그인 응답 한 번이면 충분하다 — 서버 상수라 슬롯마다 실을 필요가 없다)
- [ ] 가산 항목이 생길 때 슬롯별 내역(장비 · 특성 · 액티브 천분율)을 어디에 실을지 정한다
- [ ] 프로토콜 미러 커밋 (완료 조건 — T-025 사고 재발 방지)

## 완료 조건

클라가 역산 없이 전역 배수와 가산 내역을 읽어 효율 계산 줄을 항목별로 그릴 수 있다.

## 막고 있는 것 / 선행 일감

- 없음. 전역 배수 필드는 지금 할 수 있다. 가산 내역은 [T-002](archive/T-002-장비슬롯.md)·특성 서버 구현이 생길 때 채운다
