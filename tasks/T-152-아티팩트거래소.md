# T-152 서버 — 아티팩트 거래소 매물 (즉시 판매 없음)

## 배경

[T-150](T-150-발굴유물감정기획.md)에서 아티팩트 보관함(`t_user_artifact`)과 감정 지급은 끝났지만, **내보내는 길이 없다.**
기획([`유물감정.md`](../GameDesign/design/gathering/excavation/유물감정.md) 3장)은 중복을 시장으로 내보내는 것이 전제다(P4).

## 할 일

- 즉시 판매 — 처음엔 두지 않았다가 이슈 #81로 생겼다 → [T-181](T-181-아티팩트인벤토리도감장착.md). `BasePrice`는 거래소 단가 하한이자 즉시 판매가
- [x] 거래소 매물 — `EAuctionKind.Artifact`(4) · 경매장 `ListingKind.Artifact`. 등록하면 그 수량이 보관함에서 빠진다(`t_user_artifact` 확정 수량을 등록과 **같은 트랜잭션**에) · 취소·만료·대사면 우편으로 돌아온다
- [x] 거래소 수량 구매·목록·가격대에 종류(`kind`)를 싣는다 — TID는 종류 안에서만 유일하다(proto `kind` · 0 = 자원 · 옛 클라 호환)
- [x] 우편 첨부에 아티팩트 — `t_user_mail.artifacts`(`0004-mail-artifacts.sql`) · `MailInfo.Artifacts` · 받으면 보관함(창고 칸 검사 없음)
- [x] 등록은 아티팩트 칸(옛 이름 "인벤토리 아티팩트 탭")에서 뺀다 — 도감에 장착한 것은 올라가지 않아 효과가 꺼지지 않는다 ([T-181](T-181-아티팩트인벤토리도감장착.md)에서 바뀜)
- [x] 테스트 — `ArtifactAuctionTest`(메인 13건) · `ArtifactMarketEngineTest`(경매장 4건). 메인 891 · 경매장 118 통과
- [ ] 클라 — [T-151](T-151-클라유물감정보관함.md)

## 완료 조건

아티팩트를 거래소에 올리고 사고, 취소·만료되면 우편으로 돌아온다.
