# T-178 DB 잠김으로 세션 끊김

## 배경

10연 뽑기를 1~2초 간격으로 누르는 중(채취 정산도 도는 중) `GrantCharacterRepository`의 INSERT가
`SQLite Error 5: 'database is locked'`로 실패해 세션이 끊겼다 — [이슈 #85](https://github.com/JeongTaeWoong99/Windows_simulator/issues/85).

## 원인

- 게임 DB는 롤백 저널(`journal_mode = delete`) — 다른 연결이 **읽는 중**(SHARED)이면 커밋에 필요한 EXCLUSIVE를 못 얻는다
- `Microsoft.Data.Sqlite`는 잠김을 `sqlite3_step`에서만 재시도한다. `INSERT … RETURNING`은 커밋이 **reset 시점**에 일어나 재시도를 거치지 않고 **바로 실패**한다
- 연결에 `busy_timeout`이 없어 SQLite 자체도 기다리지 않았다

외부 프로그램 잠금이 아니라 **서버 안 연결끼리의 겹침**으로 재현된다 (`DBManagerLockTest`).
