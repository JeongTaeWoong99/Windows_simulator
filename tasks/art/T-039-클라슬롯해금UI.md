# T-039 클라 — 잠긴 작업슬롯의 해금 안내·구매 UI

## 배경

**지금 화면은 잠긴 칸과 열린 빈 칸을 구분하지 못한다.**

작업슬롯 목록의 프레임은 씬에 8칸이 있고, 전부
`Assets/Prefabs/WorkSlotFrame.prefab`의 **"비어있음."** 을 띄운다.
서버가 열어 주는 슬롯은 현재 0번 하나뿐이라, 1~7번을 누르면
배치 화면이 열리고 → 배치 요청이 나가고 → 서버가 `InvalidSlotIndex`로 거절해
*"아직 열리지 않은 작업 슬롯입니다"* 알림이 뜬다.

**플레이어 입장에서는 "왜 안 되는지"는 알아도 "어떻게 여는지"는 알 수 없다.**
잠긴 칸에 여는 방법을 표시하고, 그 자리에서 열 수 있어야 한다.

## 완료 조건

잠긴 칸이 잠긴 것으로 보이고, 여는 조건이 칸에 적혀 있으며,
조건을 만족한 상태에서 그 칸을 눌러 **실제로 슬롯이 열린다.**
