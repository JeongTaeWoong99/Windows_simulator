# 아트 대기 — 🎨만 남은 일감

**기능은 다 섰고 🎨 연출·리소스만 남은 일감이 여기 있다.** 막힌 게 아니라 미룬 것이다.
메인 시스템이 다 선 뒤에 리소스와 함께 한꺼번에 올린다.

- [INDEX](../README.md)에는 **없다** — 남은 일 목록과 섞이지 않게 뺐다. 아트 작업을 시작할 때만 연다.
- 넣는 기준은 "🎨가 있다"가 아니라 **"🎨만 남았다"** 이다. 기능 항목이 하나라도 남았으면 루트에 둔다.
- **회차(`목표`)에 넣지 않는다** — `목표: 미정`. 아트를 회차에 올릴 때 그 일감에 `목표`를 적는다 (2026-09-28).
- 🎨 작업을 시작하면 `상태: 진행중`으로 바꾸고 그대로 여기서 진행한다. 끝나면 [`archive/`](../archive/README.md)로 내린다.
- 🎨가 아닌 새 항목이 생기면 루트(`tasks/`)로 되돌리고 INDEX에 올린다.
