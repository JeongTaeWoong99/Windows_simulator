# 아트 대기 — 🎨 그림만 남은 일감

**기능도 연출도 다 섰고 🎨 그림(리소스)만 남은 일감이 여기 있다.** 막힌 게 아니라 미룬 것이다.
아트는 메인 시스템이 다 선 뒤에 한꺼번에 넣는다.

> **연출(움직임)은 여기 넣지 않는다 (2026-10-23).** 연출은 임시 그림으로 움직임까지 세우고 실측하면 끝이다 —
> 남는 것은 "같은 이름으로 그림 덮기"뿐이라 그것만 이 폴더의 일감([T-178](T-178-이펙트정식그림.md))으로 모은다.
> 연출 자체가 남은 일감은 기능 일감처럼 루트(INDEX)에 둔다. 연출만 모아 둘 폴더는 두지 않는다 — 실측까지 바로 끝나서 쌓일 일이 없다.

- [INDEX](../README.md)에는 **없다** — 남은 일 목록과 섞이지 않게 뺐다. 아트 작업을 시작할 때만 연다.
- 넣는 기준은 "🎨가 있다"가 아니라 **"그림만 남았다"** 이다. 기능·연출 항목이 하나라도 남았으면 루트에 둔다.
- **회차(`목표`)에 넣지 않는다** — `목표: 미정`. 아트를 회차에 올릴 때 그 일감에 `목표`를 적는다 (2026-09-28).
- 🎨 작업을 시작하면 `상태: 진행중`으로 바꾸고 그대로 여기서 진행한다. 끝나면 [`archive/`](../archive/README.md)로 내린다.
- 🎨가 아닌 새 항목이 생기면 루트(`tasks/`)로 되돌리고 INDEX에 올린다.
