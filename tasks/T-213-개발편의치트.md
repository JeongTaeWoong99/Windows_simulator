# T-213 개발 편의 치트

## 배경

지금 치트는 하나씩 주는 것뿐이라 테스트 상황을 만들 때 여러 칸을 눌러야 한다. 2026-11-22 사용자가 고른 5종을 넣는다(연출 바로 띄우기 · 응답 지연 흉내는 뺐다 — 불편하지 않다).

## 할 일

- [ ] 1. 계정 상태 한 번에 — 신규 · 중반 · 후반 버튼(기존 `GiveGold` · `SetTraitLevel` · `SetBuildingLevel` · `Unlock` · `GiveAllCharacters` 조합) · 값은 섹션 상단 상수
- [ ] 4. 장비 세트 지급 — 레벨 · 등급을 골라 무기 · 장신구 · 보석 한 벌(`GiveEquip` 반복)
- [ ] ⏸ 2. 상자 열기 결과 미리 세기 — 서버 `SimulateBoxOpen` ([#154](https://github.com/JeongTaeWoong99/Windows_simulator/issues/154))
- [ ] ⏸ 3. 캐릭터 레벨 일괄 — 서버 `SetCharacterLevel` ([#154](https://github.com/JeongTaeWoong99/Windows_simulator/issues/154))
- [ ] ⏸ 5. 인벤토리 비우기 — 서버 `ClearItems` ([#154](https://github.com/JeongTaeWoong99/Windows_simulator/issues/154))

## 완료 조건

치트 창에서 5종을 눌러 상황이 한 번에 만들어진다.
