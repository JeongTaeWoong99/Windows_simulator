# T-129 일감 정합성 검사 스크립트 — INDEX ↔ 일감 파일 · 보관 건수 · 끝난 선행을 기다리는 ⏸

## 배경

[T-066](archive/T-066-연계일감갱신스킬.md)에서 연계 갱신을 스킬로 만들지 않고 **공돌리기 규칙**(`github-issue-writer` 3장)에 합쳤다.
그중 **기계적으로 판정할 수 있는 어긋남**은 기억에 맡기면 또 빠진다 — 스크립트가 잡는다.
`GameDesign/check-doc-graph.ps1`처럼 돌리면 목록이 나오는 형태.

## 할 일

- [ ] INDEX 링크가 가리키는 파일이 루트 `tasks/`에 있는지 (보관된 일감이 INDEX에 남았는지)
- [ ] 루트 일감 파일이 INDEX에 다 있는지 · 프론트매터 `상태`와 INDEX `상태` 칸이 같은지
- [ ] 보관 건수(`끝난 일감 N건`)와 `archive/` 파일 수가 같은지
- [ ] `⏸`·`막고 있는 것`이 **보관된 일감**이나 **닫힌 이슈**(`gh issue view --json state`)를 가리키는지
- [ ] `tasks/` 밖 문서의 `tasks/T-0XX-…` 링크가 옮겨 간 파일을 가리키는지
- [ ] 돌릴 시점을 공돌리기 절차(`github-issue-writer` 3장)에 한 줄 추가
