# T-019 온보딩 1일차 시나리오 설계

## 배경

2026-08-01에 핵심 재미(섬 개발)·후반 목표(랭킹)·경제(sink)가 확정되면서
**[진행 및 성장](../GameDesign/design/progression/README.md)에서 유일하게 크게 빈 칸이
온보딩이 됐다.**

방치형의 온보딩은 **"첫 세션에 성장이 눈에 보이는가"** 가 전부다.
첫날 체감 성장이 없으면 다음 날 실행되지 않는다. 바탕화면 상주 앱이라
**"닫고 다시 안 여는" 것이 아니라 "삭제하는" 형태로 이탈**한다.

## 정해야 할 것

| 질문 | 상태 |
| --- | --- |
| 첫 실행 후 몇 분 만에 첫 보상을 받는가 | ✅ 0~60분 타임라인 ([진행 및 성장](../GameDesign/design/progression/README.md) 2.1 · 2026-10-02) |
| **시작 캐릭터로 무엇을 주는가** | ✅ `1001` 램볼 (2026-08-02 · [캐릭터](../GameDesign/design/character/README.md) 3.3) — 1일차 시나리오에서 "그 한 명으로 무엇을 하나"만 남았다 |
| 처음부터 5개 산업이 전부 열려 있는가 | ✅ Lv1은 전부 열림 · Lv2~5는 개척 특성 (2.0) |
| 거래소·상점·랭킹은 언제 열리는가 | ◐ 초안 — 상점·가챠 0분 · 거래소 계정 Lv10 · 랭킹은 기획 뒤 (2.7) |
| 튜토리얼을 두는가, 가이드 퀘스트로 대체하는가 | ◐ 초안 — 가이드 퀘스트 12단계로 대체 · 강조는 첫 배치만 (2.7) |
| 섬 컨셉을 언제 어떻게 보여 주는가 | ◐ 초안 — 첫 실행 한 줄 + 화면 문구 번역 (2.7) |

이미 정해진 것: **시작 슬롯 2개**(T-012).
