# T-151 클라 — 미감정 유물 감정 · 아티팩트 보관함(= 도감) 화면

## 배경

[T-150](T-150-발굴유물감정기획.md)에서 발굴은 상자 대신 **미감정 유물**(7종 · `ItemType.Relic`)을 캐고,
골드를 내고 감정하면 상자 같은 보상과 낮은 확률로 **아티팩트**(보유만으로 계정 영구 효과)가 나온다. 서버·데이터는 끝났다.

- 기획: [`유물감정.md`](../GameDesign/design/gathering/excavation/유물감정.md) · 목업: [`유물감정목업.html`](../GameDesign/design/ui/유물감정목업.html) (https://claude.ai/artifact/TZp6NxtCestLgWfkJPsJdY)
- 서버가 보내는 것:
  - 감정 = 상자 열기와 같은 요청(`C_ItemUseRequest` → `S_ItemUseResponse`). 유물은 `ItemTable.OpenCostGold` × 개수만큼 골드가 빠진다(아티팩트 할인 적용). 모자라면 `NotEnoughCurrency`
  - 보상 `GachaRewardInfo.RewardType = Artifact`(5) → `ArtifactTid`를 읽는다. 아티팩트는 **인벤토리 아티팩트 탭**(`EStorageTab.Artifact` = 3)으로 들어간다 — 탭이 가득 차면 결과 전체가 우편(`StoredInMail`) ([T-181](T-181-아티팩트인벤토리도감장착.md))
  - `S_ArtifactInventoryResponse` — 아티팩트 탭 스냅샷(`ItemInfo` · `ItemId` = 아티팩트 번호 · 칸 하나 최대 `Constants.ArtifactMaxStack`). 로그인 직후와 칸이 바뀔 때마다 통째로 온다
  - `S_ArtifactListResponse` — 도감 스냅샷(`ArtifactCodexInfo` — 번호 · 켜짐). 장착한 번호만 온다 · 켜 둔 번호만 효과가 있다
  - 장착 `C_ArtifactEquipRequest { ArtifactTid }` → `S_ArtifactEquipResponse` (번호마다 1번 · 되돌릴 수 없음 · 켜진 채로 시작) · 켜고 끄기 `C_ArtifactActiveRequest { ArtifactTid, IsActive }` → `S_ArtifactActiveResponse`
  - 즉시 판매 `C_ArtifactSellRequest { Artifacts: [ArtifactInfo] }` → `S_ArtifactSellResponse` — 판매가 `BasePrice` × `SellRatePermille`
  - 아티팩트 탭 칸 이동·정렬·합치기는 자원 탭과 같은 요청에 `Tab = Artifact`(인벤토리만 — 창고에는 없다)

## 할 일

- [ ] `S_ArtifactListResponse` 핸들러 (지금 MIKA001 경고가 난다)
- [ ] 등급 색·이름 표에 `GlobalRarity.Special`(7) — 무지개
- [ ] 유물 아이콘 7종 · **Special 칸 애니메이션**(무지개 테두리 회전 · 빛줄기 · 반짝임)
- [ ] 감정 버튼에 비용 표시(할인 반영은 서버 값 기준 — 계산식은 `User.DiscountAppraiseCost`) · 골드 부족 안내
- [ ] 감정 연출 — 흔들림 → 금 3번 → 번쩍 → 조각 → 등장 · 아티팩트/Special 유물이면 띠와 한 번 더 빛남 · 클릭으로 건너뛰기 (목업 타임라인 표)
- [ ] 인벤토리 아티팩트 탭 · 아티팩트 창(설명 · 효과 · [도감에 장착]) — 조작은 장비와 같다(우클릭 즉시 판매 담기 · Ctrl+우클릭 경매 등록)
- [ ] 아티팩트 도감 — 번호 순 고정 칸 · `장착` · 등급 필터 · 칸 상태 3가지(장착·켜짐 · 장착·꺼짐 흐리게 · 미장착 실루엣) · 켜고 끄기 · 수집 수 · 상세 패널 (효과 합계는 **보여 주지 않는다**)
- [ ] **거래소 등록** — `C_AuctionRegisterRequest { Kind = Artifact, ItemTid = 아티팩트 번호, Count, UnitPrice }` · 인벤토리 것만 올라간다(장착한 1개는 효과가 그대로). 단가 하한 = `ArtifactTable.BasePrice`
- [ ] 거래소 화면에 아티팩트 탭 — `C_MarketItemsRequest` · `C_MarketPriceRequest` · `C_MarketBuyRequest`에 `Kind = Artifact`(비우면 자원)
- [ ] 우편 `MailInfo.Artifacts` 표시 — 받으면 인벤토리 아티팩트 탭으로 간다(탭이 가득 차면 `StorageFull`)

## 완료 조건

유물을 감정해 연출을 보고, 나온 아티팩트를 인벤토리에서 도감에 장착하면 효과가 켜진다. 중복은 즉시 판매·거래소로 나간다.
