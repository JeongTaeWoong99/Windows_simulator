# T-151 클라 — 미감정 유물 감정 · 아티팩트 보관함(= 도감) 화면

## 배경

[T-150](T-150-발굴유물감정기획.md)에서 발굴은 상자 대신 **미감정 유물**(7종 · `ItemType.Relic`)을 캐고,
골드를 내고 감정하면 상자 같은 보상과 낮은 확률로 **아티팩트**(보유만으로 계정 영구 효과)가 나온다. 서버·데이터는 끝났다.

- 기획: [`유물감정.md`](../GameDesign/design/gathering/excavation/유물감정.md) · 목업: [`유물감정목업.html`](../GameDesign/design/ui/유물감정목업.html) (https://claude.ai/artifact/TZp6NxtCestLgWfkJPsJdY)
- 서버가 보내는 것:
  - 감정 = 상자 열기와 같은 요청(`C_ItemUseRequest` → `S_ItemUseResponse`). 유물은 `ItemTable.OpenCostGold` × 개수만큼 골드가 빠진다(아티팩트 할인 적용). 모자라면 `NotEnoughCurrency`
  - 보상 `GachaRewardInfo.RewardType = Artifact`(5) → `ArtifactTid`를 읽는다. 아티팩트는 **아티팩트 칸**(`EStorageTab.Artifact` = 3 · 서버 저장)으로 들어간다 — 칸이 가득 차면 결과 전체가 우편(`StoredInMail`) ([T-181](T-181-아티팩트인벤토리도감장착.md))
  - `S_ArtifactInventoryResponse` — 아티팩트 칸 스냅샷(`ItemInfo` · `ItemId` = 아티팩트 번호 · 칸 하나 최대 `Constants.ArtifactMaxStack`). 로그인 직후와 칸이 바뀔 때마다 통째로 온다
  - `S_ArtifactListResponse` — 도감 스냅샷(`ArtifactCodexInfo` — 번호 · 켜짐). 장착한 번호만 온다 · 켜 둔 번호만 효과가 있다
  - 장착 `C_ArtifactEquipRequest { ArtifactTid }` → `S_ArtifactEquipResponse` (번호마다 1번 · 되돌릴 수 없음 · 켜진 채로 시작) · 켜고 끄기 `C_ArtifactActiveRequest { ArtifactTid, IsActive }` → `S_ArtifactActiveResponse`
  - 즉시 판매 `C_ArtifactSellRequest { Artifacts: [ArtifactInfo] }` → `S_ArtifactSellResponse` — 판매가 `BasePrice` × `SellRatePermille`
  - 아티팩트 칸 이동·정렬·합치기는 자원 탭과 같은 요청에 `Tab = Artifact`(창고에는 없다)
- ⚠️ **인벤토리 화면에는 아티팩트 탭을 두지 않는다** (2026-10-25 합의 — 인벤토리 = 자원 · 캐릭터 · 장비). 아티팩트 칸을 어느 화면에 그릴지는 [T-182](T-182-거점열개편마을지도.md)에서 정한다

## 정한 것 (2026-10-25 사용자)

- 상세 패널에 [즉시 판매]를 두지 않는다 — 좋은 것은 경매에서 즉시 판매가보다 비싸게 팔 수 있다. 판매는 장비 탭 우클릭(판매 목록) · 경매는 Ctrl+우클릭
- ~~보유 칸은 도감과 따로 둔다~~ → 아티팩트는 **인벤토리 장비 탭**에 둔다(같은 날 다시 정함) · 장착은 장비 탭 좌클릭 아티팩트 창에서 · 결과 창에 바로가기를 두지 않는다
- 장착 확인 창 없음 · 메인 버튼 이름 '아티팩트' · 메인 버튼 점 알림 없음
- NEW(도감에 없는 번호)를 판매 목록에 담으면 경고한다

## 완료 조건

유물을 감정해 연출을 보고, 나온 아티팩트를 아티팩트 칸에서 도감에 장착하면 효과가 켜진다. 중복은 즉시 판매·거래소로 나간다.
