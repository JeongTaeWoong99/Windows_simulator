# T-211 클라 — 스팀 로그인 연동

## 배경

서버 스팀 로그인(T-207)은 끝났고 클라 연동(#144)이 남았다. AppID는 신원 확인(T-210) 뒤에 나오므로 그때까지 Valve 시험 앱 `480`으로 붙인다.
실행 경로마다 붙는 서버 · 로그인 방법이 달라 먼저 표로 정했다([#152](https://github.com/JeongTaeWoong99/Windows_simulator/issues/152)).

## 실행 경로 — 어디서 실행하면 무엇에 붙나

| 실행 경로 | 붙는 서버 | 로그인 | 스팀 AppID |
|---|---|---|---|
| ① 에디터 | 개발 `127.0.0.1:10050` | **지금 로그인 화면(Id) 그대로** · 스팀 시험은 에디터 전용 버튼 | 프로젝트 루트 `steam_appid.txt` |
| ② 빌드 직접 실행 | 원격 Docker `30329` | **로그인 화면 없음** — 티켓 자동 → 바로 게임 | 빌드 옆 `steam_appid.txt` |
| ③ 스팀 라이브러리 실행 | 원격 | ②와 같음 | 스팀이 넘긴다(`steam_appid.txt` 없음) |

| 서버 | AppId | Web API 키 | `AllowDevLogin` |
|---|---|---|---|
| 개발 (이 PC · IDE) | 480 → 우리 AppID | 개인 키 → Publisher 키 · git 밖 자리(#152에서 정함) | 켬 |
| 원격 (이 PC의 Docker) | 같음 | `Server/.env` | 지금 켬 → 친구 빌드가 스팀으로 바뀌면 끔 |

## 할 일

### 내가 할 것 (사람)
- [ ] 개인 Web API 키 발급 — steamcommunity.com/dev/apikey (내 스팀 계정) → `Server/.env`에 `STEAM_WEB_API_KEY=...` · 개발 서버 자리(#152)에도
  - 스팀 쪽 확인 — steamcommunity.com/dev/apikey 페이지에 키와 등록한 도메인이 보이면 발급된 것. 브라우저로 `https://api.steampowered.com/ISteamWebAPIUtil/GetSupportedAPIList/v1/?key=<키>`를 열어 `ISteamUserAuth`가 목록에 있으면 살아 있는 키(틀리면 403)
  - 확인 ② 서버가 읽었나 — `Server/`에서 `docker compose up -d`로 다시 띄우면 서버 시작 로그에 `키 있음`이 찍힌다(`GameServer.cs` — 없으면 `키 없음(스팀 로그인 불가)`)
  - 누가 넣나 — 키는 **서버 환경 변수**라 서버가 도는 곳마다 하나씩. 에디터는 Id 로그인이라 키가 없어도 된다. 빌드는 원격 개발 서버에 붙으니 **원격 서버(#152 — 진우)** 에 넣어야 스팀 로그인이 된다. 각자 PC의 로컬 서버는 로컬에서 스팀 로그인을 시험할 사람만 `Server/.env`에 넣는다(같은 키를 나눠 써도 된다 — 채팅·이슈·커밋에는 적지 않는다)
  - ⚠️ 개인 키는 앱 480(Spacewar) 시험용이다. 진짜 AppID가 나오면 Steamworks 파트너 사이트의 **퍼블리셔 Web API 키**로 바꾼다(T-210)
  - 확인 ③ 끝까지 — 클라 연동 뒤 빌드로 접속해 계정이 `steam:<id>`로 생기는지
- [ ] 시험할 때 스팀 클라이언트를 켜고 로그인해 둔다

### 클라 코드

- [ ] 스팀 초기화 · `GetAuthTicketForWebApi("wsgame")` → `C_LoginRequest.SteamTicket`(hex)
- [ ] 로그인 화면 UI — 빌드는 Id 입력칸 · [로그인]을 숨기고 "스팀 확인 중…" 한 줄 + 실패 문구 + [다시 시도] · [종료]만 둔다. 에디터는 지금 화면 + [스팀으로] 시험 버튼
- [ ] 빌드: 로그인 화면을 띄우지 않고 "스팀 확인 중" 대기 → 바로 게임 · 실패 코드별 안내(#144 코멘트 표 — `SteamAuthFailed` 1회 재시도 · `SteamUnavailable` 다시 시도 · `Banned` 종료)
- [ ] 에디터: 지금 Id 로그인 유지 + 스팀 시험 버튼
- [ ] 스팀이 꺼져 있을 때 안내(빌드)
