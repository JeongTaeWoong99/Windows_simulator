# T-195 소모품 사용 효과 적용

> ⏩ 261107 회차에 못 끝내 261121로 자동 이월 (2026-11-08)
> 번호 정리 (2026-11-11): 같은 내용으로 미커밋 `T-192-소모품효과적용.md`가 따로 있었는데, T-192는 서버 비용 일감이라 이 파일로 합쳤다.
> 이슈 #107·#110·#111·#113에 적힌 "T-192"의 소모품 부분이 이 일감이다.

## 배경

[T-112](archive/T-112-아이템다양화.md)에서 일회성 소모품을 기획하고 `ItemTable`에 넣었다([아이템](../GameDesign/design/item/README.md) 4.1·4.4).
하지만 서버의 아이템 사용(`C_ItemUseRequest`)은 **상자 개봉(`OpenGachaId`)만 처리한다.** 그래서 아래 아이템은
얻어도 쓸 수 없고 `ItemNotUsable`로 거절된다. 출처: [이슈 #107](https://github.com/JeongTaeWoong99/Windows_simulator/issues/107) "비약(소모품) 효과 적용".

| ItemTID | 이름 | 효과 | 사용 대상 |
| --- | --- | --- | --- |
| `100041~100043` | 성장의 비약 (소·중·대) | 캐릭터 경험치 +100 / +500 / +2,500 | 캐릭터 지정 |
| `100044` | 신속의 영약 | 다음 20회 판정 동안 작업속도 +300‰ | 슬롯 지정 |
| `100045` | 풍요의 영약 | 다음 20회 판정 동안 산출량 +300‰ | 슬롯 지정 |
| `100046` | 망각의 묘약 | 건물 특성 트리 전부 초기화 | 대상 없음 |
| `100010` · `100034` · `100035` | 낡은 · 은빛 · 황금 보물 지도 | 판정 1 / 3 / 5번 즉시 · 슬롯 1 / 2 / 3개 — [이슈 #111](https://github.com/JeongTaeWoong99/Windows_simulator/issues/111) 확정 | 슬롯 지정 |
| `100036` · `100011` · `100037` | 낡은 · 은빛 · 황금 나침반 | 상자 확률 +50% / +100% / 상자·유물 +100% · 20회 · 슬롯 1 / 2 / 3개 — [이슈 #111](https://github.com/JeongTaeWoong99/Windows_simulator/issues/111) 확정 | 슬롯 지정 |

> **비약·영약·묘약 사용 규칙은 확정했다 (2026-11-03)** → [아이템](../GameDesign/design/item/README.md) 4.4 「사용 규칙」 · [이슈 #110](https://github.com/JeongTaeWoong99/Windows_simulator/issues/110).

**TID마다 분기를 하드코딩하지 않는다.** 효과의 종류·수치·대상은 데이터로 두고, 서버는 효과 종류마다 처리기 하나만 둔다.
그래야 같은 종류의 소모품을 새로 만들 때 엑셀에 행만 추가하면 된다.
