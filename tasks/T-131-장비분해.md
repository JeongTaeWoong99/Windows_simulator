# T-131 장비 분해

## 배경

중복 장비의 출구로 분해를 넣기로 했다([T-076](T-076-성장재료소비처.md) · 2026-10-07).
이번 범위는 **재료가 나오는 데까지**다 — 재료의 쓰임(교환)은 이 일감 밖이다.

> 2026-10-12 재료가 정해졌다 — `100050` 마력의 파편 · 등급별 수량 · 쓰임 (T-112 · 이슈 [#61](https://github.com/JeongTaeWoong99/Windows_simulator/issues/61)). 엑셀 `ItemTable`에 이미 있다.
규칙은 [캐릭터 5.6](../GameDesign/design/character/README.md) · [아이템 4.3](../GameDesign/design/item/README.md).

## 할 일

- [x] 분해 재료 아이템 정의 — `100050` 마력의 파편(`Special` · MaxStack 9,999 · 판매 0G) · 장비 등급별 일반 1 · 고급 2 · 희귀 5 · 영웅 15 · 전설 50 · 신화 150개 → [아이템](../GameDesign/design/item/README.md) 4.3
  - [x] 등급별 수량은 엑셀 표 — `Equip.xlsx` `DisassembleTable`(`Rarity` · `ItemTID` · `ItemCount`, 등급이 키) (2026-10-12 사용자 결정)
- [x] 서버 — `DisassembleTable`에서 등급으로 재료를 찾는다 · 분해 패킷 · 착용 중 거절 · **잠긴 장비 거절**(`EntityLocked` · [T-137](archive/T-137-잠금기능.md)) · 장비 개체 삭제(인챈트 포함) · 재료 지급 · **인벤토리 가득 차면 거절**(장비가 사라지지 않게 · 우편 넘침 보관은 쓰지 않는다 — 2026-10-12 사용자 결정)
- [ ] 클라 — 분해 버튼 · 결과 표시 → 태웅에게 이슈로 넘김
- [ ] 치트 — 기존 장비 뽑기·지급 치트(`GiveEquip = 8`)로 장비를 받아 확인 — 클라 버튼이 붙은 뒤 화면에서 본다

## 한 것 (2026-10-18)

- 패킷 `C_EquipDisassembleRequest { EquipIds }` → `S_EquipDisassembleResponse { Result, ItemChangeInfos }` (83·84) — 판매처럼 여러 개를 한 번에, **전부 성공하거나 전부 실패**
- 거절: 빈 목록·중복 `InvalidDisassembleRequest`(1300) · 착용 중 `DisassembleEquipWorn`(1301) · 미보유 `EquipNotOwned` · 잠김 `EntityLocked` · 큐브 결과 고르기 전 `EnchantPending` · 재료 칸 부족 `StorageFull`
- 창고에 있는 장비도 분해한다 — 재료는 인벤토리로 간다
- 장비 삭제(인챈트는 같은 행)와 재료 지급을 한 트랜잭션으로 쓴다 — `DisassembleEquipsRepository`
- 테스트 `UserEquipDisassembleTest` 10 · `UserPremiumCubeTest` +1 · `DisassembleEquipsRepositoryTest` 2

## 완료 조건

착용하지 않은 장비를 분해하면 장비가 사라지고 정해진 재료가 인벤토리에 들어온다.
