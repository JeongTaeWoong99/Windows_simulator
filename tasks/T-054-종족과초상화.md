# T-054 캐릭터 종족 기획 · CharacterTable 컬럼 + 초상화 · 산업 아이콘 리소스

> ⏩ 261024 회차에 못 끝내 261107로 자동 이월 (2026-10-25)

## 배경

[T-053](archive/T-053-선택화면목업구조.md)에서 작업슬롯 선택 화면에 **초상화 · 종족 · 산업 아이콘 자리**를 만들었다.
지금은 흰 네모와 `종족 추가 예정`이 들어가 있다.

- **종족은 데이터에 없다.** `CharacterTable`에는 `Name` · `GlobalRarity` · 적성 5종 · `Description`뿐이다
- 초상화 · 산업 아이콘은 **스프라이트 자체가 없다**

- **종족은 분류(표시)만 · 적성은 그림 기준** (2026-10-25 · [캐릭터 기획 4.1·4.2](../GameDesign/design/character/README.md)) — 종족 보정·상성·전용 스킬은 없다. "드워프는 채굴을 잘한다" 같은 경향은 사람이 캐릭터마다 적성 값으로 조절한다

## 261024 회의 안건 (2026-10-18 진우) — [이슈 #79](https://github.com/JeongTaeWoong99/Windows_simulator/issues/79)

- **종족을 이 회의에서 이야기한다.** 종족은 외형과 엮여 있어 **아트·에셋부터** 본다
  - 들어온 그림 27종이 어떤 종족으로 묶이는가 · 종족마다 그림이 더 필요한가
  - 그다음 종족 목록 → 적성 분포(캐릭터 기획 4장 — 외형 + 적성 분포만, 상성·전용 스킬 없음) → `Race` 컬럼
