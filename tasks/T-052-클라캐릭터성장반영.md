# T-052 클라 — 캐릭터 레벨·경험치 푸시 반영과 표시

> GitHub 이슈: [#25](https://github.com/JeongTaeWoong99/Windows_simulator/issues/25) — 클라 담당(JeongTaeWoong99)에게 할당 (2026-09-13)

## 배경

[T-003](T-003-캐릭터성장.md)에서 서버가 **캐릭터 경험치를 실제로 쌓기 시작했다** (2026-09-13).
판정이 정산될 때마다 배치된 캐릭터의 레벨·경험치가 바뀌고, 서버는 바뀐 개체 1건을
**`S_CharacterSyncResponse`(PacketId 21)** 로 밀어 준다.

클라는 아직 이 푸시를 받지 않는다. `PlayerDataModel._characters`는 로그인 때 받은
`S_CharacterListResponse` 스냅샷 그대로라 **서버가 밀어도 화면 레벨은 로그인 시점 값**이고,
레벨·경험치를 그리는 UI 자체도 아직 없다 (`CharacterInfo.Level`·`Exp`를 읽는 코드가 0곳).

## 서버가 이미 준 것

| 것 | 위치 |
| --- | --- |
| 패킷 `S_CharacterSyncResponse { CharacterInfo Character }` | `Assets/Scripts_Server/Protocol/MikaPacket.cs` (미러 완료) |
| Unity 핸들러 · 이벤트 `ServerPacketHandler.CharacterSynced` | `Assets/Scripts_Server/Network/MikaNetwork.Unity/ServerPacketHandler.cs` |
| 레벨 곡선 테이블 `CharacterLevelTable` (`CharacterLevelTID`=레벨 · `RequiredExp`) | `Assets/StreamingAssets/Data/CharacterLevelTable.bytes` · `Scripts_Server/GameData/Tables/` |

**규칙** (→ [캐릭터 5.2](../GameDesign/design/character/README.md))

- `Exp`는 **현재 레벨에서 쌓은 양**이다. 레벨업하면 필요치를 뺀 나머지로 줄어든다 — 증감이 아니라 **확정값이라 덮어쓴다.**
- `RequiredExp(L)` = 레벨 L에 **도달하는 데** 직전 레벨에서 필요한 양. 진행 바의 분모는 `RequiredExp(Level + 1)`이다.
- 만렙 = 테이블의 **마지막 행**(지금 100). `Level + 1` 행이 없으면 만렙이다.
- 한 정산에서 캐릭터 여럿이 바뀌면 패킷도 여럿 온다. 판정이 없거나 만렙이면 오지 않는다.
- ⚠️ **레벨은 아직 아무 효과도 없다** (속도가 안 바뀐다). 이 일감은 **표시**까지다.

## 할 일

- [ ] `PlayerDataModel` — `ServerPacketHandler.CharacterSynced` 구독·해제, `_characters`에서 `CharacterId`로 찾아 **교체**한 뒤 `CharactersChanged` 발행.
      목록에 없는 개체가 오면 추가하지 말고 경고만 남긴다 — 목록의 원본은 스냅샷이다
- [ ] 창고 캐릭터 칸(`CharacterSlotSource`)에 **레벨 표시** (이름 옆 `Lv.N` 정도. 5칸 적성 스트립 자리를 침범하지 않게)
- [ ] 캐릭터 상세(호버 UI, [T-050](T-050-칸정보호버.md))에 **경험치 진행** `Exp / RequiredExp(Level+1)`. 만렙이면 `MAX`.
      `RequiredExp`는 `GameDataLoader`가 `CharacterLevelTable`에서 읽는다 (적성과 달리 정적 곡선이라 클라가 읽어도 된다)
- [ ] 🎨 레벨업 연출 (칸 반짝임·토스트) — 뒤로. 기능은 위 세 개로 선다

## 완료 조건

슬롯에 배치한 캐릭터를 두고 기다리면 **재로그인 없이** 창고 칸의 레벨이 오르고,
호버에서 경험치가 차오르는 것이 보인다. 재로그인해도 같은 값이다.
