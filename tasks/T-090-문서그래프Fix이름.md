# T-090 check-doc-graph -Fix가 README 문서 이름을 영문 폴더명으로 쓴다

## 배경

`powershell -File GameDesign/check-doc-graph.ps1 -Fix`를 돌리면 **관련 없는 문서까지 19개의
`바뀌면 갱신` 블록을 덮어쓰고**, 링크 이름이 한글 문서명 대신 영문 폴더명이 된다.

```
기존:  [`거래`](../trade/README.md)
-Fix:  [`trade`](../trade/README.md)
```

T-092(인챈트) 작업 중 발견했다(2026-09-23). 그때는 덮어쓴 것을 되돌리고 필요한 블록만 손으로 고쳤다.
**`-Fix` 없이 돌리는 검사 모드는 정상이다** — 문제는 블록을 다시 쓰는 경로뿐이다.

## 원인

`Get-DocName`(`GameDesign/check-doc-graph.ps1:66-74`)이 `README.md` 문서의 이름으로 **부모 폴더명**을 돌려준다.

```powershell
if ($rel -like '*/README.md') {
    return (Split-Path (Split-Path $rel -Parent) -Leaf)
}
```

**2026-08-08에 폴더를 영문으로 바꾸기 전에는** 폴더명이 곧 한글 문서명(`거래/`)이라 맞았다.
개명 후에는 `trade`가 나온다. `-Fix`가 이 이름으로 블록을 새로 쓰므로 한글 이름이 전부 영문으로 바뀐다.

> 처음 보고에서는 "PowerShell 5.1 문제"로 적혔지만 **버전과 무관하다.** 폴더 개명이 원인이다.

## 할 일

- [ ] README 문서의 표시 이름을 폴더명이 아닌 곳에서 얻는다 — 후보: 문서 첫 `#` 제목, 또는 기존 블록에 이미 적힌 한글 이름을 그대로 유지
- [ ] 검사 모드의 경고 문구(`[trade] 블록에 남음: …`)도 같은 이름을 쓰므로 함께 한글로 나오는지 확인
- [ ] `-Fix`를 돌려 **바뀌는 문서가 0개**인지 확인 (지금 블록은 전부 손으로 맞춰져 있다)
- [ ] `GameDesign/CLAUDE.md`의 폴더 개명 절(`폴더명이 코드에 박힌 곳도 본다`)에 이 사례를 한 줄 남긴다
