# T-083 클라 — 우편함 화면

## 배경

서버 우편([T-081](archive/T-081-서버우편.md))을 보고 받는 화면이다 → [우편](../GameDesign/design/mail/README.md) 4장.

## 할 일

- [ ] **우편함 버튼 위치를 정한다** — 클라 결정
- [ ] 목록 — 제목·발신자·첨부·도착 시각 · 받은 우편은 "받음" 표시(7일 뒤 사라짐)
- [ ] 수령 · 모두 받기 — **인벤토리 부족** 거절 안내 · 모두 받기는 받은 수·남은 수 안내
- [ ] 받은 우편 삭제 — 안 받은 우편에는 삭제 버튼이 없다
- [ ] 새 우편 표시 — **우편함 버튼의 점 하나만.** 숫자·기한·토스트·소리 없음(P1) → [게임 UI](../GameDesign/design/ui/README.md) 2.4의 예외
- [ ] 치트창 — 우편 발송(템플릿 TID · 대상 UID, 0이면 전체)

## 완료 조건

치트로 보낸 우편이 점으로 표시되고, 우편함에서 받기·모두 받기·삭제가 된다.
