# T-156 서버 — 경매·거래소 거래 기록 조회 (완료 탭)

## 배경

경매장 목업([T-147](T-147-경매장전체화면목업.md))의 **완료 탭** — 판매 완료 · 구매 완료 · 기간 만료 · 취소 기록을 구분·기간 드롭다운으로 보고,
새 기록은 탭에 배지를 단다. 지금은 거래 결과가 **우편으로만** 남고 조회 패킷이 없다.
`t_auction_trade`는 판매자 쪽 원장이라 거래소(수량 구매)의 구매자별 기록이 없다.

## 할 일

- [ ] 기록 저장 — 판매 완료 · 구매 완료 · 기간 만료 · 취소를 유저별로 (정산·반환 트랜잭션과 같은 트랜잭션)
- [ ] 조회 패킷 — 구분 · 기간 · 페이지
- [ ] 새 기록 배지 — 마지막으로 본 시각 이후 건수
- [ ] 보관 기간 — 오래된 기록 정리
- [ ] 테스트 · 프로토콜 미러 · `경매장.md`
- [ ] 클라 — 완료 탭 → 태웅에게 이슈로 넘김

## 완료 조건

판매·구매·만료·취소가 일어나면 그 유저의 기록에 한 줄씩 남고, 완료 탭 조회로 구분·기간별로 볼 수 있다.
