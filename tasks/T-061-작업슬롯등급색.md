# T-061 클라 — 작업슬롯 칸 바탕을 캐릭터 등급 색으로

## 배경

창고 칸(`SlotView`)과 배치 화면 줄(`CharacterStateRowView`)은 이미 등급 색을 칠한다 (`RarityPalette.Get`).
그런데 작업슬롯 목록(`WorkStationSlotView`)과 위젯 미니 칸(`WidgetMiniSlotView`)은 등급이 안 보여서,
어떤 등급 캐릭터가 일하는지 글자를 읽어야 안다.
나중에 등급 이미지로 바뀔 예정이지만, 지금은 **색으로 가시성만** 올린다.

## 할 일

- [ ] `WorkStationSlotView`에 바탕 `Image` 참조 추가 (`= null!` + `RequireRef`) · `Bind`에서 등급 색 적용
- [ ] `WidgetMiniSlotView`도 같은 방식 — 기존 `characterImage`와 다른 바탕 이미지인지 확인하고 고른다
- [ ] 등급 출처: `slot.CharacterId`(개체 번호) → `PlayerDataModel.GetCharacterTid` → 캐릭터 테이블 등급.
      뷰가 직접 조회하지 않고 **패널(Presenter)이 등급을 넘긴다** — `characterName`을 넘기는 기존 방식과 같다
- [ ] 캐릭터가 없는 칸(대기)은 `RarityPalette.Unknown`
- [ ] 잠긴 칸(T-039)의 기존 표시와 겹치지 않는지 확인
- [ ] 씬에서 바탕 `Image` 연결 — 에디터 수작업이면 `unity-handoff`
- [ ] 칸 글자가 밝은 등급색(일반·신화) 위에서 읽히는지 눈으로 확인

## 완료 조건

작업슬롯 목록과 위젯에서 캐릭터를 배치하면 칸 바탕이 그 캐릭터 등급 색으로 바뀌고, 해제하면 회색(`Unknown`)으로 돌아온다.
