# T-161 클라 — 같은 자원이 여러 칸에

## 배경

서버가 자원을 칸별 묶음으로 바꾸면([T-160](T-160-자원칸별묶음서버.md)) 한 아이템이 여러 칸에 온다.
지금 클라 캐시·공급자는 `ItemId` 하나 = 칸 하나를 전제한다(`PlayerDataModel.GetItemCount` 첫 줄만 읽음 등). → [이슈 #73](https://github.com/JeongTaeWoong99/Windows_simulator/issues/73)
