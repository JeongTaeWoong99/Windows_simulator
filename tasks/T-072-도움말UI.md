# T-072 클라 — 시스템 가이드 · 도움말 UI

> 2026-09-20 QA 피드백 6번 ([`0920-피드백 및 답변 정리.md`](../gyub/0920-피드백%20및%20답변%20정리%28정태웅%29/0920-피드백%20및%20답변%20정리.md)).
> **지금은 기록용 일감이다** — [T-071](T-071-백그라운드알림.md)과 같은 이유로 우선순위가 낮다.

## 배경

화면에 뜨는 수치(**산업 점수 · 작업 속도** 등)가 무엇인지, 어떻게 조작하는지 설명이 없다.
처음 보는 사람은 숫자가 무엇을 뜻하는지 알 수 없다.

### 왜 우선순위가 낮음인가

도움말은 **화면과 수치를 글로 옮긴 것**이라 기획·UI가 바뀌면 그대로 낡는다.
지금은 둘 다 자주 바뀌는 중이라 먼저 쓰면 두 번 쓰게 된다. **틀이 굳은 뒤에 쓴다.**

### 범위 — 개별 항목 상세는 여기가 아니다

아이템·캐릭터 **하나하나의 상세**는 [T-050](T-050-칸정보호버.md)(칸 정보 호버)이 맡는다.
이 일감은 **화면 단위 설명**(이 화면이 무엇인가 · 이 숫자가 무엇인가 · 어떻게 조작하나)만 담는다.

## 할 일

- [ ] 어디서 여는가 — 화면마다 `?` 버튼인지, 메뉴에 도움말 한 칸인지
- [ ] 무엇을 설명하는가 — 화면 목록과 각 화면의 설명 대상(수치 이름 · 조작)
- [ ] 글의 출처 — 코드에 박을지, 엑셀/데이터로 뺄지 (표시 이름 출처 정리는 [T-085](T-085-공용상수소유권.md))
- [ ] 실측

## 완료 조건

주요 화면에서 도움말을 열면 그 화면의 수치와 조작법을 읽을 수 있다.
