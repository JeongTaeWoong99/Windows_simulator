# T-204 경매 더미 매물 치트 — 장비·캐릭터·아티팩트까지 종류를 골라 올린다

## 배경

[이슈 #124](https://github.com/JeongTaeWoong99/Windows_simulator/issues/124) — 더미 매물 치트(`SeedAuctionListings`, T-168)가 자원(`EAuctionKind.Item`)만 올린다.
장비·캐릭터·아티팩트의 검색·정렬·구매 화면을 시험하려면 그 종류의 매물도 있어야 한다.

## 할 일

- [x] `AuctionDummy.Build`가 자원·장비·캐릭터·아티팩트를 섞어 만든다 — 장비는 인챈트 등급·옵션, 캐릭터는 레벨·응축 누적
- [x] 검색 속성(`Attrs`)을 실제 등록과 같은 함수(`AuctionAttrs`)로 채운다 — 빠지면 필터 검색에 안 걸린다
- [x] 장비·캐릭터는 더미 판매자 소유의 잠긴 개체 행을 원장 트랜잭션에서 함께 만든다 — 구매 시 소유 이전·우편 수령이 실제와 같다
- [x] 삭제(개수 0)는 더미 판매자의 남은 장비·캐릭터 행도 지운다
- [x] 치트 — `SeedAuctionListings`의 `Arg2`: 0 = 전체 섞기 · 1~4 = 종류(`EAuctionKind`) · 그 밖 = ItemTID(기존) · [`치트.md`](../Server/docs/치트.md) 갱신
- [x] 클라 치트 창의 종류 칸은 이슈 #124 요청자(태웅)가 붙인다 — 처리 코멘트로 인자를 알린다
- [ ] 실측 — 실서버에서 전체 섞기로 올리고 경매장 분류별 검색·장비/캐릭터 구매 확인(클라 칸이 붙은 뒤)

## 완료 조건

- 전체 무작위로 올리면 경매장 검색에서 장비·캐릭터·아티팩트 분류에도 매물이 나온다
- 더미 장비·캐릭터를 사면 우편으로 받아 인벤토리에 들어온다
- 서버 테스트 통과 · PR 생성
