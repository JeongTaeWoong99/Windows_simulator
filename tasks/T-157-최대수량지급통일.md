# T-157 서버 — 최대 수량 지급 통일

## 배경

[이슈 #67](https://github.com/JeongTaeWoong99/Windows_simulator/issues/67) — 수확은 칸·최대 수량으로 버린 몫을 알리지 않았고,
우편 받기 · 상자 열기 · 뽑기는 `MaxStack`을 검사하지 않아 9,999를 넘어 쌓였다.

결정(2026-10-14 사용자):
- 수확은 받지 못한 목록 없이 **"가득 차서 획득 불가"만** 알린다.
- 우편 · 상자 · 뽑기도 최대 수량을 검사하고, **넘친 몫은 버린다**(거절하지 않는다).
- 한 종류 = 여러 칸(2단계)은 하지 않는다.

## 할 일

- [x] `S_GatherResultResponse.InventoryFull` — 칸이 없거나 최대 수량이라 버린 몫이 있으면 true
- [x] `User.GainItem`이 `MaxStack`에서 자른다 — 지급 경로(수확 · 우편 · 상자 · 뽑기 · 치트)가 전부 지난다
- [x] 테스트 — 수확 플래그(칸 · 일부 · 전량 · 없음) · 우편 · 상자. 9,999 초과 보유를 전제하던 경매 등록 테스트 2개를 9,999로 맞춤
- [x] 기획 문서 아이템 `MaxStack` 줄

## 완료 조건

수확에서 버린 몫이 있으면 `InventoryFull`이 오고, 어떤 경로로도 보유량이 `MaxStack`을 넘지 않는다.
