# T-015 산업 5종 아이템 클라 적용 · 특별 이벤트 탭 자리 확보

> **T-005의 이양분이다.** 서버가 엑셀 작업과 패킷 테스트를 끝내면 여기서 이어받는다.

## 배경

지금 클라가 표시할 수 있는 채취 산출물은 **낚시 6종뿐**이다.
[T-005](T-005-드롭테이블.md)가 끝나면 **5산업 × 6등급 = 30종**이 한 번에 들어온다.

> ⚠️ **표시 대상이 156종이 됐다 (2026-08-02 정정).** 2026-08-01 산업 레벨 도입으로
> 레벨마다 6종이 붙어 **산업 자원 150종 + 가챠 전용 6종**이다.
> 아래 서술의 "30종"은 그 이전 시점 기준이며, **아이콘·툴팁 작업량이 5배**다.
> → [아이템](../GameDesign/design/item/README.md) 1.3

- 아이템 TID가 **산업별 10000 단위 대역**으로 정리된다 (낚시 `10001~`, 농사 `20001~`, …)
- **낚시 아이템 TID가 `1001~1006` → `10001~10006`으로 이설된다.**
  클라에 TID를 하드코딩한 곳이 있으면 조용히 깨진다 — **전수 확인이 필요하다**

## 중앙 UI 최하단 탭 — 특별 이벤트 자리

**중앙 UI 최하단에 탭 한 줄을 비워 둔다.** 지금은 비어 있어도 되지만,
나중에 **채취 루프 바깥의 콘텐츠**가 여기로 들어온다.

| 들어올 후보 | 근거 |
| --- | --- |
| **보스** | 사냥에서 티켓을 모아 도전. 채취 루프 밖으로 나가는 유일한 통로 → [사냥](../GameDesign/design/gathering/hunting/README.md) 4장 |
| **대형 작업물 채취** | 여러 슬롯·시간을 들여 하나를 캐는 형태 (미기획) |
| 기타 기간·조건부 이벤트 | 미기획 |

**요구사항은 "자리를 만들어 두는 것"이지 콘텐츠를 만드는 것이 아니다.**

- 중앙은 **작업슬롯 전용**이고(방향제안 2장), 최하단 탭은 그 아래 별도 층이다
- 탭이 늘어나도 **슬롯 영역이 밀리거나 줄지 않게** 레이아웃을 잡는다
- 비어 있을 때는 **탭 줄 자체를 숨긴다.** 잠긴 탭을 보여 주면 "지금 못 하는 것"이 상시로 눈에 남는다

> ⚠️ **P1을 지키는 선은 보스 기획에 이미 있다** ([사냥](../GameDesign/design/gathering/hunting/README.md) 4.2) —
> 도전 시점 자유 · 실시간 조작 없음 · 실패해도 티켓만 손실 · **기간 한정 없음**.
> 이 탭에 들어오는 것은 무엇이든 같은 선을 지킨다.
> **배지·타이머·"오늘까지" 표시를 붙이지 않는다.** 붙이는 순간 상시 위젯이 재촉하는 물건이 된다.

> ⚠️ **연출은 큰 창에서만 돌린다** (방향제안 8.2). 상시 위젯은 텍스트+게이지 유지.
> 창을 닫으면 그리기를 멈춘다 — 상시 실행 앱에서 리소스는 기능이 아니라 생존 조건이다.

## 완료 조건

**5종 산업을 슬롯에 배치했을 때 각 산업의 아이템이 실제로 내려와** 인벤토리에
희귀도 색으로 정상 표시되고, 중앙 UI 최하단에 탭을 추가해도 슬롯 레이아웃이 흔들리지 않는다.
