# T-202 클라 — 작업슬롯 10칸

## 배경

작업슬롯을 8칸 → 10칸으로 늘렸다([이슈 #125](https://github.com/JeongTaeWoong99/Windows_simulator/issues/125)). 서버·데이터는 진우가 `805385d6`에 넣었다 — `WorkSlotTable` 8·9번 · `UnlockTable` 1008(20,000,000 G) · 1009(40,000,000 G).
클라의 작업슬롯 화면은 **씬에 놓인 칸 틀 개수(`slotParent.childCount`)만큼만** 그린다. 틀이 8개라 9·10번째 칸이 안 보이고 경고만 남는다. 위젯 줄은 슬롯 수만큼 칸을 만들어서 손댈 것이 없다.

## 할 일

- [x] 씬 `WorkStation List Presenter/Viewport/Content`에 `Work Slot (8)` · `(9)` — `Work Slot (7)`을 복제(씬 오버라이드 `WorkSlotFrameView`·자식 포함) (2026-11-16)
- [x] 플레이 확인 — 9·10번째 칸이 잠김 · 20,000,000 G / 40,000,000 G · "작업슬롯 8번 해금 필요" · 잘린 글자 0건 (2026-11-16)
- [ ] 실측 — 실제로 해금해서 10칸을 다 채웠을 때 위젯 줄에 머리 10개가 들어가는지 (테스트 계정 골드를 6천만 쓰므로 직접 확인)

## 완료 조건

10칸이 작업슬롯 화면과 위젯 줄에 보이고, 해금·배치가 된다.
