# T-145 클라 — 위젯 알림 표시

## 배경

위젯만 남기고 열을 다 접어도 작업은 돈다. 그런데 작업 완료 · 인벤토리 꽉 참 같은 알림은 지금 팝업(알림 창)으로 뜬다 —
열이 닫혀 있으면 갑자기 창이 튀어나오거나, 알림이 나온 열이 접혀 있으면 놓친다.
**위젯만 있거나 알림이 나온 열이 닫혀 있을 때는 팝업 대신 위젯 위에 표시**하는 방향으로 간다(사용자 제안 2026-10-11).

## 할 일

- [ ] 알림 목록 정하기 — 작업 완료 · 인벤토리 꽉 참 · (우편 도착 · 경매 낙찰 · 상자 상한 등 후보) — 어떤 것이 위젯 표시 대상인가
- [ ] 표시 방식 정하기 — 레드닷 · 작은 말풍선(텍스트 박스) · 아이콘 흔들림 등. 알림 종류별로 다를 수 있다 (목업으로 비교)
- [ ] 조건 — "위젯만 있다" · "알림이 속한 열이 닫혀 있다"를 판단하는 곳(`WidgetPositionLayout`·열 여닫기 상태)을 정한다. 열이 열려 있으면 지금처럼
- [ ] 지우는 때 — 그 열을 열었을 때 · 해당 화면을 봤을 때 · 시간이 지나면
- [ ] 쌓인 알림 — 여러 개가 겹치면 숫자 배지? 최근 하나만?
- [ ] 구현 · 실측
- [ ] 치트: 기존 치트로 작업 완료·인벤토리 꽉 참을 만들 수 있는지 확인 — 없으면 추가 요청

## 완료 조건

위젯만 남긴 상태(또는 알림의 열이 닫힌 상태)에서 작업 완료 · 인벤토리 꽉 참이 팝업 없이 위젯 위 표시로 보이고, 열을 열면 지워진다.
