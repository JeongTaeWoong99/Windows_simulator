# T-145 클라 — 위젯 알림 표시

## 배경

위젯만 남기고 열을 다 접어도 작업은 돈다. 그런데 작업 완료 · 인벤토리 꽉 참 같은 알림은 지금 팝업(알림 창)으로 뜬다 —
열이 닫혀 있으면 갑자기 창이 튀어나오거나, 알림이 나온 열이 접혀 있으면 놓친다.
**위젯만 있거나 알림이 나온 열이 닫혀 있을 때는 팝업 대신 위젯 위에 표시**하는 방향으로 간다(사용자 제안 2026-10-11).

## 결정 (2026-11-26 태웅 · T-071 흡수)

[목업](../GameDesign/design/ui/위젯특수알림목업.html) — **B안: 위젯 위 상태 줄**. 레드닷 = "열면 볼 것이 있다"(조용히) · 상태 줄 = "놔두면 손해 / 걸어 둔 결과가 나왔다"(부른다).

**상태 줄 (위젯만 띄워 둔 상태)**
- 위젯 바로 위에 짧은 띠가 쌓인다 — 색: 경고 빨강 · 결과 초록 · 진행 파랑. 풀리면 띠가 사라진다. 같은 사유는 풀릴 때까지 한 번만
- **띠를 누르면 3열이 다 열린다.** 사유에 맞는 화면을 보여 준다
  - 인벤토리 가득 참 → 인벤토리 **자원 탭**(가득 차는 것은 자원뿐)
  - 작업슬롯 빔 → 작업슬롯
  - 큐브 자동 → 큐브 팝업(진행 중이면 진행 · 끝났으면 결과)
- 부를 사건: 인벤토리 가득 참(경고) · 작업슬롯 빔(경고) · 큐브 자동 진행·끝(진행·결과). 레이드 결과 · 자동 사용 소모품 바닥은 콘텐츠가 서면 더한다

**큐브 자동 [내리기]** — 팝업 DIM은 그대로 둔다(뒤를 막는 규칙에 예외를 두지 않는다)
- 자동이 도는 동안에만 [내리기]가 보인다 → 누르면 **3열이 다 닫히고 위젯만** 남는다. 자동은 계속 돌고 공개 연출은 건너뛴다
- 위젯 상태 줄에 `큐브 자동 n/100 · 목표 ○○` → 끝나면 결과 띠
- 띠를 누르거나 [창 열기]를 누르면 3열이 열리고 **큐브 팝업이 그 상태 그대로** 다시 뜬다
- 자동 루프를 큐브 창 밖(매니저)으로 옮긴다 — 서버 변경 없음

**레드닷 추가** (지금 있는 곳: 우편 · [마을] 버튼 · 마을 건물 이름판 · 경매 [완료] 탭 · 인벤토리 [장비] 탭)
- 하단 [경매장] 버튼 — 안 본 낙찰·판매 완료(`HistoryUnseenCount`)
- 하단 [인벤토리] 버튼 — 상급 큐브 선택 대기 · 인벤토리 가득 참(`InventoryFull`)
- 하단 [아티팩트] 버튼 — 도감에 없는 번호가 인벤토리에 있다
- 작업슬롯 칸 — 해금할 수 있는 슬롯(골드 충분) · 빈 슬롯 + 놀고 있는 캐릭터
- (나중) [레이드] 버튼 — 티켓이 남았다
- 넣지 않는다: 상자 쌓임(1000개까지 정상) · 응축 가능(너무 자주 켜져 재촉이 된다)
