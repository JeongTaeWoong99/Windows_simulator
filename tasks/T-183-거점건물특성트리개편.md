# T-183 거점 개편 — 건물 · 특성 트리

## 배경

[이슈 #75](https://github.com/JeongTaeWoong99/Windows_simulator/issues/75)(섬 건물 화면)를 다시 열면서 방향을 바꿨다(2026-10-25 사용자).
거점은 **핵심 시스템**이 되고, 계정 특성은 거점 건물로 옮긴다.
[T-166](T-166-섬건물서버.md)의 "산업당 건물 1채 · 자원만 · 해금 행" 구조는 **갈아엎는다.**

## 결정 (2026-10-25 사용자)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 화면 흐름 | [거점] → 거점 화면(2D로 건물 배치) → 건물 누르기 → [업그레이드] · [특성] |
| 2 | 건물 | 산업당이 아니라 **분류(콘텐츠·속성)당 1채 · 5채** — 편의 · 산업 · 거래 + 둘(목업 가칭: 인력 · 수집) |
| 3 | 업그레이드 비용 | **자원 + 골드** — 골드의 출구가 필요하다. 건물 README 확정 #8 "자원만"을 바꾼다 |
| 4 | 업그레이드 화면 | 현재 레벨 → 다음 레벨 · 필요한 자원 · 골드를 보여 준다 |
| 5 | 특성 | 건물마다 **노드 + 선으로 된 트리**. 노드를 누르면 내용(설명 · 지금/다음/최대 효과 · 조건)이 나온다 |
| 6 | 포인트 | **건물 Lv1당 그 건물 포인트 1점** — 건물마다 따로 |
| 7 | 노드 잠금 | 건물 레벨로 노드를 잠그지 않는다(예: "작업장 Lv6 필요" 없음). **앞 노드를 최대 레벨까지 다 찍어야** 다음 노드가 열린다 |
| 8 | 계정 레벨 | **특성 포인트(`AccountLevelTable.TraitPoint`)를 없앤다.** 계정 레벨이 **건물 레벨의 상한**이다 · 계정 최대 레벨 **100 → 150** |
| 9 | 옛 계정 특성 16개 | 산업 건물(목업 '작업장') 트리로 옮긴다 — 개척 · 속도 · 공통/산업 산출량 |
