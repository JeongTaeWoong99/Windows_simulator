# T-031 클라 — 가챠 화면 · 뽑기 결과 연출

## 배경

**"좋은 아이템이 나왔다"를 플레이어가 확인할 수 있어야 뽑기가 재미가 된다.**
서버가 결과를 내려줘도 화면이 없으면 인벤토리 숫자만 조용히 늘 뿐이다.

`S_GachaDrawResponse`는 이미 **연출용 델타(`Rewards`)와 인벤 반영용 누적(`ItemChangeInfos`)을
분리해서** 내려준다 — 뽑힌 순서 그대로 하나씩 열어 보이는 연출이 가능하다.
희귀도(`EGlobalRarity`)도 함께 실려 있고, **등급 색상은 `Enum.xlsx`에 정의돼 있다.**

## 할 일

> ◐ = 일부만 됐다 · ⏸ = **기획·서버가 먼저 와야 한다**(클라가 지금 못 한다)
> 🎨 = **연출·리소스. 의도적 후순위다** — 메인 시스템이 선 뒤에 한다
>
> **남은 여섯 = ⏸ 넷 + 🎨 둘.** 이 일감에서 **지금 클라가 진행할 것은 없다** —
> 기다리거나(T-026·T-027), 나중에 하기로 정한 것(연출·스프라이트)뿐이다.

- [x] 가챠 화면 — 단차/10연차 버튼 (`GachaPresenter`)
- [ ] ⏸ **T-027** — 가챠 화면 · 풀 목록 · **비용 표시** (버튼 둘만 있고 풀·비용은 아직 없다)
      → `GachaTableRow`에 비용 컬럼 자체가 없다(`GachaTID`·`GachaId`·`ItemTID`·`Count`·`Weight`·`Description`).
      **풀 목록만은 지금도 그릴 수 있다** — 비용 칸이 빈 화면을 먼저 만들 이유가 없어 함께 묶어 둔다
- [ ] ⏸ **T-027** — 보유 골드 표시 · 부족하면 버튼 비활성
      (**클라 판단은 표시용일 뿐, 거절은 서버가 한다**)
      → 골드 값 자체는 이미 있다(`PlayerDataModel.Gold`, `StatePresenter`·`WidgetPresenter`가 표시 중).
      막힌 것은 **"부족"의 기준**이다 — 비용을 모르면 비교할 수가 없다
- [x] 결과 창 — 뽑힌 목록을 5열 × n행으로 한 번에 표시(수량 표시는 끔), 희귀도 **색상** 적용
      (`UI/System/GachaResultPresenter/`, 칸은 `InventorySlotView` 프리팹 재사용)
- [ ] 🎨 결과 **연출** — 한 번에 띄우는 지금 방식 대신 뽑힌 순서대로 하나씩 공개
      → **길은 이미 열려 있다**(`S_GachaDrawResponse.Rewards`가 뽑힌 순서의 델타다).
      **못 해서가 아니라 뒤로 미룬 것이다** — 보상 종류 축(T-026)이 들어오면 연출이 다뤄야 할
      대상이 바뀐다. **한 화면에서 아이템·캐릭터를 함께 처리하는 모양이 정해진 뒤에 만든다**
- [ ] 🎨 희귀도 **스프라이트** — 지금은 `RarityPalette`가 색만 돌려준다
      (코드에 TODO. 표 한 줄과 `InventorySlotView.Bind` 한 줄을 sprite 대입으로 갈아끼우면 끝난다).
      **색으로 이미 구분되므로 기능은 서 있다.** 리소스가 준비되는 시점에 붙인다
- [ ] ⏸ **T-026** — **캐릭터 결과와 아이템 결과를 한 화면에서 처리한다** (T-026의 보상 종류 축)
      → `GachaRewardInfo`에 `ItemId`·`Count`·`Rarity`뿐이라 **아이템인지 캐릭터인지 구분할 축이 없다**
- [ ] ⏸ ◐ **T-026·T-027** — 뽑은 뒤 캐릭터 목록·인벤토리·골드 표시가 재로그인 없이 갱신되는지 확인
      → **인벤토리는 확인됐다** (2026-08-26, 10연차 실행 검증).
      **캐릭터·골드는 확인할 대상 자체가 아직 없다** — 뽑아도 캐릭터가 안 나오고 골드도 안 줄어든다
- [x] 실패 응답(`NotEnoughCurrency` 등) 처리 — 연출을 재생하지 않고 사유를 보여준다
      → `GachaPresenter.OnGachaFailed`가 `ResultMessages.ToText`로 문구를 만들어 대기를 `Fail`로 닫는다.
      `GachaResultPresenter`는 `GachaCompleted`만 구독하므로 **실패 시 팝업이 아예 뜨지 않는다**

## 완료 조건

화면에서 골드로 10연차를 뽑아 **결과가 순서대로 열리고**,
뽑은 캐릭터가 배치 화면 목록에 바로 나타난다.
