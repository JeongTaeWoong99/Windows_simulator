# T-160 서버 — 자원 칸별 묶음

## 배경

- 자원은 **종류 하나 = 칸 하나**라 `MaxStack`(자원 9,999 · 상자·유물 1,000)에 닿으면 칸이 남아도 버려진다([T-157](archive/T-157-최대수량지급통일.md)).
- `MaxStack`을 **칸 하나의 상한**으로 바꾸고, 차면 빈 칸에 이어 쌓는다. 버려지는 것은 **칸이 전부 찼을 때뿐** (2026-10-15 태웅).
- 수치는 `Item.xlsx`의 `MaxStack` 그대로 — 엑셀 값 변경 없음(컬럼 설명만 "칸 하나의 상한"으로).
- → [이슈 #73](https://github.com/JeongTaeWoong99/Windows_simulator/issues/73)

## 할 일

- [ ] 보관함(인벤토리·창고) 자원을 칸 단위로 — 같은 아이템 여러 칸 · 보유량 = 칸들의 합
- [ ] DB `t_user_inventory` PK `(user_id, container, slot)` 마이그레이션
- [ ] 지급 — 덜 찬 칸부터 채우고 새 칸 · `HasStorageFor`는 필요한 칸 수로
- [ ] 차감 — TID·수량 요청 그대로, 서버가 칸을 고른다(덜 찬 칸부터)
- [ ] 칸 이동·창고 — 같은 아이템이면 `MaxStack`까지 합침 · 정렬은 덜 찬 칸을 합친다
- [ ] `ItemChangeInfo` 칸마다 한 줄 · 프로토콜 미러 커밋

## 완료 조건

9,999개인 자원을 더 수확하면 빈 칸에 새 묶음이 생기고, 칸이 전부 찼을 때만 `InventoryFull`이 온다.
