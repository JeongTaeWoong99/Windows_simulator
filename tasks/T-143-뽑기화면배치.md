# T-143 클라 — 뽑기 화면 배치 개선

> **배치 확정 (2026-10-10 태웅)** — 슬레이어 키우기식 **풀마다 카드 한 장 · 탭 없이 한 목록.**
> 처음 낸 세 안(탭+배너 · 2×2 카드 · 묶음 머리줄)은 모두 기각했다.

## 배경

거래 열의 뽑기 화면(`UI/Market/GachaPresenter`)은 **풀 4개 × [1회 · 10회] = 버튼 8개를 그냥 나열**한다.
어느 버튼이 어느 풀인지 글자를 읽어야 알고, 풀마다 무엇이 나오는지(캐릭터 30종 · 무기 31종 …)도 화면에 없다.

## 확정 배치

```
              소환
┌──────────────────────────────────────┐
│ [P] 캐릭터 소환 (일꾼)                 │
│ [아이콘]   ┌─ 1회 ─┐   ┌─ 10회 ─┐     │
│ 캐릭터 30종 │ ● 1,000 │   │ ● 10,000 │     │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│ [P] 무기 소환 (작업속도 증가)          │
│ …  장신구 소환 · 보석 소환 같은 카드    │
└──────────────────────────────────────┘
```

| 자리 | 내용 |
|---|---|
| 카드 순서 | 캐릭터 소환 → 무기 → 장신구 → 보석 |
| `[P]` | 등급 확률 팝업 — 가챠 테이블 가중치 합(지금 확률표 UI는 없다 → 이 일감에서 만든다) |
| 제목 괄호 | 그 풀이 올려 주는 것 — 장비 3종 "작업속도 증가" · 캐릭터 "일꾼" |
| 아이콘 · 아래 글자 | 🎨 풀 대표 그림(임시 점 그림) · "무기 31종"처럼 나오는 종수 |
| 버튼 | `1회` · `10회` — 머리줄 + 골드 아이콘 · 비용. 10회는 강조색 |

- **뺀 것** (나중에 넣을 수 있다): 왼쪽 안내 캐릭터 · 소환 레벨 · 누적 게이지 · 광고 무료 뽑기
- **탭은 풀이 늘면** 그때 나눈다 — 지금 4개라 한 목록이 낫다
- 목업: 태웅 바탕화면 `뽑기화면_목업.html` (저장소 밖 — 색은 `UIThemePalette`, 확률은 실제 테이블 값)

## 완료 조건

뽑기 화면이 풀마다 카드로 보이고, 8가지 뽑기가 전부 예전처럼 요청 · 잠금 · 결과 팝업까지 돈다. `[P]`가 등급 확률을 보인다.
