# T-066 연계 일감 갱신 스킬 — 작업이 끝나면 관련된 미완료 일감을 전부 갱신

## 배경

일감이나 이슈를 처리하면(엑셀 추가 · 서버 작업 · 기획 결정 등) 그 결과가 **다른 미완료 일감**의 선행·할 일·상태를 바꾸는 경우가 많다.
지금은 처리한 일감 하나만 갱신하고 끝나서 **연계 일감의 갱신이 누락된 채 쌓여 있다** —
예: T-060 완료 후에도 `cheat-console 규칙.md`의 ⚠️ 설명이 남았고, `tasks/README.md`의 보관 건수가 21건으로 어긋나 있었다(실제 30건).

지금 있는 [`task-writer`](../.claude/skills/common/task-writer/SKILL.md)는 **일감 한 개**의 등록·갱신 규칙이다. 이 스킬은 **작업 하나가 퍼뜨리는 영향**을 따라간다.

## 할 일

- [ ] 발동 조건 정하기 — 일감(`T-0XX`)·이슈(`#N`)를 처리하고 커밋하기 전. 단순 질의·탐색은 제외
- [ ] 연계 일감 찾는 절차
  - 대기·진행중·보류 일감 **전부**(▶ · ⏸ · 🎨 세 표 + 일감 파일)에서 처리한 일감 ID · 이슈 번호 · 바뀐 패킷/테이블/함수 이름 검색
  - ⏸ 표의 「무엇을 기다리나」가 방금 끝난 것이면 ▶로 옮긴다
  - "일감조차 없는 공백" 표 · 순서 메모 · 규칙 문서(`*규칙.md`) 속 참조도 확인
- [ ] 갱신 항목 — 체크박스 · 선행 일감 · 상태 · INDEX 표 위치 · 보관 건수 · 링크 경로
- [ ] 결과 보고 형식 — "갱신한 일감 / 확인했지만 바꿀 것 없던 일감"을 나눠 적는다(누락 여부가 보이게)
- [ ] `task-writer`와 경계 정하기 — 합칠지, 별도 스킬로 두고 서로 링크할지
- [ ] 루트 `CLAUDE.md` "Skills 참조" 공용 표에 등록
- [ ] 지금 누락된 연계 갱신을 이 스킬로 한 번 전수 정리

## 완료 조건

일감이나 이슈 하나를 처리하면, 관련된 미완료 일감이 모두 갱신되고 무엇을 확인·갱신했는지 목록으로 남는다.
기존 누락분이 한 번 정리돼 INDEX와 일감 파일이 서로 맞는다.
