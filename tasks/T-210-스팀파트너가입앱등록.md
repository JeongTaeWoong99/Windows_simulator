# T-210 스팀 파트너 가입 · 앱 등록

## 배경

목표는 **스팀에 무료로 게임을 올리는 것**이고, 그 앞 단계(파트너 가입 → AppID)를 태웅이 맡았다 ([#149](https://github.com/JeongTaeWoong99/Windows_simulator/issues/149) 1122 회의).
AppID가 있어야 열리는 일이 셋 있다.

- 클라 스팀 연동을 `480`(Spacewar) 대신 우리 AppID로 돌린다 — [#144](https://github.com/JeongTaeWoong99/Windows_simulator/issues/144)
- 서버가 티켓을 검증할 **Publisher Web API 키** — [T-207](https://github.com/JeongTaeWoong99/Windows_simulator/pull/148). 480으로는 서버 검증을 시험할 수 없을 가능성이 높다(480 키는 우리가 발급받지 못한다)
- 비공개 Playtest·개발 브랜치 빌드 배포

## 전체 그림

```
[무료 구간]                                [$100 결제 이후]
① 스팀 계정 준비 → ② 파트너 가입 · 서류 서명 ─→ ③ 앱 등록비 결제 → ④ 은행 · 세금 · 신원 확인(최대 30일)
                                              │
                                              └→ ⑤ AppID 발급 → Steamworks SDK · 빌드 업로드 · Playtest
                                                  ⑥ 스토어 페이지 → 검수(3~5영업일) → 출시 예정 2주 이상
                                                  ⑦ 빌드 검수(3~5영업일) → 「Release App」 버튼은 직접 누른다
                                                  ⚠️ 결제일부터 출시까지 최소 21~30일 대기(첫 몇 작품)
```

Stove처럼 한 화면에서 이끌어 주지 않는다. **공식 문서를 순서대로 따라가고 막히면 한국어 후기 글을 본다.**

## 할 일

### A. 결제 전 — 돈이 들지 않는 단계

- [x] **명의 정하기** — 개인으로 가입한다(사업자 없이 가능). 회사 형태는 `Sole Proprietorship`, 회사명 칸에 **본인 영문 실명**(닉네임·팀명 불가). 은행 예금주 영문명과 글자까지 같아야 한다
- [x] 스팀 계정에 **Steam Guard 모바일 인증 · 휴대폰 등록** (파트너 계정은 이 스팀 계정에 묶인다)
- [x] [Steam Direct](https://partner.steamgames.com/steamdirect?l=koreana)에서 가입 시작 → 이름·주소 입력
- [x] **NDA · Steam 배포 계약(SDA)** 전자 서명

### B. 결제 — ⚠️ 결정이 먼저 필요하다

- [x] **결제 시점 결정 (진우와)** — 지금 결제로 정했다(2026-11-22) — #144에서는 "출시 준비 때 결제"로 했다. 하지만 아래 셋을 보면 **지금 결제하는 쪽이 낫다**
  - 결제 → 출시 **최소 21~30일 대기**. 출시 직전에 결제하면 일정이 그만큼 밀린다
  - 서버 스팀 로그인(T-207)은 우리 AppID의 Web API 키 없이 끝까지 시험할 수 없다
  - Playtest·데모도 본편 앱에 딸려서만 만들 수 있다 — 결제가 먼저다
- [x] 앱 등록비 **$100** 결제 — ₩135,000 (2026-11-22)

### C. 결제 후 — 은행 · 세금 · 신원

- [x] **은행 정보** — 무료 게임도 필수다. 해외 송금(달러) 받을 수 있는 계좌 · 은행 SWIFT 코드(은행 홈페이지) · 중개은행은 비워도 된다
- [x] **세금 설문(W-8BEN)** — 제출함, 조약 세율 10% 적용 확인(2026-11-22) — 5~10분, **중간 저장 안 됨.** 한국 거주 개인 → W-8BEN
  - 「in my own name」 · 주소는 **주민등록상 주소**(Permanent Address) · 우편번호 필수
  - 조세 조약 국가 `Korea, South` 선택 → 미국 매출분 원천징수 30% → **10%**
  - 납세자 번호(Foreign TIN) = 주민등록번호 (후기 두 곳 기준 · 화면 안내문을 직접 확인)
  - ⚠️ 틀리게 내면 30%로 떼이고, **이미 떼인 돈은 돌려주지 않는다** — 매출이 생기기 전에 바로잡는다
- [ ] **신원 확인** — 주민등록증으로 진행. 2026-11-22 제출 후 「신원 정보 확인 보류 중」 — 화면 안내 **영업일 기준 최대 45일.** 끝나기 전엔 세금 정보를 못 고친다
- [ ] **여권 발급 (대기 중 미리)** — 주민등록증이 반려되면 여권으로 다시 낸다. 다시 내면 대기 순서가 처음부터일 수 있어 미리 만들어 둔다

### D. 앱 만들기 · 팀 연결

- [ ] `Create new app` → **AppID 확보** → #144에 코멘트로 적는다(클라 `steam_appid.txt`가 한 곳에서 바뀌게)
- [ ] 진우를 파트너 그룹 사용자로 초대 → **Publisher Web API 키** 발급(서버 T-207용) — 권한은 필요한 만큼만
- [ ] Depot · 기본 브랜치 확인 → 빌드 1개 올려서 스팀 라이브러리에서 실행 (스토어 공개 전 개발자 계정으로 실행됨)
- [ ] Playtest(비공개 테스트)를 쓸지 정한다

### 대기 중 — 스팀 연동은 `480`으로 먼저 (진우)

신원 확인이 끝나야 AppID를 만들 수 있다(공식 가입 안내의 순서상 — 「확인 전 불가」를 직접 적은 문장은 없어 대시보드에 `새 앱` 메뉴가 생기는지 함께 본다).
기다리는 동안 Valve 공개 테스트 앱 **`480`(Spacewar)** 으로 연동을 먼저 붙여 둔다. AppID가 나오면 번호만 바꾼다.

- [ ] 클라 — `steam_appid.txt`에 `480`으로 Steamworks.NET 초기화 · 세션 티켓 발급까지 ([#144](https://github.com/JeongTaeWoong99/Windows_simulator/issues/144))
- [ ] 서버(T-207) — 480 티켓을 개인 Web API 키(steamcommunity.com/dev/apikey)로 `ISteamUserAuth/AuthenticateUserTicket` 검증이 되는지 시험. 되면 AppID 전까지 서버 흐름도 미리 끝낼 수 있다. 안 되면 우리 AppID의 Publisher 키를 기다린다

### E. 출시까지 (이번 회차 밖 — 큰 줄기만)

- [ ] 콘텐츠 설문(AI 생성물 사용 공개 포함) · 스토어 캡슐·스크린샷 규격 맞추기
- [ ] 스토어 페이지 검수(3~5영업일, 7영업일 전 제출) → 「출시 예정」 2주 이상 → 빌드 검수 → 직접 출시
