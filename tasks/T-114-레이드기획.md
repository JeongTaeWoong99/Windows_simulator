# T-114 기획 — 레이드 콘텐츠

## 배경

채취 루프 **바깥**의 콘텐츠가 없다. 기획에는 **사냥의 보스**(티켓을 모아 도전)가 자리만 있고
**획득 경로 · 전투 형태 · 보상 · 난이도가 전부 미정**이다 → [사냥](../GameDesign/design/gathering/hunting/README.md) 4장.
레이드 콘텐츠를 기획한다.

## 지금 있는 것 (2026-10-02)

- 사냥 = "모아서 보스로 간다"가 정체성 — 보스 티켓 **획득 경로 미정**
- 게임기획코어: 보스는 **실시간 조작을 요구하지 않는다**(P1) · 도전 시점은 플레이어가 정한다
- 후반 목표 = 섬 가치 랭킹(구간 리그) · 최종 도달 약 10주 이후는 업데이트 → [진행 및 성장](../GameDesign/design/progression/README.md) 2장

## 할 일

- [ ] **레이드가 무엇인가** — 혼자 / 여럿(유저 협력) · 사냥 보스와 같은 것인가 별개인가
- [ ] **참여 방식** — 무엇을 내고 도전하나(티켓 · 캐릭터 파견 · 자원) · 결과는 어떻게 정해지나(조작 없음 — P1)
- [ ] **보상** — 레이드에서만 나오는 것 (T-112 아이템 다양화와 연결)
- [ ] **주기·리듬** — 상시 / 주간 / 이벤트 — P3("놓쳐도 손해 없다")와 부딪히지 않게
- [ ] **진행 곡선 안의 위치** — 몇 주차부터 열리나 (진행 및 성장 2장 타임라인)
- [ ] 기획 문서 신설(새 시스템이면 `game-design-reference` 「새 시스템 문서 추가」 절차) · 서버 구현 항목 정리

## 완료 조건

레이드 기획 문서가 서고(무엇 · 참여 · 보상 · 주기 · 열리는 시점), 구현할 것이 일감·이슈로 넘어갔다.
