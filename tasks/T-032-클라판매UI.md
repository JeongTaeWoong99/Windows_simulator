# T-032 클라 — 인벤토리 판매 UI

## 배경

**방치형은 인벤토리가 자동으로 찬다.** 낮은 등급을 하나씩 골라 파는 UI면
플레이어가 매일 수십 번 클릭하게 되고, 이는 P1(주의를 뺏지 않는다)을 정면으로 어긴다.

**일괄 판매가 기본 동선이어야 한다.** 서버(T-028)가 목록 단위 요청을 받도록 설계된 이유다.

## 할 일

- [ ] 인벤토리에서 판매 선택 — 개별 선택 + **희귀도/산업 단위 일괄 선택**
- [ ] 판매가 미리보기 — 선택분 합계 골드
- [ ] 판매 후 인벤토리·골드 표시 갱신 (`S_ItemSellResponse` + `S_CurrencyResponse`)
- [ ] **확인 단계를 둔다** — 되돌릴 수 없는 조작이다. 다만 매번 모달을 띄우지 않는 형태로
      (P1: 화면 중앙 팝업 최소화)
- [ ] 상위 등급(Rare~Mythic) 오판매 방지 — 기본 선택에서 제외하거나 눈에 띄게 구분

## 완료 조건

화면에서 Common·Uncommon을 일괄 선택해 팔면 **골드가 오르고 목록에서 사라진다.**
그 골드로 가챠 화면(T-031)에서 바로 뽑을 수 있다.
