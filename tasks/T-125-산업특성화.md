# T-125 기획 — 산업 특성화

## 배경

[이슈 #42](https://github.com/JeongTaeWoong99/Windows_simulator/issues/42)에서 **산업 차등(희귀도 분포 · 회당 산출 · 가격)을 폐기하고 5산업 공통값**으로 가기로 했고,
산업 개성의 축을 **"쓰임새 + 고유 메커니즘"** 으로 바꾸는 데도 동의했다 (2026-10-06 진우).

## 할 일

- [x] **산업 특성화 아이디어** — 5대 산업 고유 역할 및 자원 싱크(농사: 도시락, 벌목: 슬롯 건축 개량, 채굴: 슬롯 기계 개량, 사냥: 보스 토벌령, 유적 발굴: 상자 보물 특화)
- [x] 아이디어마다 **구체적인 이유** — [게임기획코어](../GameDesign/design/게임기획코어.md) 4장 심리 정의 완벽 계승
- [x] 아이디어마다 **어떻게 하면 재밌는가** — **상호 순환 구조(Cross-Dependency Loop)**를 통해 8개 슬롯 분산 배치 전략 유도
- [x] 위 표의 판단에 대한 의견 — **A안 강화 대상을 장비 $\rightarrow$ [작업슬롯(산업 설비)]으로 치환**하여 큐브와 충돌 없이 타 산업 자원 크로스 소모 달성 (B안 및 요일제는 P1·P3 위배로 기각 유지)
- [x] 정한 것을 [게임기획코어](../GameDesign/design/게임기획코어.md) 4장 · 5장 확정표에 반영 완료

### 지켜야 할 것

- **희귀도 분포 · 회당 산출 · 가격은 5산업 공통이다** — 숨은 확률로 차별화하지 않는다(#42 합의). (✅ 준수)
- **고유 메커니즘은 동일한 방치형 루프를 유지한다** ([T-011](archive/T-011-판정단위충돌.md)). (✅ 준수)
- **방치형이라 재촉하지 않는다**(P1 · P3) — 굶주림/감가상각 없는 긍정적 버프/영구 인프라 강화. (✅ 준수)

## 완료 조건

5산업 각각에 **개성(무엇이 다른가) · 이유 · 재미 포인트**가 문서로 정리되고, 진우가 그 방향에 동의했다. (✅ 완료)
