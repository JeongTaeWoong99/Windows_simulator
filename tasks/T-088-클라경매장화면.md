# T-088 클라 — 경매장 화면

## 배경

서버 쪽 경매장(즉시구매)이 [T-087](archive/T-087-경매장서버.md)로 섰다. 패킷은 다 있고 클라 구독자가 0건이다.
플레이어 규칙은 [거래](../GameDesign/design/trade/README.md) 4장, 패킷 계약은 `MikaPacket.cs`의 `C_/S_Auction*` 주석.

## 할 일

- [ ] 검색 — 이름 입력을 **클라가 TID 목록으로 바꿔** `C_AuctionSearchRequest.Tids`에 싣는다(서버는 이름을 모른다). 종류·분류·희귀도·인챈트 등급·옵션 필터
- [ ] 페이지 — 다음 페이지는 마지막으로 본 `(UnitPrice, ListingId)`를 커서로 보낸다(오프셋 없음)
- [ ] 구매 — 목록에서 본 `TotalPrice`를 `ExpectedTotalPrice`로 보낸다. `AuctionPriceChanged`면 다시 검색을 유도한다. 산 물건은 **우편**으로 온다
- [ ] 등록 — 자원(TID·수량) / 장비(개체 — 착용 중이면 막힘). 단가 입력은 하한 `BasePrice` ~ 상한 ×10 안내. 응답의 `ItemChangeInfos`·`EquipId`로 창고에서 뺀다
- [ ] 내 매물 · 취소 — `Reserved`(구매 중)는 취소 버튼을 막는다. 취소하면 물건이 우편으로 돌아온다(등록비 미환급)
- [ ] 우편 — `MailInfo.Equips`(경매 장비 개체, 인챈트 포함) 표시 — [T-083](T-083-클라우편함.md)과 함께
- [ ] 결과 코드 1000~1012 안내 문구

## 완료 조건

클라에서 등록 → 다른 계정으로 검색·구매 → 우편 수령까지 화면으로 돈다.
