# 나중에 — 먼 훗날 할 일감

**지금 손대지 않고, 배포 전이나 먼 훗날에야 할 일감이 여기 있다.**
남은 일 목록에 계속 떠 있으면 지금 할 일이 가려져서 따로 뺐다.

- [INDEX](../README.md)에는 **없다.** 평소에는 열지 않는다 — 배포 준비·마일스톤 점검 때 연다.
- 넣는 기준: **지금 해도 되지만, 지금 하면 안 되거나 할 이유가 없는 것.**
  선행을 기다리는 것(⏸)은 여기가 아니라 INDEX에 둔다 — 재촉할 대상이 있기 때문이다.
- 옮길 때는 `git mv` + 파일 안 상대 링크를 한 단계 깊게 + 다른 문서의 링크 경로 수정 + 아래 표에 한 줄.
- 다시 할 때가 되면 루트(`tasks/`)로 되돌리고 INDEX에 올린다.

> ⚠️ **배포 전 게이트**(켜 둔 채로 배포하면 안 되는 설정 등)를 여기 넣으면 표의 `언제` 칸에 **배포 전**이라고 적는다.
> 배포 준비 때 이 표부터 본다.
