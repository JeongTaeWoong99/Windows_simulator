# T-158 클라 — 단축키 전체 설계

> 2026-10-15 `later/`로 등록 — 언젠가 한꺼번에 한다(사용자 결정). 그때까지 **인게임 키는 마우스와 함께 쓰는 것만** 둔다.
> 할 때가 되면 루트로 되돌리고 INDEX에 올린다.

## 배경

지금 인게임 키는 **Shift+우클릭(인벤토리 칸 → 경매 등록) 하나**다(2026-10-11 사용자 결정 — 마우스로 하는 게임).
2026-10-14에 경매장 닫기 Esc를 지시 없이 넣었다가 2026-10-15에 뺐다 — 키를 화면마다 하나씩 붙이면
같은 키가 화면마다 다른 뜻이 되고, 무엇이 있는지 아무도 모르게 된다. **단축키는 전체를 한 번에 설계해서 넣는다.**

키는 [`KeyInputManager`](../../Assets/Scripts_Client/Managers/KeyInputManager.cs) 한 곳에서만 읽는다 — 키 표는 [`Managers 규칙.md`](../../Assets/Scripts_Client/Managers/Managers%20규칙.md).

## 지금 있는 키 (2026-10-15)

| 구역 | 키 | 하는 일 |
|------|----|---------|
| 아웃게임(로그인 화면) | Enter (아이디 칸) | 로그인 |
| 아웃게임 | 방향키·WASD · Enter/Space | EventSystem 기본 UI 이동 — 인게임에서는 끈다 |

## 할 일

- [ ] **후보 목록 정하기** — 사용자와 함께 정한다. 후보:
  - Esc — 맨 위 창부터 닫기(팝업 → 등록 창 → 경매장 …). **닫는 순서를 한 곳(창 스택)에서 정한다** — 화면마다 따로 Esc를 받지 않는다
  - Enter — 검색칸에서 검색(경매장 공용 검색창 · 인벤토리 찾기) · 확인 팝업의 [확인]
  - 창 열기·닫기 — 인벤토리 · 거점 · 경매장 · 우편 · 설정 (I · B · M … 키는 정할 것)
  - 탭 전환 — 숫자 키 · Tab
  - 인벤토리 — Ctrl+클릭 · Shift+클릭 같은 마우스 조합 보강
- [ ] **막는 조건 공통 규칙** — 입력칸에 포커스가 있을 때 · 로딩·차단막이 떠 있을 때 · 요청 대기 중일 때는 키를 무시한다
  (예전 Esc가 화면마다 `IsCovered`를 따로 봤다 — 한 곳에서 판정)
- [ ] **창이 포커스를 잃었을 때** — 데스크톱 위 투명 창이라 다른 앱을 쓰는 중엔 키가 오지 않는다. 그 동작이 맞는지 확인(전역 단축키는 하지 않는 것이 기본)
- [ ] 설정 화면에서 **바꾸기(리바인딩)** 가 필요한지 결정 — 필요하면 Input System 액션 맵으로
- [ ] 화면에 단축키 표시 — 버튼 툴팁에 "(Esc)" 같은 표기 · 도움말([T-072](../T-072-도움말UI.md))과 맞춘다
- [ ] `KeyInputManager` · `Managers 규칙.md` 키 표 갱신 · 실측(키는 자동 입력이 닿지 않는다 — 사람 손으로)

## 완료 조건

정한 단축키가 `KeyInputManager` 한 곳에서 읽히고, 키 표에 전부 올라 있으며, 막는 조건이 화면마다 같다.
