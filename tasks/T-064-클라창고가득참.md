# T-064 클라 — 창고가 가득 차 뽑기가 거절될 때 안내

## 배경

[T-063](archive/T-063-창고한도뽑기거부.md)에서 서버가 창고 칸이 모자란 뽑기를 거절하게 된다.
클라는 그 결과 코드를 받아 **왜 안 됐는지** 보여 줘야 한다 — 안 그러면 버튼이 먹통처럼 보인다.

## 할 일

- [ ] `ResultMessages`에 `StorageFull`(103) 문구 추가 (예: "창고가 가득 찼습니다. 정리한 뒤 다시 뽑아 주세요") — **서버가 냈다**(2026-09-22). 상자 개봉 거절도 같은 코드다
- [ ] 가챠 화면의 거절 처리 경로에서 문구가 뜨는지 확인
- [ ] (선택) 창고 탭에 `보유 N / 200` 표시 — 한도 값을 서버가 내려줄지는 T-063 결정을 따른다
- [ ] 칸 프레임 수(200)가 서버 한도와 같은지 확인

## 완료 조건

캐릭터 200명 계정에서 캐릭터 뽑기를 누르면 재화가 줄지 않고 가득 참 안내가 뜬다 (실플레이).
