# T-207 서버 — 스팀 로그인 인증

## 배경

지금 로그인은 클라가 보낸 `C_LoginRequest.Id` 문자열을 그대로 `CreateUser(pid)`에 넘긴다. 남의 아이디를 넣으면 그 계정으로 들어가진다.
스팀으로 출시하면서 **스팀이 서명한 티켓을 서버가 스팀 Web API로 확인하고, 그 SteamID로 자동 가입·로그인**하게 바꾼다.
유저는 스팀에서 게임을 누르면 로그인 화면 없이 바로 게임에 들어간다.

```
클라: SteamAPI.Init → GetAuthTicketForWebApi("<identity>") → C_LoginRequest { SteamTicket }
서버: ISteamUserAuth/AuthenticateUserTicket (퍼블리셔 키 · appid · ticket · identity)
      → steamid → provider_id = "steam:<steamid>" → CreateUser → S_LoginResponse
```

게임 서버 SDK(`BeginAuthSession`)는 쓰지 않는다 — 서버가 .NET 10 · Docker(리눅스)라 네이티브 Steamworks를 올리는 것보다 HTTP 호출 하나가 단순하다.

## 결정 (2026-11-21 진우)

- **패밀리 공유로 쓰는 사람도 받는다** — `ownersteamid ≠ steamid`여도 거절하지 않는다. 계정은 실제 플레이어의 `steamid`로 만든다.
- **기존 테스트 계정(`Id` 로그인)은 잇지 않는다** — 스팀 계정은 새로 시작한다.
- `t_account.provider_id`(UNIQUE)에 `steam:<steamid>`로 넣는다 — DB 마이그레이션 없음.

## 할 일

- [ ] **1. 스팀 앱 준비 — 출시 준비 때 결제** — Steamworks 파트너 가입 · 앱 등록(Steam Direct, 앱당 $100 · 매출 $1,000 넘으면 환급)으로 **AppID** 받기 · **퍼블리셔 Web API 키** 발급(사용자 및 권한 → 그룹 관리).
  그전에는 클라 테스트용 AppID `480`(Spacewar) · 서버는 `AllowDevLogin`으로 진행한다. 480 + 일반 Web API 키로 서버 검증이 되는지는 확인 안 됨 — 붙여 보고 결과를 여기 적는다
- [ ] 2. 설정 — `appsettings.json` `Game` 절에 `SteamAppId` · `SteamWebApiKey` · `SteamTicketIdentity` · `AllowDevLogin`. 원격은 docker 환경 변수로 덮는다 ([`도커.md`](../Server/docs/도커.md)). **키는 커밋하지 않는다**
- [ ] 3. 패킷 — `C_LoginRequest`에 `SteamTicket`(hex) · `EResultCode`에 `SteamAuthFailed` · `SteamUnavailable` · `Banned`
- [ ] 4. `SteamAuthClient` — `AuthenticateUserTicket` 호출(타임아웃) · `publisherbanned`면 거절 · 응답 파싱 테스트
- [ ] 5. 로그인 핸들러 — 티켓 검증은 **로직 스레드 밖**에서, 결과만 로직 스레드로 넘겨 `CreateUser`. 티켓이 비었으면 `AllowDevLogin`일 때만 지금의 `Id` 로그인(에디터·더미 클라·`MikaLoadTest`)
- [ ] 6. 닉네임 — 첫 가입 때 `ISteamUser/GetPlayerSummaries`의 이름. 클라가 보낸 이름은 믿지 않는다
- [ ] 7. 클라 연동 — Steamworks.NET · 실행 시 바로 로그인 → [이슈 #144](https://github.com/JeongTaeWoong99/Windows_simulator/issues/144)로 태웅에게
- [ ] 치트: 해당 없음 — 로그인 경로라 `AllowDevLogin`으로 시험한다

## 완료 조건

스팀에서 실행하면 로그인 화면 없이 게임에 들어가고, 운영 설정(`AllowDevLogin = false`)에서는 티켓 없는 로그인이 거절된다 · 패밀리 공유 계정으로도 들어가진다 · 사용자 실측.
