# T-039 클라 — 잠긴 작업슬롯의 해금 안내·구매 UI

## 배경

**지금 화면은 잠긴 칸과 열린 빈 칸을 구분하지 못한다.**

작업슬롯 목록의 프레임은 씬에 8칸이 있고, 전부
`Assets/Prefabs/WorkSlotFrame.prefab`의 **"비어있음."** 을 띄운다.
서버가 열어 주는 슬롯은 현재 0번 하나뿐이라, 1~7번을 누르면
배치 화면이 열리고 → 배치 요청이 나가고 → 서버가 `InvalidSlotIndex`로 거절해
*"아직 열리지 않은 작업 슬롯입니다"* 알림이 뜬다.

**플레이어 입장에서는 "왜 안 되는지"는 알아도 "어떻게 여는지"는 알 수 없다.**
잠긴 칸에 여는 방법을 표시하고, 그 자리에서 열 수 있어야 한다.

## 할 일

> 2026-09-14 — 슬롯 해금은 [해금 시스템](../GameDesign/design/unlock/README.md)으로 통일됐다. **조건은 클라가 테이블에서 만든다** —
> `WorkSlotTable.WorkSlotTID`(칸 번호) → `UnlockTID` → `UnlockTable`의 골드·선행·계정 레벨. 테이블은 이미 미러돼 있어 표시는 지금 만들 수 있다.
> 요청·열린 목록 패킷(`C_UnlockRequest` · `S_UnlockResponse` · `S_UnlockListResponse`)만 [T-038](T-038-슬롯해금서버.md)을 기다린다.

**요청·결과 항목이 [T-038](T-038-슬롯해금서버.md) 패킷 대기다.** 표시 항목은 테이블로 먼저 갈 수 있다.

- [ ] 잠긴 칸을 **"비어있음."이 아니라 잠김 상태로** 그린다 — 열림 여부는 `S_UnlockListResponse`(⏸) · 칸 목록은 `WorkSlotTable`
      (`WorkSlotFrame.prefab` + `WorkStationListPresenter.Rebuild`)
- [ ] 칸에 **여는 방법**을 표시한다 — `UnlockTable`의 골드·선행(`Name`으로 표시)·계정 레벨을 문구로. 보유 골드와 대조해 "지금 열 수 있음"도 구분
- [ ] ⏸ 잠긴 칸 클릭 → 배치 화면이 아니라 **해금 안내·구매**로 분기한다.
      지금은 `WorkStationListPresenter.OpenSelect`가 배치 여부와 무관하게 무조건 배치 화면을 연다
- [ ] ⏸ `C_UnlockRequest{UnlockTID, Currency}` 전송(지금은 골드뿐) + `ServerWaitManager.Begin` 대기 + 결과 문구
      (`UI/Shared/ResultMessages.cs`에 `InvalidUnlockTID` · `AlreadyUnlocked` · `UnlockLocked` 문구를 더한다 — `NotEnoughCurrency`는 있다)
- [ ] ⏸ 해금 성공 시 슬롯 목록이 즉시 갱신되는지 확인 (`PlayerDataModel` 경유)
- [ ] 🎨 해금 연출

## 완료 조건

잠긴 칸이 잠긴 것으로 보이고, 여는 조건이 칸에 적혀 있으며,
조건을 만족한 상태에서 그 칸을 눌러 **실제로 슬롯이 열린다.**
