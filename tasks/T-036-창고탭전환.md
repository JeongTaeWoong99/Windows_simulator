# T-036 클라 — 창고 탭 전환 (자원 · 캐릭터 · 장비 · 특성)

## 배경

**창고에 탭 버튼 4개가 있지만 눌러도 아무것도 바뀌지 않는다.**
`StorageTabPresenter`는 지금 **버튼을 잡아 두고 "화면이 없다"를 로그로 남기는 것까지**다
(`OnTabClicked` → `ClientLogger.Warn`). 실재하는 것은 **자원 탭 하나**뿐이고,
`InventoryPresenter` 하나가 아이템 전부를 한 칸에 쏟아낸다.

**막힌 것은 탭 전환이 아니라 탭에 담을 내용이다.**
전환 구조 자체는 지금도 만들 수 있다 — 문제는 켤 화면이 없다는 것이다.
**무엇을 기다리는지는 아래 할 일에 항목별로 적는다**(이 일감이 그 목록의 단일 출처다).

## 할 일

> ⏸ = 기획·서버가 먼저 와야 한다 · 남은 하나는 **지금 할 수 있다**

- [ ] **탭 전환 seam을 넣는다** ← **선행 없음. 지금 할 수 있다**
      - [ ] 탭 enum 하나를 두고 **켜고 끄는 곳을 `StorageTabPresenter` 한 곳으로 모은다**
            (본은 `UIManager.ShowMainScreen` — [`Storage 규칙.md`](../Assets/Scripts_Client/UI/Storage/Storage%20규칙.md) "탭 전환도 층은 하나다")
      - [ ] ⚠️ **탭 enum에 값을 중간에 끼우지 않는다.** 씬에 int로 저장돼 순서가 밀리면
            배선이 조용히 어긋난다 — `MainScreen`에서 실제로 겪었다(`UIManager.cs`)
      - [ ] 새 Presenter는 `#Storage Canvas` 아래 **형제**로 두고
            `LayoutElement`를 `pref 0 · flexH 1`로 맞춘다
- [ ] ⏸ **T-026** — 캐릭터 탭
      → 보유 캐릭터가 **시작 지급 1종뿐**이라 목록·필터를 실검증할 수 없다.
      획득 경로가 가챠로 확정되는 것이 [T-026](T-026-캐릭터가챠.md)이다
- [ ] ⏸ **T-002** — 장비 탭
      → **장비 시스템 자체가 없다.** [T-002](T-002-장비슬롯.md)는 장착·해제만 다루고
      **획득 경로는 기획에도 없다** → `README.md` 순서 메모의 "일감조차 없는 공백"
- [ ] ⏸ **서버** — 특성 탭
      → 기획은 있으나([`trait/`](../GameDesign/design/trait/README.md)) 서버 구현·패킷이 없다
- [ ] 자원 탭 — **이미 실재한다.** 이 일감에서는 seam에 얹기만 한다
      (탭 안쪽의 산업별 필터·정렬은 [T-015](T-015-산업아이템클라적용.md)의 몫이다)

## 완료 조건

탭을 누르면 **그 탭의 목록만 보이고**, 새 탭을 추가할 때 켜고 끄는 코드를 한 곳만 고치면 된다.

> ⚠️ **네 탭이 다 차야 끝나는 일감이 아니다.** seam이 서고 자원 탭이 그 위에 얹히면
> 이 일감의 구조적 몫은 끝난다 — 나머지 셋은 선행이 풀리는 대로 얹는다.

## 막고 있는 것 / 선행 일감
