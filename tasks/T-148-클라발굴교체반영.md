# T-148 클라 — 낚시 → 유적 발굴 교체 반영

[T-142](T-142-낚시제거대체산업.md)에서 데이터·서버·enum이 **유적 발굴(`Excavation`)** 로 바뀌었다 (값 2 · TID 그대로).
클라 코드는 **컴파일이 깨지는 참조만** 진우가 바꿔 두었다 — 남은 것은 화면 글자 · 클라 문서 · 아트다.
요청 창구는 [이슈 #66](https://github.com/JeongTaeWoong99/Windows_simulator/issues/66).

## 진우가 이미 바꾼 것 (확인만)

- `EIndustryType.Fishing` → `Excavation` · `GameTable.FishingBasicTable` → `ExcavationBasicTable` · `Row.Fishing` → `Row.Excavation`
- 순서 배열(`StripIndustries` · 특성 줄 · `ArtValidator`) · `EnchantAutoFocus.Fishing` → `Excavation`(값 그대로)
- `IndustryLabel` — `"낚시"` → `"발굴"` · 주석·툴팁의 "낚시" → "발굴"
- ⚠️ **Unity에서 컴파일을 돌려 보지 않았다** — 열어서 오류가 없는지 먼저 본다
