# T-194 클라 — 소모품 사용 화면 · 영약 자동 사용 칸

> ⏩ 261107 회차에 못 끝내 261121로 자동 이월 (2026-11-08)

## 배경

소모품 규칙이 확정됐다([이슈 #110](https://github.com/JeongTaeWoong99/Windows_simulator/issues/110)) — 서버는 [T-195](T-195-소모품효과적용.md), 클라는 사용 화면(캐릭터·슬롯 고르기 · 사용 개수)과 슬롯의 잔여 횟수 표시가 필요하다.
영약은 Lv1 기준 약 10분이면 끝나 **자동 사용 칸**을 제안했다 — 흔한 영약은 칸에 직접 넣어 자동으로 쓰고, 좋은 영약은 원하는 때에 직접 쓴다([이슈 #113](https://github.com/JeongTaeWoong99/Windows_simulator/issues/113) · 2026-11-04 태웅). **넣기로 했다(2026-11-11 진우)** — 서버 패킷은 T-195(PR #120)에 있다: `C_SlotAutoUseRequest`/`S_SlotAutoUseResponse` · 칸 내용은 `WorkStationSlotInfo.AutoUse`.
