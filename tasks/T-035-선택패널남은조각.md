# T-035 클라 — 작업슬롯 선택 패널의 남은 표시 조각

## 배경

**작업슬롯 선택 화면에서 "지금 무슨 상태인가"가 화면에 안 나오는 자리가 둘 남았다.**
둘 다 기능이 없는 게 아니라 **표시가 없다** — 동작은 하는데 사용자가 판단할 근거가 화면에 없다.

이 둘은 원래 [T-006](archive/T-006-작업슬롯UI.md)이 끝난 뒤 남은 조각으로 개인 메모에만
적혀 있었다. **일감으로 세워 목록에 올린다.**

> 같은 화면의 세 번째 조각인 **산업 교체**는 [T-034](T-034-슬롯산업교체.md)로 따로 세웠다 —
> 그쪽은 표시가 아니라 **요청이 나가지 않는 문제**라 성격이 다르다.

## 할 일

> **둘 다 선행이 없다. 지금 진행할 수 있다.**

- [ ] **(a) 이미 다른 슬롯에 배치된 캐릭터를 목록에서 구분한다**
      → 지금은 배치 중인 캐릭터도 목록에 **그냥 뜬다.** 눌러서 배치하면 그 캐릭터가
      **어느 슬롯에서 빠져나오는지** 알 수 없다
      - [ ] 숨기지 않고 **표시한다** — 목록에서 빼면 "내 캐릭터가 왜 안 보이지"가 된다
            (적성 0 처리와 같은 원칙 → `WorkStationSelectPresenter` 클래스 주석)
      - [ ] 어느 슬롯에 있는지까지 보일지 정한다 (슬롯 번호 표시 vs 배치 중 표시만)
      - [ ] 판정 근거는 `PlayerDataModel.WorkStationSlots` — 화면이 자체 플래그를 들지 않는다
            ✅ **판정 헬퍼가 이미 있다 (2026-09-02 · [T-036](archive/T-036-창고탭전환.md)).**
            **`PlayerDataModel.FindSlotIndexOf(characterId)`** 를 쓴다 — 배치 안 됐으면 `-1`.
            창고 캐릭터 탭이 같은 것을 보므로 **각자 `WorkStationSlots`를 훑지 않는다**
            (두 화면이 다른 말을 하게 된다)
- [ ] **(c) 3단계 세팅 패널에 배치된 캐릭터 정보를 표시한다**
      → 지금 `Character Setting Panel`에는 **해제 버튼 하나뿐**이다.
      헤더의 "슬롯 N 설정" 문구로만 짐작하고, **누가 일하고 있는지가 화면에 없다**
      - [ ] 캐릭터 이름 · 그 산업의 적성값 (`PlayerDataModel.GetAptitude`)
      - [ ] 산업 교체(T-034)가 붙으면 **이 표시가 갱신돼야 한다** — 함께 작업하면 한 번에 끝난다

## 완료 조건

배치 화면에서 **이미 일하고 있는 캐릭터가 눈에 구분되고**,
배치된 슬롯을 열면 **누가 무슨 적성으로 일하는지가 화면에 보인다.**

  (`CharacterInfo.Aptitudes` · `WorkStationSlots`)
