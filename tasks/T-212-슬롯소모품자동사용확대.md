# T-212 슬롯 소모품 자동 사용 확대

## 배경

신속 · 풍요의 영약은 작업슬롯 설정에서 켜 두면 서버가 자동으로 쓴다(#113 · #123). 나침반 · 보물 지도는 아직 인벤토리 → 팝업 → 슬롯 고르기로 한 번씩 쓴다.
같은 슬롯 소모품이 두 방식으로 갈려 있어 슬롯 소모품을 전부 ON/OFF로 맞춘다(2026-11-22 사용자).

## 할 일

- [ ] ⏸ 기획 · 서버 — 나침반 3종 자동 사용 대상 추가 · 보물 지도 방식 결정 · 팝업 직접 사용을 남길지 ([#153](https://github.com/JeongTaeWoong99/Windows_simulator/issues/153))
- [ ] 클라 — `ItemUseLabel.IsAutoUsable`을 서버 기준에 맞춘다(자동 사용 칸은 표에서 읽어 저절로 는다)
- [ ] 클라 — 자동 사용 칸이 늘어도 슬롯 설정 칸 배치가 넘치지 않는지 확인
- [ ] 클라 — 인벤토리에서 이 소모품을 누르면 팝업 대신 "작업슬롯 설정에서 켜세요" 안내(직접 사용을 없애기로 하면)
- [ ] 치트: 기존 아이템 지급으로 시험

## 완료 조건

슬롯 소모품은 전부 작업슬롯 설정에서 켜고 끄며, 켜 둔 슬롯은 버프가 끊길 때 자동으로 쓴다.
