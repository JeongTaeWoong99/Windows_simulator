# T-212 슬롯 소모품 자동 사용 확대

## 배경

신속 · 풍요의 영약은 작업슬롯 설정에서 켜 두면 서버가 자동으로 쓴다(#113 · #123). 나침반 · 보물 지도는 아직 인벤토리 → 팝업 → 슬롯 고르기로 한 번씩 쓴다.
나침반 3종을 영약과 같은 슬롯 자동 사용 칸에 추가하고, 보물 지도는 인벤토리에서 슬롯을 골라 바로 사용한다.

## 할 일

- [x] 기획 · 서버 — 나침반 3종의 자동 사용을 추가했다. 여러 등급은 동시에 소모·적용하며 보물 지도는 직접 사용한다. 구버전 호환을 위해 서버는 영약·나침반 직접 사용 요청도 받는다. ([#153](https://github.com/JeongTaeWoong99/Windows_simulator/issues/153))
- [ ] 클라 — `ItemUseLabel.IsAutoUsable`을 서버 기준에 맞춘다(자동 사용 칸은 표에서 읽어 저절로 는다)
- [ ] 클라 — 자동 사용 칸이 늘어도 슬롯 설정 칸 배치가 넘치지 않는지 확인
- [ ] 클라 — 인벤토리에서 영약·나침반을 누르면 "작업슬롯 설정에서 켜세요" 안내를 표시한다. 보물 지도의 슬롯 선택 팝업은 유지한다.
- [ ] 치트: 기존 아이템 지급으로 시험

## 완료 조건

작업슬롯 설정에서 영약과 나침반을 종류별로 켜고 끈다. 켜 둔 버프가 끝나면 슬롯이 자동으로 다시 쓴다. 보물 지도는 인벤토리에서 슬롯을 골라 쓰면 해당 슬롯의 판정이 즉시 진행된다.
