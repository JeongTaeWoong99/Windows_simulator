# T-212 슬롯 소모품 자동 사용 확대

## 배경

신속 · 풍요의 영약은 작업슬롯 설정에서 켜 두면 서버가 자동으로 쓴다(#113 · #123). 나침반 · 보물 지도는 아직 인벤토리 → 팝업 → 슬롯 고르기로 한 번씩 쓴다.
같은 슬롯 소모품이 두 방식으로 갈려 있어 슬롯 소모품을 전부 ON/OFF로 맞춘다(2026-11-22 사용자).

## 할 일

- [x] 기획 · 서버 — 나침반 3종 자동 사용 대상 추가(PR #162 · 진우) · 보물 지도는 직접 사용 유지 · 같은 슬롯에 켠 나침반은 각자 소모 · 가산 합산 ([#153](https://github.com/JeongTaeWoong99/Windows_simulator/issues/153))
- [x] 클라 — `ItemUseLabel.IsAutoUsable`을 서버 기준에 맞춘다(자동 사용 칸은 표에서 읽어 저절로 는다)
- [x] 클라 — 자동 사용 칸이 늘어도 슬롯 설정 칸 배치가 넘치지 않는지 확인 — 한 줄 2칸(3칸이면 이름이 안 들어간다 — 2026-11-27 사용자) · 갈래(영약 / 나침반)가 바뀌면 새 줄. 칸 순서는 효과 · 등급 순
- [x] 클라 — 인벤토리에서 이 소모품을 누르면 팝업 대신 "작업슬롯 설정의 [자동 사용]에서 켜 주세요" 토스트 — 영약도 같다(자동 사용 소모품 전부). 보물 지도는 그대로 사용 창
- [ ] ⏸ 기획 · 서버 — 나침반 1개 = 판정 1번 · 2종(낡은 = 상자·유물 50% / 황금 = 상자·유물 100%)으로 · 은빛 삭제 ([#168](https://github.com/JeongTaeWoong99/Windows_simulator/issues/168))
- [ ] 실측 — 나침반 켜기/끄기 · 지도 직접 사용(치트 아이템 지급) — #168 데이터가 들어온 뒤 한 번에. 칸 배치 · 토스트는 2026-11-27 Claude 플레이 확인 · #162는 2026-11-27 main에 받음
- 이슈는 #168 하나로 모았다 — #153(첫 판 클라 확인 요청)은 2026-11-27 닫음

## 완료 조건

슬롯 소모품은 전부 작업슬롯 설정에서 켜고 끄며, 켜 둔 슬롯은 버프가 끊길 때 자동으로 쓴다.
