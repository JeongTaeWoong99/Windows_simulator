# 신규 계정 램볼 작업 배치

## 목적 / 배경

- 첫 접속부터 일하는 모습을 보여 준다. → T-019 · [#163](https://github.com/JeongTaeWoong99/Windows_simulator/issues/163)

## 변경 내용

- `AccountRepository.cs`에서 자동 가입과 램볼 지급, 농사 배치를 함께 저장한다.
- `AccountRepositoryTest.cs`에서 첫 로그인과 재로그인 스냅샷, 기존 계정, 슬롯 저장 실패 후 재시도를 검증한다.

## 주요 결정 / 근거

- 가입 트랜잭션 안에서 배치를 저장해야 접속이 끊기거나 저장에 실패해도 다음 로그인에서 빈 슬롯으로 시작하는 계정이 남지 않는다.
- 서버 슬롯 인덱스 0이 화면의 1번이다. 판단 시각과 속도는 기존 로그인 적재 흐름에서 초기화한다.
- 캐릭터가 없는 기존 계정의 기존 지급 경로는 유지한다. 자동 배치는 새 계정 INSERT 경로에서만 실행된다.

## 후속 작업 / 주의사항

- 머지 후 클라이언트에서 신규 계정으로 실제 첫 화면을 확인한다.
