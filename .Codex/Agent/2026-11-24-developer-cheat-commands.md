# 개발 편의 치트 서버 명령 3종

## 목적 / 배경

- [T-213](../../tasks/archive/T-213-개발편의치트.md)의 클라 치트 창에서 상자 보상 검증, 장비 레벨 조건 재현, 보관함 정리를 할 수 있게 한다. [T-215](../../tasks/T-215-개발편의치트서버.md)

## 주요 결정 / 근거

- 개봉 시뮬레이션은 실제 상자 추첨 함수를 공유하고 집계만 돌려준다. 서로 다른 종류의 TID가 겹칠 수 있으므로 응답에 보상 종류를 넣고, 골드 합산에는 64비트 정수를 쓴다.
- 레벨 변경 전 채취를 정산한다. 레벨과 조건 미달 장비의 착용 매핑 해제를 같은 트랜잭션에서 저장한다.
- 보관함 비우기에 판매의 소유·경매 보호 SQL을 재사용한다. 잠금, 착용, 배치, 인챈트 대기, 마지막 캐릭터를 보존한다.

## 후속 작업

- 클라 요청·파싱 계약은 [서버 치트 문서](../../Server/docs/치트.md) 2.1에 있다. UI 연결과 실측은 T-213에서 진행한다.
