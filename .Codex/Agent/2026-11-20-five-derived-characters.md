# 파생 캐릭터 5종 데이터 반영

## 목적 / 배경

- 이슈 #133의 기존 그림 5종에 캐릭터 TID `1037~1041`을 배정했다. 아트 쪽에서 이 번호를 레시피와 `VisualCatalog`에 사용한다.

## 주요 결정 / 근거

- 공격 주기는 각 그림 바탕 캐릭터를 따랐다. 레이드 기본 공격력·체력은 공격 주기와 등급이 같은 기존 캐릭터와 맞췄다. 작업 적성은 기존 등급 상한과 산업 역할에 맞췄다.
- 뽑기권 A~D에 동급 가중치로 넣었다. 닫힌 골드 직접 풀은 그대로 둔다.

## 후속 작업

- 데이터 머지 후 아트 레시피를 굽고 인게임에서 확인한다. 이슈 #133과 T-174 참조.
