# 테마 상자 장비 레벨 보상 연결

## 목적 / 배경

- 테마 상자 개봉으로 고레벨 장비를 얻어 클라의 레벨 표시와 착용 제한을 확인할 수 있게 한다. 범위는 [T-209](../../tasks/T-209-테마상자열기보상.md)의 장비 레벨 보상이다.

## 변경 내용

- `Gacha.xlsx`의 장비 보상 행과 `Item.xlsx`의 왕실 개봉 풀을 연결했다. 새 풀 이름은 아이템의 기존 영어 번역을 사용한다.
- 서버 데이터 검사에서 실제 생성된 테마 상자 레벨 구간과 아티팩트 확률을 확인한다.

## 주요 결정 / 근거

- 장비 행을 낮은 레벨과 높은 레벨로 나눌 때 기존 가중치에 각각 7과 3을 곱하고, 다른 보상 행은 10을 곱했다. 한 풀에서 모든 보상 유형을 함께 굴리므로 이 비례가 장비 당첨률과 기존 보상 확률을 유지한다.
- 무기·보석은 같은 산업과 등급의 장비에 연결했다. 광부 상자의 발굴 전용 목걸이는 같은 등급의 범용 장신구로 연결하고 기존 장신구 가중치를 합산했다.
- 왕실 풀은 수정 전 성주 풀을 바탕으로 만든다. 성주 장비 보상을 레벨별로 나눈 뒤 복사하면 장비 비중에 배율이 중복된다.

## 후속 작업 / 주의사항

- [T-209](../../tasks/T-209-테마상자열기보상.md)에서 캐릭터 등급 분포와 상자 기대 가치를 계속 정한다. 클라에서는 개봉 결과의 레벨 표시와 낮은 레벨 캐릭터의 장착 거절을 확인한다.
