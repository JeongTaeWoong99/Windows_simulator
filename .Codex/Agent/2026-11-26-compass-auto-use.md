# 나침반 슬롯 자동 사용

## 목적

- #153의 나침반 3종을 슬롯 자동 사용에 연결했다. 보물 지도는 인벤토리에서 직접 사용한다.

## 주요 결정

- ItemUseTable의 슬롯 버프 분류와 기존 충전 경로를 재사용했다. 아이템 효과, 수치, 슬롯 범위는 기존 데이터에서 읽는다.
- 여러 등급이 켜지면 각각 소비되고 확률 가산이 합산된다. 서버는 구버전 클라이언트의 영약·나침반 직접 사용 요청을 계속 받는다.

## 검증과 후속 작업

- 나침반의 20회 충전·재충전, 여러 등급 동시 차감, 지도 토글 거절을 포함해 게임 서버 테스트 1,369개를 통과했다.
- T-212에서 나침반 토글과 인벤토리 안내를 추가하고, 보물 지도 슬롯 선택을 유지한다.
