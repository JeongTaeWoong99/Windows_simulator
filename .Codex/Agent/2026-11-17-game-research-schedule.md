# 게임별 재미 연구와 정기 게시

## 목적 / 배경

- 사용자가 해 보지 않은 방치형·Desktop Companion을 게임별로 공부한다. 이용자 동기·구체적 재미·불만·관찰 과제를 wsdocs 기획 (AI)에 쌓는다. 사용자 일정은 매일 KST 06·12·18시다.
- 현재 운영 계약은 [게임연구예약](../../GameDesign/scripts/게임연구예약.md), 진행은 [T-203](../../tasks/T-203-게임별재미연구예약.md).

## 결정 / 근거

- 기존 references는 시스템을 우리 게임에 옮기는 제안이다. 새 game-studies는 원작을 이해하는 학습 자료이므로 폴더·배지·목록 제목을 구분하고 기존 /proposals 경로를 유지했다.
- 일반 예약 도구가 없어 이 PC의 Windows 작업 스케줄러와 로그인된 Codex CLI를 쓴다. 전원·로그인·CLI 연결이 필요한 로컬 예약이며 클라우드 상시 실행이라고 안내하지 않는다.
- 조사 모델은 읽기 전용 웹 검색만 수행하고 게시기는 별도 detached Git worktree를 쓴다. 사용자 main·staged 변경·DB를 보존하는 실제 Git 테스트를 두었다.
- 검토에서 잘못된 퍼센트 상대 링크가 Astro 빌드를 깨는 경로를 확인했다. 실패 테스트로 재현한 뒤 게시 전 인코딩 검증을 추가했다.
- 리뷰는 질적 사례이며 인구통계나 생산성의 인과를 입증하지 않는다. 실제 게임 실행·성능 측정을 했다는 표현을 금지했다.

- 초기 연구 3편, Astro check 0 오류·0 경고, build 338페이지.
- Node 검증·게시 테스트 6개 통과. 별도 검토의 차단 문제는 수정 완료.
- Windows 예약·실제 실행·공개 배포 확인 완료. 최초 실행은 Chillquarium 연구를 `00aaf947`로 게시했고, 종료 코드 0과 다음 06시 실행을 확인했다. GitHub Actions 배포 `43908350490` 성공 및 공개 /proposals 페이지의 연구 4편 링크를 확인했다.
- T-203은 사용자 열람 확인만 남아 Resolve로 인계한다. 정기 실행 장애는 운영 문서의 latest.json과 로그를 먼저 확인한다.
