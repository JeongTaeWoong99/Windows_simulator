# 아티팩트 5종과 획득처 추가

- #107의 아티팩트 종류 확장으로 TID 24~28을 나무·은 상자와 희귀·영웅·전설 유물 감정에 배정했다. 효과와 획득률은 유물감정 기획 3.4에 적었다.
- 신규 보상 풀에서 기존 보상끼리의 상대 가중치를 같은 배수로 보존하면서 아티팩트 확률을 정확히 맞췄다. 일반·고급 유물은 동급 내 균등 배분을 유지하며, 정수 가중치를 내림해 각 풀의 합계가 1%를 넘지 않게 했다.
- 데이터 테스트가 풀별 아티팩트 합계 1%와 지급 수량 1개, 신규 TID의 정확한 획득처·확률을 검사한다.
- 새 아이콘과 도감 상세의 획득처 표시는 클라 작업이다.

## 업데이트 (2026-11-21)

- 채취 획득처는 `DropCommon.xlsx`의 `GatherArtifactTable`에서 산업·레벨별 1행을 둔다. 앞으로 Lv2~5를 열 때는 그 레벨에 따로 행을 추가한다.
- 채취 배치 정산에서도 각 판정에 같은 확률을 적용한다. 자원 산출량과 유물 발견 확률 보정은 아티팩트 지급 수량과 확률에 적용하지 않는다.
- 지급은 기존 아티팩트 칸과 넘침 우편을 재사용한다. 채취 결과 알림에는 기존 인벤토리 스냅샷을 쓰므로 별도 획득 메시지와 도감 획득처 표시는 클라이언트 작업에서 다룬다.
