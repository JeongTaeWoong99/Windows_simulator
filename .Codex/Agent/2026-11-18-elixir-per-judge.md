# 영약 1개당 판정 1회 전환

- #123 후속은 `worktree-T-195-elixir-per-judge`에서 진행했다. 상자 44행의 당첨 수량과 영약 지속 횟수 변경을 테이블 파이프라인으로 생성했다.
- 풍요의 영약은 산출 판정 때만 소비한다. 신속의 영약은 진행 구간의 속도 때문에 다음 1회분을 미리 적용한다. 배치 해제와 영약 버프 제거를 같은 DB 트랜잭션으로 저장한다.
- 마석 교환은 기획에만 있으므로 40개당 영약 20개로 문서에 반영했다. 나침반은 기존 20회다.
- 개발 중인 데이터라는 사용자 결정에 따라 기존 영약 재고와 저장 데이터를 일괄 변환하지 않는다. 개당 판매가는 500골드다.
- 서버 테스트 1,222개를 통과했다. 클라이언트 버프 칩 표시는 #123 후속이다.
