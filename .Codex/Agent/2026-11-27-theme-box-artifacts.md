# 테마 상자 전용 아티팩트

## 목적 / 배경

- [#161](https://github.com/JeongTaeWoong99/Windows_simulator/issues/161)에서 확정한 테마 상자별 전용 보상과 Special 등급을 [T-209](../../tasks/T-209-테마상자열기보상.md)에 반영했다.

## 변경 내용

- `Artifact.xlsx`, `Gacha.xlsx`, `Loc_Artifact.xlsx`에서 전용 보상과 신규 4종의 번역을 구성했다. 풀의 전체 가중치와 아티팩트 행 가중치를 유지했다.
- `Equip.xlsx`의 `DisassembleTable`에 Special을 추가했다. 서버와 클라가 같은 표를 조회하므로 기존 분해 경로를 이용한다.

## 주요 결정 / 근거

- No.23~25의 효과를 유지하고, 신규 4종에는 이슈 표의 효과를 초기값으로 적용했다. 신규 기준 가격은 기존 400·1,200에서 시작하는 단계별 가격 흐름을 따라 3,600·10,800·32,000·96,000으로 뒀다. No.28은 감정 보상으로 기존 이름을 사용한다.
- Special에 분해 행이 빠지면 기존에도 분해할 수 있었던 No.23~25가 등급 변경과 함께 거절된다. 사용자 결정에 따라 신화 300개에 20%를 더한 360개를 지급한다.

## 후속 작업

- 도감의 상자·레이드 전용 줄과 신규 아이콘은 클라에서 연결한다.
