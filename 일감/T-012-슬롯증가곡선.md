# T-012 최대 슬롯 증가 곡선 결정

## 배경

**슬롯 수가 곧 경제 총량의 배수다.** 슬롯이 2개면 재화가 2배로 생긴다.
그런데 시작 슬롯 수·증가 수단·상한이 전부 미정이라, 지금 서버는
`LoginRepository.DefaultSlotCount = 1`이라는 **임시값**으로 돌고 있다.

```csharp
/// <summary>신규 유저에게 기본으로 열어 주는 작업슬롯 수. 시작 슬롯 수가 미확정이라 1개로 둔다.</summary>
private const int DefaultSlotCount = 1;
```

## 2026-08-01 확정 — 구조는 정해졌다

| 항목 | 값 |
| --- | --- |
| 시작 슬롯 수 | **2개** |
| 상한 | **8개** |
| 증가 수단 | **계정 레벨(상한) × 골드(구매)의 이중 게이트** |

| 한쪽만 쓰면 | 문제 |
| --- | --- |
| 레벨만 | 슬롯 확장이 sink가 아니게 된다 |
| 골드만 | `골드 → 슬롯 → 골드` 자기가속이 폭주한다 |

**남은 것은 곡선이다** — 레벨 N에 상한 몇 개인가, 슬롯 N번째의 가격은 얼마인가.

## 할 일

- [x] 시작 슬롯 수 결정 → **2**
- [x] 증가 수단 결정 → **레벨 × 골드**
- [x] 상한 결정 → **8**
- [ ] **레벨별 상한 곡선** (레벨 N에 몇 개까지)
- [ ] **슬롯별 구매 비용 곡선**
- [ ] 거래소 경제와의 관계 검토 — 슬롯이 곧 faucet 배수다
- [ ] `DefaultSlotCount` **1 → 2로 교체** + 해금·구매 로직 구현

## 완료 조건

"레벨 N이면 슬롯 M개까지, 각 슬롯의 가격은 얼마"가 데이터로 정해지고,
서버가 그에 따라 슬롯을 연다.

## 막고 있는 것 / 선행 일감

- **계정 레벨 곡선이 미정이다** — 슬롯 상한이 계정 레벨에 걸려 있으므로 함께 정해야 한다
  → [캐릭터](../GameDesign/기획/캐릭터/README.md) 3.1 · 3.2
- 상점 가격 체계(거래 6장)와 함께 봐야 총량이 맞는다
