## 순서 메모

- **T-008(희귀도 확률)의 성격이 바뀌었다 (2026-07-31).** 분포 통일이 폐지되어
  **산업마다 정한다.** 작업량은 5배지만 **이 일감이 곧 산업 차별화**가 됐다 —
  수치 축이 회당 산출 하나까지 줄었던 것을 되감는 자리다. T-009와 함께 정하는 게 낫다.
- **T-005 → T-015가 한 줄기다.** 1·2단계(엑셀 + 서버 등록)는 끝났고,
  남은 것은 **채취 푸시 실물 확인**과 `t_user_inventory` 구 TID 정리다.
  **낚시 아이템 TID가 이설됐으므로**(`1001~1006` → `10001~10006`)
  클라에 TID를 박아 둔 곳이 있으면 이양 시점에 깨진다.
- **T-004(전역 배수 복귀)는 T-006(작업슬롯 UI) 뒤에** 하는 게 좋다.
  UI를 눈으로 확인하려면 5초 주기가 필요하다.
- T-010(캐릭터 문서화)은 구현이 이미 끝나서 **옮겨 적기만 하면 되는데**,
  방치하면 다음에 이 영역을 건드릴 때 "미정"으로 보고 다시 설계하게 된다.
