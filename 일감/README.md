**보류**는 사람이 무언가를 결정해 줘야 풀린다.

| 일감 | 무엇이 정해져야 하나 |
|------|--------------------|
| T-003 캐릭터 성장 | 경험치 획득 경로 · 레벨업 곡선 · 적성 기여식 |
| T-005 드롭 테이블 | T-008(희귀도 확률)이 먼저 |

> **T-002는 풀렸다 (2026-07-30).** `EquipSlot` = 무기1 · 장신구2 · 보석1(4칸)로 확정.

## 순서 메모

- **T-008(희귀도 확률)이 가장 앞에 있다.** 전 산업 공통이라 한 번만 정하면 되는데,
  T-005와 거래소 경제가 여기에 걸려 있다. 게임기획코어도 "최우선"으로 적어 뒀다.
- **T-004(전역 배수 복귀)는 T-006(작업슬롯 UI) 뒤에** 하는 게 좋다.
  UI를 눈으로 확인하려면 5초 주기가 필요하다.
- T-010(캐릭터 문서화)은 구현이 이미 끝나서 **옮겨 적기만 하면 되는데**,
  방치하면 다음에 이 영역을 건드릴 때 "미정"으로 보고 다시 설계하게 된다.
