# T-010 캐릭터 시스템 기획 문서화

## 배경

**구현이 문서를 앞질렀다.** 캐릭터가 서버에서 실제로 돌고 있는데
(`CharacterTable` → 적성 → `WorkSpeedTable` → 슬롯 속도),
기획 문서는 아직 이렇게 적혀 있다:

- 게임기획코어 시스템 지도: `캐릭터 — (미작성) — ❌ 전부 미정`
- 작업슬롯 5장: `캐릭터 (미작성 · 전제 시스템)` — 스탯 구성·기여식·육성·획득 전부 `❌ 미정`
- 자원채취 README: `캐릭터스탯 — ❌ 미작성`

**실제로는 상당수가 정해졌다.** 문서에 반영하지 않으면
다음에 이 영역을 건드릴 때 "미정"이라 보고 다시 설계하게 된다.

## 이미 정해진 것 (문서에 옮겨야 함)

| 항목 | 결정 |
| --- | --- |
| 스탯 구성 | **캐릭터 스탯 = 산업 적성.** 산업 5종 각각이 스탯이다 (사냥은 전투력) |
| 적성 범위 | 0~10. **0이면 그 산업에 배치 불가** |
| 기여식 | 적성 → `WorkSpeedTable` → 속도(천분율). 산출량이 아니라 **속도**에 작용 |
| 기본 캐릭터 | TID 1 고정. 신규 유저에게 로그인 시 지급 |
| TID 대역 | 2~1000 예약, 일반 캐릭터는 1001부터 |
| 개체 vs 정의 | `t_character.character_id`(개체 PK) ≠ `character_tid`(테이블) |
| 소유 경계 | 인벤토리 = 유저 소유, 장비 슬롯 = 캐릭터 소유 |
