# T-005 농사·벌목·채굴·사냥 드롭 테이블 작성

## 배경

산업 5종 중 **낚시만** 드롭 테이블이 있다(`FishingBasicTable`).
나머지 4종은 슬롯에 배치해도 정산 때 테이블이 없어 조용히 건너뛴다:

```
WRN [채취] 드롭 테이블 없음, 건너뜀: Mining (슬롯 0)
```

즉 **배치는 되는데 아무것도 안 나온다.** 예외로 죽지는 않게 막아 뒀지만,
산업 4종이 사실상 비어 있는 상태다.
