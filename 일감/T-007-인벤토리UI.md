# T-007 인벤토리·재화 UI

## 배경

서버는 인벤토리와 재화(골드)를 이미 보내고 있는데 표시할 화면이 없다.
채취로 아이템이 쌓여도 유저가 볼 방법이 없으면 채취 자체가 의미를 갖지 못한다.

| 패킷 | 내용 |
| --- | --- |
| `S_InventoryResponse` | 로그인 시 인벤토리 전체 스냅샷 |
| `S_UpdateItemResponse` | 아이템 증감 |
| `S_CurrencyResponse` | 재화 보유량 — **스냅샷과 변경이 같은 패킷** |

## 할 일

- [ ] 인벤토리 목록 — `ItemTable`에서 이름·희귀도를 읽어 표시
- [ ] 증감 반영 — `S_UpdateItemResponse`
- [ ] 재화 표시 — `S_CurrencyResponse`는 **증감이 아니라 확정 잔액**이므로
      재화 종류로 **덮어쓰기**만 하면 된다. 더하지 않는다
- [ ] 희귀도별 색상 — `Enum.xlsx`에 이미 정의돼 있다

## 완료 조건

채취 결과가 도착하면 인벤토리 수량이 늘어나는 것이 화면에서 보이고,
재접속해도 같은 값이 나온다.
